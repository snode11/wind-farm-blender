**Mac 快速体验雷达：**下载完整仓库并解压，进入 `scripts/blender`，双击 `打开净空雷达演示.command`。默认使用 `/Applications/Blender.app`；启动后选择“正常测量”或“较小净空”，用“播放”或“暂停”控制回放。

雷达回放使用 FAST.Farm 预计算仿真结果，画面为刚性运动示意。离线回放、实时仿真和强化学习训练是不同工作流程；回放结果不代表现场实测。各版验证范围见详细变更记录，Windows 实机与现场设备仍需另外验收。
