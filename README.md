# Wind Farm Blender · 更新记录

记录这个风电场 Blender 项目的每次迭代：新增了什么、改进了什么、修复了什么。**最新更新在最上方。**

项目围绕风场三维展示、相机与云台交互、仿真后端连接，以及激光净空雷达离线回放持续开发。

### 2026-09-16 · v0.3.0 · 完整 MAPPO 回放与后端启动修复

- **完整三机演示：**安装包内置 MAPPO 60 秒结果，T1/T2/T3 共九片叶片独立形变，共用仿真时间轴；替换旧 66 秒 SYNTH Demo，离线播放无需启动后端。
- **统一操作：**MAPPO 侧栏集中播放、暂停、单步、停止、复位与进度定位，支持 Down、T1 侧前方和全景；切换观察视角保留进度与轨迹。
- **测量与遥测：**增加彩色叶尖轨迹、三道红色叶尖标记及 B2 雷达到叶片的原始斜距；展示同次 FAST.Farm 的三机功率、转矩、叶根载荷和曲线，支持 JSON 导出。无效或过期测量显示 `--`。
- **原命令启动：**`run_wfrl_macos.sh` 默认停在 60 秒 MAPPO 的 T1 侧前方首帧，Bridge 后台待用；主动选择 Replay / Interactive 并连接后，自动加载指定 YAML 场景。
- **稳定性修复：**修复初始化暂停后单步等待、立即重连被旧连接拒绝、切机轨迹错误首点，以及保存重开、重建和注销时的对象引用与回调清理。
- **交付与范围：**发布 0.3.0 ZIP、校验清单及项目侧启动/后端修复。三机物理片段仍为 REVIEW_ONLY；T1 雷达有效率、数值收敛、稳定 60 FPS、控制收益、Windows 与现场设备尚未完成验收。

[下载 0.3.0](https://github.com/snode11/wind-farm-blender/releases/tag/v0.3.0) · [详细变更](CHANGELOG.md#030--2026-09-16) · [MAPPO 操作说明](docs/blender/MAPPO演示.md) · [发送前验证记录](docs/blender/0.3.0发送前检查.md)

### 2026-09-15 · v0.2.5 · 雷达回放进度与观察视角

- **回放更直观：**进度改为 0–100% 滑块，显示已播放时长；按钮随状态显示播放、暂停或重新播放，片尾展示本段统计。
- **统计更清楚：**明确 B2 有效样本与预期样本的分母，展示经过测量区次数；整次漏测仅在片尾汇总，移除卡片中的演示阈值提示。
- **观察更方便：**测量区改为左前方 45° 透视，新增雷达特写；切镜头保留工况、进度和暂停状态。
- **操作分区：**离线回放直接在 Camera 面板控制；后端运行按钮集中到“后端运行”，连接与环境配置放入相应高级折叠区。
- **交付：**发布 0.2.5 安装包，继续复用 normal-v1.1 / close-v1.1，未重新计算物理数据。

### 2026-09-13 · v0.2.4 · 雷达展示与旧场景修复

### 2026-09-13 · v0.2.3 · 雷达回放流程优化

**Mac 快速体验雷达：**下载完整仓库并解压，进入 `scripts/blender`，双击 `打开净空雷达演示.command`。默认使用 `/Applications/Blender.app`；启动后选择“正常测量”或“较小净空”，用“播放”或“暂停”控制回放。

雷达回放使用 FAST.Farm 预计算仿真结果，画面为刚性运动示意。离线回放、实时仿真和强化学习训练是不同工作流程；回放结果不代表现场实测。各版验证范围见详细变更记录，Windows 实机与现场设备仍需另外验收。
