## 现有环境的调用方式

虚拟环境随文件夹移动后，其 `activate` 和部分工具启动脚本仍带旧绝对路径。当前直接调用环境中的 Python；安装管理使用 `python -m pip`。依赖版本已核对，原始环境快照仍在 `out/trial-20261004/environment-freeze.txt`。

以下评分命令读取已有结果，不覆盖输出：

```sh
cd '/Users/eason/Desktop/wfcrl/wind farm RL/blade_recon'
.venv-trial/bin/python -B evaluate.py \
  --recon out/trial-20261004/synth20/recon.json \
  --truth data/synth20/truth.json --skip 50
```

需要重新建环境时，可另建 `.venv` 并安装 `requirements.txt`。`docs/make_figures.py` 还需要 matplotlib，默认读取新生成的 `out/synth20/`，出图环境需要额外提供 matplotlib，正式插图全部保留。

## Blender 查看与证据范围

相机矩阵兼容查看脚本会根据自己的文件位置定位工程，移到当前目录后路径仍适用。在单独启动的 Blender 中查看已有结果：

```sh
cd '/Users/eason/Desktop/wfcrl/wind farm RL/blade_recon'
'/Applications/Blender.app/Contents/MacOS/Blender' --factory-startup \
  --python out/trial-20261004/blender/compat/blender_view_compat.py -- \
  --recon out/trial-20261004/synth20/recon.json \
  --truth data/synth20/truth.json --cameras data/synth20/cameras.json
```

该脚本会重新创建它所在 Blender 进程的场景。保存的 `.blend` 是快照，不保存 Python 帧回调。
