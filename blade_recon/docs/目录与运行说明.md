# blade_recon 目录与运行说明

`blade_recon/` 提供三摄轮廓基线及独立表面研究工具。当前 13 维状态、动态输入和材料点候选位于相邻 [blade_recon0.2](../../blade_recon0.2/README.md)，两个目录的模型与结果分别识别。

## 目录与依赖

| 位置 | 内容与用途 |
| --- | --- |
| 根目录 `*.py` | 参数化模型、重建、评分、预览、合成及 Blender 导入导出源码 |
| [README](../README.md)、[算法说明](算法说明_三摄视频叶片三维重建_v0.1.md) | 轮廓基线、输入、输出与精度边界 |
| [requirements.txt](../requirements.txt) | 固定版本的 NumPy、OpenCV 和 SciPy 运行依赖 |
| `input_bundle.py`、`surface_io.py`、`surface_geometry.py`、`window_surface_fit.py`、`surface_texture.py` | 显式 RGB／标定输入、固定材料绑定、窗口求解和图集；[研究结论](../../research/blade-surface/README.md)分别判定 |
| `docs/fig/` | 算法正文插图；出图脚本另需 Matplotlib |
| `data/`、`out/` | 输入及结果；大资源按[分发说明](../../docs/PUBLICATION.md)恢复，新运行使用独立输出目录 |

Python 环境不随源码或资源分发。可在自己的环境中安装固定依赖；不要复制作者本机虚拟环境或依赖其绝对路径。从仓库根目录执行：

```sh
python3 -m venv /path/to/blade-recon-env
/path/to/blade-recon-env/bin/python -m pip install -r blade_recon/requirements.txt
```

算法文档出图需要另行安装 Matplotlib。Blender、FFmpeg 与所用环境按具体入口单独配置。

## 轮廓基线使用

以下命令在 `blade_recon/` 目录执行，`python` 指已安装依赖的环境；输出目录应为独立新目录：

```sh
python coverage.py --back 6 --down 3 --pitch-down 45
python recon.py --data /path/to/input --out /path/to/new-result --overlay
python evaluate.py --recon /path/to/new-result/recon.json \
  --truth /path/to/evaluation/truth.json --skip 50
```

输入包含各路原图或视频及匹配相机标定。默认轮廓分割和可选掩码的合同见 [README](../README.md)。评分真值只由独立评价读取，不能将评价数据用作拟合或初始化。合成样例可通过 `synth.py` 生成；合成数据的精度不能推广为柔性回放或现场精度。

## Blender 查看与证据

普通查看使用 `blender_view.py`；静态相机矩阵的兼容性与具体运行范围按所用输入单独核验。保存的 `.blend` 是场景快照，不自动保存外部 Python 帧回调，也不自动更新已安装扩展。

保存的合成试跑证据对应 `out/trial-20261004/`。恢复该资源后，可按其中 `blender/compat/blender_view_compat.py` 的参数查看对应结果；该脚本按自身位置定位资源，会重建它所在 Blender 进程的场景。冻结脚本与日志保留其输入身份，复查前须核对当前路径和依赖，不直接将其后台结论归入其他源码、ZIP 或安装版。

已有试跑与 Blender 后台抽检只覆盖对应合成样例；相机导入问题、fy 近似及具体范围以相应报告为准。实时 FPS、原生完整交互、真实风机几何精度和健康诊断没有由这些报告验收。资源清单未提供的原始输入、日志或场景不能从文档路径推定存在。
