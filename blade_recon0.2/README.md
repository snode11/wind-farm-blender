# blade_recon v0.2：视频叶片几何与表面纹理

该目录提供可解释显式表面重建：用物理参数化叶片模型拟合各路原图轮廓，逐帧输出叶片状态，并用同一模型还原网格。默认求解采用轮廓；稳定 RGB 材料点重投影须显式启用，纹理融合使用冻结估计几何。职责与使用合同见[纹理辅助几何](docs/纹理辅助几何_职责与合同.md)，环境、动态输入和保存恢复见[运行与输入验证](docs/接入与正确性验证.md)。

当前局部材料点候选在固定独立协议下为 **Patch 2/8、Crack 7/8（87.5%，低于90%门槛）**，跨相机 RGB 对应 **0/264**。`same_material_error_m = null`、`primary_gains = null`，科学状态为 **`FAILED_GATE / NOT_ACCEPTED`**。完整比较、拒绝原因、软件检查和证据限制见[材料点对应实验报告](docs/材料点对应实验报告_2026-10-11.md)。软件运行、原生显示和合成回归不能替代该科学门槛。

外部研究算法未替换前端内置的601样本正式资源。F/G 原始运行输入与冻结产物不在当前工作区或公开分发中，报告只支持所列测量，不能据此声称完整复现；正式结果、安装扩展和独立合成样例须分别核对来源。

## 1. 思路

```
三路原图(C1/C2/C3，各自 K 与外参，不拼接)
   │ 分割(YOLO 掩码 或 天空背景自动阈值) → 轮廓 → 距离变换
   ▼
状态 x = [方位角, 桨距×3, 挥舞1阶×3, 摆振1阶×3, 挥舞2阶×3] ← 当前CLI每帧13方向
   │ model.Rotor：NREL 5MW 外形 + ElastoDyn 振型 + 轴倾/预锥/弦长缩短 → 三片叶片网格
   │ 投影轮廓(截面包络) 与观测轮廓 双向倒角残差 + 时序先验 + 周期物理先验
   ▼
recon.json：每帧 x、标准差、逐截面"观测/推断"标记 → blender_view.py / preview.py
   │ texture.py：位姿固定，原图像素 → 叶片表面图集(可见性 + 质量权重 + 光照归一化 + 最佳视角融合)
   ▼
texture/blade{1,2,3}_tex.png：每片叶片一张纹理图 → blender_view.py --texture / preview.py --texture
```

**模型约束**：网格由“设计外形 + 结构振型 + 刚体姿态”生成，没有逐顶点自由度；允许形状受模板和低阶模态限制，这不等于已通过独立物理或几何精度验收。
不可见部分依赖模型和先验推断：

- **可观性门控**：某片叶片外侧不在任何画面里时，它的挥舞和摆振**不参与拟合**，避免这两个量被拿去吸收别处的残差。
- **周期物理先验**：只用看得清的叶片在线拟合以下关系：
  - 挥舞 = 平均推力 + 风切变 1P + 每片叶片的偏置
  - 摆振 = 重力 1P
  - 桨距 = 统一桨距 + 每片叶片的偏差

  看不见的叶片按自己的方位角从拟合结果推算。逐叶偏置单独拟合，可保留模型中的逐叶差异；该参数本身不能确诊气动不平衡。
- 可视化里**绿色 = 图像观测约束，橙色 = 模型推断**，两者不混在一起。

## 2. 文件

| 文件 | 作用 |
|---|---|
| `model.py` | 前向模型（纯 numpy，Blender 内也能 import） |
| `camera.py` | 针孔相机、三摄共光心扇形阵列（50°×40°，3264×2548） |
| `coverage.py` | **先跑它**：给定安装位置，叶片哪一段、在哪些方位角能被看到 |
| `check_alignment.py` | 用已知状态把模型轮廓叠到视频帧上，检查坐标/相机/机组参数是否对齐 |
| `recon.py` | 轮廓基线及显式纹理辅助几何候选 |
| `surface_tracks.py` / `texture_geometry.py` | RGB固定身份跟踪、门拒绝和一次三角面绑定重投影约束 |
| `evaluate.py` | 有真值时评分；观测区和推断区分开统计 |
| `preview.py` | 不依赖 Blender 的三维预览视频 |
| `blender_view.py` | Blender 中逐帧播放重建结果，可叠加真值线框 |
| `blender_export_cameras.py` | 从 Blender 场景导出 `cameras.json`，并换算到机组坐标系 |
| `synth.py` | 自测用合成三路视频 + 真值（真值只写入 `truth.json`，重建程序不读取）；`--texture` 时带表面纹理和已知缺陷 |
| `atlas.py` | 叶片表面图集：行 = 展向 r，列 = 截面周线弧长；表面坐标 (r, c)；Blender UV |
| `raster.py` | 三角形光栅化、z-buffer、带纹理渲染 |
| `texture.py` | **v0.2**：视频像素 → 叶片表面纹理 |
| `eval_texture.py` | 有缺陷真值时的纹理评分与对比图 |
| `docs/` | 算法说明（含公式、插图、演示讲稿）与出图脚本 `make_figures.py`、`make_texture_figures.py` |
| `交接说明_Blender验证.md` | 给 Blender 验证同事的步骤与检查清单 |

## 3. 用法

```bash
# 0) 安装位置可观性（不渲染，秒级）
python coverage.py --back 6 --down 3 --pitch-down 45

# 1) 自测：合成 20 s 三路视频 → 重建 → 评分 → 预览
python synth.py   --out data/synth20 --seconds 20 --fps 10 --scale 0.25
python recon.py   --data data/synth20 --out out/synth20 --overlay
python evaluate.py --recon out/synth20/recon.json --truth data/synth20/truth.json --skip 50
python preview.py --recon out/synth20/recon.json --truth data/synth20/truth.json --out out/synth20/preview.mp4

# 2) 你们的 Blender 视频
blender 场景.blend --background --python blender_export_cameras.py -- \
        --cams C1 C2 C3 --hub <轮毂对象名> --upwind <上风方向> --out <数据目录>/cameras.json
#    数据目录放 C1.mp4 C2.mp4 C3.mp4（或 C1/ C2/ C3/ 帧目录）
python recon.py --data <数据目录> --out <输出目录> [--masks <YOLO掩码根目录>] [--polarity bright]

# 3) 表面纹理（v0.2；位姿不变，只做纹理）
python texture.py --data <数据目录> --recon <输出目录>/recon.json [--exposure-ms <曝光>] [--skip 50]
python preview.py --recon <输出目录>/recon.json --texture <输出目录>/texture --out <输出目录>/preview_tex.mp4
python preview.py --recon <输出目录>/recon.json --texture <输出目录>/texture --out <输出目录>/preview_tex_follow.mp4 \
        --follow-blade 1 --az 180 --el -10 --dist 25        # 跟拍叶片 1 外段

# 4) Blender 可视化
blender --python blender_view.py -- --recon <输出目录>/recon.json \
        [--truth truth.json] [--cameras <数据目录>/cameras.json] [--texture <输出目录>/texture]
```

轮廓基线的 YOLO 掩码目录结构为 `<masks>/C1/000000.png …`，每帧一张二值图，可合并所有叶片。材料点对应另需核验固定 blade/face/bary 的可见性及同实例描述子支持；合并 occupancy 不能作为跨相机同材料身份的证明。
没有掩码时，程序按天空背景自动阈值分割；近红外补光下叶片比天空亮，这时加 `--polarity bright`。

### 评分模型与样本身份

`evaluate.py --mode same-model-state` 只评估同一固定机型模型中的状态恢复，默认使用该模式。重建与真值须分别携带完整 `turbine` 配置，并且模型身份相同，包括固定健康模板的内容与摘要；尺寸、拓扑或模板不匹配时拒绝评分，不以重建模型代替真值模型。普通与 `--texture` 合成都在 `truth.json` 中写入独立机型身份。不同模型／网格的几何对应和独立表面误差不属于此评分器的能力。

既有真值缺少机型身份时，只能显式提供独立真值配置：`--truth-turbine <配置.json>`；该 JSON 可为完整机型配置或含 `turbine` 的对象。配置须来自生成真值的实际模型，不能复制重建结果来补出真值。采样帧编号须唯一、与真值对应；状态必须完整且有限，`observed_sections` 须与机型截面数一致。统计继续区分观测区与推断区，软件评分不构成实测或物理精度验收。

提供的 `t` 必须是有限秒数；配对帧双方均有 `t` 时，时间差不得超过 1 ns。显式时间独立于帧编号与名义 FPS，合法的偏移或非均匀时钟按原值比较，不以 `frame/fps` 替代。任一方缺少 `t` 的旧数据仍按帧身份评分，输出明确标记“时间未验证”。

相机投影使用完整 3×3 内参矩阵；缩放按实际偶数输出尺寸分别计算水平／垂直比例，并保留像素中心与 skew。

动态输入 allowlist 对同一实际 RGB／掩码文件只物化一次，逐帧／逐相机保留访问身份；选择帧和重映射注释不改写原始输入对象。

## 4. 自测结果（合成数据，20 s / 10 fps / 816×636，跳过第一圈）

安装：轮毂后 6 m、下 3 m，三路下俯 45°。每帧 0.62 s（CPU，单线程）。

| 指标 | 结果 |
|---|---|
| 方位角误差 | 均值 0.17°，最大 0.22° |
| 桨距误差 | 均值约 0.2°，P95 0.46° |
| 挥舞幅值误差 | 叶片可见时均值 0.15 m，P95 0.34 m；不可见时均值 0.41 m |
| 摆振幅值误差 | 均值 0.07~0.10 m |
| **截面网格误差（观测区）** | **均值 6.8 cm，P95 14 cm** |
| 截面网格误差（推断区） | 均值 16 cm，P95 56 cm，最大 1.2 m |
| 气动不平衡（叶 1 注入 +0.6 m 挥舞） | 准确指向叶 1，幅值误差约 1% |

**这些数字的适用范围**：合成数据使用的是同一个参数化模型，合成时只额外加了挥舞 2 阶分量；成像是理想针孔，没有运动模糊和镜头畸变。它们验证该合成配置下的管线与参数恢复，**不代表**在 Blender 柔性回放或实机上的精度。
完整的算法说明、公式、插图和演示讲稿见 `docs/算法说明_三摄视频叶片三维重建_v0.2.md`。

## 5. 关键发现：安装朝向决定能重建什么

`coverage.py` 的结果（轮毂后 6 m、下 3 m）：

| 三路下俯角 | 一圈中能看到的最外截面 | 叶尖可见的方位角比例 |
|---|---|---|
| 0°（水平朝前） | **r = 29 m**，叶片外侧一半始终看不到 | 0% |
| 20° | 63 m | 2% |
| 45° | 63 m | 14% |
| 60° | 63 m | 27% |

光轴水平朝前时，叶尖相对光轴的夹角约为 atan(63/6) ≈ 84°，超出了 75° 的半视场。**要让叶尖部分有图像依据，阵列需要下俯 40°~60°。**
即使下俯 45°，一圈中被观测到的截面也只占约 13%，其余部分都是推断。所以输出时必须带着"观测/推断"标记。

## 6. 已知限制（位姿部分）

- 静态 `cameras.json` 只适用于静态相机；动态输入使用 `input_bundle.json` 的逐帧 `T_cv_from_model`、真实 frame/t、RGB 与显式掩码。见[运行与输入验证](docs/接入与正确性验证.md)。
- 当前 CLI 状态包含方位角、每片桨距、1 阶挥舞、1 阶摆振和 2 阶挥舞，共 13 维；没有独立弹性扭转自由度。跟踪阶段外侧可见支持不足时，三种挥舞／摆振方向由可观性门控冻结；2 阶挥舞保持最近观测值，不是全程固定为 0。图像不可辨识方向仍需按输出质量信息读取，13 维状态不代表每帧都可观。
- 叶片编号存在 120° 循环歧义：三片叶片外形相同时，"叶片 1"是相对编号。如果要和 SCADA 编号对应，需要一个可识别的标记，或已知某一时刻的方位角。
- 外形取 NREL 5MW 公开弦长、扭角和翼型族近似，不是精确的制造外形；翼型截面用 NACA00xx 与圆的混合近似。
- 第一圈内周期先验尚未建立，推断区误差较大，所以评分时跳过了第一圈。
- Blender显示、保存及重开证据按运行来源分别记录，见[运行与输入验证](docs/接入与正确性验证.md)。`blender_export_cameras.py`只导出单个静态时刻，不能代替动态输入bundle。
- `spin=-1`（反向转动）只在合成数据上测过一次（12 s，观测区网格误差 5.3 cm）。
- 本机未测试 4K 原分辨率下的速度。耗时大约随轮廓点数线性增长，主要取决于加密倍数 `DENSE` 和截面数；可以用 `--fit-scale` 降低求解分辨率。

## 7. 表面纹理（v0.2）

**做什么**：视频里肉眼看得到的表面特征，比如裂纹、修补块、腐蚀斑、污渍、明暗起伏，要在三维叶片上的**同一位置**也看得到。

**怎么做**：不生成纹理，只把原图像素搬过去。

1. 每片叶片一张图集：行 = 展向 r，每行 2.5 cm；列 = 截面周线弧长，768 列；
2. 每帧每路相机：纹素 → 三维点 → 投影到原图，经过 z-buffer 可见性、掠射角、离轮廓距离三项检查后取灰度；
3. 质量权重：像素脚印（米/像素）、离轮廓距离，给出曝光时间时再加运动模糊；
4. 光照归一化：除以展向 2 m × 弦向 0.6 m 的低频分量，只保留表面细节；
5. 融合：每块区域（约 0.5 m）取最清楚的那**一个**视角。

**输出**（`<recon 目录>/texture/`）：

| 文件 | 内容 |
|---|---|
| `blade{1,2,3}_tex.png` | 纹理（BGRA）。150 = 平均亮度，**A = 0 = 从未看清** |
| `blade{1,2,3}_raw.png` | 不做光照归一化的原始亮度 |
| `blade{1,2,3}_res.png` | 展向分辨率伪彩图，说明可信程度 |
| `texture.json` | 图集定义，逐 5 m 的覆盖率和分辨率 |
| `texture_data.npz` | 浮点结果 |

缺陷位置统一用表面坐标表示：**(叶片, r, c)**，其中 r = 距转轴的展向半径，c = 从前缘量起的表面弧长，正值 = 背风面。

**合成验证**：原分辨率 3264×2548，12 s / 10 fps，下俯 45°，6 个已知缺陷，用 `eval_texture.py` 评分。

| 缺陷 | 结果 | 定位误差（展向 / 弦向） |
|---|---|---|
| D1 弦向裂纹 60×1.5 cm，r = 57 m | **看得到**，对比度保留 22% | −5 / −1 cm |
| D2 展向裂纹 60×1.5 cm，r = 51 m | **看得到**，对比度保留 26% | +6 / −3 cm |
| D3 修补块 40×30 cm（亮），r = 59 m | **看得到**，对比度保留 69% | −6 / −5 cm |
| D4 鼓包 50×50 cm、高 2 cm | **很淡**，只有明暗变化 | — |
| D5 前缘腐蚀 4 m | **看不到**（前缘只覆盖 25%） | — |
| D6 修补块 50×40 cm（暗，叶片 2），r = 45 m | **看得到**，对比度保留 43% | +24 / −8 cm |

**合成配置的限制**：以下数字仅对应上述合成配置；当前运行合同及科学状态见本页开头的入口。

- **展向压缩**：相机几乎顺着叶片看过去。叶尖附近**展向约 7 cm/像素，弦向约 1.5 cm/像素**；60 cm 的展向细线约占9个像素；
- **只看得到背风面**（吸力面）外侧 r = 10~60 m 的背风面 93~98% 被看到（背风面本身约占周长一半）。迎风面和大部分前缘看不到，在 Blender 中显示为证据色；
- **起伏不能测量**，只体现为明暗；
- **运动模糊**：r = 57 m 处线速度约 72 m/s。曝光 1 ms 时细节会被抹掉，**需要 ≤ 0.2 ms**；
- **原始合成配置的绝对位置误差最大约 0.25 m**，来自位姿误差。`texture.py` 融合使用冻结估计位姿；默认关闭的 RGB 固定身份点重投影候选可显式加入几何求解，职责与失败验收见[纹理辅助几何合同](docs/纹理辅助几何_职责与合同.md)；不能将该候选写成已完成光度精修或已验收的位置改善；
- **速度**：每帧约 4 s（CPU，原分辨率），属于离线处理；
- `blender_view.py --texture` 的显示、保存与重开范围见[运行与输入验证](docs/接入与正确性验证.md)。健康模板候选使用独立原生文件；安装 reader 对该模板的兼容性须单独核验，不能混用两种显示证据。

复现命令见算法说明附录 C。`data/synth_tex`（约 800 MB）没有放进交付包，需要用附录 C 的 `synth.py` 命令重新生成。
