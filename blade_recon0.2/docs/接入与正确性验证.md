# blade_recon v0.2：运行、输入与显示验证

本页说明外部算法环境、输入合同、纹理采样和保存恢复。默认轮廓求解、显式 RGB 辅助候选及科学验收分别阅读；候选职责见[纹理辅助几何合同](纹理辅助几何_职责与合同.md)，当前科学状态见[材料点对应实验报告](材料点对应实验报告_2026-10-11.md)。

## 运行入口

从实际 Git 根目录执行。`/path/to/venv/bin/python` 需替换为已安装 `blade_recon0.2/requirements.txt` 所列依赖的 Python：

```bash
python3 blade_recon0.2/run.py --python /path/to/venv/bin/python --check-env
python3 blade_recon0.2/run.py --python /path/to/venv/bin/python recon --data blade_recon0.2/data/synth20 \
  --out outputs/my-v02-run --max-frames 12 --overlay
python3 blade_recon0.2/run.py --python /path/to/venv/bin/python texture --data blade_recon0.2/data/synth20 \
  --recon outputs/my-v02-run/recon.json --out outputs/my-v02-run/texture --max-frames 12
python3 blade_recon0.2/run.py --python /path/to/venv/bin/python preview --recon outputs/my-v02-run/recon.json \
  --texture outputs/my-v02-run/texture --out outputs/my-v02-run/preview.mp4 --frames 0 3
```

`run.py` 的默认解释器路径为 `blade_recon/.venv-trial/bin/python`，该本地环境不随源码或分发附件提供。克隆后需在子命令前指定 `--python /path/to/venv/bin/python`，或设置 `BLADE_RECON_PYTHON`。NumPy、SciPy、OpenCV 依赖见[requirements.txt](../requirements.txt)；该入口不会创建环境或安装依赖。Blender 内置 Python 用于查看保存结果，不能替代外部算法环境。动态 bundle 校验复用相邻 `blade_recon/input_bundle.py`，须保留两个目录。

双击 打开纹理重建样例.command（本地文件：`scripts/blender/打开纹理重建样例.command`） 会在新 Blender 进程中通过日常安装扩展打开已有120帧纹理样例。该示例来自原合成交付；其 `params.register=false`。运行入口不重新生成视频、不求解 FAST.Farm。

自己的结果可以从独立 **N → 叶片三维重建** 标签导入，或执行：

```bash
/Applications/Blender.app/Contents/MacOS/Blender \
  --python scripts/blender/open_blade_recon_review.py -- \
  --recon outputs/my-v02-run/recon.json --texture outputs/my-v02-run/texture
```

工作区 `--source`、构建 ZIP 和日常安装扩展是不同运行来源。保存自己的 `.blend` 后，安装扩展恢复嵌入重建数据和 packed 纹理。独立 `blender_view.py` 入口另外保存原生几何动画，用于没有扩展的重开场景；证据显示层的恢复范围以验证报告为准。

## 输入合同

动态数据优先提供 `input_bundle.json`，沿用 `blade-surface-input.v1`：`extrinsic_from_frame=model`、原图像素中心、RGB 顺序。每帧明确给出 `frame`、`t` 和各相机的 `name/W/H/K/T_cv_from_model/rgb/mask`。相机位姿在每帧更新，纹理按重建保存的 frame/t 查找同一份输入；不能只把 MODEL 外参改名为 WORLD 后当静态相机。

静态输入接受 `cameras.json` 和同步视频／数值文件名帧目录。没有显式掩码时可选择自动分割；显式掩码缺失、不可解码、尺寸错误必须报错。跨相机身份／时间不一致、坏帧和不一致标定必须停止。动态 bundle 使用声明的掩码；不会退回阈值分割。求解输入加载器不自动发现相邻真值。

没有图像观测时，有限模型状态只用于先验预测／未就绪显示，不能宣称有效重建。求解输出保留观测数量、求解器状态和可辨识性信息；不可辨识方向不报零不确定度。连续方位角保持展开时间序列，数值雅可比使用受控绝对步长。 只有求解成功、图像信息有效且状态全有限的接受帧更新转速、时序历史、最近可靠值和周期先验。拒绝的有限候选只用于后续求解初值；非有限候选保存为有限预测状态并标记 `nonfinite_solution`，不更新观测历史或先验。

## 光栅化与纹理采样

光栅化用逐像素透视深度比较选择可见三角形。展向配准裁切图集边界，越界权重无效；周向允许循环。CPU 纹理采样只环绕列、钳制行；Blender 材质保留周向周期插值，并把展向限制在叶根／叶尖像素中心内。自定义图集评分校验真值 atlas 元数据，并按物理表面坐标重采样，未提供自定义元数据时使用默认真值合同。

光栅化保留原近裁面策略：任何顶点在近裁面后方的三角形整体排除，没有实现相交三角形的近裁面切分。近裁面切分与正深度表面间遮挡是不同检查。

## 验证证据与边界

接入与保存恢复证据为验收报告（本地文件：`outputs/blade-recon-v02/阶段1-2_接入与正确性/blade-recon-v02-stage12-20261007-a01/验收报告.md`）。原始 审计基线（本地文件：`outputs/blade-recon-v02/审计与验收/blade-recon-v02-audit-20261007-a01/检查报告.md`） 对应独立的证据对象，不据此覆盖其他结果的验收状态。

几何显示忠实、合成反例通过、安装与保存重开通过，只证明对应软件行为。真实 MAPPO 几何精度、现场缺陷定位／高度／深度和完整4K管线未获该报告验收；`texture.py` 融合不反馈几何求解，RGB 重投影候选只有显式配置时参与求解。`data/synth_tex` 缺三路原视频，已有纹理样例可显示，完整重算仍需要输入。
