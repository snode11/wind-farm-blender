# 纹理辅助几何候选的职责与合同

RGB 固定身份点重投影提供显式开关，默认使用轮廓求解。当前候选为 Patch 2/8、Crack 7/8，跨相机 RGB 0/264，`FAILED_GATE / NOT_ACCEPTED`；`same_material_error_m` 与 `primary_gains` 为 `null`。软件回归、原生显示、独立对应和现场精度分别判断。

## 模块职责

|模块|输入及职责|输出边界|
|---|---|---|
|`input_adapter.py`|严格声明的RGB、派生mask、原frame/t/K/T、未知域；显式许可健康设计资产|共同输入合同和访问声明；不发现邻近truth/evaluation|
|`model.py`|原解析模型，或显式固定设计健康loft；既有13个全局状态方向|健康网格；不含局部裂纹、凹坑、鼓包参数|
|`surface_tracks.py`|fit RGB的固定传感器ROI角点；RGB仿射运动播种、局部LK、前后向及竞争描述子门|固定首帧身份、原像素坐标及拒绝/缺失；丢失后不重新获取|
|`material_tracks.py`|原固定锚点、同一fit输入的轮廓估计；固定三角面局部投影只作为RGB匹配种子|所有fit相机/时刻的独立双向RGB匹配与完整失败分母；估计同blade支持不等于真实实例身份|
|`texture_geometry.py`|RGB侧车、允许的标定/mask/known域、估计健康网格|锚点只绑定一次blade/face/bary；后续原像素重投影约束，保留完整分母|
|`recon.py`|轮廓残差与可选稳定RGB点残差；既有物理/时序先验|轮廓、纹理、组合image Jacobian分别保存；先验不冒充图像信息|
|`texture.py`|冻结估计网格和允许原RGB；共享三角面图集坐标|纹理融合与逐纹素追溯；仍不拟合损伤深度|
|独立评价脚本|冻结候选后读取独立留出RGB，必要的源数据仅限评价|原像素边界误差、完整计划分母、显示追溯；不反哺tracker/solver/fusion|

## 候选目标与身份

候选使用稳定RGB点的重投影：已固定的估计健康三角面重心点随13D状态变形，由原标定投影到目标原图，与独立跟踪原像素比较。鲁棒图像残差进入同一个求解器，先验保持原二次目标。首帧先轮廓拟合再绑定锚点，自锚像素不添加几何信息；固定绑定不能在失败后重新选择。没有使用源材质坐标、动态网格或nearest-source建立答案。

质量门保持：条件定位sigma≤1px、RGB前后向误差≤1px、NCC≥.8、对比≥12灰度、独立峰ZSSD比≥2，且观测点在实际前景与known域。sigma是局部RGB平移模型条件估计，不能作为独立定位精度。NCC数学范围截断修复浮点舍入，不改变.8质量门。前后向距离以原锚图像素计，目标uv以原目标图像素计；不把帧间尺度变化描述成已完成双向几何证明。

未知多边形保持，未知像素不进入几何或纹理。运动播种可读原ROI RGB，但只有通过known/前景/身份质量门的点能形成残差。正深度检查不证明无遮挡，独立评价仍要求可见比例≥.9、固定绑定覆盖≥.9、原像素边界P95≤1px、完整计划接受比例≥.9。受控点ψ恢复回归只证明一个全局方向的实现，不能推出完整13D准确性。

## 使用与显示

从仓库根目录使用具备算法依赖的外部 Python，配置方法见[接入与正确性验证](接入与正确性验证.md)。RGB跟踪先写独立新目录，再显式给重建程序 `--texture-observations <tracks.json> --texture-weight 1`；不给此参数则保持轮廓基线。`--texture-weight 0`保留侧车审查但不增加残差行，可作严格消融。首次/跟踪预算仍为150/60。

健康模板是可选输入顶层 `healthy_template={path,sha256}`；路径限声明input根，资产是固定健康设计，求解JSON内嵌规范payload和hash，可脱离资产文件还原。其参数化不自动建立与实际动态源网格的同材质点对应。实际指定点米误差在这一合同未建立时保留null，不能用最近源表面替代。

当前用户安装扩展的reader尚不支持内嵌健康loft。独立显示文件用冻结外部算法直接构造原生估计网格、绝对shape keys、同三角面UV与packed融合PNG，交付独立blend。安装reader兼容性失败与原生blend显示/重开结果分开记录；不要把健康JSON通过旧reader生成的解析网格当作健康模板候选结果。

测试目标尺寸为40×30cm亮修补、50×40cm暗修补、60×1.5cm两方向细线。没有毫米裂纹、自动分类、深度恢复或现场实测接受结论。

联合基线证据：优化与独立验收报告（本地文件：`outputs/blade-recon-v02/阶段4_纹理辅助几何/blade-recon-v02-stage4-20261007-a01/优化与独立验收报告.md`）、[机器结果](../../outputs/blade-recon-v02/阶段4_纹理辅助几何/blade-recon-v02-stage4-20261007-a01/final-verification.json)、可复现命令（本地文件：`outputs/blade-recon-v02/阶段4_纹理辅助几何/blade-recon-v02-stage4-20261007-a01/复现命令与来源.md`）。当前局部材料点候选的独立比较另见下方报告。

## 局部材料点对应（本地研究）

`material_tracks.py` 从原锚点一次绑定的估计健康三角面预测局部 homography，再用原 RGB 双向 LK 和原 sigma/FB/NCC/对比/独立峰质量门测量位置。轮廓 seed 必须与声明的 fit 输入的哈希、frame/t、相机和模型完全一致，且没有纹理目标；不读取源动态网格或独立验收图像。每个相机分支失效后保持终止，不从几何投影补 UV，不重新选点。描述子的目标、反向返回位置、插值来源和同估计叶片支持分别检查。完整实例及真实同材料身份仍需独立建立。

局部材料点侧车显式声明 `binding_visibility: "estimated_surface.v1"`。消费者检查固定 face/bary 点是否为三片估计叶片的最近正面命中，异叶片重合深度记歧义；不可见时保留两行失败残差，不能归零或重新绑定。此判断只覆盖估计叶片，不含塔筒/机舱遮挡模型。`positive_depth_only` 作为兼容入口，不能称为无遮挡。权重零仍不添加残差，按精确消融验证。

`rgb_masks.py` 只填不与图边八连通的背景孔，保留对角背景通道；冻结实验的16张mask保持原字节。`surface_tracks.py` 检查仿射参考描述子的原锚支持。`surface_observations_subpixel.py` 的当前绑定使用声明相机精确逆、全部表面首命中及异blade等深歧义拒绝；原独立评分冻源保持原字节，不能用改评分器制造改善。

局部材料点候选使用固定8个独立观察和原阈值：Patch 2/8，Crack 7/8（87.5%<90%）；Crack持出42帧P95=1.269635px。跨相机RGB接受0/264；未知、遮挡与失败项保留在分母中。独立评分、联合基线比较和逐例失败见[材料点对应实验报告](材料点对应实验报告_2026-10-11.md)。该算法未替换前端内置601样本正式包，科学状态为 `FAILED_GATE / NOT_ACCEPTED`，真实同材料点米误差为 `null`。F/G 原始运行输入与冻结产物不在当前工作区或分发中，报告只支持所列测量，完整复现条件尚不具备。

## 跨相机拒绝诊断

`material-footprint-diagnostic.v1` 记录原布尔门实际检查的像素及其known/occupancy/估计blade、7×7原灰度来源、梯度halo、两阶段双线性warp来源与首个失败阶段；诊断不能回填观测。图像画幅检查单独记录，`VISIBLE_FIXED_FACE` 只表示估计射线首命中可见，不能据此声称RGB在画幅内。`termination_origin` 保留源锚原拒绝及其质量值，`termination_chain` 保留每个后继计划，失败后不重获。

264项原跨相机计划中，17项首帧近景互看预测画外，34项到Wide的中心有效但25px完整描述子支持不足，153项继承这些首败；另外60项继承5个原源锚RGB身份拒绝。到Wide的近景25px纹理只投约0.35–0.65个目标像素，固定25个目标像素描述子反投所需源支持也不足；这34项在LK前退出，没有RGB匹配质量实测结论。逐项fit诊断结论及原独立验收汇总见[材料点对应实验报告](材料点对应实验报告_2026-10-11.md)。诊断不修改任何数值质量门、描述子/LK窗口、绑定、评分或失败分母，不建立真实同材料三维精度。
