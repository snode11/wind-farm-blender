## 求解与纹理行为

首次有效图像总是全局搜索，相位及估速使用实际图像观测的时间差。空帧继续作为先验预测；未初始化的兼容 rpm=0 配有 `rpm_status=not_initialized`。残差只在当前调用内复用几何，跳过空相机，不改变模型、目标、权重和有效性。

纹理按重建原 frame identities 选择输入，稀疏首尾保持原 source_indices、时间和动态标定。无 raster 像素的叶片不构建完整 atlas；best／mean 分别只分配需要的融合数组。bundle provenance 只跳过 manifest 中声明未选的文件，选中文件及 manifest hash 必须一致，未知路径报错。没有通过降采样、减少合法帧或改变透明度来换性能。

固定输入 dr=.01／768 列、best／不配准的三次测量中，对照实现中位23.031 s，优化实现中位17.881 s，耗时减少约22.36%；全部 PNG 与重要数组、NaN、覆盖、分辨率及身份完全一致。累加器分配减少21.05%，全量峰 RSS 范围重叠且优化实现中位更高，不能称全量峰内存下降。性能快照和 provenance 检查对应各自冻结源码，不能外推到其他版本。

## 运行和预算

从 Git 根 `/Users/eason/Desktop/wfcrl/wind farm RL` 使用已有外部环境，无需安装依赖：

```bash
blade_recon/.venv-trial/bin/python blade_recon0.2/run.py --check-env
blade_recon/.venv-trial/bin/python blade_recon0.2/run.py recon \
  --data /path/to/input --out outputs/new-recon \
  --initial-max-nfev 150 --tracking-max-nfev 60
blade_recon/.venv-trial/bin/python blade_recon0.2/run.py texture \
  --data /path/to/input --recon outputs/new-recon/recon.json \
  --out outputs/new-texture --atlas-dr .01 --atlas-cols 768
```

预算须 ≥1；默认与原算法一致，空观测仍为2。提高至300的近景缺陷重跑仍3/4帧达到上限，未将其标为成功，也未融合无效帧。`input_contract.frames` 是读取／核对过的身份，不能当作实际融合帧数。
