# 合成表面纹理样例

本目录逐字节保存 `blade_recon0.2/out/synth_tex/recon.json` 与三张 `blade*_tex.png`、`texture.json`，共 120 个 10 Hz 保存样本（源时刻 0–11.9 秒）。合成身份由原 v0.2 文档、合成数据元数据和已知纹理真值证据支持；manifest 保存这些证据的文件摘要。这里不包含视频、求解器或评分真值，不生成新的重建结果。

这份样例与左侧 MAPPO 柔性回放使用独立数据和时钟，不能称为同一风场的同步重建或实测缺陷。检查点是人工查看保存图集后选定的亮斑和细线位置。

实际显示模型仍为扩展原有 `_vendor/blade_recon/model.py`。当前 v0.2 源码增加了本样例未使用的健康模板功能，其文件哈希与显示模型不同；`reference/model.py` 保留该源码快照。对全部 120 个保存状态核对后，顶点、叶片轴线、面索引、半径和截面坐标均逐位相同。manifest 区分这两个文件身份，不声称原求解器保存了模型哈希。

原始纹理为求解器保存的光照归一化表面细节图集（平均灰度 150；A=0 表示未看清）。界面增强仅修改材质颜色，原图、透明度、UV 和几何均保留。
