结论：本机已验证 0.3.0 的 60 秒 MAPPO 展示和真实 FAST.Farm 后端连接链路，可作为阶段成果演示。物理片段仍是 REVIEW_ONLY，不能表述为现场精度、数值收敛或控制收益已验收。

## 当前启动行为

继续使用原 `scripts/blender/run_wfrl_macos.sh` 命令，参数不变。完整命令和点击步骤见 [MAPPO 演示说明](MAPPO演示.md)。

- 默认加载本机已安装的 0.3.0，展示 MAPPO 60 秒片段，停在 T1 侧前方首帧；手动点击播放。
- Bridge 在本地 8765 端口待用；默认不连接、不运行求解器或训练。
- 选择 Replay 或 Interactive 后连接，确认握手后自动加载指定的 `turb3_row.yaml`。实际窗口已验证 CONNECTED / READY，并能返回 MAPPO 离线回放。
- 本轮修改的是项目启动脚本和 Bridge；扩展 ZIP 内容未改，不需要重新安装 0.3.0。仅发送扩展 ZIP 不包含项目侧启动脚本和后端修复。

## 发送前修复

1. 启动器只连接、不载入场景，容易停留在默认方块：改为按用户选择默认展示 MAPPO，并在主动连接后加载指定后端场景。
2. 初始化阶段重复第 0 步导致暂停后单步一直等待：暂停和单步统一在新的控制步边界确认，跳过预热及重复进度通知。
3. 立即断开重连偶尔被旧连接拒绝：Bridge 在接收新连接前检查并回收旧连接 EOF，保留活动连接的单客户端约束。

## 汇报时需要明确的范围

- 实时后端工况为 YAML 中的 8 m/s；离线 60 秒 MAPPO 是已保存的随机阵风片段，不能混为同一次实时求解。
- 实时三机偏航、变桨、功率、转矩返回有限值，来源标记 DIRECT。实时转速由功率、效率、转矩和齿轮比推算，保留 SYNTH 与公式来源；这不意味着本次用了 fake 后端，也不等同于离线文件的转速记录。
- 离线片段 T1/T2/T3 的 B2 有效样本分别为 13/117、43/118、50/120；有效样本 MAE 约为 0.360/0.245/0.209 m。T1 测量有效率偏低，不能只引用 MAE 宣称整体测量可靠。
- 当前窗口全景展开侧栏时可能遮住 T3；演示全景时把鼠标放在三维画面按 N 收起侧栏。侧前方更适合作为开场画面。
- 完整后台测试曾出现 3 项旧单机回放失败，原因为 `results/lidar/raw/normal-v1/FarmInputs/vtk` 已清理，不能读取旧 VTP。保留失败日志，未把缺失数据测试算作通过。
- 尚未完成 Windows、现场设备、长期运行稳定性、稳定 60 FPS、数值细化收敛、控制收益对照，以及全部截图录制/动画渲染输出验收。后台曾有小量内存退出提示；静帧渲染曾报告阴影缓存容量提示，未据此宣称渲染性能通过。
