## 从源码构建

完整克隆仓库并检出 `v0.3.13`，或完整解压该标签的 Source code。Python 3.11+，从仓库根目录执行：

```bash
python3 scripts/blender/build_extension.py
```

构建读取源码树中的完整资源并校验两个双束结果层与共享源，输出 `dist/wfrl_blender-0.3.13.zip`、SHA-256 文件与逐文件 inventory；规范读取器及协议由仓库源码生成到 ZIP 内。离线构建和回放不需要外部原始 FAST.Farm / VTP，也不启动求解器。安装与升级步骤见[安装说明](INSTALL.md)。

## 研究与验收边界

同一开发片段的 400 个有效配对，旧法 / TLS MAE 为 4.268685 / 0.776096 m；独立单机固定 9 rpm 工况、40/80 Hz 网格的 TLS MAE 约为 0.943/0.970 m。各自来源、窗口、采样率及评分条件不同，数值单列，不能理解为现场精度。三阶段实施与来源证据见[候选总报告](../lidar/双束TLS候选实施与验证总报告.md)。其中“未发布”的阶段描述是研究当时状态，本页记录后续软件交付。

两种双束方法继续为 **REVIEW_ONLY / PENDING_ACCEPTANCE**。TLS 是轮毂约束直线候选，高精度柔性状态反演、设备原始采样、现场漏测率和保护延迟尚未验收。没有读数或没有报警不表示安全。固定相机仍有遮挡和空画面；完整片段 FPS、长期稳定性、实体标定及拼接算法没有通过本次软件发布自动获得验收。
