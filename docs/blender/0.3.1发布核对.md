## 可复现命令

从项目根目录，在已有测试依赖的 Python 环境中运行：

```sh
PYTHONPATH=blender_frontend:. python -m pytest \
  blender_frontend/tests/test_extension_package.py \
  blender_frontend/tests/test_tip_deflection.py \
  tests/test_farm_flex_package.py tests/lidar/test_moving_tower.py \
  tests/lidar/test_tower_numerics.py tests/lidar/test_replay.py -q
python scripts/blender/build_extension.py
python scripts/lidar/validate_tower_package.py \
  blender_frontend/wfrl_blender/assets/mappo /tmp/all-tips.json
python scripts/blender/verify_lidar_delivery.py dist/wfrl_blender-0.3.1.zip \
  results/lidar/packages/normal-v1.1 results/lidar/packages/close-v1.1 \
  --output /tmp/independent-packages.json
```

原始 VTP 不随发布交付；源表面抽查测试在本次本地完整证据环境中通过，其他机器缺少原始 VTP 时会明确跳过该项。两个独立雷达包校验也需要原有外部包，默认三机回放无需它们。以上 `/tmp` 为本次 macOS 验证输出路径，Windows 可改用自己新建的临时目录。

Blender 脚本为 `blender_frontend/tests/blender/tower_flex_regression.py` 与 `mappo_demo_regression.py`。`WFRL_TEST_RUNTIME` 指向包含解包后 `wfrl_blender` 的父目录；塔架脚本另设置 `WFRL_FARM_FLEX_PACKAGE` 为该扩展的 `assets/mappo`、`WFRL_TEST_OUTPUT` 为新的 JSON 输出文件。

## 历史证据与尚未验收

此前塔架开发版已检查实际窗口播放/暂停、寻址、切页及净空读数。本次显示实现沿用该版本，发布检查为后台原生回归与文档静态核对，未重新进行全部鼠标操作验收，也未改装本机原有全局扩展或旧便携目录。

此前有限数值敏感性对照中，最细 OpenFAST 步长相对原包塔顶最大差 0.442 mm、叶片分量最大差 11.410 mm，塔筒积分节点细化的塔顶最大差 6.445 mm；这些只支持对应参数的展示用途筛查，不是完整风场、尾流、气动展向或边界影响的收敛认证。

**Windows 实机、持续 60 FPS、长期训练/运行、完整录制/渲染、现场雷达精度和控制收益尚未验收。** T1 B2 有效样本为 18/122，低有效率保留；固定标定估计未补偿塔架弯曲。塔筒没有专用虚影、位移箭头或数值卡片。

本次只提交相关修改文件与新扩展包。原始 VTP、临时录制/截图、缓存、旧包重上传及本地清理删除不纳入发布提交。
