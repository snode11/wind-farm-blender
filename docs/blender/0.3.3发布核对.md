# 0.3.3 发布核对 · 2026-09-17

本次包含雷达反馈与塔顶附件修复；复用正式 0.3.1 的物理数据，仍为 REVIEW_ONLY。

- 旧密封圈在 151.733 秒相对正确支承变换偏移约 0.2164 m；现接入塔顶截面随动。28 / 56 m 焊缝也接入各自截面。
- 装饰密封圈外半径由 1.983 m 收至 1.898 m，避免与雷达外壳相交；不改变物理塔架或雷达标定。
- macOS / Blender 5.2.1 LTS：源码和独立 ZIP 各 99 次附件检查通过，最大数值误差约 0.0273 mm。涵盖三机、截图时刻、倒退、重复帧、保存重开、清除恢复和重建。
- 塔架/机舱/雷达挂载、九叶片连接及回放、雷达反馈与机舱附件原生回归通过。10 项宿主测试通过，含 7203 个保存叶尖核对。
- 本机安装 77 个文件与 ZIP 清单一致；8 个物理资源文件与更新前逐字节一致。修复前后特写已做离线渲染核对。
- 尚存外观问题：短服务电缆末端悬空，末端中心距离机舱表面约 6.7 cm。Windows 实机、新窗口鼠标交互、稳定 FPS、全时段全部零件碰撞扫描尚未验收。

## 复现

原生测试位于 `blender_frontend/tests/blender/`：`tower_fittings_regression.py`、`tower_flex_regression.py`、`farm_flex_regression.py`、`radar_feedback_regression.py`、`hub_mount_regression.py`。

运行 `Blender --background --factory-startup --python-exit-code 1 --python <脚本>`；结果脚本需设置 `WFRL_TEST_OUTPUT`。独立 ZIP 解包至 `runtime/wfrl_blender` 后设置 `WFRL_TEST_RUNTIME=runtime`，塔架脚本还需 `WFRL_FARM_FLEX_PACKAGE=runtime/wfrl_blender/assets/mappo`。

宿主：`PYTHONPATH=blender_frontend:. python -m unittest blender_frontend.tests.test_radar_feedback blender_frontend.tests.test_tip_deflection -q`。

部分 Blender 退出日志仍有少量未释放内存提示，进程退出码为 0；不据此宣称长期内存稳定。

下载 `wfrl_blender-0.3.3.zip`，在 Blender 5.2+ 从磁盘安装，重启后重新加载 MAPPO Demo。无需 Python 后端或求解器。
