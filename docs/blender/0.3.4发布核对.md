# 0.3.4 发布核对 · 2026-09-18

默认内置 BeamDyn 预弯 v3 三机 60 秒离线回放，包含独立未受载参考、根系 xyz 挠度、1.5 秒轨迹渐隐和 Down 视角修复。数据仍为 REVIEW_ONLY。

## 本次运行验证

- ZIP CRC、内置清单哈希与本机已安装 0.3.4 的 107 个文件逐字节匹配；SHA-256 为 `3f2c718e3ae438a49786df4de2f92a1153fd405ea026521d8c19f3e22434a9b0`。
- 19 项宿主测试通过，覆盖可重复打包、独立导入、全部 7203 个 T1 保存叶尖、原始表面独立变换、雷达状态/过期/阈值以及 v3 参考合同。
- 独立 ZIP 在 macOS Blender 5.2.1 LTS 后台通过三机回放、同刻视角/FPS 切换、保存重开及独立参考恢复。抽样保存帧最大分量偏差 1.378 mm，插值帧 1.913 mm。
- 本次后台帧更新 p95 为 73.19 ms，不宣称稳定 60 FPS。退出码为 0，但 Blender 报告少量未释放内存，长期稳定性未验收。

## 复现与安装

`python scripts/blender/build_extension.py` 默认构建相同的 v3 数据包。

`PYTHONPATH=blender_frontend:. python -m pytest blender_frontend/tests/test_extension_package.py blender_frontend/tests/test_tip_deflection.py blender_frontend/tests/test_radar_feedback.py tests/test_prebend_contract.py -q`

原生回归：将 ZIP 解包到独立 `runtime/wfrl_blender`，设置 `WFRL_TEST_RUNTIME`、`WFRL_FARM_FLEX_PACKAGE` 和 `WFRL_TEST_OUTPUT` 后，用 Blender 后台运行 `blender_frontend/tests/blender/prebend_regression.py`。原始 VTP 不随安装包发布，无原始数据时相应独立几何核验跳过。

从 GitHub Release 下载 `wfrl_blender-0.3.4.zip`，在 Blender 5.2+ 从磁盘安装并重启。发布页同时提供 SHA-256 与 inventory；无需下载原始仿真数据。
