# 0.3.7 发布核对

本版基于当前本地全部功能改动整理，发布仓库为 snode11/wind-farm-blender。0.3.6 未发布，本版接续 GitHub 0.3.5。

## 本次实际验证

- 宿主机检查初次 **408 passed、3 skipped**；两项缺少 MediaMTX 环境变量的集成测试单独补跑，**2 passed**，合计 **410 项通过、1 项跳过**。另一项需要未随离线包分发的原始 VTP。
- Blender 5.2.1 LTS / macOS：隔离安装 0.3.7，真实扩展命名空间启用后逐文件校验。6 组后台与 4 组真实 GPU 窗口脚本全部通过：注册及卸载、相机事务、两种投影、视频输出、旧机舱相机、原生观察窗口、编辑与采集、四路同刻/序列导出、退出和清理。
- 视频输出采用独立 3 秒测试图视频，验证 MP4 字节一致、两次 RTSP 收流与严格解码、重连、停止和文件加载时回收进程。未重新渲染正式视频母版。
- 窗口脚本不等于本次人工鼠标验收；短时播放不等于长期稳定性或性能达标。历史布局覆盖和性能结果按其原环境解释。
