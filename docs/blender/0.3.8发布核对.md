# 0.3.8 发布核对

三相机堆叠盒体替代原来的四台独立相机。先安装整个盒体，再分别调整 C1、C2、C3 的俯仰角。

- 加载 MAPPO 演示自动创建三台小相机和共用盒体；整盒移动时三台光心一起移动，保持上下堆叠。
- 新增机舱选点安装及整体 XYZ / 水平朝向输入；各相机独立调整俯仰角、方向和视场。
- 保留三路原生预览、同刻/序列 PNG、内外参、布局导入导出及撤销；盒体位置和相机参数共同保存、恢复。
- 移除第四槽、四路观察入口及旧试用布局。旧四路 JSON 会明确拒绝，当前布局保持不变。
- 修复重复加载时盒体残留，以及相机编辑/恢复后的机身关联。

安装：Blender 5.2+，下载 ZIP，在 Preferences → Get Extensions → Install from Disk 安装；重启 Blender 后重新加载 MAPPO 演示。旧 .blend 不会自动重建为新盒体。

验证：170 项宿主测试（含安装包复现检查）通过；macOS / Blender 5.2.1 LTS 的已安装包、三视口、同步原图、序列采集、撤销与失败回滚检查通过。鼠标选点尚未做人工点击验收，Windows/Linux 未验收。

限制：盒体初始尺寸 29×18×10 cm、相机约 2.8 cm，为仿真假设；未标定真实镜头和玻璃。固定视野以参考姿态配置，不保证整个转动周期无盲区，不包含拼接算法。沿用既有 REVIEW_ONLY 仿真数据，未重新运行 FAST.Farm。退出时仍有 Blender 小量未释放内存块提示。
