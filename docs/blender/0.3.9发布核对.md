## 复现入口

在匹配的源码标签与测试环境下执行：

```bash
python3 scripts/blender/build_extension.py
PYTHONPATH=blender_frontend:. python3 -m pytest \
  blender_frontend/tests --ignore=blender_frontend/tests/blender -q

python3 -m zipfile -e dist/wfrl_blender-0.3.9.zip \
  outputs/release-0.3.9/zip-root/wfrl_blender

WFRL_ADDON_ROOT="$PWD/outputs/release-0.3.9/zip-root" \
WFRL_TEST_OUTPUT="$PWD/outputs/release-0.3.9/default" \
BLENDER_USER_CONFIG="$PWD/outputs/release-0.3.9/config-default" \
/Applications/Blender.app/Contents/MacOS/Blender \
  --background --factory-startup --python-exit-code 1 \
  --python blender_frontend/tests/blender/three_camera_default_regression.py
```

同样的隔离方式用于 `box_surface_install_regression.py` 和 `box_swivel_regression.py`，每次使用独立输出目录。窗口回归运行 `three_camera_recommended_window.py`，去掉 `--background`，另设 `WFRL_CHECK_DEFAULT_ONLY=1` 与 `WFRL_TEST_QUIT=1`；画质恢复检查运行 `demo_presentation_regression.py`。

窗口脚本的定时器会捕获异常，不能只看退出码：还必须确认本次目录内对应 JSON 为 PASS，且没有 `window-error.txt` 或 `error.txt`。使用新的输出目录，避免把历史结果误当本次结果。

本次原始窗口截图、PNG 和完整日志保留在发布工作区的 `outputs/release-0.3.9/`，未上传为额外附件。仓库中的结构化记录概括实际执行的检查与范围。上传后的 ZIP 下载回核对结果写入 Release 说明。

## 仍然存在的限制

- 根部与极尖端有局部遮挡，连续投影视场不等于完整表面可见；固定相机不保证全转动周期完整覆盖。
- 播放仍有低帧率；曾观察到单路切三路后停止推进，尚未定位，不宣称本版已修复。
- 本机旧播放基准存在超时也报 PASS 的缺陷；该脚本和旧窄区默认取景验收不作为本版发布通过依据，也未原样纳入本次源码增量。
- 内置数据仍为 REVIEW_ONLY，固定三束测量覆盖率未通过。Windows/Linux、长期稳定性、拼接、实体相机标定和现场精度未验收。
- 2×2、总览内放大及进一步性能改进仍在[后续更新计划](../../前端更新计划.md)中，不属于本版已实现功能。
