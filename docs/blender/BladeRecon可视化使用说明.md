# Blade Recon 叶片三维重建可视化 · 0.3.20+1

适用于 Blender 5.2+ 的公开 NREL **0.3.20+1**。从[专用 ZIP](https://github.com/snode11/wind-farm-blender/releases/download/v0.3.20.1/wfrl_blender-0.3.20%2B1.zip)安装并重启；当前源码入口为 [`wind-farm-rl-all-work`](https://github.com/snode11/wind-farm-blender/tree/wind-farm-rl-all-work)。开发机日常安装使用同 manifest、不同载荷的 **LOCAL_UNPUBLISHED_REVISION**，该安装载荷与当前源码及既有公开 ZIP 分别识别，详见[身份与验证范围](发布状态与验证范围.md)。外部研究求解器不随扩展打包。

几何与纹理保持 **NOT_ACCEPTED**，原 0.2 mm 叶尖门保持 **FAILED_GATE**。外部材料点候选 Patch 2/8、Crack 7/8、跨相机 RGB 0/264，仍为 FAILED_GATE / NOT_ACCEPTED，same_material_error_m 与 primary_gains 均 null；该[研究结果](../../blade_recon0.2/docs/材料点对应实验报告_2026-10-11.md)未替换正式 601 样本与图集。

## 同源 MAPPO 601 样本纹理同步对照

先在 **N → MAPPO → 打开几何重建示例…**进入完整风机几何对照，再点击**切换到同源纹理对照**；**切换到几何重建**可返回，双向切换保留当前时间、播放状态和有效视角。左侧保存 MAPPO、右侧对应保存重建与图像纹理共用播放、暂停、寻址及样本时钟；入场严格校验 MAPPO 包、模型、纹理文件摘要和全部绝对时钟。601 样本从 0–60 s 对应仿真 117–177 s，10 Hz、每 6 个 60 Hz 显示帧保持一个样本。frame 52 是 117.850 s 播放／117.800 s 样本，保持 50 ms。保留的样本步进工具先暂停并钳制首尾；连续原生播放到末端会两侧共同循环。

几何／同源纹理两侧均按完整风机取景。**中段观察点／叶尖观察点**先暂停并一次定位右侧人工观察位置，之后可自由缩放、平移和绕转；继续播放保留手动视图，共享时钟继续驱动两侧旋转。观察点称**同源图集观察点**，不命名为裂纹、亮斑或修补缺陷，也不持续锁定视角。**原始纹理 → 对比增强／对比增强 → 原始纹理**切换显示并恢复整机取景，再用鼠标选择观察距离；它不改原始图像、UV、几何或观测证据。左侧镜头切换保留右侧独立视图；**退出对照**后可用**返回重建对照**恢复当前来源和时间。MAPPO 与独立合成分别保存模式、增益、检查位置和开关；异常失败不改变当前来源或污染设置。另存 `.blend` 后通过 embedded 输入和 packed 图片恢复，无需外部数据目录。

绿为输入约束支持，橙为模型推断，**两者均为算法估计**。灰度图集保留实际条带、接缝、叶尖错贴及拖影；增强只改变显示。软件同步／保存重开通过不等于纹理映射外观、几何精度、缺陷恢复或现场适用性验收。全部 601 几何数据与原规范模型一致；保留原生求值的既有最大约 0.320910 mm 偏差，不宣称精度改善。


独立结果导入入口把 `blade_recon` 算法输出的重建模型接入 Blender，按保存的模型参数显示叶片随时间变化的三维表面。入口位于三维视口右侧 N 侧栏的独立 **叶片三维重建** 标签，与 Item、MAPPO、View 并列。

独立算法导入的重建回放使用单独场景。进入时保留原场景的对象与回放位置；点击 **返回原场景** 可继续查看原有风场。重建数据和 MAPPO、雷达结果使用各自的数据来源。

## 独立合成纹理资产

独立 `synth_tex` 资产和底层工具提供另一来源的 **120 个 10 Hz 样本、0–11.9 s**，使用独立游标；不是同源 MAPPO 记录。统一几何／同源侧栏不显示独立合成入口，使用独立 **叶片三维重建 → 导入结果** 或匹配的保存样例。已有合成样例兼容恢复其样本与显示选择；人工亮斑／横细线／纵细线观察点不代表自动检测。

## 规范几何示例

1. 使用 Blender 5.2+，在 Preferences → Get Extensions → Install from Disk 安装启用 [0.3.20+1 发布页](https://github.com/snode11/wind-farm-blender/releases/tag/v0.3.20.1) 的扩展附件 `wfrl_blender-0.3.20+1.zip`，升级后重启 Blender。
2. 三维视图按 **N → MAPPO → 打开几何重建示例…**。当前文件未保存时由 Blender 原生对话框提示保存；打开的是安装目录内 `assets/examples/mappo_reconstruction_split.blend`，原几何示例和同源 MAPPO 纹理均含 601 个保存样本，与独立合成纹理的 120 样本分开。当前分屏用 **切换到同源纹理对照／切换到几何重建**双向切换；退出后用 **返回重建对照**恢复当前模式。建议另存到自己的文件，避免覆盖安装目录里的示例。
3. 两侧均显示完整风机，播放／暂停共用时间轴。直接用时间轴寻址，侧栏只保留模式切换、同源中段／叶尖观察点、原始／增强显示及退出；旧样本步进、完整取景与恢复布局工具继续保留在底层。两侧可自由缩放和绕转，窗口缩放可恢复可用区域，左侧相机切换保留右侧独立视图。
4. **退出对照**保留数据和当前时间，可重新进入。另存自己的 `.blend` 后，启用匹配扩展即可原生重开恢复。

ZIP 自带 MAPPO 数据、便携场景及四张 packed 天空／地表纹理，无 linked libraries，不需要作者本机文件路径或在线后端。当前安装与源码边界见本页开头。

此示例右侧三片叶片各有 **601 个 absolute shape keys**，以 **CONSTANT holds** 保存，**无 drivers**。MAPPO 保存数据为 **40 Hz**，重建保存样本为 **10 Hz**，共享时间轴为 **60 Hz**、frame 1–3601；每 6 帧一个重建样本。**frame 52** 显示播放 **117.850 s**、样本 **117.800 s**、保持 **50 ms**。时间轴帧之间不产生新观测。绿为输入约束支持，橙为模型推断，两者均为算法估计；重建精度未验收，60 Hz 时间轴不代表稳定 60 FPS。

规范源为 `blender_frontend/wfrl_blender/assets/examples/mappo_reconstruction_split.blend`，应保留。便携场景通过非空 `__WFRL_BUNDLED_MAPPO__` 路径 marker 与已保存 manifest hash 匹配当前安装的数据；开发时不得清空该路径或改为读取器不支持的 `//` 相对路径，完整恢复合同见 [实现与维护](../../blender_frontend/README.md)。安装与保存重开的证据只属于所标明包及运行环境，见[便携场景包核对](releases/0.3.15发布核对.md)。Windows/Linux 尚未实测。

## 独立算法导入入口：开始查看

1. 启用包含此功能的 WFRL Blender 扩展，在三维视口按 `N` 打开侧栏。
2. 选择 **叶片三维重建** 标签。
3. 点击 **加载合成样例**，先查看算法模型的三维回放及显示图例。合成样例标记为 **SYNTHETIC**，用于演示输入和显示流程。
4. 使用面板中的 **正面**、**侧面** 和 **总览** 按钮观察叶片；通过 Blender 原生时间轴播放、暂停、逐帧或跳转。
5. 查看完毕后点击 **返回原场景**。

独立算法导入场景的时间轴每一帧对应输入重建序列中的一个保存时刻。当前帧的模型参数、表面和标记使用同一时刻；改变 Blender 播放帧率只改变目标播放速度，不改写算法输出时刻。

## 导入自己的算法结果

在 **叶片三维重建** 标签点击 **导入结果**，在打开的文件选择器中选择 `blade_recon` 生成的 `recon.json`。使用原算法输出，保留其模型参数、时间序列和输入来源；Blender 可视化不重新拟合图像，也不在查看时启动求解器。

### 看清图集局部细节

独立算法导入场景使用 **叶片三维重建 → 表面纹理** 的增强与局部检查控件。

当前源码分支提供 `scripts/blender/打开纹理细节检查.command`；按所需输入和[资源说明](../PUBLICATION.md)准备完整源码工作区后使用，启动来源与已安装扩展分别核对。当前公开扩展的同源纹理从上述统一入口切换，独立算法导入使用 **叶片三维重建** 面板。

打开 **表面纹理** 后可选 **原始纹理**、**增强灰度** 或 **青／洋红增强**。增强强度可调；青色表示比叶片基准偏亮，洋红表示偏暗，亮暗阈值越低会显示越多细节及噪声。未覆盖区域继续保留绿色／橙色证据显示。开关与增强只影响材质，原始 packed 图片、重建状态和尺寸不变。

**局部检查** 可选择叶片、距轮毂的半径、沿截面周线的表面位置和局部范围，点击 **局部放大** 会暂停并正对该估计表面。**检查框** 标出手动选中的区域。改变帧或位置后可再次点击定位；**正面／侧面／总览** 返回整体视角。

独立合成样例提供 **亮斑／横细线／纵细线** 三个快捷点，它们来自对已保存合成图集的人工查看，不是自动检测结果；当前同源面板只显示中段／叶尖观察点。增强颜色不区分裂缝、修补、污渍或拼接差异；放大不增加原观测分辨率。显示增强不构成材料身份或缺陷恢复证据。

需要指定纹理、真值或相机输入时，先填写可选路径字段，再点击 **导入结果**。纹理字段选择 `texture.py` 输出目录，必须有 `texture.json` 和三张尺寸匹配的 RGBA `blade*_tex.png`；导入后保存 packed 图片、UV 和元数据。可用 **表面纹理** 开关对照轮廓证据色。字段未填时会尝试读取 `recon.json` 同目录的 `truth.json` 和 `cameras.json`。真值用于显示对照层，相机用于显示标定位置与朝向；未提供且未找到对应输入时，这些显示层保持不可用。导入失败时查看 Blender 的操作错误报告，再核对文件类型、完整性和时间序列。

成功导入后，使用 **真值线框** 控制真值对照层，使用 **三摄位置** 控制相机示意层。真值对照和相机位置帮助理解重建结果，三维重建本身按 `recon.json` 中的模型生成。

## 颜色与观测范围

显示图例区分与已拟合轮廓相符的采样标记，以及依赖模型推断的部分。这里的观测标记表示该模型采样点与输入轮廓的符合关系；它不表示该点已获得独立的三维测量，也不表示完整叶片表面都在原图中可见。

轮廓以外的完整三维表面由算法模型推断。查看这些部分时结合原输入、相机布局和可选真值判断，不把合成样例的完整表面当作实拍重建精度结果。

正式 601 样本几何来自轮廓／剪影约束，固定保存位姿后把 RGB 灰度反投影为纹理；安装扩展不运行外部材料点求解器，不能把修补颜色或局部纹理解释为缺陷高度／深度。 [NREL 缺陷编辑器](NREL缺陷编辑器.md)提供合成展示与输入制作，两者不构成缺陷重建验证。表面特征研究的当前结论从 [表面研究入口](../../research/blade-surface/README.md)读取。

独立 NREL 动态研究查看器使用 合并目录的统一入口（本地路径：`outputs/nrel-video-dynamic/runs/20261004-integrated/README.md`），载入冻结源码与研究包，状态仍为 `REVIEW_ONLY / DY1 NOT PASSED`。它只有四个保存估计时刻，其余帧为 `UNAVAILABLE; no interpolation`；这与上述 601 样本便携分屏分别判断，软件播放同步不证明动态计量通过。

## 保存与重新打开

导入成功后保存 `.blend`，重建回放所需的输入内容会嵌入场景，显式导入的三片纹理会 pack 到文件中。重新打开时可恢复回放，无需保持原 `recon.json`、真值或相机输入路径可用。

恢复动态回放需要启用包含此功能的 WFRL Blender 扩展，或通过匹配的启动入口打开。仅保存对象几何不能替代回放代码；重新打开后应在 **叶片三维重建** 标签核对数据来源、当前帧与就绪状态。
