# Blade Recon 叶片三维重建可视化

公开交付版本为 **0.5.0.0.1**（GitHub 标签 `v0.5.0.0.1`，Blender manifest 为 `0.5.0+0.1`）。安装与公开载荷身份以 `publication/daily-installation.json` 和发布交付记录为准。

适用于 Blender 5.2+ 的公开 NREL **0.5.0.0.1**。从[专用 ZIP](https://github.com/snode11/wind-farm-blender/releases/download/v0.5.0.0.1/wfrl_blender-0.5.0%2B0.1.zip)安装并重启；当前源码入口为 [`main`](https://github.com/snode11/wind-farm-blender/tree/main)。开发机日常安装的当前版本、实际来源与验证范围见[统一发布状态](发布状态与验证范围.md)和[安装核对](../../publication/daily-installation.json)。外部研究求解器不随扩展打包。

几何与纹理保持 **NOT_ACCEPTED**，叶尖显示门槛按[工作区源码与安装载荷](发布状态与验证范围.md#研究与物理边界)分别判定。外部材料点候选 Patch 2/8、Crack 7/8、跨相机 RGB 0/264，仍为 FAILED_GATE / NOT_ACCEPTED，same_material_error_m 与 primary_gains 均 null；该[研究结果](../../blade_recon0.2/docs/材料点对应实验报告_2026-10-11.md)未替换正式 601 样本与图集。

工作区前端的 **叶片三维重建** 与 **MAPPO** 页共用完整风机对照入口，仅提供几何和同源纹理模式。默认扩展运行时不加载或恢复独立合成三叶片画面。工作区改动与上面记录的公开交付、日常安装分别核对。

## 同源 MAPPO 601 样本纹理同步对照

先在 **N → MAPPO → 打开几何重建示例…**进入完整风机几何对照，再点击**切换到同源纹理对照**；**切换到几何重建**可返回，双向切换保留当前时间、播放状态和有效视角。左侧保存 MAPPO、右侧对应保存重建与图像纹理共用播放、暂停、寻址及样本时钟；入场严格校验 MAPPO 包、模型、纹理文件摘要和全部绝对时钟。601 样本从 0–60 s 对应仿真 117–177 s，10 Hz、每 6 个 60 Hz 显示帧保持一个样本。frame 52 是 117.850 s 播放／117.800 s 样本，保持 50 ms。保留的样本步进工具先暂停并钳制首尾；连续原生播放到末端会两侧共同循环。

几何／同源纹理两侧均按完整风机取景。**中段观察点／叶尖观察点**先暂停并一次定位右侧人工观察位置，之后可自由缩放、平移和绕转；继续播放保留手动视图，共享时钟继续驱动两侧旋转。观察点称**同源图集观察点**，不命名为裂纹、亮斑或修补缺陷，也不持续锁定视角。**原始纹理 → 对比增强／对比增强 → 原始纹理**切换显示并恢复整机取景，再用鼠标选择观察距离；它不改原始图像、UV、几何或观测证据。左侧镜头切换保留右侧独立视图；**退出对照**后可用**返回重建对照**恢复当前来源和时间。同源纹理保存模式、增益、检查位置和开关；异常失败不改变当前来源或污染设置。另存 `.blend` 后通过 embedded 输入和 packed 图片恢复，无需外部数据目录。

绿为输入约束支持，橙为模型推断，**两者均为算法估计**。灰度图集保留实际条带、接缝、叶尖错贴及拖影；增强只改变显示。软件同步／保存重开通过不等于纹理映射外观、几何精度、缺陷恢复或现场适用性验收。全部 601 几何数据与原规范模型一致；保留原生求值的既有最大约 0.320910 mm 偏差，不宣称精度改善。


## 规范几何示例

1. 使用 Blender 5.2+，在 Preferences → Get Extensions → Install from Disk 安装启用 [0.5.0.0.1 发布页](https://github.com/snode11/wind-farm-blender/releases/tag/v0.5.0.0.1) 的扩展附件 `wfrl_blender-0.5.0+0.1.zip`，升级后重启 Blender。
2. 三维视图按 **N → MAPPO → 打开几何重建示例…**。当前文件未保存时由 Blender 原生对话框提示保存；打开的是安装目录内 `assets/examples/mappo_reconstruction_split.blend`，原几何示例和同源 MAPPO 纹理均含 601 个保存样本。当前分屏用 **切换到同源纹理对照／切换到几何重建**双向切换；退出后用 **返回重建对照**恢复当前模式。建议另存到自己的文件，避免覆盖安装目录里的示例。
3. 两侧均显示完整风机，播放／暂停共用时间轴。直接用时间轴寻址，侧栏只保留模式切换、同源中段／叶尖观察点、原始／增强显示及退出；样本步进、完整取景与恢复布局工具可由脚本调用。两侧可自由缩放和绕转，窗口缩放可恢复可用区域，左侧相机切换保留右侧独立视图。
4. **退出对照**保留数据和当前时间，可重新进入。另存自己的 `.blend` 后，启用匹配扩展即可原生重开恢复。

ZIP 自带 MAPPO 数据、便携场景及四张 packed 天空／地表纹理，无 linked libraries，不需要作者本机文件路径或在线后端。当前安装与源码边界见本页开头。

此示例右侧三片叶片各有 **601 个 absolute shape keys**，以 **CONSTANT holds** 保存，**无 drivers**。MAPPO 保存数据为 **40 Hz**，重建保存样本为 **10 Hz**，共享时间轴为 **60 Hz**、frame 1–3601；每 6 帧一个重建样本。**frame 52** 显示播放 **117.850 s**、样本 **117.800 s**、保持 **50 ms**。时间轴帧之间不产生新观测。绿为输入约束支持，橙为模型推断，两者均为算法估计；重建精度未验收，60 Hz 时间轴不代表稳定 60 FPS。

规范源为 `blender_frontend/wfrl_blender/assets/examples/mappo_reconstruction_split.blend`，应保留。便携场景通过非空 `__WFRL_BUNDLED_MAPPO__` 路径 marker 与已保存 manifest hash 匹配当前安装的数据；开发时不得清空该路径或改为读取器不支持的 `//` 相对路径，完整恢复合同见 [实现与维护](../../blender_frontend/README.md)。安装与保存重开的证据只属于所标明包及运行环境，见[便携场景包核对](releases/0.3.15发布核对.md)。Windows/Linux 尚未实测。

## 颜色与观测范围

显示图例区分与已拟合轮廓相符的采样标记，以及依赖模型推断的部分。这里的观测标记表示该模型采样点与输入轮廓的符合关系；它不表示该点已获得独立的三维测量，也不表示完整叶片表面都在原图中可见。

轮廓以外的完整三维表面由算法模型推断。查看这些部分时结合原输入、相机布局和可选真值判断，不把合成样例的完整表面当作实拍重建精度结果。

正式 601 样本几何来自轮廓／剪影约束，固定保存位姿后把 RGB 灰度反投影为纹理；安装扩展不运行外部材料点求解器，不能把修补颜色或局部纹理解释为缺陷高度／深度。 [NREL 缺陷编辑器](NREL缺陷编辑器.md)提供合成展示与输入制作，两者不构成缺陷重建验证。表面特征研究的当前结论从 [表面研究入口](../../research/blade-surface/README.md)读取。

独立 NREL 动态研究查看器使用 合并目录的统一入口（本地路径：`outputs/nrel-video-dynamic/runs/20261004-integrated/README.md`），载入冻结源码与研究包，状态仍为 `REVIEW_ONLY / DY1 NOT PASSED`。它只有四个保存估计时刻，其余帧为 `UNAVAILABLE; no interpolation`；这与上述 601 样本便携分屏分别判断，软件播放同步不证明动态计量通过。

## 保存与重新打开

完整风机对照的重建输入嵌入 `.blend`，图集与环境图片打包保存。启用匹配扩展后，按来源清单及摘要恢复几何／同源纹理模式、时间与视角；原始场景与正式样本不由加载操作改写。

算法研究可通过 `blade_recon0.2/blender_view.py` 显式指定自己的结果。研究数据和导入工具不作为日常前端入口，独立结果不自动加入 MAPPO 时间轴。
