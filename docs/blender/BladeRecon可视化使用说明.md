更新日期：2026-10-07。当前 NREL 扩展为 **0.3.17**，接入保存的 Blade Recon 0.2 重建结果、三片 RGBA 纹理、显示增强及保存恢复，并保留原始几何示例。安装使用 [wfrl_blender-0.3.17.zip](https://github.com/snode11/wind-farm-blender/releases/download/v0.3.17/wfrl_blender-0.3.17.zip)，升级后重启 Blender；最终安装包验证见 [0.3.17 发布核对](releases/0.3.17发布核对.md)。外部算法求解研究代码不随扩展打包。

独立结果导入入口把 `blade_recon` 算法输出的重建模型接入 Blender，按保存的模型参数显示叶片随时间变化的三维表面。入口位于三维视口右侧 N 侧栏的独立 **叶片三维重建** 标签，与 Item、MAPPO、View 并列。

独立算法导入的重建回放使用单独场景。进入时保留原场景的对象与回放位置；点击 **返回原场景** 可继续查看原有风场。重建数据和 MAPPO、雷达结果使用各自的数据来源。

## 0.3.17：MAPPO＋细节表面纹理

0.3.17 通过 **N → MAPPO → 进入重建对照** 进入：左侧保留 MAPPO 风场，右侧直接显示 `synth_tex` 输出的带纹理表面，并定位到人工选定的亮斑近景。右侧可一键切换 **原始纹理／增强显示**，或选择 **亮斑／横细线／纵细线**；**完整取景**返回三片叶片全景，**退出对照**返回 MAPPO 单视图，再次进入保留样本和显示选择。

右侧是独立合成纹理样例：**120 个保存样本，10 Hz，0–11.9 s**。左侧仍使用自己的 MAPPO 回放时间；右侧样本按钮只改变纹理样例游标，并暂停左侧回放。两者不同来源，不声称同源同步。原始 packed RGBA、UV、重建几何和观测证据保持独立，增强亮暗颜色仅用于外观检查。

最终发布 ZIP 的隔离安装及保存重开见 [0.3.17 发布核对](releases/0.3.17发布核对.md)；此前本机窗口证据见修复验证记录（本地归档：`outputs/blade-texture-split-fix-20261007-b01/实施与验证.md`，未公开），本次最终包未重测可见窗口或 FPS。下述 0.3.16 几何示例按历史版本阅读。

## 已发布 0.3.16 的原始几何示例

1. 使用 Blender 5.2+，在 Preferences → Get Extensions → Install from Disk 安装启用 [0.3.16 发布页](https://github.com/snode11/wind-farm-blender/releases/tag/v0.3.16) 的唯一手动附件 `wfrl_blender-0.3.16.zip`，升级后重启 Blender。
2. 三维视图按 **N → MAPPO → MAPPO＋重建示例**。当前文件未保存时由 Blender 原生对话框提示保存；打开的是安装目录内 `assets/examples/mappo_reconstruction_split.blend`。
3. 左侧观察 MAPPO，右侧观察三片保存重建。播放／暂停共用时间轴；**上一样本／下一样本**先暂停并跳到真实样本，端点钳制；**完整取景**和**恢复布局**用于取景与分屏恢复。窗口缩放可恢复可用区域，左侧相机切换保留右侧独立视图。
4. **退出对照**保留数据和当前时间，可重新进入。另存自己的 `.blend` 后，启用匹配扩展即可原生重开恢复。

ZIP 自带 MAPPO 数据、便携场景及四张 packed 天空／地表纹理，无 linked libraries，不需要作者本机文件路径或在线后端。0.3.16 仅发布 ZIP，新版源码未提交／推送；GitHub 自动 Source code 不包含完整新版实现，不能作为安装包。

此示例右侧三片叶片各有 **601 个 absolute shape keys**，以 **CONSTANT holds** 保存，**无 drivers**。MAPPO 保存数据为 **40 Hz**，重建保存样本为 **10 Hz**，共享时间轴为 **60 Hz**、frame 1–3601；每 6 帧一个重建样本。**frame 52** 显示播放 **117.850 s**、样本 **117.800 s**、保持 **50 ms**。时间轴帧之间不产生新观测。绿为两端截面受约束，橙为模型推断；重建精度未验收，60 Hz 时间轴不代表稳定 60 FPS。

Release ZIP 内的便携场景位于 `assets/examples/mappo_reconstruction_split.blend`；本地工作区规范源 `blender_frontend/wfrl_blender/assets/examples/mappo_reconstruction_split.blend` 尚未同步到公开源码。便携场景通过非空 `__WFRL_BUNDLED_MAPPO__` 路径 marker 与已保存 manifest hash 匹配当前安装的数据；开发时不得清空该路径或改为读取器不支持的 `//` 相对路径，完整恢复合同见 [实现与维护](../../blender_frontend/README.md)。隔离安装、便携恢复、实际分屏窗口、保存重开和注册生命周期的 macOS Blender 5.2.1 LTS 证据属于 [0.3.15 历史发布核对](releases/0.3.15发布核对.md)。0.3.16 延续示例，但未重测分屏窗口；本版后台安装与已知失败见 [0.3.16 发布核对](releases/0.3.16发布核对.md)。Windows/Linux 尚未实测。

## 独立算法导入入口：开始查看

1. 启用包含此功能的 WFRL Blender 扩展，在三维视口按 `N` 打开侧栏。
2. 选择 **叶片三维重建** 标签。
3. 点击 **加载合成样例**，先查看算法模型的三维回放及显示图例。合成样例标记为 **SYNTHETIC**，用于演示输入和显示流程。
4. 使用面板中的 **正面**、**侧面** 和 **总览** 按钮观察叶片；通过 Blender 原生时间轴播放、暂停、逐帧或跳转。
5. 查看完毕后点击 **返回原场景**。

独立算法导入场景的时间轴每一帧对应输入重建序列中的一个保存时刻。当前帧的模型参数、表面和标记使用同一时刻；改变 Blender 播放帧率只改变目标播放速度，不改写算法输出时刻。

## 导入自己的算法结果

在 **叶片三维重建** 标签点击 **导入结果**，在打开的文件选择器中选择 `blade_recon` 生成的 `recon.json`。本入口仅支持与随包旧解析前向模型兼容的结果；含 `healthy_template` 的新版研究输出尚不受支持。使用兼容算法输出，保留其模型参数、时间序列和输入来源；Blender 可视化不重新拟合图像，也不在查看时启动求解器。

### 看清小修补块和细线（0.3.17）

公开安装版先安装 0.3.17 Release ZIP，再用 **N → MAPPO → 加载 MAPPO · 60 秒 → 进入重建对照** 检查亮斑近景及青／洋红增强。`scripts/blender/打开纹理细节检查.command` 是本地开发入口，未随公开源码或扩展 ZIP 提供。

打开 **表面纹理** 后可选 **原始纹理**、**增强灰度** 或 **青／洋红增强**。增强强度可调；青色表示比叶片基准偏亮，洋红表示偏暗，亮暗阈值越低会显示越多细节及噪声。未覆盖区域继续保留绿色／橙色证据显示。开关与增强只影响材质，原始 packed 图片、重建状态和尺寸不变。

**局部检查** 可选择叶片、距轮毂的半径、沿截面周线的表面位置和局部范围，点击 **局部放大** 会暂停并正对该估计表面。**检查框** 标出手动选中的区域。改变帧或位置后可再次点击定位；**正面／侧面／总览** 返回整体视角。

纹理样例启动入口会附带 **亮斑／横细线／纵细线** 三个快捷点，它们来自对已保存合成图集的人工查看，不是自动检测结果。增强颜色不区分裂缝、修补、污渍或拼接差异；放大不增加原观测分辨率。这些显示增强已随 0.3.17 安装 ZIP 提供；公开 0.3.16 附件仍保留历史内容。

需要指定纹理、真值或相机输入时，先填写可选路径字段，再点击 **导入结果**。纹理字段选择 `texture.py` 输出目录，必须有 `texture.json` 和三张尺寸匹配的 RGBA `blade*_tex.png`；导入后保存 packed 图片、UV 和元数据。可用 **表面纹理** 开关对照轮廓证据色。字段未填时会尝试读取 `recon.json` 同目录的 `truth.json` 和 `cameras.json`。真值用于显示对照层，相机用于显示标定位置与朝向；未提供且未找到对应输入时，这些显示层保持不可用。导入失败时查看 Blender 的操作错误报告，再核对文件类型、完整性和时间序列。

成功导入后，使用 **真值线框** 控制真值对照层，使用 **三摄位置** 控制相机示意层。真值对照和相机位置帮助理解重建结果，三维重建本身按 `recon.json` 中的模型生成。

## 颜色与观测范围

显示图例区分与已拟合轮廓相符的采样标记，以及依赖模型推断的部分。这里的观测标记表示该模型采样点与输入轮廓的符合关系；它不表示该点已获得独立的三维测量，也不表示完整叶片表面都在原图中可见。

轮廓以外的完整三维表面由算法模型推断。查看这些部分时结合原输入、相机布局和可选真值判断，不把合成样例的完整表面当作实拍重建精度结果。

本版随包 `synth_tex` 样例使用已保存的轮廓／剪影几何与 RGBA 图集；前端纹理及 shader 增强不反馈几何，不能把修补颜色或局部纹理解释为缺陷高度／深度。外部纹理辅助几何候选不随扩展打包，其研究范围另行判断。0.3.16 的 [NREL 缺陷编辑器](NREL缺陷编辑器.md)提供合成展示与输入制作，两者不构成缺陷重建验证。表面特征扩展的最新执行状态从 2026-10-06 方案与交接入口（本地归档：`docs/proposal/叶片表面重建_2026-10-06/README.md`，未公开）读取。

独立 NREL 动态研究查看器使用 合并目录的统一入口（本地归档：`outputs/nrel-video-dynamic/runs/20261004-integrated/README.md`，未公开），载入冻结源码与研究包，状态仍为 `REVIEW_ONLY / DY1 NOT PASSED`。它只有四个保存估计时刻，其余帧为 `UNAVAILABLE; no interpolation`；这与上述 601 样本便携分屏分别判断，软件播放同步不证明动态计量通过。

## 保存与重新打开

导入成功后保存 `.blend`，重建回放所需的输入内容会嵌入场景，显式导入的三片纹理会 pack 到文件中。重新打开时可恢复回放，无需保持原 `recon.json`、真值或相机输入路径可用。

恢复动态回放需要启用包含此功能的 WFRL Blender 扩展，或通过匹配的启动入口打开。仅保存对象几何不能替代回放代码；重新打开后应在 **叶片三维重建** 标签核对数据来源、当前帧与就绪状态。

## 开发与验证范围

0.3.17 已发布保存结果及 v0.2 纹理可视化；MAPPO＋重建原始几何示例于 0.3.15 发布并随 0.3.16 延续。外部纹理辅助几何／健康 loft 求解器没有集成到安装扩展。工作区源码、构建 ZIP 和已安装扩展是不同运行来源，修改源码不会自动更新已安装扩展；安装新包后重启 Blender，再核对实际载入模块路径。实际检查应分别记录输入读取、模型回放、场景切换、保存重开、安装版及可见窗口结果。

此可视化入口展示算法输出与合成流程；重建精度、实拍适用性和播放性能以各自数据与测量记录为准。前端维护入口见 [Blender 实现与维护](../../blender_frontend/README.md)。
