# Blender 内的相机视频输出

位置：按 **N → MAPPO → 视频输出**。这是完整 WFRL 前端中的一页，原有挠度、净空、机舱相机、云台、回放与工具功能继续保留。

## 两个功能

1. **导出离线 MP4**：选择输出文件名，将“相机视频”所选的已生成 MP4 原样导出。不会重新压缩，也不会覆盖已有文件或源视频。
2. **启动 RTSP / 停止 RTSP**：按正常速度循环播放同一份视频。启动成功后显示地址，可以点击“复制 RTSP 地址”。停止只回收本插件启动的两个视频进程，不改变 Blender 回放。

这里输出的是已经生成的相机视频，不是 Blender 操作界面录屏，也不随着当前视口或云台改变。现有五分钟视频已完成，无须重新渲染；它是 60 秒源片段重复五次，接点存在画面跳变。

## 设置

“相机视频”选择现有 `video.mp4`。展开“视频输出设置”可设置 FFmpeg、MediaMTX 的可执行文件位置，RTSP 端口默认 8554。路径保存在 Blender 偏好设置中，可点击“保存视频输出设置”，不会硬编码到插件源码或安装包里。

本机地址：`rtsp://127.0.0.1:8554/windfarm/camera1`，读取使用 RTSP over TCP。允许局域网读取后，其他电脑将 `127.0.0.1` 替换为这台电脑的局域网 IP；服务机防火墙需允许所选 TCP 端口。只开放 RTSP，管理 API、网页播放器与 HTTP 标签服务均关闭。

切换 `.blend`、禁用插件或正常退出 Blender 会停止本插件的推流与未完成导出。启动失败时面板显示原因；端口被占用时不会结束其他程序。

## Windows

Windows 使用同一份完整 Blender 扩展。选择 Windows 版 `ffmpeg.exe` 和 `mediamtx.exe`，重新指定视频文件并保存偏好设置；不能沿用 Mac 上的文件路径。MP4 导出不依赖 FFmpeg 或 MediaMTX，推流才需要这两个工具。

Windows 实机与实际局域网需要在目标电脑检查。制作端的 Blender 验证不能代替 Windows 实机验收。

如需更改场景并重新生成画面，原有渲染/数据生成入口仍见[固定机舱相机视频使用说明](固定机舱相机视频使用说明.md)。本页两种输出都使用已生成的视频，导出不是重新计算一段仿真。
