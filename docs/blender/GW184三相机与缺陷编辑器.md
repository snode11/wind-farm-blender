# GW184 三相机与叶片缺陷编辑器 0.4.0

[下载 0.4.0 独立运行 ZIP](https://github.com/snode11/wind-farm-blender/releases/download/v0.4.0/gw184_three_camera_defects-0.4.0.zip)。

更新日期：2026-10-07（更新 NREL 关联入口）。项目入口、源码与视频任务见[GW184 README](../../projects/gw184-single/README.md)，详细编辑与检查说明见[缺陷编辑器说明](../../projects/gw184-single/DEFECT_EDITOR.md)。仓库文档会继续维护；已发布 ZIP 的版本与内容以 0.4.0 包为准。

这是用于固定三相机观察和合成缺陷检查的独立 Blender 运行包。完整解压后启动，无需安装 NREL 前端、Python 后端、FAST.Farm 或 Bridge；不要通过 Blender 的“Install from Disk”安装本 ZIP。

NREL 5MW 柔性回放、MAPPO 与双束净空属于另一套扩展，当前为 [NREL 0.3.17](https://github.com/snode11/wind-farm-blender/releases/tag/v0.3.17) 的 `wfrl_blender-0.3.17.zip`；该版也已加入 [NREL 六类缺陷编辑器](NREL缺陷编辑器.md)，雷达功能仍仅在 NREL 扩展中提供。两套缺陷配置不能直接互用。GW184 0.4.0 保持原运行包；其历史发布页中的 NREL 0.3.12 附件仍保留。

## 启动

需要 Blender 5.2+。请将整个文件夹解压到有写入权限的位置，保持内部目录结构。

- macOS：双击 `打开GW184.command`。默认使用 `/Applications/Blender.app`；其他位置可通过环境变量 `BLENDER_BIN` 指定 Blender 可执行文件。
- Windows：双击 `Open-GW184.bat`。它查找 PATH 或默认的 Blender 5.2 安装目录；其他位置可设置 `BLENDER_BIN` 为 `blender.exe` 的完整路径。Windows 启动脚本尚未经实机验证。
- 任意平台也可使用下面的命令，把 `blender` 换成实际可执行文件路径。在解压目录中运行：

```sh
blender --factory-startup --python scripts/blender/gw184_defects.py -- --mode edit --all-presets
```

启动会打开一个独立 Blender 进程，并加载六种合成示例；不修改已有 NREL 扩展，也不启动图片或视频渲染。

## 编辑与三相机观察

在三维视图按 **N**，选择 **叶片缺陷** 面板。

1. 选择现有缺陷并修改，或选择类型后新建；可输入叶片、吸力/压力侧、展向和弦向位置，也可点击健康参考表面定位。
2. 调整方向、长度、宽度与适用的深度，点击预览，再确认或取消。编辑期间时刻冻结。
3. 用正面/斜侧近景检查缺陷；选择 C1/C2/C3 检查原固定视角。近景导航不改变三台固定相机的安装布局。
4. 健康对照临时隐藏所选叶片的全部缺陷；返回后恢复。辅助轮廓仅用于定位，不是缺陷外观图。
5. 使用绝对路径保存或加载缺陷 JSON。复制生成新的实例 ID，默认禁用；调整位置后再启用，避免重叠。
6. 修改时刻后可进行当前几何可见性分析，或对指定时间范围逐帧扫描；选择新的空输出目录保存结果。

六类示例：材质细裂纹、实体开口裂缝、凹坑、局部表面侵蚀、材质涂层剥落，以及烧蚀材质与实体凹坑组合的雷击损伤。缺陷未与结构或气动求解耦合，暂不支持重叠的独立缺陷。

恢复已保存配置到可操作编辑器：

```sh
blender --factory-startup --python scripts/blender/gw184_defects.py -- --mode edit --config /absolute/path/defects.json
```

从 `.blend` 检查快照重建编辑器：

```sh
blender --factory-startup --python scripts/blender/gw184_defects.py -- --mode edit --reopen /absolute/path/GW184-defect-editor.blend
```

仅双击 `.blend` 会打开静态检查快照；通过以上入口才能恢复编辑器和运动处理器。

## 模型与边界

模型采用 DTU 10MW 参考数据中的弦长、相对厚度和扭角分布，结合固定的 FFA 翼型轮廓，适配为 184 m 参考直径、90 m 叶片和 3 m 静态预弯的 GW184 尺寸合成几何。它不是制造商 CAD，也不是原 NREL 5MW 柔性模型。详细参数与来源保留在 `projects/gw184-single/geometry/target.json` 和 `projects/gw184-single/sources/provenance.json`；WISDEM 参考许可一并保留。

三相机采用固定布局，不会为了让缺陷可见而自动跟踪、放大或避开遮挡。几何可见性不等于肉眼可辨或算法检出。实体视口不能验收细裂纹、剥落和烧蚀的最终材质外观；六种预设均为合成示例。

本版发布检查不生成图片或长视频。包中保留原三相机视频管线及按需图片入口，渲染需要明确启用相应参数和额外的运行时间，完整 MP4 未包含在本 ZIP 中。第一阶段整体、Windows/Linux 实机、现场真实性和长期性能未完成验收。
