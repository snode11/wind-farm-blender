# MAPPO 60 秒演示 · 0.3.1

当前交付版本为 **0.3.5**：[下载](https://github.com/snode11/wind-farm-blender/releases/tag/v0.3.5)。默认内置预弯 v3 数据，新增机舱云台视角（默认 120°）及相邻两圈轨迹定格淡出，保留原 Down 视角。固定三束覆盖率失败，仍为 REVIEW_ONLY；详见发布核对。

## Windows / macOS 快速开始

1. 安装 Blender 5.2+，从 [0.3.5 发布页](https://github.com/snode11/wind-farm-blender/releases/tag/v0.3.5)下载 **wfrl_blender-0.3.5.zip**，不要解压，不选 Source code。
2. **Edit → Preferences → Get Extensions → 菜单 → Install from Disk**，安装并启用 WFRL Blender，然后重启。
3. 新建 General 场景，三维视图按 **N → MAPPO → 三机 MAPPO 回放 → 加载 MAPPO · 60 秒**。
4. 点击播放。ZIP 已带完整数据，离线演示不需要后端环境、网络或原始仿真文件。

Windows 不运行 Mac 的 `.command`。若从本地 0.3.2–0.3.5 中间版迁移，先另存场景、移除旧扩展，再安装正式 0.3.1。

## 建议演示顺序

1. **挠度**：选择 T1 的叶片 1/2/3，点“叶尖”并开启“虚影 / 分量”；暂停读面外/面内仿真值、坐标差及 mm 偏差。
2. 点“叶轮”或“Down”看叶片及塔架运动。灰色参考随塔顶整体运动，表中为叶片自身挠度；塔筒没有专用虚影/分量。
3. **净空**：分别点 T1/T2/T3 Down，查看 B2 斜距、净空真值/估计/误差。留意测量时刻和读数年龄，等待测量不代表零距离。
4. **工具 → 机组、视角与云台**：看风场全景；**三机遥测、曲线与导出**：看功率、转速、载荷与曲线。
5. 顶部可暂停、单步、复位和拖动进度；工具页的“数据来源与重新加载”提供重新加载和从头重播。

切页不改变时间或镜头。轨迹颜色是叶片 1 橙、2 蓝、3 红；结构叶尖对照点与轨迹收尖点定义不同。截图及录制在“工具 → 截图、录制与渲染”，先设置当前电脑可写的输出目录。

## 记录与范围

本版内置三机柔性塔架 v2 包，原仿真 117–177 s，2401 个源时刻；九片叶片、塔筒、机舱和雷达共用时钟。MAPPO 控制偏航，基线控制器负责转矩/变桨。60 Hz 显示时间轴不保证 60 FPS。

数据仍为 **REVIEW_ONLY**。已做有限数值敏感性检查，但没有完整风场收敛或现场精度认证；B2 固定估计未补偿塔架弯曲，T1 缺测仍照实显示。Windows 实机尚未验收。

完整安装、读表、真实后端和排障见[用户手册](用户使用手册.md)，本轮测试见 [0.3.1 发布核对](0.3.1发布核对.md)。
