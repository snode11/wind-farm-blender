# MAPPO 60 秒演示

更新日期：2026-10-08。公开扩展版本为 **0.3.18**，要求 Blender 5.2+；[发布页](https://github.com/snode11/wind-farm-blender/releases/tag/v0.3.18)提供 172 文件扩展 ZIP，匹配源码已同步至 v0.3.18。发布身份和源码复建见[发布核对](releases/0.3.18发布核对.md)，发布前软件修复与安装／原生检查见[本地修复与验证](validation/NREL本地0.3.18修复与验证.md)，两类记录分别阅读。

## 快速开始

1. 下载 [wfrl_blender-0.3.18.zip](https://github.com/snode11/wind-farm-blender/releases/download/v0.3.18/wfrl_blender-0.3.18.zip)，保留压缩格式。
2. **Edit → Preferences → Get Extensions → Install from Disk**，安装并启用 WFRL Blender，然后退出并重启。
3. 新建 General 场景，三维视图按 **N → MAPPO → 三机 MAPPO 回放 → 加载 MAPPO · 60 秒**。
4. 点击播放。ZIP 已带完整数据，离线演示无需后端环境、网络或原始仿真文件。

升级前另存自己的场景与相机布局。Windows 使用上述 ZIP 安装，不运行 Mac 的 `.command`；本版 Windows/Linux 尚未实机验收。详细步骤见[安装说明](INSTALL.md)。

## 建议演示顺序

1. **挠度**：选择 T1 的叶片 1/2/3，点“叶尖”并开启“虚影 / 分量”；暂停读根系 x/y/z 仿真值、坐标差及 mm 偏差。
2. 点“叶轮”或“Down”看叶片及塔架运动。灰色参考随塔顶整体运动，表中为叶片自身挠度；塔筒没有专用虚影／分量。
3. **净空**：选择“双束净空 / S1”，分别点 T1/T2/T3 Down；显式“TLS 候选 / S1”与原 B2 回放分别使用自己的方法和读数。留意测量时刻、来源和读数年龄，等待测量不代表零距离。
4. **View → 三相机 → 三路对照**查看共盒 C1/C2/C3、安装示意与单路放大；固定相机仍有遮挡和空画面。
5. **工具 → 机组、视角与云台**看风场全景；**三机遥测、曲线与导出**查看已记录通道。顶部可暂停、单步、复位和拖动进度，工具页提供重新加载和从头重播。
6. 如需对照重建，在 **MAPPO → 同源纹理同步对照**观看 601 个保存样本；**打开几何重建示例…**与**独立合成纹理样例**是另外两个入口，独立合成的 120 样本游标不与 MAPPO 冒充同源同步。

切页保留时间和镜头。轨迹颜色为叶片 1 红、2 绿、3 蓝；结构叶尖与轨迹收尖点定义不同。截图及录制在“工具 → 截图、录制与渲染”，先设置当前电脑可写的输出目录。

## 记录与范围

三机柔性塔架与九片叶片复用预弯 v3 保存结果，原仿真 **117–177 s、40 Hz、2401 个源时刻**；60 Hz 显示时间轴不保证稳定 60 FPS。MAPPO 控制偏航，基线控制器负责转矩／变桨。观察或播放不重跑求解器。

数据、雷达和重建仍按各自 **REVIEW_ONLY / PENDING_ACCEPTANCE / NOT_ACCEPTED** 边界阅读；软件播放、保存重开和 GPU 检查不能代替精度验收。0.3.18 的 float64 姿态读取修复后，原 **0.2 mm** 叶尖门槛仍为 **FAILED_GATE**，安装版抽样最大分量误差约 1.0613 mm；不能称科学精度已修复。原生多窗口修复以 owner scene 判断控制归属，Blender 同进程仍只有单一全局原生 player。

完整操作与排障见[用户手册](用户使用手册.md)，公开包软件证据见[0.3.18 发布核对](releases/0.3.18发布核对.md)，各版本范围见[发布状态](发布状态与验证范围.md)。[0.3.1 发布核对](0.3.1发布核对.md)保留旧版演示背景，不能作为当前安装或验收说明。
