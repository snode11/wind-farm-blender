# NREL 叶片缺陷编辑器

发布版本为 **0.3.42.1**（GitHub 标签 `v0.3.42.1`，Blender manifest 为 `0.3.42+1`）。安装与公开载荷身份以 `publication/daily-installation.json` 和发布交付记录为准。

适用于 Blender 5.2+ 的公开 NREL **0.3.42.1** 扩展；[下载专用 ZIP](https://github.com/snode11/wind-farm-blender/releases/download/v0.3.42.1/wfrl_blender-0.3.42+1.zip)，[按安装说明](INSTALL.md)手动安装并重启。当前源码入口为 [`wind-farm-rl-all-work`](https://github.com/snode11/wind-farm-blender/tree/wind-farm-rl-all-work)，开发机日常安装的版本、实际来源与验证范围见[统一发布状态](发布状态与验证范围.md)和[安装核对](../../publication/daily-installation.json)。当前公开包的身份与适用验证见[0.3.42.1 交付身份](../../publication/blender-0.3.42.1.json)；其他载荷的编辑器窗口证据不等于当前包或日常安装整套重新验收，叶尖显示门槛按工作区源码与安装载荷分别判定，源码通过不替代安装验收。

该编辑器把 GW184 的六类合成缺陷操作接入 NREL 5MW / MAPPO 柔性回放。先打开主前端的 **MAPPO · 60 秒**，在 **MAPPO** 侧栏的 **NREL 5MW · 叶片缺陷** 面板点击 **启动缺陷编辑器**；目标可以选择 T1、T2、T3 的任一叶片。缺陷尺寸、位置与形态是用户定义的合成参数，不代表现场实测损伤。

当前源码分支提供 `scripts/blender/打开NREL缺陷编辑器.command`、`scripts/blender/open_nrel_defect_editor.py` 和 `scripts/blender/nrel_defects.py`。公开安装用户可直接使用面板，无需运行这些项目脚本。后者提供 `edit`、`prepare`、`analyze`、`scan`、`images` 入口；证据模式要求明确输出目录，`images` 按显式请求采集图片。面板编辑与源码启动都复用保存的 MAPPO 结果，不运行求解器。

在完整源码工作区中，可双击 `scripts/blender/打开NREL缺陷编辑器.command`，或从仓库根目录运行以下命令，打开使用工作区源码的独立 Blender 窗口；这与已安装扩展来源不同：

```sh
blender --factory-startup --python scripts/blender/open_nrel_defect_editor.py
```

支持材质细裂纹、几何开口裂缝、凹坑、局部表面侵蚀、涂层剥落和雷击损伤。细裂纹与涂层剥落只有材质外观；开口裂缝、凹坑和侵蚀改变显示网格；雷击损伤组合烧蚀区域与凹坑，不模拟放电或内部损伤。

当前 ZIP 操作流程：

1. **选择缺陷。** 在“缺陷列表”直接点击条目，高亮项就是当前目标；条目显示风机、叶片和类型，勾选图标表示启用。新建时在“新建缺陷”中选择风机与类型，再点击“新建所选类型”。
2. **调整并预览。** 点击“编辑选中缺陷”后，常用位置、长度、宽度和适用的深度直接显示；方向角、边缘形态与种子位于默认折叠的“高级形态参数”。先选定风机和叶片，也可点击“在所选叶片上点选位置”。更改参数后点击“更新预览”。
3. **应用或取消。** “更新预览”只显示候选效果；“应用修改”将参数应用到场景，“取消编辑”恢复编辑前的完整状态及列表选择。0.3.42.1 编辑期间只暂停编辑器所属场景的播放，结束后恢复该场景的编辑前时刻；其他场景的播放不受影响。只有原播放窗口仍存在、仍显示该场景且没有其他播放任务时，才在原窗口恢复播放。
4. **观察效果。** 在“观察效果”中使用正面／斜侧近景或 C1／C2／C3 相机。“对比健康叶片”临时关闭目标叶片的全部缺陷；点击“返回缺陷效果”恢复，不改写提交配置。
5. **需要时保存。** 展开“配置文件”，设置 JSON 路径并点击“保存配置”。保存只包含已应用参数，不渲染图片。也可保存 `.blend` 后重开恢复 MAPPO 与缺陷状态；JSON 仍绑定 NREL 健康参考几何及参数化身份，不直接接受 GW184 配置，也不自动按叶长缩放旧位置。

已有缺陷仍支持启用／停用、删除、复制、撤销及重做；复制后自动选中新副本，副本默认停用。没有选中缺陷、正在编辑、健康对照或扫描期间，不适用的操作会置灰；状态提示说明下一步。分析与导出集中在默认折叠的“几何分析与导出（G / A）”，普通编辑无需展开。

编辑使用手动“更新预览”；点选定位仍需先选择风机和叶片，尚未加入自动识别目标或视口拖拽手柄。

缺陷显示网格、辅助轮廓与几何可见性支持区域使用同一份保存的柔性变换。时间跳转和反向寻址更新显示姿态，不重新执行 Boolean，也不修改 FAST.Farm / BeamDyn 的保存结果、材料刚度或净空测量。

0.3.42.1 中，使用 Blender 原生操作删除辅助轮廓不会删除缺陷配置；时间更新和显隐会跳过缺失标记，重新生成标记时按配置恢复。关闭编辑器会分别清理自有资源并保护共享数据。若资源释放失败，界面保留“关闭未完成”状态，可重试关闭；不把部分清理视为成功退出。

G 分析和扫描报告理想针孔相机下的投影与几何遮挡；`VISIBLE`、候选最佳帧、投影宽度或可见面积不证明图片中可辨识。扫描区间仅覆盖实际评估的离散时刻。材质外观仍需独立审核，保存配置与 G 分析不会自动渲染图片。

当前表面域排除根部过渡、示意叶尖和跨前后缘路径；缺失数据不能靠插值生成测量。编辑器不构成结构损伤、修复效果、硬件相机同步或现场检测性能的证据。

当前源码提供宿主 `blender_frontend/tests/test_nrel_defects.py` 与对应原生验证工具。可见性、保存重开和窗口扫描脚本用于独立验证，不是安装用户操作的前提。输入、显示与几何分析的证据适用范围见[模块验证](validation/NREL缺陷编辑器移植验证.md)、[编辑器包核对](releases/0.3.16发布核对.md)和[当前发布状态](发布状态与验证范围.md)；软件通过不替代材质辨识或物理精度验收。
