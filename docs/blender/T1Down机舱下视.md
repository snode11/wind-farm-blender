# T1/T2/T3 Down 机舱下视

本说明适用于公开扩展 **0.3.29**，包含 T1/T2/T3 Down 机舱下视与 NREL／rootkink 叶片外形选择。[下载专用 ZIP](https://github.com/snode11/wind-farm-blender/releases/download/v0.3.29/wfrl_blender-0.3.29.zip) 后手动安装并完全重启 Blender；包身份见[交付身份](../../publication/blender-0.3.29.json)，日常安装与适用验证见[安装核对](../../publication/daily-installation.json)。

## 使用

在已加载 MAPPO 的场景中点击 **T1 Down**、**T2 Down** 或 **T3 Down**，从对应风机机舱前部下方的中心线安装点正下观察叶片与塔筒。三台风机使用相同的挂点计算、光学预设和完整画框显示规则，各自保留独立相机。预设光轴严格沿机舱局部 −Z，塔筒方向位于画面上方；“正对塔筒”表示画面方向以塔筒为参照，不表示光轴穿过塔轴。固定光心和方向继承机舱偏航、塔顶运动与微小摆动，不随叶轮自转，不自动追踪叶片，也不锁定世界重力方向。参考取景使用 **rootkink** 叶片。

云台拖动改变观察方向，滚轮改变视场。普通云台操作和播放保留安装点；再次点击对应机组的 **Down** 或在该机组 Down 模式点击 **相机复位**，恢复该机组的安装位置、预设方向、视场和镜头偏移。切换观察相机保留回放时刻和所选叶片外形，不自动进入参考姿态；使用照片参考构图前，先在 **MAPPO → 叶片外形** 选择 **商用形制叶根拐点改型（rootkink）**。

已有挂载标记 `wfrl_gimbal_mount_revision=3` 的相机在载入时保留保存的位置、手动云台姿态和光学参数；需要使用表中预设时，显式点击对应机组 **Down** 或 **相机复位**。较早挂载的相机原位迁移，保留相机对象及其数据身份。

视口按完整相机画框适配侧栏以外的可见区域，框外使用遮罩；窗口内的取景缩放不改变光学视场或输出尺寸。近乎被面板遮满的视口可能受 Blender 最小缩放限制，需要扩大视口或收起侧栏。

“机舱相机”按钮使用独立的 `NacelleGimbal` 对象及 8 mm、59°×40°光学参数，具体限制见 [NREL 机舱相机](NREL机舱相机.md)。C1/C2/C3 共盒三相机也独立于各机组的 Down 相机。

## 安装与参数

Down 对象命名为 `WFRL.Camera.<机组>.Gimbal`，父级是同机组的 `WFRL.Turbine.<机组>.YawRoot`，其中 `<机组>` 为 T1、T2 或 T3。该坐标系以塔顶为原点，+X 顺风、−X 朝叶轮、+Y 横向、+Z 向上，长度单位为米。

每台风机分别使用当前场景中自身的实际机舱外壳计算安装点：在 YawRoot 坐标中，从 `(−3.8, 0, −5)` 沿 +Z 发射射线，将起点和方向转换到外壳局部坐标后求交。将命中点转换回 YawRoot 坐标，再加偏移 `(0, 0, −0.40)` m，得到固定光心。在标准 NREL 展示外壳下，名义挂点约为 `(−3.8, 0, 0.46256)` m，光心位于挂点正下方 **0.40 m**，处于机舱前部下方的中心线上。外壳缺失或安装射线没有交点时无法建立该机位。

| 参数 | 默认值 |
| --- | --- |
| 名义 YawRoot 局部位置 | 约 `(−3.8, 0, 0.06256)` m；实际位置由场景外壳网格求交决定 |
| 挂点到光心的 YawRoot 偏移 | `(0, 0, −0.40)` m |
| 水平朝向 yaw | 180° |
| 俯仰 pitch | −90°，光轴沿机舱局部 −Z |
| 光学滚转 roll | 180°，与 yaw 共同确定俯视画面方向 |
| 水平视场 | 110° |
| 传感器宽度／焦距 | 36 mm／约 12.60 mm |
| 镜头水平／垂直偏移 | 0.100／−0.070 |
| 近／远裁剪 | 0.05 m／30000 m |

三台风机采用相同的表内参数；实际局部位置由各自外壳确定，世界位置和朝向还包含各自风机的位置、偏航及塔顶运动。传感器采用水平适配，垂直视场随场景输出画幅而定。面板显示的世界坐标 Pan / Tilt 会包含当前机舱姿态，不必等于上表的局部预设。

## 模型与可见性要求

参考构图采用 rootkink 合成叶片与保存回放，观察正下方叶片及塔筒的位置关系。rootkink 的近根拐点位于距轮毂中心 **8.3333 m** 处，该站最大弦长为 **4.85 m**；宽叶根及其向叶身收窄的后缘轮廓是观察重点。预设保持机舱局部正下光轴，画面范围由视场和镜头偏移确定；叶片几何和保存运动保持各自定义。

rootkink 继续使用 NREL 保存的运动、载荷来源和雷达读数，不产生新机型的物理求解。参考照片只确定观察区域和构图目标，不要求逐像素复刻；该合成外形不是厂家 CAD，也不证明与照片中的实体叶片具有相同几何或物理性能。选择 NREL 外形时保留 NREL 几何，其粗根段和过渡轮廓不保证形成相同画面。

可见性检查分别判断正下光轴、塔筒的画面方向、参考位置入框、表面遮挡和画框裁切。[参考构图静态检查](../../outputs/down-reference-view/reference-checks.json)使用模块 `bl_ext.user_default.wfrl_blender` 的 **0.3.26** 载荷、rootkink 外形、T1/B1 保存运动与 **1920×1080** 画幅。局部光轴为 `(0, 0, −1)`；记录姿态的世界正下方向偏差约 0.273°，来自机舱和塔顶姿态。三个姿态的拐点参考位置均投影入框；在半径 8.3333 m 的最大弦长肩部附近，对后缘侧末端 15% 弦长区域各取 54 个面中心进行可见性采样。

| B1 相对垂直向下角度 | 保存运动时刻 | 后缘侧区域可见面中心 | 精确后缘中点 |
| --- | --- | --- | --- |
| −20° | 117.461559 s | 12 / 54 | 被本叶片自遮挡 |
| −15° | 117.537532 s | 23 / 54 | 被本叶片自遮挡 |
| −10° | 117.613465 s | 23 / 54 | 被本叶片自遮挡 |

区域中存在可见表面不等于精确后缘端点可见，也不证明该端点形成无遮挡的图像外轮廓。[参考图](../../outputs/down-reference-view/reference.png)采用 −15° 姿态；[安装点示意](../../outputs/down-reference-view/camera-mount.png)中的挂点、连线与光心仅为诊断标记，不表示实体支架。以上为安装版静态渲染与有限采样证据，不是原生窗口交互通过结论。

独立的[源码挂载间距检查](../../outputs/down-reference-view/mount-clearance/checks.json)使用 rootkink 保存柔性网格，在 117–177 s 内每机抽取 120 个保存时刻，共 360 个机组样本，未检出理想光心或挂点至光心的零半径线段与叶片相交。该结果不涵盖采样间的连续扫掠体、实体相机／支架体积或现场安装安全认证。

静态示例和有限角度检查只归属于实际记录的模型、机组、姿态、画幅及载荷。T2/T3 需按各自回放姿态检查，相同相机参数不保证相同遮挡关系。叶片旋转、变桨和柔性形变会改变入镜区域与遮挡，不能外推为全运动范围、完整叶片或根到尖连续无遮挡。近根封口、法兰、机舱、塔筒和叶片自身的遮挡均保留。

该安装表达仿真相机光心与展示外壳的位置关系，不包含实体支架设计、承载验证、现场镜头标定或安装验收。相机调整只影响观察画面，不修改雷达标定或同源重建图集。
