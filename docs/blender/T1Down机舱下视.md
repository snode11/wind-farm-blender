# T1/T2/T3 Down 机舱下视

本说明描述当前工作区的 Down 机位。公开附件、日常安装和源码使用各自载荷身份，见[发布状态与验证范围](发布状态与验证范围.md)。源码不会自动更新已安装扩展。

## 使用

MAPPO 场景的 **T1 Down／T2 Down／T3 Down** 使用对应机组的固定机舱相机。手动场景的 **Down 相机与叶片外形** 提供同样三个观察入口，并可显示 B1／B2／B3 叶片编号。编号是根据几何方位选择的标注，不是图像识别结果；叶片暂未入框时仍显示最接近观察方向的叶片编号。

Down 朝叶轮侧偏离机舱局部正下方向 7.5°，随各自机舱偏航和塔顶姿态运动，不随叶轮自转或追踪叶片，不锁定世界重力方向。固定支架在机舱底壳偏叶片后缘一侧，机舱、轮毂、塔筒和叶片的真实结构遮挡保留。

显式点击 Down 或对应 Down 模式的 **相机复位**，恢复安装位置与光学预设；切视图保留回放时刻和所选外形。有效保存挂载保留手动云台位置与镜头设置；挂载标记小于 5 时原位恢复当前预设，保留对象与镜头身份。视口适配完整画框，框外显示遮罩；视口缩放不改变镜头视场。

## 安装与光学参数

MAPPO 相机命名为 `WFRL.Camera.<机组>.Gimbal`，父级为同机组 `YawRoot`。手动相机通过当前条目的 `yaw_object` 定位，具有独立对象、镜头数据和场景归属；复制场景中的重命名相机及其编号对象按归属复用。

挂点计算在各自 YawRoot 坐标系进行：从 `(−3.5, −1.15, −5)` 沿 +Z 向实际机舱外壳发射射线，命中点转换回 YawRoot 后加 `(0, 0, −0.2151)` m，得到光心。该坐标系 +X 顺风、−X 朝叶轮、+Y 横向、+Z 向上。外壳缺失、归属不符或射线无交点时拒绝建立机位，失败构建清理自身资源。

| 参数 | 预设 |
| --- | --- |
| 挂点横向位置 | YawRoot 中 X = −3.5 m，Y = −1.15 m |
| 挂点到光心偏移 | `(0, 0, −0.2151)` m |
| yaw／pitch／roll | 181.2°／−82.5°／175.9° |
| 焦距 | 8 mm |
| 水平传感器宽度 | 约 16.4224 mm |
| 16:9 水平／垂直视场 | 约 91.4928°／60° |
| 镜头水平／垂直偏移 | 0／0 |
| 近／远裁剪 | 0.05 m／30000 m |

传感器按水平方向适配；改变画幅比例会改变垂直视场。面板世界 Pan／Tilt 包含机舱姿态，不必等于局部预设。独立 `NacelleGimbal` 的 8 mm、59°×40°参数和 C1/C2/C3 的光学参数分别维护，不继承 Down 的传感器尺寸或复位设置。

## 模型、导出与限制

手动场景默认 rootkink，可选 NREL。rootkink 网格沿叶根增加 5°上风方向展示倾斜，径向坐标保持不变；MAPPO 仍使用 NREL 保存运动、载荷和测量文件，不生成新机型的物理结果。冻结 T1 试验启用时锁定外形。

**所选 Down MP4** 便捷导出使用独立场景副本、所选机组转速与普通变桨速度，其他机组冻结；支持叶片编号。**T1 Down 视频** 后台作业使用最近确认的冻结试验，输出不带编号标注。两种入口的时间、依赖和失败恢复方式见[手动控制](风机手动控制.md)。

同样光学参数不保证三台机组具有相同遮挡关系。有限射线、静态入框或短片回归不代表完整叶片、整个旋转周期连续可见，也不代表实体相机标定、支架承载或现场安装验收。不得隐藏或缩小结构以制造可见性通过结论。
