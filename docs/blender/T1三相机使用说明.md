# NREL 5MW T1 三相机堆叠使用说明

更新日期：2026-10-02。本文适用于 **NREL 5MW / WFRL 0.3.13**，要求 Blender 5.2+。从 [0.3.13 发布页](https://github.com/snode11/wind-farm-blender/releases/tag/v0.3.13) 下载 `wfrl_blender-0.3.13.zip` 并通过 Install from Disk 安装；旧 0.3 系列发布页与安装包保留。

另一个 [GW184 0.4.0 发布页](https://github.com/snode11/wind-farm-blender/releases/tag/v0.4.0) 中的 `gw184_three_camera_defects-0.4.0.zip` 是独立解压运行的模型与缺陷编辑器，不能作为 NREL 扩展安装。其固定三相机、DTU/FFA 参考合成几何和六类缺陷见 [GW184 使用说明](GW184三相机与缺陷编辑器.md)；本文的 NREL 默认相机参数不适用于 GW184，缺陷编辑器也未加入 NREL。

NREL 0.3.13 已同步完整前端、雷达及构建资源源码，[对应标签](https://github.com/snode11/wind-farm-blender/tree/v0.3.13) 和 Source code 归档可独立构建扩展。以下启动命令仍加载已安装扩展，须先安装匹配 ZIP 并重启 Blender。GW184 完整实现继续随其独立 ZIP 提供。当前实际安装与窗口检查见 [0.3.13 发布核对](0.3.13发布核对.md)，各版本证据见[发布状态](发布状态与验证范围.md)。

加载 MAPPO · 60 秒后自动创建三台小相机和共用盒体。C1 在底层看叶根，C2 在中层看中段，C3 在顶层看叶尖。普通“加载 MAPPO”现在直接采用 927 连续覆盖布局：支架安装位置、盒体转向和 C1/C2/C3 视场均自动生成。盒体高 29 cm、宽 18 cm、深 10 cm，相机机身约 2.8 cm、光心间距 8 cm，均为可调整的初始假设。

## 默认三相机与启动

使用原有 `scripts/blender/run_wfrl_macos.sh` 命令启动，也会自动创建本节的默认三相机。主视图先显示 T1 总览，打开 **N 侧栏 → View → 三相机 → 三路对照** 即可查看。完整命令及实际验证见 [前端使用说明](../../前端readme.md)。

安装版可直接按上一段的界面步骤加载，无需额外启动器。完整本地工作区也可从仓库根目录运行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup --python scripts/blender/open_recommended_three_cameras.py
```

该脚本加载已安装扩展，停在第 1 帧 / 117 s，关闭轨迹和挠度辅助物，再打开三路窗口。原根目录 `.command` 快捷入口已不在本地工作区，不再作为操作前提。需要手动恢复布局时，在 View → 三相机 → 布局导入选择扩展中的 `assets/cameras/t1-three-camera-default.json`；JSON 不控制回放时刻和辅助显示。

这版取景以**同一片叶片从叶根到叶尖连续进入三路视场**为目标，不要求三等分，也不再使用中间有空缺的三个局部特写。相邻画面保留重叠，输出同步原图；拼接由后续算法负责。

| 相机 | 用于计算视场的叶长范围 | 画幅 |
| --- | --- | --- |
| C1 叶根 | 0–18 m | 1920×1080 |
| C2 中段 | 14–38 m | 1920×1080 |
| C3 叶尖 | 34–61.5 m | 1920×1080 |

这些是瞄准和包围范围，不是图像裁切线；透视会让画面包含额外的叶段。核对取景时同时检查完整入画和遮挡。原始模型里的根部连接件、机舱及叶片自身遮挡仍保留；视场连续不代表每个表面点都可见，也不等于拼接已经验证成功。

推荐支架基点在 T1 机舱局部坐标 `(1.000, -1.648761, 2.200)` m，盒体在支架末端转向 `-30°`，三个光心仍固定于同一个盒体。转动时叶片会经过并离开视场，推荐布局不自动追踪叶片。每次明确重新加载 MAPPO 场景时使用这套默认配置；在已有场景中播放、切换视图、重新打开相机面板不会重置用户调整。

## 使用

1. 更新后重启 Blender，加载 MAPPO 演示，以生成新场景。已经打开的旧场景不会自行变成新盒体。
2. 在 N 侧栏 → View → 三相机中，点击“贴合安装 / 调整整个盒体”。单击 T1 机舱外壳，支架安装端会对齐并接触所选表面，盒体位于支架外端。现有支架尺寸下，盒体背面离安装面约 27.4 cm。此时仍是预览：可重复选点，在同一侧栏调整“贴面旋转”和“盒体转向”，或点击对应左右 15° 按钮；Shift + 滚轮调整贴面旋转。盒体转向绕支架末端进行，支架安装端保持贴合；中键调整观察视图。点击“确认安装”或 Enter 提交，Esc / 右键 / “取消”恢复安装前的整套布局。选点时暂停回放。三台相机随盒体刚性移动和转动，保留各自相对盒体的方向和视场。会使盒体或支架穿入机舱的候选位置被拒绝。
   - “高级设置 · 自由坐标”默认折叠，其中的“整体 XYZ / 水平转向”用于特殊位置的自由调整，会解除表面贴合；日常安装不需要使用。
3. 再选择 C1、C2 或 C3，点击“调整俯仰角 / 方向与视场”，优先调整俯仰角；角度、视场与输出长边确认后生效，取消恢复原设置。光心不移动，另外两台参数不变。通过“三路对照”检查覆盖和遮挡。整盒移动和各相机修改均可撤销。
4. “三路对照”默认打开 2×2：C1/C2/C3 三路和静态安装示意。顶部可切到 C1 叶根 → C2 中段 → C3 叶尖的三列，各路显示同一仿真时钟。播放／暂停旁的“单步”暂停并同步前进一帧，末帧保持停止。顶部“流畅／高清”切换预览质量：流畅模式保留材质，降低预览分辨率与采样、关闭实时阴影及环境遮蔽；原图采集临时恢复打开窗口前的质量设置。主窗口临时使用实体预览，退出三路或关闭窗口后恢复。画幅仍为真实 16:9，允许留黑边。
   - “查看单路画面”和三路中的“放大 C1/C2/C3”固定采用轻量实体视图：保留材质颜色与动态回放，不运行实时材质光照，不显示画质切换按钮；侧栏不再提供“精确材质预览”入口。
   - 返回三路时恢复进入单路前的三路画质。单路模式不改相机位置、方向、视场和画幅，原图采集仍使用独立的原始画质设置。
5. “采集设置”选择当前时刻或时间序列，输出三路原图及相机内外参、时间戳和数据来源。默认 1920×1080；改变双 FOV 后按实际画幅输出。各路同刻采集，图像不含界面或视锥标记。
6. 布局 JSON 导入导出、相机撤销、取消采集继续可用。第四槽和四路观察入口已移除；旧四路 JSON 被拒绝，当前布局不会因拒绝而改变。

2026-09-29 的 0.3.12 轻量单路通过 118 项宿主机检查及安装版窗口切换、短时播放、暂停、视场与画质恢复检查，公开摘要见[当前发布状态](发布状态与验证范围.md)；原始本地记录为 `outputs/single-camera-lightweight-20260929/verification.json`，未随文档上传。该轮没有完整片段帧率验收或重新采集原图。升级安装后重启 Blender 生效。

2026-09-30 两包发布时保留原 NREL ZIP，并通过隔离安装和双束后台回归；该结果没有新增三相机完整片段帧率结论。本次文档同步仅补充操作及版本边界，没有重新执行窗口、采集、渲染或播放验收。

源码启动入口（在仓库目录运行）：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup --python scripts/blender/open_custom_cameras.py
```

可调参数示例：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup --python scripts/blender/open_stacked_cameras.py -- --center 2.30 -2.12 1.70 --spacing 0.08 --box-size 0.18 0.29 0.10 --box-yaw -45 --long-edge 1920
```

坐标和尺寸单位米，box-size 为宽、高、深。整体安装位置使用界面上的盒体按钮；盒体尺寸仍可通过启动参数生成。不要只拖动盒体 Empty。新版 JSON 同时记录盒体位置、完整方向、贴合面和相机参数，导入与撤销会一起恢复；兼容旧的仅水平朝向布局，导入前须已加载相同尺寸的盒体。

支架接触以点击处的局部切平面为基准；盒体和支架保持刚性，不会弯成机舱曲面。曲面处不代表安装端每一点均与外壳重合，也不是实体安装强度或接触面的工程验收。旧的背面贴合 JSON 保持原位置读入；再次使用“贴合安装”选点后采用支架外伸方式。

## 物理与输出范围

叶片运动、形变和环境复用现有仿真包，不重跑求解器，也不包含拼接算法。三个光心固定于机舱，不跟随叶轮旋转，不自动追踪叶片。第 1 帧 / 117 s 为参考姿态，默认方向与视场针对这一姿态生成，此后保持不变。普通入口和 927 推荐入口使用同一套相互重叠的连续取景。固定相机仍会有空画面，不保证全周期持续覆盖。整体移盒或自行修改相机后，需要重新检查取景与遮挡。

采用理想针孔模型，各路视场不同；真实镜头、玻璃折射、噪声和曝光尚未标定。保留机舱、连接件和叶片自身遮挡，视锥覆盖不等于完整表面可见或拼接算法验证通过。数据原有 REVIEW_ONLY 状态不变。

已启用匹配扩展且完整匹配数据可用时，打开保存的 MAPPO `.blend` 会恢复回放状态。0.3.13 对失效旧安装路径按保存的 manifest 哈希恢复匹配内置包；缺少扩展时只能查看静态快照，缺包或哈希不匹配时回放显示未就绪。保存与数据迁移规则见[用户手册](用户使用手册.md)第 8 节。新建动态场景可加载 MAPPO 或使用启动器。

连接后端的用户还需单独更新后端项目源码并重启 Bridge，才能使用已发布的 MPI/macOS 启动环境修复；安装 0.3.13 扩展 ZIP 不会更新服务器。离线三相机观察无需 Bridge，详细操作见 [前端使用说明](../../前端readme.md#10-连接后端与维护)。
