# T1 三相机堆叠使用说明

0.3.8。已替代四台独立相机工作流。

加载 MAPPO · 60 秒后自动创建三台小相机和共用盒体。C1 在底层看叶根，C2 在中层看中段，C3 在顶层看叶尖；相邻视野有重叠。盒体高 29 cm、宽 18 cm、深 10 cm，相机机身约 2.8 cm、光心间距 8 cm，均为可调整的初始假设。

## 使用

1. 更新后重启 Blender，加载 MAPPO 演示，以生成新场景。已经打开的旧场景不会自行变成新盒体。
2. 在 N 侧栏 → View → 三相机中，先用“在机舱上选择位置”安装整个盒体；可中键调整视图，单击 T1 机舱外壳提交，Esc / 右键取消。也可用“整体 XYZ / 盒体朝向”精确输入，三台相机一起移动。选点时暂停回放。
3. 再选择 C1、C2 或 C3，点击“调整俯仰角 / 方向与视场”，优先调整俯仰角；角度、视场与输出长边确认后生效，取消恢复原设置。光心不移动，另外两台参数不变。通过“三路对照”检查覆盖和遮挡。整盒移动和各相机修改均可撤销。
4. “采集设置”选择当前时刻或时间序列，输出三路原图及相机内外参、时间戳和数据来源。默认 1920×1080；改变双 FOV 后按实际画幅输出。各路同刻采集，图像不含界面或视锥标记。
5. 布局 JSON 导入导出、相机撤销、取消采集继续可用。第四槽和四路观察入口已移除；旧四路 JSON 被拒绝，当前布局不会因拒绝而改变。

源码启动入口（在仓库目录运行）：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup --python scripts/blender/open_custom_cameras.py
```

可调参数示例：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup --python scripts/blender/open_stacked_cameras.py -- --center 2.30 -2.12 1.70 --spacing 0.08 --box-size 0.18 0.29 0.10 --box-yaw -45 --long-edge 1920
```

坐标和尺寸单位米，box-size 为宽、高、深。整体安装位置使用界面上的盒体按钮；盒体尺寸仍可通过启动参数生成。不要只拖动盒体 Empty。新版 JSON 同时记录盒体位置和相机参数，导入与撤销会一起恢复；导入前须已加载相同尺寸的盒体。

## 物理与输出范围

叶片运动、形变和环境复用现有仿真包，不重跑求解器，也不包含拼接算法。三个光心固定于机舱，不跟随叶轮旋转，不自动追踪叶片。第 1 帧 / 117 s 为参考姿态，默认视场针对这一姿态生成，不能保证整个转动周期一直完整覆盖。

采用理想针孔模型，各路视场不同；真实镜头、玻璃折射、噪声和曝光尚未标定。保留机舱、连接件和叶片自身遮挡，视锥覆盖不等于完整表面可见或拼接算法验证通过。数据原有 REVIEW_ONLY 状态不变。

仅打开保存的 .blend 为静态参考快照；动态回放请加载 MAPPO 或使用启动器。
