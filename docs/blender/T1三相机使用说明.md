# NREL 5MW T1 三相机堆叠使用说明

适用于 Blender **5.2+** 的公开 NREL **0.3.40**；[下载专用扩展 ZIP](https://github.com/snode11/wind-farm-blender/releases/download/v0.3.40/wfrl_blender-0.3.40.zip)，使用 Install from Disk 安装并重启。当前源码入口为 [`wind-farm-rl-all-work`](https://github.com/snode11/wind-farm-blender/tree/wind-farm-rl-all-work)，Release 标签自动 Source code 不能代替安装包。

开发机日常安装的实际模块为 `bl_ext.user_default.wfrl_blender`，当前版本、文件身份与验证范围见[统一发布状态](发布状态与验证范围.md)和[安装核对](../../publication/daily-installation.json)。公开 0.3.22 的隔离安装、默认三相机与原生投影检查见[交付身份](../../publication/blender-0.3.22.json)，不能作为其他日常安装载荷的完整窗口或性能复测。软件与原生脚本窗口证据按实际载荷分别引用。升级扩展后须重启 Blender。

[GW184 0.4.0](GW184三相机与缺陷编辑器.md)是独立合成刚性模型及固定三相机；NREL [六类缺陷编辑器](NREL缺陷编辑器.md)随九片叶片的保存柔性运动。两套相机参数和缺陷 JSON 不直接互用。

要观看 MAPPO 与两相机已求解重建的同步对照，在 **MAPPO → 打开几何重建示例…** 打开内置便携场景，再用 **切换到同源纹理对照** 查看 601 样本保存纹理；该例使用 T1 Down 与机舱图像，不是本文叶根/中段/叶尖三摄的新求解或拼接结果。用法见[前端说明](../../前端readme.md)。

加载 MAPPO · 60 秒后自动创建三台小相机和共用盒体。C1 在底层看叶根，C2 在中层看中段，C3 在顶层看叶尖。“加载 MAPPO”采用连续重叠布局：支架安装位置、盒体转向和 C1/C2/C3 视场均自动生成。盒体高 29 cm、宽 18 cm、深 10 cm，相机机身约 2.8 cm、光心间距 8 cm，均为可调整的初始假设。

## 默认三相机与启动

使用原有 `scripts/blender/run_wfrl_macos.sh` 命令启动，也会自动创建本节的默认三相机。主视图先显示 T1 总览，打开 **N 侧栏 → View → 三相机 → 三路对照** 即可查看。完整命令及实际验证见 [前端使用说明](../../前端readme.md)。

安装版可直接按上一段的界面步骤加载，无需额外启动器。完整本地工作区也可从仓库根目录运行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup --python scripts/blender/open_recommended_three_cameras.py
```

该脚本加载已安装扩展，停在第 1 帧 / 117 s，关闭轨迹和挠度辅助物，再打开三路窗口。需要恢复默认安装和取景时，在 **N → View → 三相机 · T1 · 研发 → 1 安装整个盒体** 点击 **恢复默认三相机**；也可通过布局导入读取扩展中的 `assets/cameras/t1-three-camera-default.json`。

**恢复默认三相机** 恢复随包默认 JSON 中的整盒位置、朝向与 C1/C2/C3 相对位置、方向、视场和输出参数，支持相机专用撤销，保留当前帧、子帧和自由观察视角。已是默认配置时不新增撤销记录。预览修改、采集、选点安装或等待后端暂停期间不可复位，应先结束相应操作；没有三相机盒体时先加载 MAPPO。复位后仍可正常退出单路观察。

取景以**同一片叶片从叶根到叶尖连续进入三路视场**为目标，不要求三等分。相邻画面保留重叠，输出同步原图；拼接由后续算法负责。

| 相机 | 用于计算视场的叶长范围 | 画幅 |
| --- | --- | --- |
| C1 叶根 | 0–18 m | 1920×1080 |
| C2 中段 | 14–38 m | 1920×1080 |
| C3 叶尖 | 34–61.5 m | 1920×1080 |

这些是瞄准和包围范围，不是图像裁切线；透视会让画面包含额外的叶段。核对取景时同时检查完整入画和遮挡。原始模型里的根部连接件、机舱及叶片自身遮挡仍保留；视场连续不代表每个表面点都可见，也不等于拼接已经验证成功。

推荐支架基点在 T1 机舱局部坐标 `(1.000, -1.648761, 2.200)` m，盒体在支架末端转向 `-30°`，三个光心仍固定于同一个盒体。转动时叶片会经过并离开视场，推荐布局不自动追踪叶片。每次明确重新加载 MAPPO 场景时使用这套默认配置；在已有场景中播放、切换视图、重新打开相机面板不会重置用户调整。

## 使用

1. 安装或更新后重启 Blender，加载 MAPPO 生成场景与默认三相机。
2. 在 N 侧栏 → View → 三相机中，点击“贴合安装 / 调整整个盒体”。单击 T1 机舱外壳，支架安装端会对齐并接触所选表面，盒体位于支架外端。现有支架尺寸下，盒体背面离安装面约 27.4 cm。此时仍是预览：可重复选点，在同一侧栏调整“贴面旋转”和“盒体转向”，或点击对应左右 15° 按钮；Shift + 滚轮调整贴面旋转。盒体转向绕支架末端进行，支架安装端保持贴合；中键调整观察视图。点击“确认安装”或 Enter 提交，Esc / 右键 / “取消”恢复安装前的整套布局。选点时暂停回放。三台相机随盒体刚性移动和转动，保留各自相对盒体的方向和视场。会使盒体或支架穿入机舱的候选位置被拒绝。
   - “高级设置 · 自由坐标”默认折叠，其中的“整体 XYZ / 水平转向”用于特殊位置的自由调整，会解除表面贴合；日常安装不需要使用。
   - 同一区域的“恢复默认三相机”将整盒与三路取景一起恢复为随包默认值，保留当前回放时刻和自由视角；复位后可用相机撤销恢复复位前布局。
3. 再选择 C1、C2 或 C3，点击“调整俯仰角 / 方向与视场”，优先调整俯仰角；角度、视场与输出长边确认后生效，取消恢复原设置。光心不移动，另外两台参数不变。通过“三路对照”检查覆盖和遮挡。整盒移动和各相机修改均可撤销。
4. “三路对照”默认打开 2×2：C1/C2/C3 三路和静态安装示意。顶部可切到 C1 叶根 → C2 中段 → C3 叶尖的三列，各路显示同一仿真时钟。播放／暂停旁的“单步”暂停并同步前进一帧，末帧保持停止。顶部“流畅／高清”切换预览质量：流畅模式保留材质，降低预览分辨率与采样、关闭实时阴影及环境遮蔽；原图采集临时恢复打开窗口前的质量设置。主窗口临时使用实体预览，退出三路或关闭窗口后恢复。观察窗口不绘制画幅外遮罩或画幅边界，周围场景保持可见；原图采集仍按各路真实 FOV 和画幅输出。
   - “查看单路画面”和三路中的“放大 C1/C2/C3”固定采用轻量实体视图：保留材质颜色与动态回放，不运行实时材质光照，不显示画质切换按钮；原生观察不使用逐帧 PNG 预览。
   - 返回三路时恢复进入单路前的三路画质。单路模式不改相机位置、方向、视场和画幅，原图采集仍使用独立的原始画质设置。
5. “采集设置”选择当前时刻或时间序列，输出三路原图及相机内外参、时间戳和数据来源。默认 1920×1080；改变双 FOV 后按实际画幅输出。各路同刻采集，图像不含界面或视锥标记。
6. 布局 JSON 导入导出、相机撤销、取消采集继续可用。只接受三路布局；四路 JSON 被拒绝且保持当前布局。

**观察与保存**：主窗口切换 Down、总览或其他机组不改变三路观察各自的镜头绑定。观察期间保存 `.blend` 使用打开观察前的画质和真实 C1/C2/C3 相机，不保存临时代理；保存成功或文件写入失败后恢复当前观察质量及自由视角。原生撤销会关闭观察并恢复所属场景设置，之后可重新打开三路。

**片尾与重开**：单路播放到片尾停止后，关闭观察并打开三路会保留终帧；点击播放从起点重播，三路共用同一时钟，到片尾再次停止。中途关闭保留当前时刻和播放状态。延迟停止或续播请求在用户启动新播放、暂停或加载后失效。0.3.30 载荷的连续路径检查见[对应验证报告](../../publication/blender-0.3.30/verification.json)，该范围不转记为当前包的独立复验。日常安装的实际来源与启动范围见[安装核对](../../publication/daily-installation.json)。

**槽位与采集一致性**：C1/C2/C3 按固定槽位寻址，缺少 C2 时拒绝 C2 操作及不完整三路分析，C3 保持第三路身份。采集核对原生／评估相机姿态、父级逆矩阵、约束、镜头与裁剪；非有限值或原生修改中断采集并保留用户修改。回放时刻与播放状态未被外部操作改变时，完成、取消或异常中断均恢复采集前的回放状态；外部寻址、播放或暂停会中断采集并保留当前状态。GPU target 在事务内按输出尺寸复用；对照证据不构成播放 FPS 或整套无泄漏验收。

**观察异常清理**：在代理或镜头损坏时分别释放临时资源、恢复主视口和画质，错误显示于三相机面板，成功重开后清除；关闭及延迟恢复不取消另一场景的播放。公开包与本地日常载荷的原生验证分别按[发布状态](发布状态与验证范围.md)读取。

**场景与对象保护**：加载 `.blend` 后和模块重载后保留相机失效回调，避免复用过期预览。布局提交、恢复默认与清理在修改前核对相机 Object 的归属：被其他 Scene 引用（包括时间线相机标记）或被非所属／无法确认归属的局部相机视口引用时拒绝操作。独立相机 Object 可共享同一 Camera 数据，保留共享数据名称、身份与光学参数。该行为包含于 0.3.40 发布源码与扩展，适用范围见[源码验证](发布状态与验证范围.md#源码软件合同与验证)；日常 0.3.40 工作区构建按独立身份记录使用；[维护说明](../../blender_frontend/README.md)给出完整合同。

**编辑预览画幅**：当前日常工作区构建按所属场景的播放状态选择画质与提示。宽／高画幅保留完整 FOV，必要时增加预览长边使短边至少 16 像素，仍须满足 GPU 尺寸上限；正式采集尺寸与原画质不受预览预算影响。此行为按[日常安装身份](../../publication/daily-installation.json)核对。

源码启动入口（在仓库目录运行）：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup --python scripts/blender/open_custom_cameras.py
```

可调参数示例：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup --python scripts/blender/open_stacked_cameras.py -- --center 2.30 -2.12 1.70 --spacing 0.08 --box-size 0.18 0.29 0.10 --box-yaw -45 --long-edge 1920
```

坐标和尺寸单位米，box-size 为宽、高、深。整体安装位置使用界面上的盒体按钮；盒体尺寸仍可通过启动参数生成。不要只拖动盒体 Empty。布局 JSON 同时记录盒体位置、完整方向、贴合面和相机参数，导入与撤销会一起恢复；兼容旧的仅水平朝向布局，导入前须已加载相同尺寸的盒体。

支架接触以点击处的局部切平面为基准；盒体和支架保持刚性，不会弯成机舱曲面。曲面处不代表安装端每一点均与外壳重合，也不是实体安装强度或接触面的工程验收。兼容布局按其保存位置读入；显式“贴合安装”使用支架安装端贴合约束。

## 物理与输出范围

叶片运动、形变和环境复用现有仿真包，不重跑求解器，也不包含拼接算法。三个光心固定于机舱，不跟随叶轮旋转，不自动追踪叶片。第 1 帧 / 117 s 为参考姿态，默认方向与视场针对这一姿态生成，此后保持不变。普通加载与推荐相机启动入口使用同一套相互重叠的连续取景。固定相机仍会有空画面，不保证全周期持续覆盖。整体移盒或自行修改相机后，需要重新检查取景与遮挡。

采用理想针孔模型，各路视场不同；真实镜头、玻璃折射、噪声和曝光尚未标定。保留机舱、连接件和叶片自身遮挡，视锥覆盖不等于完整表面可见或拼接算法验证通过。数据原有 REVIEW_ONLY 状态不变。

已启用匹配扩展且完整匹配数据可用时，打开保存的 MAPPO `.blend` 会恢复回放状态。对失效安装路径按保存的 manifest 哈希恢复匹配内置包；缺少扩展时只能查看静态快照，缺包或哈希不匹配时回放显示未就绪。保存与数据迁移规则见[用户手册](用户使用手册.md)第 8 节。新建动态场景可加载 MAPPO 或使用启动器。

连接后端的用户还需单独同步匹配的后端项目源码并重启 Bridge；安装扩展 ZIP 不会更新服务器。当前工作区的 `state_revision` 恢复语义需要匹配前端与 Bridge，认领新后端身份须显式确认且不停止旧任务。离线三相机观察无需 Bridge，详细操作见[前端使用说明](../../前端readme.md#10-连接后端与维护)。
