# X100 安装覆盖、材料采样与叶片估计

本文描述工作区源码的面积材料采样、有限安装搜索和叶片关联／连续估计，三项由 0.3.42.5 扩展及配套源码提供，日常安装使用 0.3.42.4。离线工具使用已有同源 FarmFlex 运动，不启动训练或求解。通用来源、点云和记录操作见[X100雷达](X100雷达.md)，保存的数值与画布证据见[研究验证](发布状态与验证范围.md#x100-观测研究工作区验证)；几何研究结果不作为厂家精度或现场保护结论。

## 界面操作

1. 加载所属场景的风场柔性回放，在 **N → X100 → 几何仿真 → 配置** 设置安装与采样预算，点击“应用配置”。复现保留的叶片评价使用2048候选点。
2. 需要应用离线搜索结果时，在 **配置 → 安装覆盖搜索** 选择与当前几何来源匹配的报告，再点“应用搜索推荐安装”；预算和场景时刻保留。
3. 在 **叶片关联与估计** 启用研究模型，查看三叶状态；通过 **显示 → 打开点云窗口 → 5／机舱XZ** 查看彩色拟合段和有支持的叶尖十字。

预算编辑在下一新源样本生效；暂停状态需要点击“应用配置”重新建立观测，或推进到下一源样本。文件回放和实时设备模式不提供这层模型估计；记录目录不保存该派生上下文。

## 安装覆盖搜索

从项目 Git 根执行：

```bash
/Applications/Blender.app/Contents/MacOS/Blender \
  --background --factory-startup --python-exit-code 1 \
  --python scripts/radar_x100/optimize_mount.py -- \
  --output /path/to/new-search.json
```

默认在原安装位置、机舱侧面位置比较 XYZ 安装角，包含两个现有预设作为对照；扫描 roll=0°、pitch=60°／75°／82.5°／90°、yaw=150°／180°／210°，去重后共25种安装。`--location x y z` 可重复提供额外允许位置，`--roll`、`--pitch`、`--yaw` 指定有限角度集合，最多256个候选。机械安装、相位中心与电磁可行性须独立确认。

默认按1024／2048候选点、100／101／102三个种子分别评价。整个源区间逐一枚举30 Hz网格；名义下方经过以转子角180°±30°及三叶偏移定义，仅完整经过参与主评分。每帧至少3个展向归一化位置≥0.8的可见观测点才记为有支持。阈值分别由 `--budgets`、`--seeds`、`--minimum-points`、`--distal-span`、`--half-window-deg` 明确配置。

排序依次考虑所有配置中最差的单叶片支持比例、最差完整经过比例、最长连续缺口、平均支持比例和遮挡比例。它评价有限候选中的观测覆盖；不推定全局最优、叶尖可辨识性或安全合格。UNKNOWN不作为缺测零值，零分母保持N/A；存在UNKNOWN、缺少三叶完整经过或最差支持比例为零时，没有可应用推荐。

JSON保留每种安装、每组采样配置、各叶片／经过分母、连续缺口、源身份、材料计划与代码摘要。输出文件必须不存在。来源、几何及采样算法匹配后，在 **N → X100 → 配置 → 安装覆盖搜索** 选择报告，点击“应用搜索推荐安装”。应用保留场景时刻与当前采样预算，预算可在配置面板单独设置；相机采集、记录或共享安装占用按原安装切换约束处理。

复现当前叶片评价时，在配置面板将采样预算设为 **2048**。界面初始预算为512，导入安装不会自动提高预算；[预算对照结果](../../outputs/x100-observation-research/search-area.json)中，该预算的部分种子／叶片缺少足够远端点，不能沿用1024／2048搜索报告中的支持比例。

## 面积材料采样

`AREA` 以源起点表面的三角面积作为采样权重，使用随机平移Halton序列确定三角面及面内重心坐标。相同种子的小预算是大预算的前缀，便于核对预算敏感性。坐标固定在材料上，位置和速度差分均运输同一组点，源参考几何不随安装位置改变。

面细分不会按三角面数量增加区域采样概率，但有限点预算仍可能漏掉细小区域。不同三角化下不保证逐点完全重合，应比较区域覆盖和统计稳定性。`CENTROID` 是显式质心对照模式，不作为默认观测模型。材料计划摘要、算法、参考时刻、种子、预算及输出点索引随帧保留；三角面索引不单独构成唯一材料点身份。

几何点继续经过名义视场与首交遮挡筛选。面积采样不模拟RCS、SNR、散射概率、天线方向图或实际chirp过程，未知属性保持缺失。

## 叶片关联与连续估计

**N → X100 → 叶片关联与估计** 提供开关、三叶状态、支持点数、拟合残差、外推距离及有支持时的模型估计塔距，开关默认启用。点云窗口按 **5** 进入机舱XZ，可见候选拟合段；有支持的模型叶尖以十字标记表示。B1／B2／B3分别使用橙／蓝／黄；拟合段存在不代表叶尖已满足外推和稳定性条件。

推理输入为当前观测点、同刻塔筒侧壁、已声明的三叶根部姿态及名义叶尖径向坐标。Blender 先验以轮毂中心为原点、根部方向为坐标轴，末端局部Z取结构参数 `TipRad`。逻辑叶片编号来自根部姿态先验，观测关联不读取真实材料ID、仿真叶片标签、变形叶尖或位移通道。无相应标定／姿态上下文的历史记录和实时设备输入不提供这层估计。

候选点须在唯一叶片走廊内，排除已知塔面附近点；此筛选只影响派生估计，原始点云、原索引和侧壁距离诊断完整保留。展向分箱中位数经稳健二次曲线拟合，得到观测支持的局部叶片段；名义叶尖径向坐标截面的外推满足条件才输出模型叶尖。

| 研究参数 | 默认值 |
| --- | --- |
| 叶片走廊 | 根部局部Z为名义叶尖径向坐标的0.55～1.03；横向半径≤10 m |
| 已知塔面排除带 | 距离≤0.15 m |
| 最少点数／有效跨度分箱 | 8点／4箱；总分箱10 |
| 最少观测展向跨度 | 名义叶尖径向坐标的18% |
| 最大叶尖外推距离 | 名义叶尖径向坐标的6% |
| 最大拟合残差／拟合离散度 | 0.8 m／1 m |
| 局部平滑时间常数／最大连续间隔 | 0.10 s／0.20 s |

上述参数定义于 `tracking.FitConfig`，是研究配置。塔面附近的真实叶片点也可能被排除；点数不足、关联不清、外推过远或拟合不稳定时只显示拒绝状态，不能解释为安全。当前模型从表面观测拟合名义叶尖径向坐标截面，不能保证恢复结构参考轴或实际三维叶尖；拟合离散度不是物理误差或标定置信区间。

连续估计仅平滑根部局部坐标中的横向分量，旋转使用当前姿态；重复帧不重复更新，后退、换来源及长间隔清除历史。当前帧拒绝时不显示上次叶尖或净空。估计层故障不撤回合法原始观测，结果不写入原始记录，也不作为硬件Track流。

估计在会话主线程更新中按新配对帧派生，不依赖点云窗口是否打开；关闭估计开关清除派生结果和历史。窗口只绘制已有结果，不在draw中进行采样、塔面查询或拟合。

## 独立评价

```bash
/Applications/Blender.app/Contents/MacOS/Blender \
  --background --factory-startup --python-exit-code 1 \
  --python scripts/radar_x100/evaluate_blades.py -- \
  --output /path/to/new-evaluation.json \
  --search-report /path/to/new-search.json \
  --candidates 2048
```

省略 `--search-report` 使用原安装预设。评价在完整30 Hz网格运行因果估计，再从独立保存的结构材料点计算叶尖误差和塔距误差；材料标签只在评价端核对关联正确率。报告保留三叶完整名义经过的N、支持比例、拒绝原因、关联分母、平均／p95／最大误差、未知项、安装及代码身份。未满足估计条件的帧保留在覆盖分母中，不以已有估计插值补齐。

软件检查覆盖面积度量、网格细分、预算前缀、材料速度、解析曲线估计、背景／关联拒绝、时间回退、安装来源与回滚。真实窗口绘制、完整源实验、实机精度和持续性能分别判断。同源几何评价可以检查研究模型的局限，不能代替独立场景或真实设备验证。
