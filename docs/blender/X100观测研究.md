# X100 安装覆盖、材料采样与叶片估计

0.5.1 扩展提供固定面积材料采样、报告导入和有拒绝条件的叶片关联／连续估计。有限安装搜索及独立评价工具通过配套源码运行，使用已有同源 FarmFlex 运动。通用来源、点云和记录操作见[X100 雷达](X100雷达.md)。保存的数值和画布证据见[研究验证](发布状态与验证范围.md#x100-观测研究工作区验证)。几何研究结果仅适用于记录的研究配置。

## 界面操作

1. 加载所属场景的风场柔性回放，在 **N → X100 → 仿真 → 配置** 选择GEOMETRY或DETECTIONS并设置安装，点击“应用配置”。GEOMETRY默认512候选点，复现保留的几何叶片评价使用2048；DETECTIONS固定16384积分点、最多4096输出点。
2. 在 **配置 → 安装覆盖搜索** 选择与当前几何来源、安装包络和机械筛选要求匹配的 `.summary.json`，或不超过 16 MiB 的完整报告，再点“应用搜索推荐安装”。预算和场景时刻保留。
3. 在 **叶片关联与估计** 启用研究模型，查看三叶状态；通过 **显示 → 打开点云窗口 → 5／机舱XZ** 查看彩色拟合段和有支持的叶尖十字。

预算编辑在下一新源样本生效；暂停状态需要点击“应用配置”重新建立观测，或推进到下一源样本。GEOMETRY估计需要当前同源场景上下文；DETECTIONS目录回放可显示与原帧摘要匹配的已记录净空结果，不借当前场景重新推理。实时设备模式尚不提供这层估计，记录不保存塔面或形状先验等推理上下文。

## 安装覆盖搜索

从项目 Git 根执行：

```bash
/Applications/Blender.app/Contents/MacOS/Blender \
  --background --factory-startup --python-exit-code 1 \
  --python scripts/radar_x100/optimize_mount.py -- \
  --output /path/to/new-search.json
```

工作区工具将逐帧研究证据写入 `new-search.json`。存在可应用推荐时，另写 `new-search.summary.json`，保留所有候选的排名依据、来源及机械筛选要求，并记录完整报告的文件名和 SHA-256。请使用未被占用的输出文件名。摘要写出失败时，已提交的完整报告保留，命令报告失败及完整报告路径。

搜索将任务专属目录打印为 `X100_SEARCH_CHECKPOINTS`。目录中的 `metadata.json` 记录来源、筛选设置和候选顺序，每个完成的候选原子写入单独的 `candidate-NNN.json`。排名使用候选的筛选与评分字段，最终报告按排名逐个读取并写入候选的完整证据。失败或中断时可读取已完成的候选，完整交付成功后清理检查点。检查点供诊断和研究核对。

已有完整 v2 报告且缺少摘要时，从仓库根用安装了 NumPy 的 Python 提取。

```bash
python3 scripts/radar_x100/extract_mount_summary.py /path/to/new-search.json
```

默认写入相邻的 `new-search.summary.json`，也可用 `--output` 指定新路径。提取只读取原报告，核对当前机械筛选要求和候选排名，摘要须在 16 MiB 内。当前包络或机械筛选要求不符时，按诊断重跑安装搜索。

候选由 [scene.py](../../blender_frontend/wfrl_blender/radar_x100/scene.py) 的 `installation_catalog()` 按绑定机舱外壳生成，包含原位、前部下视、侧面和尾部下视基准。有限搜索在前部、前部内侧、尾部三个纵向锚点，默认横向偏移0／±1／±2 m、壳底下移0.25／0.50 m，组合下视法向的纵向／横向倾角 `(0,0)`、`(10,0)`、`(14,0)`、`(20,0)`、`(14,-10)`、`(14,10)`、`(0,-20)`、`(0,20)` 度；最终保存转换后的XYZ欧拉角。`--lateral-offsets`、重复的 `--tilt` 可限定集合，倾角绝对值不超过20°。14°仅是代码声明的同行示意图搜索种子，不是X100安装要求。

`--location x y z` 可重复增加位置，仅这些额外位置使用 `--roll`／`--pitch`／`--yaw` 的XYZ扫描，默认0°／70、76、90°／180°。候选按位置和实际旋转矩阵去重，等价欧拉角只保留首项，基准候选优先，最多256个；`--candidate-ids` 可选显式子集。`--passages-per-blade` 为正时只评价各叶最前若干完整经过，报告标为筛选用途，`winner_id=null`，不能直接应用；默认0评价全部完整经过。

| 基准 | 机舱局部位置与方向 |
| --- | --- |
| `ORIGINAL` | 保留 `(-3.5, -1.7, -2.0) m`、XYZ `(0°, 82.5°, 180°)` 作对照；按外壳中点和轮毂位置判断是否位于朝叶轮的前半部，不等于前端板安装批准 |
| `NACELLE_FRONT_DOWN` | X 保留 −3.5 m，Y 取外壳中心，Z 在外壳底部下方 0.50 m；采用原位朝向 |
| `NACELLE_SIDE` | 负 Y 侧壁外移“旋转后包络沿法向半径 + 0.04 m”，XYZ `(0°, 0°, −100°)` |
| `NACELLE_REAR_DOWN` | 从背离叶轮的一端向内退 0.50 m，Y 取外壳中心，Z 在底部下方 0.50 m；XYZ `(0°, 90°, 180°)` |

原位评估和各候选的通过／拒绝状态均保留，不能因为是既有位置就跳过约束。界面的快捷切换仍只有原位／侧面，前部和尾部下视属于离线搜索候选。

### 机械约束与来源

[installation.py](../../wfrl/radar_x100/installation.py) 的 `MechanicalPolicy` 和 `profile_metadata()` 保存数值及依据：

| 参数／约束 | 数值或规则 | 依据与限制 |
| --- | --- | --- |
| 安装单元 W×H×D | 0.173×0.2025×0.1756 m（外壳连支架） | 用户提供的现场安装尺寸。手册雷达本体 H×W×D 为 0.120×0.095×0.040 m（PDF 第 5 页） |
| 包络轴与原点 | X=深、Y=宽、Z=高；包络中心位于传感器原点 | `RESEARCH_ASSUMPTION`；厂家相位中心与轴向图尚缺 |
| `service_clearance_m` | 0.02 m | `RESEARCH_ASSUMPTION`，外壳外服务空间 |
| `maximum_bracket_reach_m` | 0.75 m | `RESEARCH_ASSUMPTION`，安装中心到壳面的最大支架距离 |
| `motion_clearance_m` | 0.10 m | `RESEARCH_ASSUMPTION`，运动净空阈值 |
| `rear_inset_m`、`underside_drop_m` | 各 0.50 m | `RESEARCH_ASSUMPTION`，尾部内退与下视安装下移 |
| 固定方式／开孔 | 螺栓固定；仅外部安装，不假定开孔 | 固定方式引用同手册第 5 页；孔距、线缆包络和支架 CAD 缺失 |

静态检查用旋转后的安装单元包围盒与机舱 AABB 的分离判定外置与空间，检查支架距离，并用包住硬件角域的保守圆锥判断无需开孔的出射；该圆锥不是天线增益模型。运动检查在完整 30 Hz 源网格，以安装单元／服务空间包围球检查同刻叶片和塔筒的距离及中心包含关系。任意失败为 REJECTED，未知时刻保留 UNKNOWN；离散帧之间的运动未验证。外壳来源标为展示几何而非厂家 CAD，`physical_installation_approved=False`；通过只记 `PASS_RESEARCH`。

`point_inside_closed_mesh()` 要求闭合且相邻面绕序一致，边、顶点及面上的点计为包含；开放或绕序不一致的网格拒绝用于该判定。零宽裁剪保留线段／点，退化三角面仍按其线段／点计算距离。无效外壳边界拒绝，缺失或非有限运动距离保持未知，不能成为 `PASS_RESEARCH`。

### 检测主指标与几何辅助指标

**主指标是完整叶片经过期间的模拟检测支持。** `passage_detection_support.metric` 为 `DISTAL_ROI_PASSAGE_DETECTIONS.v1`。名义经过由保存转子方位180°±30°及三叶偏移定义；默认在完整30 Hz源网格中选取全部完整经过，截断经过不参与主评分。它不是实测叶片识别区间，也不表示最小净空一定发生在正下方。

| 指标 | 口径 |
| --- | --- |
| 末段ROI检测支持率 | 每个完整经过的期望网格帧为分母；机舱ROI内至少 `--detection-min-points` 个非纯噪声检测才支持，默认1个。分别保留逐经过、逐叶及最差比例 |
| 最长连续漏检 | 已知而不满足点数门槛的连续网格帧数／30，单位秒；经过边界、非相邻时刻及UNKNOWN都打断连续段，UNKNOWN不变成已知漏检 |
| 精确正下方支持 | 在插值确定的180°穿越时刻另行采样，不能用最近网格帧替代；逐经过保留时刻与支持状态 |
| 塔距误差 | ROI内非纯噪声检测点到同刻塔筒侧壁的最小距离，减去该叶片远端表面经ROI／展向裁剪后到塔面的最小距离。误差仅统计有支持且有真值的帧，报告bias、MAE、RMSE；无远端表面时标 `NO_DISTAL_SURFACE_IN_ROI`，不补零 |

ROI内非纯噪声返回可能来自塔架或合并背景，检测帧没有材料／叶片身份。因此支持率不等于叶片识别率，最小检测塔距也不是已关联叶片的净空；塔架回波可能使估计接近零并产生偏差。材料标签、转子相位和裁剪表面真值仅在离线评价端使用。

检测默认面积积分16384、输出上限4096，面积种子100／101／102，噪声种子100；由 `--integration-budget`、`--output-point-limit`、`--seeds`、`--noise-seeds` 配置。`--detection-config` 可覆盖 `DetectionConfig`，完整参数与假设见[工程检测模型](../../wfrl/radar_x100/README.md#工程检测模型)。合法空帧计零，缺失／不完整帧为UNKNOWN，纯噪声虚警不算支持。`simulated_detection_support` 汇总实际评价网格；在安装搜索中该网格是完整经过的并集，不是任意全时段或单叶片身份统计。

**几何覆盖为辅助。** 默认对1024／2048候选点及上述三个面积种子分别评价。每帧至少3个展向归一化位置≥0.8、位于ROI内且通过FOV／量程／遮挡的材料点才记该叶片有几何支持；参数为 `--budgets`、`--minimum-points`、`--distal-span`、`--half-window-deg`。这不经过工程门限，不代替检测支持或识别能力。

硬件 `hardware_profile` 保存方位±60°、俯仰±22°、0.2～396 m、最多4096点及手册出处。软件 `analysis_roi` 默认机舱系下界 `(-15,-15,-70) m`、上界 `(-2.5,15,-40) m`；默认与 `--roi` 均为研究配置，只筛评价点，不缩小硬件范围或检测积分域。

候选须通过机械／运动 `PASS_RESEARCH`，每组配置的三叶完整经过检测、正下方状态与适用塔距误差须已知，最差叶片检测支持率为正，才进入检测排名。依次比较各配置中的最差经过支持率、最长连续漏检（越短越好）、正下方支持率、最差叶片支持率、塔距RMSE（越小越好）及平均ROI非纯噪声检测数；几何最差叶片覆盖只在检测评分相同时辅助排序。最后一项平均点数覆盖所评经过并集，不是叶片识别点数。几何零覆盖本身不是检测排名的否决条件，不合成设备可靠性分数。

JSON为 `x100-installation-search.v2`，分别保存机械、几何、检测、分母、缺口、正下方采样、塔距误差、源身份和代码摘要。`rank()` 与 `selected_installation()` 共用候选资格校验：所需检测指标必须齐全、有限且在有效范围内，模拟支持须已知且为正，几何覆盖字段须齐全；缺失或非有限的几何辅助分数保留未知，不代替检测分数。候选ID须为唯一非空字符串，安装位置及XYZ角各含三个有限数值。

摘要和完整报告使用同一导入校验，核对来源、几何、面积算法、完整经过范围与重算排名。`mechanical_policy` 必须匹配当前安装单元 W×H×D、包络轴与原点、研究参数及其单位和依据、仅外部安装规则，并声明 `physical_installation_approved=false`。机械策略缺失或不符时，按诊断中的字段检查并重新运行 `scripts/radar_x100/optimize_mount.py`。来源或几何字段冲突、重复ID、筛选报告或无效推荐均拒绝。应用保留预算、观测模式和场景时刻。相机采集、记录与共享安装仍受互斥约束。

经过索引必须按顺序覆盖显式网格中的完整经过，不得遗漏首帧、内部帧或末帧；时间步长须符合声明频率。正下方采样须具有匹配时刻、有效点数及适用误差；缺项或无效值不能建立已知支持，未知帧仍保留在分母中。

界面默认 `GEOMETRY`。报告仅在存在可应用推荐，且所有所评配置的每个完整经过网格帧和精确正下方时刻均有检测支持时，将 `recommended_observation_mode` 设为 `DETECTIONS`；否则仍为 `GEOMETRY`。即使达到该研究门槛，也不改变 `UNCALIBRATED`，不表示实机可靠性或叶片识别已验证。

复现当前叶片评价时，在配置面板将采样预算设为 **2048**。界面初始预算为512，导入安装不会自动提高预算；[预算对照结果](../../outputs/x100-observation-research/search-area.json)中，该预算的部分种子／叶片缺少足够远端点，不能沿用1024／2048搜索报告中的支持比例。

## 面积材料采样

`AREA` 以源起点表面的三角面积作为采样权重，使用随机平移Halton序列确定三角面及面内重心坐标。相同种子的小预算是大预算的前缀，便于核对预算敏感性。坐标固定在材料上，位置和速度差分均运输同一组点，源参考几何不随安装位置改变。

面细分不会按三角面数量增加区域采样概率，但有限点预算仍可能漏掉细小区域。不同三角化下不保证逐点完全重合，应比较区域覆盖和统计稳定性。`CENTROID` 是显式质心对照模式。材料计划摘要还包含参考面积度量及 `area_weights_m2` 的字节摘要；权重改变时 `sampling_plan_id` 改变，坐标前缀相同不代表权重或计划身份相同。几何帧保留材料点索引，三角面索引不单独构成唯一材料点身份；工程检测帧因合并与虚警不保留一一材料关联。

材料三角面索引须为非负、可用int32表示的整数，不截断小数或将布尔值当索引。几何对照继续经过名义视场与首交遮挡筛选，不生成RCS、SNR或检测概率。工程检测路径在同一面积积分基础上另作响应、方向图、噪声和检测计算，模型值保存在诊断字段，厂家属性仍为未知；两条路径都不模拟真实chirp过程。

## 叶片关联与连续估计

**N → X100 → 叶片关联与估计** 的开关默认启用，按实际观测模式选择估计器。GEOMETRY提供三叶状态、支持点数、拟合残差、外推距离及有支持时的模型估计塔距。点云窗口按 **5** 进入机舱XZ，可见候选拟合段；有支持的模型叶尖以十字标记表示。B1／B2／B3分别使用橙／蓝／黄；拟合段存在不代表叶尖已满足外推和稳定性条件。

### 几何点云估计

推理输入为当前观测点、同刻塔筒侧壁、已声明的三叶根部姿态及名义叶尖径向坐标。Blender 先验以轮毂中心为原点、根部方向为坐标轴，末端局部Z取结构参数 `TipRad`。逻辑叶片编号来自根部姿态先验，观测关联不读取真实材料ID、仿真叶片标签、变形叶尖或位移通道。无相应标定／姿态上下文的历史记录和实时设备输入不提供这层估计。

候选点须在唯一叶片走廊内，排除已知塔面附近点；此筛选只影响派生估计，原始点云、原索引和侧壁距离诊断完整保留。展向分箱中位数经稳健二次曲线拟合，得到观测支持的局部叶片段；名义叶尖径向坐标截面的外推满足条件才输出模型叶尖。

| 研究参数 | 默认值 |
| --- | --- |
| 叶片走廊 | 根部局部Z为名义叶尖径向坐标的0.55～1.03；横向半径≤10 m |
| 已知塔面排除带 | 距离≤0.15 m |
| 最少点数／有效跨度分箱 | 8点／4箱；总分箱10 |
| 最少观测展向跨度 | 名义叶尖径向坐标的18% |
| 最大叶尖外推距离 | 名义叶尖径向坐标的6% |
| 最大拟合残差／拟合离散度 | 0.8 m／1 m |
| 局部平滑时间常数／最大连续间隔 | 0.10 s／0.20 s |

上述参数定义于 `tracking.FitConfig`，是研究配置。塔面附近的真实叶片点也可能被排除；点数不足、关联不清、外推过远或拟合不稳定时只显示拒绝状态，不能解释为安全。当前模型从表面观测拟合名义叶尖径向坐标截面，不能保证恢复结构参考轴或实际三维叶尖；拟合离散度不是物理误差或标定置信区间。

连续估计仅平滑根部局部坐标中的横向分量，旋转使用当前姿态；重复帧不重复更新，后退、换来源及长间隔清除历史。连续有效估计的计数允许跨过最大间隔以内未处理的源帧。当前帧拒绝时不显示上次叶尖或净空。工作区源码对同一帧的临时估计错误限频重试，估计层故障不撤回合法原始观测，结果不写入原始记录，也不作为硬件Track流。

估计在会话主线程更新中按新配对帧派生，不依赖点云窗口是否打开；关闭估计开关清除派生结果和历史。窗口只绘制已有结果，不在draw中进行采样、塔面查询或拟合。

### 工程检测净空与离线跟踪

DETECTIONS使用 [clearance.py](../../wfrl/radar_x100/clearance.py) 的 `ClearanceTracker.update()`。输入为观测位置、径向速度、声明的位置误差、同刻塔面、根部姿态和未加载叶片截面形状；有模型诊断时仅使用观测总功率及其噪声比，不读取纯信号功率／SNR、虚警真值、材料标签、受载几何或真实叶尖。它区分叶片、塔架和其他回波，再以未加载形状拟合结构叶尖及塔距；参数由 `ClearanceConfig` 定义，与上表GEOMETRY参数不同。前端显示“工程模型估计 · UNCALIBRATED”、支持／拒绝原因及近似95%区间。

前端因果估计要求当前帧有支持；缺测或拒绝时不沿用旧净空。秩亏拟合的条件数记为 `null`，负塔距、非有限最近点或过大不确定度不出数；叶片编号和拟合计数须满足整数约束。离线平滑的观测协方差须有限、对称且正定。区间仅是未标定模型的不确定度，不是实机置信保证。

离线 `track_clearance_passage()` 在同一叶片、同一经过内对根部局部位置／速度运行Kalman／RTS平滑，旋转由各时刻的根部姿态提供。已有受支持单帧值原样保留；缺测帧仅在局部窗内有足够锚点时估计，包括使用未来锚点的插值和反向预测，统一标为“跟踪外推”／`TRACKING_EXTRAPOLATED`。默认局部窗0.20 s、至少3个锚点；距最近锚点超过0.20 s、净空标准差超过0.45 m、数值奇异或无有效塔面查询时仍不出数。时间后退、重复或间隔超过0.12 s时分段，不能跨经过或无锚点补数。这是离线评价接口，不改变 `ClearanceTracker.update()` 的因果行为，也不写成新增检测。

DETECTIONS录制可在 `clearance/<帧索引>.json` 保存与原始帧摘要绑定的分类、显示结果或不可估计原因，原始点云保持不变。目录回放核对sidecar及原帧摘要后显示；缺失或损坏时保留不可估计原因，不用当前场景补历史先验。离线经过跟踪结果写入独立评价报告，不自动进入这些前端记录。

## 独立评价

```bash
/Applications/Blender.app/Contents/MacOS/Blender \
  --background --factory-startup --python-exit-code 1 \
  --python scripts/radar_x100/evaluate_blades.py -- \
  --output /path/to/new-evaluation.json \
  --search-report /path/to/new-search.json \
  --candidates 2048
```

省略 `--search-report` 使用原安装预设。默认几何评价在完整30 Hz网格运行因果估计，再从独立保存的结构材料点计算叶尖误差和塔距误差；材料标签只在评价端核对关联正确率。报告保留三叶完整名义经过的N、支持比例、拒绝原因、关联分母、平均／p95／最大误差、未知项、安装及代码身份；未满足估计条件的帧保留在覆盖分母中。

使用 `--detections` 评价工程检测净空，可加 `--save-observations /path/to/new-observations.json.gz` 保存观测与独立评价真值。已有该观测缓存时，无需Blender即可从仓库根运行：

```bash
python3 scripts/radar_x100/evaluate_blades.py --detections \
  --observations /path/to/observations.json.gz --output /path/to/new-clearance-evaluation.json
```

检测评价先完成单帧支持的因果估计和离线经过跟踪，再读取真值评分。`single_frame`／`estimated_tip` 保留单帧支持口径，`tracked_tip` 包含合格跟踪外推，`tracking_extrapolated_tip` 单列缺测帧的模型结果，比例分母均为全部经过帧；逐帧保存原拒绝状态、最近锚点年龄和跟踪拒绝原因。报告还保留参数、代码摘要及读入观测缓存的摘要，不能把两种支持比例混为检测率。

软件检查覆盖面积度量、网格细分、预算前缀、材料速度、解析曲线估计、背景／关联拒绝、时间回退、安装来源与回滚。真实窗口绘制、完整源实验、实机精度和持续性能分别判断。同源几何评价可以检查研究模型的局限，不能代替独立场景或真实设备验证。
