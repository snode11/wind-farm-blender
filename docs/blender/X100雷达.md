# X100 雷达使用与验证范围

X100 在公开 0.3.42.6 扩展、工作区源码与本机安装中使用独立侧栏标签 **N → X100**。公开扩展与本机安装提供几何仿真、文件回放、本地采集通道、独立点云窗口、机舱 XZ／同帧侧壁距离和零载荷参考；离线双预设覆盖由配套源码显式运行。公开附件、日常安装和工作区按各自载荷身份核对。

工作区的 X100 标签顶部提供“几何仿真／文件回放／实时输入”分页、“应用配置”“关闭 X100”、会话状态与错误。其下依次为可折叠子面板：“配置”显示当前来源的安装、文件或连接参数；“显示”提供着色与点云窗口；“叶片关联与估计”显示研究模型开关及三叶状态；“帧与数据流”在有观测时列出来源、有效性、时间质量、时钟域及各流计数，默认折叠；“记录”在非实时会话中提供新记录目录和开始／结束记录，并在已有终态时显示上次记录结果，默认折叠。各来源的坐标与限制说明位于“说明与限制”折叠项，窄栏中标题显示为“说明”。相机采集、盒体安装、相机草稿编辑或窗口录制占用期间，雷达设置与记录控件锁定，状态和错误保持可见。X100 与原有三束理想激光、双束净空和报警统计相互独立。

工作区源码提供按表面积生成的固定材料采样、离线安装搜索，以及“叶片关联与估计”面板。机舱 XZ 可叠加候选拟合段与有观测支持的模型叶尖。这三项由 0.3.42.6 扩展及配套源码提供，日常安装使用 0.3.42.6，命令、先验、拒绝条件和评价入口见[X100 观测研究](X100观测研究.md)。

## 参数生效与当前来源

工作区源码的会话状态显示已应用的数据源、安装或路径／连接配置，以及当前帧的原始观测来源。单帧 PLY 的来源标为用户声明。编辑相关参数后显示“未应用”；恢复到已应用值会清除提示。改变显示设置、采样预算、回放位置或下一次记录目录不会产生未应用配置提示。

| 参数 | 生效方式 |
| --- | --- |
| 数据源、挂载、安装位置与旋转、文件路径、单帧来源声明、实时端口和过期阈值 | 点击“应用配置”；编辑值不热切换已有安装或连接。来源／路径／单帧声明与当前会话不匹配时撤回旧观测。 |
| 安装位置快捷按钮 | 显式切换同一台雷达，成功后显示为已应用；重复有效预设复用当前观测，预算编辑不强制重采样。 |
| 安装搜索报告与“应用搜索推荐安装”（源码） | 在“配置 → 安装覆盖搜索”选择离线报告并显式应用；核对来源、几何、采样算法及完整有效推荐，保留场景时刻和当前预算。 |
| 采样预算 | 下一新样本读取；暂停时保留原帧和其预算，状态中提示编辑值将在下一新样本生效。候选预算不等于输出点数。 |
| 着色、速度色标与范围、名义视场开关、实时显示流 | 即时显示设置，不重新应用来源或标定。点云窗口的着色与色标选择属于该观察窗口。 |
| 机舱 ROI、塔距色标上限 | 公开扩展支持；ROI 变化在冻结配对快照上重算距离，色标只改颜色，不生成原始观测。 |
| 叶片关联与估计开关（源码） | 控制派生估计，关闭时清除模型结果；需要同帧塔面、根部姿态和已对齐的几何仿真点云。 |
| 回放时间与播放控制 | 操作独立文件时间轴，不改变原始物理时间。 |
| 新记录目录 | 开始下一次记录时使用；记录期间显示当前实际目录，编辑值不迁移正在写入的记录。 |

完整记录目录采用文件内的来源信息，单帧 PLY 声明对目录无效，也不算待应用差异。配置提示描述活动会话；场景绑定失效、记录错误和未完成关闭仍分别显示，不由配置提示替代。

## 独立点云输出窗口

工作区源码在 **N → X100 → 显示 → 打开点云窗口** 提供独立画布，直接消费所属场景现有 X100 会话的最新有效帧。打开窗口不应用安装配置、不采样新观测、不启动回放、训练或求解；同一场景重复打开复用已有窗口。该窗口包含于 0.3.42.6 公开扩展，本机安装的身份、场景恢复与观察窗口检查见安装记录。

窗口默认显示当前瞬时帧，不累积历史。几何仿真使用传感器坐标 `+X` 前、`+Y` 左、`+Z` 上，默认角度视图显示方位角与俯仰角；正视为 Y/Z、俯视为 Y/X、侧视为 X/Z 米制正交投影。原始视图按钮或数字键 1～4 切换，5／机舱XZ 为分析视图，公开 0.3.42.6 扩展已包含；滚轮缩放，中键拖动平移，F／Home 或“复位”重新取景，C／“着色”切换距离、径向速度、高度、RCS、SNR 和动静属性。工作区与本机安装的窗口保持可读字号，窄窗自动换行按钮；径向速度下用 V／色标按钮切换固定对称与当前帧范围，固定范围由侧栏“速度色标 ± (m/s)”设置。观察变换只影响显示，不改变安装、视场、运动、观测帧或相机画面。窗口使用帧内的传感器坐标，不按当前机舱姿态再次变换旧帧；未确认原始坐标方向的文件使用原始轴正交视图，不推定厂家轴映射。

来源、流、序号、源时间、时间质量、有效性、原始点数及可绘制点数分别显示。非有限坐标不绘制；有效零点帧清空旧点并显示有效空帧，来源关闭或失效时撤回旧点。文件回放保持原始来源与独立时间轴，不因显示窗口而与风机同步。原始四视图与三维叠加使用相同属性着色；机舱 XZ 的塔距色标独立，不随 C／属性选择或速度色标改写。工作区与本机安装的动静属性固定使用 0／1 两种颜色；径向速度默认使用以零为中心的固定对称色标，超出显示范围的值使用端点颜色，原始速度不变，也可选择当前帧自动范围。图例注明实际显示范围与口径；未知属性显示灰色，高度沿用三维叠加的已对齐世界 Z 或未对齐原始 Z，径向速度符号沿用来源声明。

点云窗口内的固定／逐帧色标选择只作用于该窗口；三维叠加使用侧栏中的显示设置。固定速度范围仅为显示参数，不代表设备速度限制，也不裁剪或改写记录中的速度值。

工作区源码按窗口分别缓存背景／按钮、网格／坐标轴／边框、色带及机舱分析参考四个辅助层，每层只保留当前配置，不缓存历史帧。窗口尺寸、实际 UI 缩放、视图、取景范围、缩放／平移及色带类型／范围按各层依赖失效。点云随新帧或着色变化重建，文字与当前来源、有效性和未知数量每次绘制；辅助层命中不阻止帧与状态更新。绘制上下文归属改变、窗口关闭、加载、撤销／重做和卸载释放 GPU 引用，绘制异常清除绘制缓存供下次重建。缓存减少辅助 batch 构造，不承诺特定播放 FPS。

Esc／画布关闭按钮或系统关闭按钮只关闭观察窗口，雷达会话和记录继续运行。窗口绑定创建时的场景，不迁移观测来源；Blender 工作区联动若使观察窗口改绑 Scene，则关闭该专属观察窗口并释放缓存；所属场景删除、观察窗口改绑、文件加载、撤销／重做和扩展卸载时释放观察资源。保存的雷达专用画布在文件加载后关闭，保留普通图像编辑器窗口；需要观察时重新打开点云窗口。普通三维视口仍提供世界坐标点云叠加，独立窗口只显示点云及显示辅助信息；两者不进入原始相机离屏 RGB。

工作区源码在合法暂停帧的 GPU 构建／绘制失败后限频重建叠加，不改变原帧、采样预算或记录数；来源无效时仍撤回点云。机舱 XZ 固定使用连续塔距点色和色条，单位为米，普通 MS／速度说明不混入该视图。独立参考输入按已验证来源和绑定代复用，逐帧只变换参考曲线，不进入观测求解。

## 机舱局部分析（工作区源码）

独立窗口按 **5／机舱XZ** 查看机舱局部 X/Z，按 **R** 显示或隐藏独立零载荷49点参考曲线。点、柔性塔筒侧壁、黄色雷达前向和蓝色名义视场均使用原帧源时刻；局部 Z 随完整机舱姿态运动，不保证重力竖直。二维视场投影只作示意。实体安装仍跟随当前 Scene，三维批绘视场使用有效原帧外参。机舱分析包含于公开 0.3.42.6 扩展；本机安装按独立身份识别。

**显示**面板设置机舱局部 ROI 最小／最大坐标及塔距色标上限；ROI 内有限点按三维无符号最近距离着色，ROI 外和距离未知的有限坐标点保留灰色，非有限坐标仅统计而不绘制，不据塔距删除点或分类。默认 ROI 为 `[-100,-100,-150]` 至 `[100,100,50] m`，色标上限 10 m；均为研究配置，不是安全阈值或厂商指标。面板显示原始、有限、ROI、有效数量及 min/p10/p50/p90/max 距离；空统计为 N/A，窗口注明饱和数。缩放、平移和像素裁剪不改变 ROI 统计，内部索引保留原始点对应关系。

指标是观测点到同刻指定塔筒侧壁的三维最短距离，内外状态未判定、目标未关联。它不是叶尖净空、二维投影间距或现有双束同高度水平距离。侧壁按构造多边形与三角化映射核对，排除封口；无可靠区域映射、退化面或上下文不配对时只撤回分析。零载荷曲线经当前来源与保存根边界核对，仅为独立参考，不是观测、完整叶片外轮廓或识别结果。

运行时把原始帧与只读塔面上下文配对发布。窗口的主线程轮询按需求建立专用锚点 BVH，并对 BVH 选中的三角面用 float64 精化最近点和距离；draw/consume 只消费已有结果。关闭窗口停止该窗口的 ROI 分析需求，重开或 ROI 变化可复用冻结快照，不生成新观测；工作区启用叶片估计时，会话仍按新配对帧计算派生估计。身份包含运行代、会话、来源／几何／标定、源帧／时钟及适用回放索引；每会话最多持有一份当前上下文、侧壁 BVH 和逐点距离结果；每窗口只缓存当前显示，不构成进程内存上界。分析上下文不进入帧 provenance 或记录队列；无上下文的历史记录保持原始显示，不借当前 Scene 补历史。原始来源、分析、普通 GPU 更新和录制错误分开；安装切换的必需 GPU 准备失败仍回滚。显示参考不进入在线分析，真实材料 ID、叶片标签与变形叶尖不参与在线距离求解。

工作区源码在临时距离分析失败后保留原始帧、撤回距离结果，并在当前机舱分析窗口仍有需求时限频重试；同一失败请求至少间隔0.25秒，ROI改变可立即重算。重试使用冻结的同帧上下文，不推进播放或产生新观测。

## 离线安装覆盖研究

在独立 Blender 后台进程显式运行，不依赖 UI 消费帧数，也不启动训练：

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python scripts/radar_x100/coverage.py -- --output /tmp/x100-coverage.json
```

输出文件必须不存在。默认完整枚举所选源区间的 30 Hz 网格，用同一来源、预算和种子比较原安装位与机舱侧面。`--package` 指定来源；`--candidates`、`--seed`、`--targets-per-group`、`--distal-span`、`--half-window-deg`、`--roi`、`--bins` 为显式研究配置。覆盖 ROI 使用塔基固定坐标，与在线机舱 ROI 独立。

固定目标目录来自叶片外表面三角面重心，属于有限离散近似。默认每片两组各256点，三片总请求1536点；报告记录各组实际预算、去重数量及每时刻参考／驻留预算。E 是参考目录驻留集合，V 是其中通过几何视场与遮挡的集合，O 是独立候选采样实际输出的远端目标集合，V 不是 O 的严格上界。O 非空而 V 为空单独计数，不作为逻辑错误。真值材料身份仅用于离线评价，不写回在线分析。

当前工作区的 O 使用面积材料采样，以输出材料点索引及固定重心坐标评价展向位置；E／V 的质心参考目录独立保留。保存报告须按其 `sampling_method`、采样计划及对应载荷身份识别，不能用同名脚本推定不同载荷采用相同观测模型。

完整名义下方经过以保存解缠方位及叶片偏移、180°中心和显式角窗定义，不代表真实最小净空时刻。报告分别标注完整、截断、停转、反转、UNKNOWN，保留经过网格、角度分箱、条件计数与分母、连续段及缺口。主时间分母 N 是该经过期望源网格数，不删除 E 为空的时刻；零分母以 JSON null／N/A 表示。UNKNOWN 单列，含未知的评价不称完整求值。叶尖可辨识性及安全合格性为 NOT_EVALUATED。

保存的质心采样载荷[完整覆盖报告](../../outputs/x100-analysis/coverage.json)枚举1801个源时刻；两预设各有33次完整名义经过、期望网格累计895帧。原安装位有876帧出现远端目标输出，侧面为0，UNKNOWN均为0。该结果仅适用于报告的角窗、ROI、预算、seed及有限目标目录，不能理解成侧面所有时刻无点云或侧装已适合净空任务。完整参数、可见计数与证据边界见[工作区验证](发布状态与验证范围.md#x100-工作区源码验证)。

## 安装搜索与叶片估计（工作区源码）

安装搜索使用已有同源运动，在完整30 Hz网格比较有限位置／朝向和多个预算／种子，以最差叶片和完整经过的支持比例优先排序。在 **配置 → 安装覆盖搜索** 选择报告，点击“应用搜索推荐安装”；推荐只改变同一台雷达的安装，不自动提高当前预算。来源、几何或采样算法不符、存在未知帧或缺少有效推荐时拒绝应用。命令、支持阈值和机械可行性边界见[安装覆盖搜索](X100观测研究.md#安装覆盖搜索)。

**叶片关联与估计** 在几何仿真中使用同帧塔面、已知根部姿态和名义叶尖半径。机舱 XZ 中 B1／B2／B3 为橙／蓝／黄，线段表示候选拟合段，十字表示满足支持条件的模型叶尖；点数、跨度、外推或拟合条件不足时显示拒绝状态，当前帧没有叶尖或塔距时不沿用旧结果。该派生层不改写原始点云或逐点侧壁距离，不写入原始记录。历史文件和实时设备输入缺少相应上下文时不提供此估计。

复现保留的叶片评价时，将采样预算设为2048并应用几何仿真配置；界面初始预算仍为512。有限安装搜索的每帧至少3个远端点、质心报告的“存在远端输出”以及叶片估计的拟合支持是不同口径，不能直接比较百分比作为覆盖提升。原位置的82.5°与90°俯仰在保留搜索报告的主要覆盖指标相同，同源叶尖估计仍有米级误差；实际数值与像素检查见[研究验证](发布状态与验证范围.md#x100-观测研究工作区验证)。

## 几何仿真

工作区源码的 **X100 → 配置 → 安装位置（同一台雷达）** 提供“原安装位置”和“机舱侧面”两个快捷按钮。原安装位置为机舱局部 `(-3.5, -1.7, -2.0) m`、XYZ 旋转 `(0°, 82.5°, 180°)`；侧面位置依据当前静态机舱负 Y 侧壁确定，外壳中心沿表面法向外移 0.04 m，旋转为 `(0°, 0°, -100°)`，朝侧方叶片区域。点击后切换同一台雷达的安装并采样当前时刻，场景时间、采样预算和着色保持不变，不需要再次应用配置。切换前完成新观测及绘制数据准备，失败时保留原安装、观测与未应用参数；成功切换保留安装对象的选择和隐藏设置。位置与来源不变时，重复选择不重建安装对象；预算编辑仍等待下一新源样本；暂停时复用当前观测，时间推进仍按源采样网格刷新。记录和相机采集期间不能切换；来源仍是文件回放或实时输入时，先应用几何仿真配置；跨场景共享安装须先应用配置建立当前场景的独立安装。保存场景保留当前实际安装参数，重新打开后仍可切换；两个位置为同一台 X100 的互斥预设，不同时生成两台雷达或两路点云。侧装使用几何视场与遮挡近似，不代表厂家安装方案或毫米波回波验证。

先加载本场景的风场柔性回放，选择“几何仿真”，设置 T1 挂载、位置、XYZ 旋转和采样预算，再点“应用配置”。位置单位为米，角度为度；内部传感器轴为 `+X` 前、`+Y` 左、`+Z` 上。机舱挂载跟随同源塔顶运动与偏航，塔基／世界挂载固定。安装或来源改变后重新应用。

工作区默认按源起点表面积生成固定材料点，采用随机平移 Halton 序列；同一预算与种子确定同一计划，小预算保留大预算前缀。位置和速度差分运输同一材料坐标，减少网格疏密的影响；有限预算仍可能漏掉远端区域。公开 0.3.42.6 扩展采用面积采样，日常安装载荷也采用面积采样。

120×95×40 mm 外壳是手册尺寸的近似外形；机械尺寸轴、相位中心和实际安装可行性尚未确认。没有厂家机械图时不建立假定孔位或支架。名义视场为方位 ±60°、俯仰 ±22°，示意长度为 60 m；范围筛选使用 0.2～396 m。示意不等于全叶轮可见或厂家检测性能。

工作区源码的筛选、外壳和视场从规范核心 `schema.PROFILE` 派生，点数上限与不对齐的 26 字节点布局由同一核心提供。独立窗口角度默认范围为方位 ±66°、俯仰 ±26°，包含独立定义的 6°／4° 显示余量；`schema.DISPLAY_DEFAULTS` 中的 60 m 示意长度和画布余量不改变探测规格。近程／远程模式各自的量程、点数与周期映射，以及完整 label 字节编码尚未确认，不按模式名推定。

仿真按本场景保存运动的 30 Hz 时间网格采样，不推进另一个场景的时钟。点云按采样时刻转换到世界坐标，不随当前机舱再次变换。暂停时仍核对源绑定、静态布局和实际安装，原生修改不匹配时撤回点云，不覆盖用户编辑；工作区与本机安装还拒绝安装对象或其父级的约束、动画及非对象父级关系，保留编辑供检查；恢复有效来源后清除过时诊断。着色变化复用当前观测。几何遮挡仅包含 T1 展示叶片、塔筒和机舱外壳，忽略其他结构、环境及合成缺陷的额外拓扑。界面显示材料点差分径向速度，没有 RCS、SNR 或真实回波模型；未知属性为灰色。工作区的叶片关联与模型估计使用独立派生层，不提供实机精度或安全报警。

工作区源码在暂停和新帧采样前核对来源 Scene、叶片／塔架／机舱及布局根的对象身份、场景归属、关键父链、父级逆矩阵与网格绑定，静态节点变换与面拓扑保持绑定。YawRoot 的父链重挂、同名替换或塔架解除场景链接均使观测失效；FarmFlex 合法更新的动态姿态不被冻结。机舱外壳还核对静态顶点和局部变换。编辑模式、约束、动画、修改器或形态键驱动的外壳不继续使用已绑定的静态缓存；检测到偏离时撤回观测并保留编辑。恢复原绑定后可恢复显示；需要使用修改后的静态外壳时，结束编辑并重新应用 X100 配置以建立新几何快照。重新绑定要求外壳为无上述驱动的静态网格，不会自动应用修改器或烘焙形态键。

当前时刻使用完整几何做遮挡；速度差分只计算输出材料点对应的顶点，静态三角拓扑与同刻遮挡树按绑定复用。该路径与完整几何差分使用相同材料点和区间，不通过减少观测或修改数值换取速度。

“开始记录”只记录实际采样到的帧。工作区源码在时间轴循环回起点或回拖造成仿真时间倒退时立即停止记录，失败原因为“仿真时间在记录期间回退（时间轴循环或回拖）；请开始新的记录”，已写入帧保留；不保证 UI 记录包含完整 30 Hz 网格。完整区间导出使用[数据接口说明](../../wfrl/radar_x100/README.md#几何观测)的独立脚本。新记录目录必须不存在，关闭或结束记录后才可完整回放。失败状态、错误与 `INCOMPLETE` 标记保留。工作区与本机安装把最后记录结果保存在所属场景，结束失败记录后仍显示“上次记录：FAILED”与失败原因；普通刷新、关闭或重新应用雷达不会把它清成成功，开始新的记录才清除上次记录错误。

工作区源码结束记录时先停止接收新记录帧，立即返回界面，再由轮询确认写盘线程退出；等待期间显示“正在结束记录”，保留记录器和会话归属，并禁止重复启动记录或替换会话。关闭 X100 同样等待写盘确认后才释放会话。文件加载、撤销／重做和卸载撤回观测并停止接收记录，保留必要的写盘收尾轮询；线程退出后释放原会话，不把记录延续到恢复后的场景。真正的记录失败保留 FAILED、原因和 `INCOMPLETE`，等待写盘本身不视为失败。公开附件与本机安装按各自载荷核对关闭方式。

工作区源码的记录至少包含一帧才可完成；零帧结束保留失败原因和 `INCOMPLETE`，有效零点帧可正常记录和回放。历史边界后的雷达按恢复场景重新绑定，不自动恢复记录。恢复复用归属明确的保存安装并保留各 View Layer 的隐藏选择；原生安装编辑与配置不一致时显示未就绪，保留编辑供用户检查。关闭安装时解除当前场景对独立共享对象的链接，保留其他场景的对象与网格。所属场景被删除时不再写入场景状态，但仍确认记录线程退出并释放会话；记录本身的失败或不完整状态不因此消失。源码、公开附件与本机安装的适用验证各按其载荷记录核对。

## 文件回放

选择“文件回放”，填写单帧 PLY 或显式索引记录目录，再应用配置。目录使用独立文件时间轴，可播放／暂停、上一帧、下一帧和跳转；工作区源码用 Python 双精度时间与索引选帧，界面时间属性负责显示／显式寻址，片尾停止后再次播放从起点开始；同一呈现时间的多帧可以按索引逐项访问。工作区源码中，路径或单帧声明改动尚未应用时，播放／暂停与上一帧／下一帧在面板显示错误而不中断操作，暂停始终停止播放。按时间寻址选取该时刻最后一项；起点前没有观测，片尾保留最后原始帧。完整记录目录保留原始来源，几何仿真记录仍显示 `GEOMETRY_SIMULATION`，合成输入不变成实测。

工作区源码的单帧 PLY 必须在“单帧 PLY 来源”中显式选择几何仿真、实测文件或测试数据，未声明时不能应用配置。PLY 本身没有来源字段；侧栏和点云窗口的“显式声明”表示用户提供的来源，不代表已验证设备或恢复原始记录元数据。改路径会清除声明，修改路径或声明后须重新应用配置，旧观测会撤回；完整记录目录忽略此单帧声明，继续使用文件内来源。来源选择不会补齐时间、速度或坐标标定。

工作区源码重录目录回放时，以实际选中原索引行的呈现时间为准，相对首个记录行归零，原始物理时间、时钟域和其他帧元数据保留。设备源时间递减或相等不会使正常向前重录失败或压缩呈现间隔。同一呈现时间的多个索引仍可逐项重录；主动返回较早索引使当前记录失败并保留不完整标记，需要另建记录目录。只记录实际显示并提交的行，不保证自动播放时捕获原包所有索引。

单帧 PLY 没有连续时间、速度或航迹身份。实测序列先按[显式索引合同](../../wfrl/radar_x100/README.md#ply-与显式索引)导入；仅提供帧率时显示 `FPS_DERIVED`，不代表硬件同步。真实样例、坐标轴、原点和运动补偿尚未核验时，按原始点云展示并标为未同步，不将其安装到不相关的 MAPPO 动画上测量。

## 实时输入

实时模式只连接本机 `127.0.0.1` 的独立采集进程，设置端口、显示流和过期阈值，再应用配置。各流独立显示年龄、缺口、重复和显示替换计数。有效空帧清空点云，过期或断开隐藏旧点；新会话显式重新应用连接。Blender 最新帧不能代替完整采集记录，实时记录由外部采集端执行。工作区本地发布端空闲时也检查连接状态，新的显式连接可接管显示槽；发送失败待重试的观测保留原到达时间，延迟交付不会重新变成新鲜观测。该机制不提供应用层逐帧送达确认。

已具备有界组帧、记录分流、本地版本／长度／身份校验和非阻塞消费基础设施；尚未实现厂家 UDP／SDK 解码或 Track 航迹。软件注入和文件转发不属于真实设备验证。真实接入最少还需要：一段逐帧真实 PLY 及明确时间索引／厂家显示对照，以及与设备固件匹配的 UDP 或 SDK、实际工作模式、网络配置、坐标／速度／时间与空帧说明。

## 相机与验证

X100 GPU 点云与批绘视场线不参与原始离屏 RGB；视场等对象使用 `wfrl_x100_role=annotation`，从原始预览和采集中排除，实体外壳保留。视场线不依赖视口辅助叠加开关；普通刷新不改写各 View Layer 的用户隐藏选择，视场开关和临时隐藏恢复相应状态，不改变相机 FOV 或画幅。相机采集期间拒绝应用／移除 X100 安装；所属场景的几何仿真保留采集前的观测，避免相机事务临时访问的时刻进入雷达记录，实时接收仍继续。实体外壳进入原始相机状态摘要，辅助物更新不改变该摘要。雷达与实机相机投影、时间同步和目标关联仍待独立实现与标定。

验证入口为 `tests/radar_x100/`（含 `test_analysis.py`）及 `blender_frontend/tests/blender/radar_x100_analysis.py`、`blender_frontend/tests/test_radar_x100_display.py`、`blender_frontend/tests/blender/radar_x100_regression.py`、`radar_x100_edges.py`、`radar_x100_history_regression.py`、`radar_x100_binding_replay.py`、`radar_x100_window.py`、`radar_x100_output_window.py` 与 `radar_x100_output_lifecycle.py`。后台检查覆盖同刻只读采样、安装变换、记录回放、暂停失效、重复时间索引、采集互斥、保存重开、原生撤销／重做与资源释放；窗口脚本分别检查雷达辅助物和独立输出窗口对真实 RGB、状态、时钟及相机参数的隔离。独立窗口脚本还检查 GPU 绘制、同帧消费、导航隔离、来源切换、有效空帧、未知属性、窗口重开与场景归属；脚本操作与真实键鼠操作分别判定。`radar_x100_output_lifecycle.py` 检查源码的保存／加载与撤销／重做清理、普通图像编辑器保护、重开及卸载时 GPU 缓存释放，不加载风场或运行求解。各脚本的源码／安装模式和身份变量按[验证入口](../../.agents/skills/windfarm-blender-dev/references/verification.md#执行环境与来源)逐项核对；`radar_x100_analysis.py` 与 `radar_x100_output_lifecycle.py` 仅验证源码，设置安装模块变量不会改变对象。原生脚本输出由 `WFRL_TEST_OUTPUT` 指向新目录。

工作区的几何基准、普通 GPU／录制错误隔离、安装回滚、实际窗口／RGB、场景历史与资源检查分别见[源码验证证据](发布状态与验证范围.md#x100-工作区源码验证)。面积采样、安装报告导入、叶片估计及拟合线／叶尖开关像素见[观测研究验证](发布状态与验证范围.md#x100-观测研究工作区验证)；脚本控制的画布检查不证明真实键鼠操作。源码结果不转记为公开ZIP或日常安装验收。历史分析上下文持久化、真实设备叶片／净空估计、实机接入与完整雷视融合仍待实现与验收；当前不考虑天气。

当前软件检查不证明连续 30 Hz 绘制、长期满载性能、真实 PLY／UDP 兼容、厂家精度或现场保护效果。日常安装身份、启动场景保护及专项检查范围见[安装记录](../../publication/daily-installation.json)。最终安装包、验证记录、布局截图、数值对照与恢复备份的保留位置及清理清单由安装记录索引；临时配置、测试场景和合成录制不作为运行依赖。原始记录中的临时路径标识测量来源，不能据此认定环境仍可复用。
