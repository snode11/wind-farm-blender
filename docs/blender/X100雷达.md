# X100 雷达使用与验证范围

X100 在公开 0.3.42.8 扩展、工作区源码与本机安装中使用独立侧栏标签 **N → X100**。公开扩展与本机安装提供几何仿真、文件回放、本地采集通道、独立点云窗口、机舱 XZ／同帧侧壁距离和零载荷参考；离线双预设覆盖由配套源码显式运行。公开附件、日常安装和工作区按各自载荷身份核对。

工作区的 X100 标签顶部提供“仿真／文件回放／实时输入”分页、“应用配置”“关闭 X100”、会话状态与错误。其下依次为可折叠子面板：“配置”显示当前来源的安装、文件或连接参数；“显示”提供着色与点云窗口；“叶片关联与估计”显示研究模型开关及三叶状态；“帧与数据流”在有观测时列出来源、有效性、时间质量、时钟域及各流计数，默认折叠；“记录”在非实时会话中提供新记录目录和开始／结束记录，并在已有终态时显示上次记录结果，默认折叠。各来源的坐标与限制说明位于“说明与限制”折叠项，窄栏中标题显示为“说明”。相机采集、盒体安装、相机草稿编辑或窗口录制占用期间，雷达设置与记录控件锁定，状态和错误保持可见。X100 与三束理想激光、双束净空和报警统计相互独立。

工作区源码提供按表面积生成的固定材料采样、离线安装搜索，以及“叶片关联与估计”面板。机舱 XZ 可叠加候选拟合段与有观测支持的模型叶尖。这三项由 0.3.42.8 扩展及配套源码提供，日常安装为同一 0.3.42.8 公开载荷，命令、先验、拒绝条件和评价入口见[X100 观测研究](X100观测研究.md)。

## 参数生效与当前来源

工作区源码的会话状态显示已应用的数据源、安装或路径／连接配置，以及当前帧的原始观测来源与实际观测模式。单帧 PLY 的来源标为用户声明。编辑相关参数后显示“未应用”；恢复到已应用值会清除提示。改变显示设置、采样预算、回放位置或下一次记录目录不会产生未应用配置提示。

保存场景会分别保留已应用配置与待应用编辑。重新打开后，仿真观测和三维视场标注与已应用视场一致。缺少已应用快照的兼容仿真文件从视场网格恢复半角和形状，固定旧网格按规格书角域恢复。应用配置在新会话通过校验并准备好所需观测和资源后才切换，准备失败会保留原会话和安装。记录写盘、会话关闭或相机采集期间暂停配置切换。

| 参数 | 生效方式 |
| --- | --- |
| 数据源、观测模式、挂载、安装位置与旋转、视场半角与形状、文件路径、单帧来源声明、实时端口和过期阈值 | 点击“应用配置”；编辑值不热切换已有安装或连接。来源／路径／单帧声明与当前会话不匹配时撤回旧观测。 |
| 安装位置快捷按钮 | 显式应用同一台雷达的安装和视场，保留待应用的观测模式。重复有效预设复用当前观测，预算编辑在下一新样本生效。 |
| 安装搜索报告与“应用搜索推荐安装”（源码） | 选择 `.summary.json` 或不超过 16 MiB 的完整报告。应用时核对来源、几何、采样算法、安装包络、机械筛选要求及有效推荐，保留场景时刻和当前预算。[搜索与摘要提取](X100观测研究.md#安装覆盖搜索) |
| GEOMETRY采样预算 | 下一新样本读取；暂停时保留原帧和其预算，状态中提示编辑值将在下一新样本生效。候选预算不等于输出点数。 |
| 着色、速度色标与范围、名义视场开关、实时显示流 | 即时显示设置，不重新应用来源或标定。点云窗口的着色与色标选择属于该观察窗口。 |
| 机舱 ROI、塔距色标上限 | 公开扩展支持；ROI 变化在冻结配对快照上重算距离，色标只改颜色，不生成原始观测。 |
| 叶片关联与估计开关（源码） | 控制派生估计，关闭时清除模型结果；仿真需要同帧塔面、根部姿态和已对齐点云，DETECTIONS另需径向速度、误差模型与未加载叶片形状先验。目录回放仅显示与原帧摘要匹配的已记录检测净空结果。 |
| 回放时间与播放控制 | 操作独立文件时间轴，不改变原始物理时间。 |
| 新记录目录 | 开始下一次记录时使用；记录期间显示当前实际目录，编辑值不迁移正在写入的记录。 |

完整记录目录采用文件内的来源信息，单帧 PLY 声明对目录无效，也不算待应用差异。配置提示描述活动会话；场景绑定失效、记录错误和未完成关闭仍分别显示，不由配置提示替代。

## 观测模式（工作区源码）

在 **N → X100 → 仿真 → 配置 → 观测模式** 设置 `wfrl_x100_observation_mode`，再点击“应用配置”。已应用模式与待应用编辑分别随场景保存。

| 模式 | 当前显示与数据 |
| --- | --- |
| `GEOMETRY`（默认） | 显示参考表面积采样、名义FOV／量程与首交遮挡筛选后的材料点，以及材料差分径向速度；不经过功率／噪声检测链。候选预算默认512，可编辑，材料身份只供独立评价 |
| `DETECTIONS` | 显示按实测无人机 PLY 校准的工程链检测点（`USER_CALIBRATED`，见[检测校准](#检测校准)），包括门限漏检、分辨率合并、测量误差和纯噪声虚警。固定内部面积积分16384点，输出上限4096，与GEOMETRY候选预算独立；检测帧没有 `material_ids` 或逐材料点索引 |

状态区和点云窗口按实际帧显示模式；工程帧另显示 `calibration_status`、每帧检测数和虚警标记数，诊断缺失时保留UNKNOWN／未知。可选“模型SNR”读取独立的线性模型SNR。界面 DETECTIONS 帧的 snr／rcs／mag 按校准映射由模型量换算，是仿真值而非设备测量；核心默认配置不启用该映射，字段保留 NaN。原始点云不因叶片估计或塔距分析被改写，记录／回放保留来源和模式。

默认保持GEOMETRY：叶片表面 RCS 密度未经叶片实测标定，全部完整叶片经过与精确正下方时刻的连续检测支持尚未建立。离线搜索只有在全部所评配置的每个完整经过网格帧和正下方时刻都有支持时才推荐DETECTIONS；导入推荐安装不自动切换模式。ROI可能含塔架回波，正支持也不能证明识别出叶片。

当前 [扩展构建清单](../../scripts/blender/build_extension.py) 包含 `detection.py` 与 `clearance.py`；隔离包验证入口运行DETECTIONS模式和净空后台检查，并核对模块及数据都来自安装包。该入口覆盖不等于公开ZIP或日常安装已经运行验证，实际结论按[发布与验证对象](发布状态与验证范围.md#软件验证的适用对象)读取。模型的77 GHz、方向图归一化、噪声、假设灵敏度锚点、四维分辨率及误差默认值见[工程检测模型](../../wfrl/radar_x100/README.md#工程检测模型)。

DETECTIONS净空显示为未标定工程模型估计；当前帧不支持、拟合退化、塔距查询无效或不确定度过大时显示不可估计，保留原始观测。离线经过跟踪可使用同一经过内的未来锚点，缺测结果明确标“跟踪外推”／`TRACKING_EXTRAPOLATED`；默认距最近锚点超过0.20 s或净空标准差超过0.45 m不出数。该离线行为不改变前端因果估计，输入、分段规则及评价分母见[工程检测净空与离线跟踪](X100观测研究.md#工程检测净空与离线跟踪)。

## 独立点云输出窗口

工作区源码在 **N → X100 → 显示 → 打开点云窗口** 提供独立画布，直接消费所属场景现有 X100 会话的最新有效帧。打开窗口不应用安装配置、不采样新观测、不启动回放、训练或求解；同一场景重复打开复用已有窗口。该窗口包含于 0.3.42.8 公开扩展，本机安装的身份、场景恢复与观察窗口检查见安装记录。

窗口默认显示当前瞬时帧，不累积历史。几何仿真使用传感器坐标 `+X` 前、`+Y` 左、`+Z` 上，默认角度视图显示方位角与俯仰角；正视为 Y/Z、俯视为 Y/X、侧视为 X/Z 米制正交投影。原始视图按钮或数字键 1～4 切换，5／机舱XZ 为分析视图，公开 0.3.42.8 扩展已包含；滚轮缩放，中键拖动平移，F／Home 或“复位”重新取景，C／“着色”切换距离、径向速度、高度、RCS、SNR 和动静属性。工作区与本机安装的窗口保持可读字号，窄窗自动换行按钮；径向速度下用 V／色标按钮切换固定对称与当前帧范围，固定范围由侧栏“速度色标 ± (m/s)”设置。观察变换只影响显示，不改变安装、视场、运动、观测帧或相机画面。窗口使用帧内的传感器坐标，不按当前机舱姿态再次变换旧帧；未确认原始坐标方向的文件使用原始轴正交视图，不推定厂家轴映射。

来源、流、序号、源时间、时间质量、有效性、原始点数及可绘制点数分别显示。非有限坐标不绘制；有效零点帧清空旧点并显示有效空帧，来源关闭或失效时撤回旧点。文件回放保持原始来源与独立时间轴，不因显示窗口而与风机同步。原始四视图与三维叠加使用相同属性着色；机舱 XZ 的塔距色标独立，不随 C／属性选择或速度色标改写。工作区与本机安装的动静属性固定使用 0／1 两种颜色；径向速度默认使用以零为中心的固定对称色标，超出显示范围的值使用端点颜色，原始速度不变，也可选择当前帧自动范围。图例注明实际显示范围与口径；未知属性显示灰色，高度沿用三维叠加的已对齐世界 Z 或未对齐原始 Z，径向速度符号沿用来源声明。

点云窗口内的固定／逐帧色标选择只作用于该窗口；三维叠加使用侧栏中的显示设置。固定速度范围仅为显示参数，不代表设备速度限制，也不裁剪或改写记录中的速度值。

工作区源码按窗口分别缓存背景／按钮、网格／坐标轴／边框、色带及机舱分析参考四个辅助层，每层只保留当前配置，不缓存历史帧。窗口尺寸、实际 UI 缩放、视图、取景范围、缩放／平移及色带类型／范围按各层依赖失效。点云随新帧或着色变化重建，文字与当前来源、有效性和未知数量每次绘制；辅助层命中不阻止帧与状态更新。绘制上下文归属改变、窗口关闭、加载、撤销／重做和卸载释放 GPU 引用，绘制异常清除绘制缓存供下次重建。缓存减少辅助 batch 构造，不承诺特定播放 FPS。

Esc／画布关闭按钮或系统关闭按钮只关闭观察窗口，雷达会话和记录继续运行。窗口绑定创建时的场景，不迁移观测来源；Blender 工作区联动若使观察窗口改绑 Scene，则关闭该专属观察窗口并释放缓存；所属场景删除、观察窗口改绑、文件加载、撤销／重做和扩展卸载时释放观察资源。保存的雷达专用画布在文件加载后关闭，保留普通图像编辑器窗口；需要观察时重新打开点云窗口。普通三维视口仍提供世界坐标点云叠加，独立窗口只显示点云及显示辅助信息；两者不进入原始相机离屏 RGB。

工作区源码在合法暂停帧的 GPU 构建／绘制失败后限频重建叠加，不改变原帧、采样预算或记录数；来源无效时仍撤回点云。机舱 XZ 固定使用连续塔距点色和色条，单位为米，普通 MS／速度说明不混入该视图。独立参考输入按已验证来源和绑定代复用，逐帧只变换参考曲线，不进入观测求解。

## 机舱局部分析（工作区源码）

独立窗口按 **5／机舱XZ** 查看机舱局部 X/Z，按 **R** 显示或隐藏独立零载荷49点参考曲线。点、柔性塔筒侧壁、黄色雷达前向和蓝色名义视场均使用原帧源时刻；局部 Z 随完整机舱姿态运动，不保证重力竖直。二维视场投影只作示意。实体安装仍跟随当前 Scene，三维批绘视场使用有效原帧外参。机舱分析包含于公开 0.3.42.8 扩展；本机安装按独立身份识别。

**显示**面板设置机舱局部 ROI 最小／最大坐标及塔距色标上限；ROI 内有限点按三维无符号最近距离着色，ROI 外和距离未知的有限坐标点保留灰色，非有限坐标仅统计而不绘制，不据塔距删除点或分类。默认 ROI 为 `[-100,-100,-150]` 至 `[100,100,50] m`，色标上限 10 m；均为研究配置，不是安全阈值或厂商指标。面板显示原始、有限、ROI、有效数量及 min/p10/p50/p90/max 距离；空统计为 N/A，窗口注明饱和数。缩放、平移和像素裁剪不改变 ROI 统计，内部索引保留原始点对应关系。

指标是观测点到同刻指定塔筒侧壁的三维最短距离，内外状态未判定、目标未关联。它不是叶尖净空、二维投影间距或现有双束同高度水平距离。侧壁按构造多边形与三角化映射核对，排除封口；无可靠区域映射、退化面或上下文不配对时只撤回分析。零载荷曲线经当前来源与保存根边界核对，仅为独立参考，不是观测、完整叶片外轮廓或识别结果。

运行时把原始帧与只读塔面上下文配对发布。窗口的主线程轮询按需求建立专用锚点 BVH，并对 BVH 选中的三角面用 float64 精化最近点和距离；draw/consume 只消费已有结果。关闭窗口停止该窗口的 ROI 分析需求，重开或 ROI 变化可复用冻结快照，不生成新观测；工作区启用叶片估计时，会话仍按新配对帧计算派生估计。身份包含运行代、会话、来源／几何／标定、源帧／时钟及适用回放索引；每会话最多持有一份当前上下文、侧壁 BVH 和逐点距离结果；每窗口只缓存当前显示，不构成进程内存上界。分析上下文不进入帧 provenance 或记录队列；无上下文的历史记录保持原始显示，不借当前 Scene 补历史。原始来源、分析、普通 GPU 更新和录制错误分开；安装切换的必需 GPU 准备失败仍回滚。显示参考不进入在线分析，真实材料 ID、叶片标签与变形叶尖不参与在线距离求解。

工作区源码在临时距离分析失败后保留原始帧、撤回距离结果，并在当前机舱分析窗口仍有需求时限频重试；同一失败请求至少间隔0.25秒，ROI改变可立即重算。重试使用冻结的同帧上下文，不推进播放或产生新观测。

## 离线安装覆盖研究

在独立 Blender 后台进程显式运行，不依赖 UI 消费帧数，也不启动训练：

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python scripts/radar_x100/coverage.py -- --output /tmp/x100-coverage.json
```

输出文件必须不存在。工作区工具完整枚举所选源区间的 30 Hz 网格，用同一来源评价原位、前部下视、侧面及尾部下视四个基准；分别保存机械筛选、几何覆盖与模拟检测支持。`--package` 指定来源；`--candidates`、`--seed`、`--targets-per-group`、`--distal-span`、`--half-window-deg`、`--minimum-points`、`--roi`、`--bins` 为显式研究配置。覆盖 ROI 使用同刻机舱局部坐标，是离线参数，不读取窗口当前 ROI；硬件 FOV 和量程单独保存且不受 ROI 改变。

工程模型的 `--integration-budget` 默认16384，`--output-point-limit` 默认4096，两个预算独立；`--noise-seeds`、`--detection-min-points`、`--detection-config` 控制噪声种子、模拟支持门槛和模型参数。模型默认 `UNCALIBRATED`，不会把模型功率写成厂家 mag／rcs／snr。两类指标的分母、机械数值及来源见[安装覆盖搜索](X100观测研究.md#安装覆盖搜索)，完整假设与参数表见[工程检测模型](../../wfrl/radar_x100/README.md#工程检测模型)。

固定目标目录来自叶片外表面三角面重心，属于有限离散近似。默认每片两组各256点，三片总请求1536点；报告记录各组实际预算、去重数量及每时刻参考／驻留预算。E 是参考目录驻留集合，V 是其中通过几何视场与遮挡的集合，O 是独立候选采样实际输出的远端目标集合，V 不是 O 的严格上界。O 非空而 V 为空单独计数，不作为逻辑错误。真值材料身份仅用于离线评价，不写回在线分析。

当前工作区的 O 使用面积材料采样，以输出材料点索引及固定重心坐标评价展向位置；E／V 的质心参考目录独立保留。保存报告须按其 `sampling_method`、采样计划及对应载荷身份识别，不能用同名脚本推定不同载荷采用相同观测模型。

完整名义下方经过以保存解缠方位及叶片偏移、180°中心和显式角窗定义，不代表真实最小净空时刻。报告分别标注完整、截断、停转、反转、UNKNOWN，保留经过网格、角度分箱、条件计数与分母、连续段及缺口。主时间分母 N 是该经过期望源网格数，不删除 E 为空的时刻；零分母以 JSON null／N/A 表示。UNKNOWN 单列，含未知的评价不称完整求值。叶尖可辨识性及安全合格性为 NOT_EVALUATED。

保存的质心采样载荷[完整覆盖报告](../../outputs/x100-analysis/coverage.json)枚举1801个源时刻；两预设各有33次完整名义经过、期望网格累计895帧。原安装位有876帧出现远端目标输出，侧面为0，UNKNOWN均为0。该结果仅适用于报告的角窗、ROI、预算、seed及有限目标目录，不能理解成侧面所有时刻无点云或侧装已适合净空任务。完整参数、可见计数与证据边界见[工作区验证](发布状态与验证范围.md#x100-工作区源码验证)。

## 安装搜索与叶片估计（工作区源码）

安装搜索使用已有同源运动，在完整30 Hz网格比较有限位置／朝向和多个预算／种子；先要求机械与运动净空研究筛选通过、经过检测及适用塔距误差已知且有正支持，再按完整叶片经过的末段ROI检测、最长连续漏检、精确正下方支持和塔距误差排序，几何覆盖仅作辅助。在 **配置 → 安装覆盖搜索** 选择同次搜索生成的 `.summary.json` 或不超过 16 MiB 的完整 `x100-installation-search.v2` 报告，点击“应用搜索推荐安装”，保留当前预算。来源、几何、采样算法、当前安装包络或机械筛选要求不符，以及存在未知帧或缺少有效推荐时，拒绝应用。报告格式、机械策略或必要证据不符时，诊断会提示重新运行 `scripts/radar_x100/optimize_mount.py`。命令、两类支持指标及机械限制见[安装覆盖搜索](X100观测研究.md#安装覆盖搜索)。

按手册外壳尺寸筛选的有限候选集保留位置、朝向、检测与塔距指标，第一名仍存在经过内漏检。界面默认保持GEOMETRY。[有限候选比较与本地证据](X100观测研究.md#有限候选比较与本地证据)

**叶片关联与估计** 在几何仿真中使用同帧塔面、已知根部姿态和名义叶尖半径。机舱 XZ 中 B1／B2／B3 为橙／蓝／黄，线段表示候选拟合段，十字表示满足支持条件的模型叶尖；点数、跨度、外推或拟合条件不足时显示拒绝状态，当前帧没有叶尖或塔距时不沿用旧结果。该派生层不改写原始点云或逐点侧壁距离，不写入原始记录。历史文件和实时设备输入缺少相应上下文时不提供此估计。

复现保留的叶片评价时，将采样预算设为2048并应用几何仿真配置；界面初始预算仍为512。有限安装搜索的每帧至少3个远端点、质心报告的“存在远端输出”以及叶片估计的拟合支持是不同口径，不能直接比较百分比作为覆盖提升。原位置的82.5°与90°俯仰在保留搜索报告的主要覆盖指标相同，同源叶尖估计仍有米级误差；实际数值与像素检查见[研究验证](发布状态与验证范围.md#x100-观测研究工作区验证)。

## 几何仿真

工作区源码的 **X100 → 配置 → 安装位置（同一台雷达）** 提供“原安装位置”“机舱侧面”“T1 Down 相机位”和“尾部吊物口”四个快捷按钮。原安装位置为机舱局部 `(-3.5, -1.7, -2.0) m`、XYZ 旋转 `(0°, 82.5°, 180°)`；侧面位置依据当前静态机舱负 Y 侧壁确定，包络中心沿表面法向外移“旋转后包络投影半径 + 0.04 m”，旋转为 `(0°, 0°, -100°)`，朝侧方叶片区域。0.04 m 为两倍默认服务间隙，属于研究假设。点击后切换同一台雷达的安装并采样当前时刻，场景时间、采样预算和着色保持不变，不需要再次应用配置。切换前完成新观测及绘制数据准备，失败时保留原安装、观测与未应用参数；成功切换保留安装对象的选择和隐藏设置。位置与来源不变时，重复选择不重建安装对象；预算编辑仍等待下一新源样本；暂停时复用当前观测，时间推进仍按源采样网格刷新。记录和相机采集期间不能切换；来源仍是文件回放或实时输入时，先应用仿真配置；跨场景共享安装须先应用配置建立当前场景的独立安装。保存场景保留当前实际安装参数，重新打开后仍可切换；各位置为同一台 X100 的互斥预设，不同时生成两台雷达或两路点云。侧装使用几何视场与遮挡近似，不代表厂家安装方案或毫米波回波验证。

“T1 Down 相机位”取 `WFRL.Camera.T1.Gimbal` 当前在 YawRoot 下的位姿：雷达原点与相机光心重合，视轴为相机 −Z，传感器 +Z 为图像上方；视场取相机矩形视场，方位半角为镜头水平半角（约 45.75°），俯仰半角由 16:9 Down 画幅换算（30°）；视场形状为“相机矩形”（`PROJECTIVE`），按针孔相机画面判定 |y/x| ≤ tan 方位半角、|z/x| ≤ tan 俯仰半角，覆盖范围与相机画面一致。其他预设的视场形状为“方位／俯仰角”（`ANGULAR`），同样半角下在视场四角覆盖更多。“尾部吊物口”位于静态机舱尾端内缩 0.5 m、底面以下 0.5 m，横向偏移 −2 m（负 Y 侧，现场吊物口最大横向偏移）；视轴对准 6 点钟叶尖（源起始时刻叶片半径在转子平面内转到竖直朝下的位置），传感器方位轴保持水平，需要俯仰与偏航两个方向的扭转。该位置按示意机舱几何确定，不代表现场吊物口尺寸。原安装位、机舱侧面、尾部吊物口与搜索推荐使用规格书视场 ±60°／±22°。俯仰 ±30° 超出实测数据中观察到的 ±22.9°，属于按相机视场的仿真假设。

先加载本场景的风场柔性回放，选择“仿真”和观测模式，设置T1挂载、位置、XYZ旋转；GEOMETRY另设候选预算，再点“应用配置”。位置单位为米，角度为度；内部传感器轴为 `+X` 前、`+Y` 左、`+Z` 上。机舱挂载跟随同源塔顶运动与偏航，塔基／世界挂载固定。安装或来源改变后重新应用。

工作区默认按源起点表面积生成固定材料点，采用随机平移 Halton 序列；同一预算与种子确定同一计划，小预算保留大预算前缀。位置和速度差分运输同一材料坐标，减少网格疏密的影响；有限预算仍可能漏掉远端区域。公开 0.3.42.8 扩展采用面积采样，日常安装载荷也采用面积采样。

安装点显示一台现场安装形态的雷达：带散热鳍片的铝外壳与天线罩、铭牌、侧向 U 形支架、两个防水接头与线缆、带方形开窗和腰形孔的镀锌安装板。外壳连支架的包络为用户提供的 **173 (W) × 202.5 (H) × 175.6 (D) mm**，中心位于传感器原点，天线罩朝 +X 视轴；安装板、孔位和线缆走向按现场照片估计。该模型只用于显示，不参与雷达采样或遮挡，也不是厂家 CAD。机械净空与安装筛选使用同一包络（`schema.UNIT_ENVELOPE`）；手册外壳 120×95×40 mm 仍保留在 `schema.PROFILE`，相位中心和实际安装可行性尚未确认。配置面板的 **查看雷达** 把当前窗口的 3D 视口对准安装中的雷达，约 1.4 m 距离从视轴前侧上方观察，模型保持真实尺寸。场景中任一相机的光心落在雷达模型包围盒内时（“T1 Down 相机位”与 Down 相机共用光心），模型在视口和渲染中隐藏，避免外壳挡住该相机画面，此时 **查看雷达** 提示并不移动视口；判定在应用配置和切换安装位置时进行，之后手动移动相机不会重新判定；相机离开后只恢复为此隐藏前的可见性，用户自行设置的隐藏保持不变。名义视场为方位 ±60°、俯仰 ±22°，示意长度为 60 m；范围筛选使用 0.2～396 m。示意不等于全叶轮可见或厂家检测性能。

工作区源码的外壳、点数上限与默认视场从规范核心 `schema.PROFILE` 派生；已应用的“视场半角”（`wfrl_x100_field_of_view`，方位／俯仰）决定筛选、检测搜索网格、视场线和点云窗口角度范围，并写入帧 `provenance.field_of_view_deg`。不对齐的 26 字节点布局由同一核心提供。独立窗口角度范围为帧视场加独立定义的 6°／4° 显示余量（规格书视场时为方位 ±66°、俯仰 ±26°）；`schema.DISPLAY_DEFAULTS` 中的 60 m 示意长度和画布余量不改变探测规格。近程／远程模式各自的量程、点数与周期映射，以及完整 label 字节编码尚未确认，不按模式名推定。

工作区源码的仿真按 X100 帧率 33 Hz（`configuration.SAMPLE_RATE_HZ`，与实测序列一致）在本场景保存运动上取源时刻采样，不推进另一个场景的时钟。点云按采样时刻转换到世界坐标，不随当前机舱再次变换。暂停时仍核对源绑定、静态布局和实际安装，原生修改不匹配时撤回点云，不覆盖用户编辑；工作区与本机安装还拒绝安装对象或其父级的约束、动画及非对象父级关系，保留编辑供检查；恢复有效来源后清除过时诊断。着色变化复用当前观测。几何遮挡仅包含 T1 展示叶片、塔筒和机舱外壳，忽略其他结构、环境及合成缺陷的额外拓扑。GEOMETRY显示材料点差分径向速度，厂家RCS、SNR等未知属性为灰色；DETECTIONS的独立模型诊断见观测模式说明。工作区的叶片关联与模型估计使用独立派生层，不提供实机精度或安全报警。

工作区源码在暂停和新帧采样前核对来源 Scene、叶片／塔架／机舱及布局根的对象身份、场景归属、关键父链、父级逆矩阵与网格绑定，静态节点变换与面拓扑保持绑定。YawRoot 的父链重挂、同名替换或塔架解除场景链接均使观测失效；FarmFlex 合法更新的动态姿态不被冻结。机舱外壳还核对静态顶点和局部变换。编辑模式、约束、动画、修改器或形态键驱动的外壳不继续使用已绑定的静态缓存；检测到偏离时撤回观测并保留编辑。恢复原绑定后可恢复显示；需要使用修改后的静态外壳时，结束编辑并重新应用 X100 配置以建立新几何快照。重新绑定要求外壳为无上述驱动的静态网格，不会自动应用修改器或烘焙形态键。

当前时刻使用完整几何做遮挡；速度差分只计算输出材料点对应的顶点。遮挡树复用同时核对来源、几何身份、时刻及只读世界顶点／三角面内容，同刻原生变换或网格改变也会失效；仅三角面内容相同时复用多边形列表。该路径与完整几何差分使用相同材料点和区间，不通过减少观测或修改数值换取速度。

“开始记录”只记录实际采样到的帧。工作区源码在时间轴循环回起点或回拖造成仿真时间倒退时立即停止记录，失败原因为“仿真时间在记录期间回退（时间轴循环或回拖）；请开始新的记录”，已写入帧保留；不保证 UI 记录包含完整 33 Hz 网格。完整区间导出使用[数据接口说明](../../wfrl/radar_x100/README.md#几何观测)的独立脚本。新记录目录必须不存在，关闭或结束记录后才可完整回放。失败状态、错误与 `INCOMPLETE` 标记保留。工作区与本机安装把最后记录结果保存在所属场景，结束失败记录后仍显示“上次记录：FAILED”与失败原因；普通刷新、关闭或重新应用雷达不会把它清成成功，开始新的记录才清除上次记录错误。

工作区源码结束记录时先停止接收新记录帧，立即返回界面，再由轮询确认写盘线程退出；等待期间显示“正在结束记录”和记录状态 `FINALIZING`，保留记录器和会话归属，写盘线程退出后才公布 `COMPLETE` 或 `FAILED`；并禁止重复启动记录或替换会话。关闭 X100 同样等待写盘确认后才释放会话。文件加载、撤销／重做和卸载撤回观测并停止接收记录，保留必要的写盘收尾轮询；线程退出后释放原会话，不把记录延续到恢复后的场景。真正的记录失败保留 FAILED、原因和 `INCOMPLETE`，等待写盘本身不视为失败。公开附件与本机安装按各自载荷核对关闭方式。

工作区源码的记录至少包含一帧才可完成；零帧结束保留失败原因和 `INCOMPLETE`，有效零点帧可正常记录和回放。历史边界后的雷达按恢复场景重新绑定，不自动恢复记录。恢复复用归属明确的保存安装并保留各 View Layer 的隐藏选择；原生安装编辑与配置不一致时显示未就绪，保留编辑供用户检查。关闭安装时解除当前场景对独立共享对象的链接，保留其他场景的对象与网格。所属场景被删除时不再写入场景状态，但仍确认记录线程退出并释放会话；记录本身的失败或不完整状态不因此消失。源码、公开附件与本机安装的适用验证各按其载荷记录核对。

记录追加或关闭抛出异常时，记录停止并标为 `FAILED`，保留原因及 `INCOMPLETE`，不能以部分帧已写入判为 `COMPLETE`。正常关闭排空已接受的记录工作；失败后释放待处理项。显示提交保存快照，写盘前重新核对帧元数据，避免提交后被修改的帧成为完整记录。

未拟合：叶片表面 RCS 密度与入射指数（尚无叶片实测）、动静标志规则（取 |径向速度| > 0.25 m/s）、地面／海面／塔基杂波。校准只约束检测链统计，不代表叶片回波强度或保护效果已验证。核心 `DetectionConfig()` 默认仍为 `UNCALIBRATED`；覆盖研究脚本使用其 `--detection-config`。

## 叶片点云导出（T1 Down 相机位）

```bash
blender --background --factory-startup --python-exit-code 1 --python scripts/radar_x100/export_blade_ply.py -- --output <新目录> [--duration 60] [--fps 33] [--blade-model rootkink]
```

在 T1 Down 相机位以相机视场和校准配置逐帧生成 DETECTIONS，单帧输出上限 4096 点，面积积分 16384 点。输出目录须不存在，包含 `recording/`（传感器轴记录，含径向速度和模型诊断）、`ply/{序号:012d}_{帧号}_RawPoints.ply`（厂家字段布局与坐标轴：x = −y传感器，y = x传感器，z = z传感器，label 为 0）、`index.json`（每帧源时刻、点数、动点数、虚警数）及 `summary.json`（安装、视场、完整检测参数与限制）。`--blade-model` 选择回放叶片外形；`--start`／`--end` 为绝对源时刻，未给 `--end` 时导出 `--duration` 秒。

只观测风机几何（叶片、塔架、机舱），不含地面、海面或其他杂波；塔架回波在该视角占多数。

界面实时观察：在 **N → MAPPO** 的“叶片外形”选择“自改结构（叶根拐点改型）”，X100 选择“仿真”与 DETECTIONS 并应用配置，点击“T1 Down 相机位”，再打开点云窗口并播放时间轴，窗口按 33 Hz 源时刻显示当前帧。X100 已应用且无待应用修改、未在记录时，切换叶片外形会在同一时刻重新应用 X100 并采样新外形；记录中或有待应用修改时保留旧观测并提示重新应用。帧为瞬时独立采样，33 Hz 源时刻在保存运动上插值。

## 文件回放

工作区的已应用回放路径独立保存。使用 `//` 时，读取以当前 `.blend` 所在目录为基准，场景与数据一并移动后可按相同目录结构恢复。另存到其他目录时也以该目录为基准，需要相应的回放数据。快照中已有的绝对路径继续指向原位置。绝对路径和 `//` 路径之间切换时，即使当前指向同一文件，也会显示待应用，点击“应用配置”后更改引用方式。

选择“文件回放”，填写单帧 PLY 或显式索引记录目录，再应用配置。目录使用独立文件时间轴，可播放／暂停、上一帧、下一帧和跳转；工作区源码用 Python 双精度时间与索引选帧，界面时间属性负责显示／显式寻址，片尾停止后再次播放从起点开始；同一呈现时间的多帧可以按索引逐项访问。工作区源码中，路径或单帧声明改动尚未应用时，播放／暂停与上一帧／下一帧在面板显示错误而不中断操作，暂停始终停止播放。按时间寻址选取该时刻最后一项；起点前没有观测，片尾保留最后原始帧。完整记录目录保留原始来源，几何仿真记录仍显示 `GEOMETRY_SIMULATION`，合成输入不变成实测。

工作区源码的单帧 PLY 必须在“单帧 PLY 来源”中显式选择几何仿真、实测文件或测试数据，未声明时不能应用配置。PLY 本身没有来源字段；侧栏和点云窗口的“显式声明”表示用户提供的来源，不代表已验证设备或恢复原始记录元数据。改路径会清除声明，修改路径或声明后须重新应用配置，旧观测会撤回；完整记录目录忽略此单帧声明，继续使用文件内来源。来源选择不会补齐时间、速度或坐标标定。

工作区源码重录目录回放时，以实际选中原索引行的呈现时间为准，相对首个记录行归零，原始物理时间、时钟域和其他帧元数据保留。设备源时间递减或相等不会使正常向前重录失败或压缩呈现间隔。同一呈现时间的多个索引仍可逐项重录；主动返回较早索引使当前记录失败并保留不完整标记，需要另建记录目录。只记录实际显示并提交的行，不保证自动播放时捕获原包所有索引。

单帧 PLY 没有连续时间、速度或航迹身份。实测序列先按[显式索引合同](../../wfrl/radar_x100/README.md#ply-与显式索引)导入；仅提供帧率时显示 `FPS_DERIVED`，不代表硬件同步。真实样例、坐标轴、原点和运动补偿尚未核验时，按原始点云展示并标为未同步，不将其安装到不相关的 MAPPO 动画上测量。

PLY只接受规定字段顺序、类型和点数的binary-little-endian布局，载荷长度须精确匹配；头部含 `end_header` 行在内最多16384字节，超长行或截断头拒绝。DETECTIONS目录可另带 `clearance/<帧索引>.json` 的派生显示结果，按自身摘要及原始帧摘要核对；缺失或损坏时显示不可估计，不使用当前场景补算历史净空。

## 实时输入

实时模式只连接本机 `127.0.0.1` 的独立采集进程，设置端口、显示流和过期阈值，再应用配置。各流独立显示年龄、缺口、重复和显示替换计数。有效空帧清空点云，过期或断开隐藏旧点；新会话显式重新应用连接。Blender 最新帧不能代替完整采集记录，实时记录由外部采集端执行。工作区本地发布端空闲时也检查连接状态，新的显式连接可接管显示槽；部分发送后断开由接收端报告截断，重试重发完整帧并保留原到达时间，延迟交付不会重新变成新鲜观测。关闭发布端会中断阻塞发送并确认线程退出。该机制不提供应用层逐帧送达确认。

本地通道拒绝重复JSON键、非有限元数据、缺失或不支持的帧schema，以及无效身份、时钟、空间或来源字段。未知点属性仍按原数据合同保留，不用这些元数据规则补成有效点。分片到达恰逢超时边界时不能再完成该帧；组帧时间须有限，容量须为范围内整数。厂家UDP／SDK报文仍需独立解码。

已具备有界组帧、记录分流、本地版本／长度／身份校验和非阻塞消费基础设施；尚未实现厂家 UDP／SDK 解码或 Track 航迹。软件注入和文件转发不属于真实设备验证。真实接入最少还需要：一段逐帧真实 PLY 及明确时间索引／厂家显示对照，以及与设备固件匹配的 UDP 或 SDK、实际工作模式、网络配置、坐标／速度／时间与空帧说明。

## 相机与验证

X100 GPU 点云与批绘视场线不参与原始离屏 RGB；视场等对象使用 `wfrl_x100_role=annotation`，从原始预览和采集中排除，实体外壳保留。视场线不依赖视口辅助叠加开关；普通刷新不改写各 View Layer 的用户隐藏选择，视场开关和临时隐藏恢复相应状态，不改变相机 FOV 或画幅。相机采集期间拒绝应用／移除 X100 安装；所属场景的几何仿真保留采集前的观测，避免相机事务临时访问的时刻进入雷达记录，实时接收仍继续。实体外壳进入原始相机状态摘要，辅助物更新不改变该摘要。雷达与实机相机投影、时间同步和目标关联仍待独立实现与标定。

验证入口为 `tests/radar_x100/`（含 `test_analysis.py`）及 `blender_frontend/tests/blender/radar_x100_analysis.py`、`blender_frontend/tests/test_radar_x100_display.py`、`blender_frontend/tests/blender/radar_x100_regression.py`、`radar_x100_edges.py`、`radar_x100_history_regression.py`、`radar_x100_binding_replay.py`、`radar_x100_window.py`、`radar_x100_output_window.py` 与 `radar_x100_output_lifecycle.py`。后台检查覆盖同刻只读采样、安装变换、记录回放、暂停失效、重复时间索引、采集互斥、保存重开、原生撤销／重做与资源释放；窗口脚本分别检查雷达辅助物和独立输出窗口对真实 RGB、状态、时钟及相机参数的隔离。独立窗口脚本还检查 GPU 绘制、同帧消费、导航隔离、来源切换、有效空帧、未知属性、窗口重开与场景归属；脚本操作与真实键鼠操作分别判定。`radar_x100_output_lifecycle.py` 检查源码的保存／加载与撤销／重做清理、普通图像编辑器保护、重开及卸载时 GPU 缓存释放，不加载风场或运行求解。各脚本的源码／安装模式和身份变量按[验证入口](../../.agents/skills/windfarm-blender-dev/references/verification.md#执行环境与来源)逐项核对；`radar_x100_analysis.py` 与 `radar_x100_output_lifecycle.py` 仅验证源码，设置安装模块变量不会改变对象。原生脚本输出由 `WFRL_TEST_OUTPUT` 指向新目录。

工作区的几何基准、普通 GPU／录制错误隔离、安装回滚、实际窗口／RGB、场景历史与资源检查分别见[源码验证证据](发布状态与验证范围.md#x100-工作区源码验证)。面积采样、安装报告导入、叶片估计及拟合线／叶尖开关像素见[观测研究验证](发布状态与验证范围.md#x100-观测研究工作区验证)；脚本控制的画布检查不证明真实键鼠操作。源码结果不转记为公开ZIP或日常安装验收。历史分析上下文持久化、真实设备叶片／净空估计、实机接入与完整雷视融合仍待实现与验收；当前不考虑天气。
