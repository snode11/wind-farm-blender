# X100 雷达使用与验证范围

X100 位于公开 0.3.42.1 扩展、工作区源码及本机日常安装的 **N → WFRL → X100 雷达**。公开附件和日常安装按各自载荷身份核对。X100 与原有三束理想激光、双束净空和报警统计相互独立。

## 几何仿真

先加载本场景的风场柔性回放，选择“几何仿真”，设置 T1 挂载、位置、XYZ 旋转和材料采样预算，再点“应用 X100 配置”。位置单位为米，角度为度；内部传感器轴为 `+X` 前、`+Y` 左、`+Z` 上。机舱挂载跟随同源塔顶运动与偏航，塔基／世界挂载固定。安装或来源改变后重新应用。

120×95×40 mm 外壳是手册尺寸的近似外形；机械尺寸轴、相位中心和实际安装可行性尚未确认。没有厂家机械图时不建立假定孔位或支架。名义视场为方位 ±60°、俯仰 ±22°，示意长度为 60 m；范围筛选使用 0.2～396 m。示意不等于全叶轮可见或厂家检测性能。

仿真按本场景保存运动的 30 Hz 时间网格采样，不推进另一个场景的时钟。点云按采样时刻转换到世界坐标，不随当前机舱再次变换。暂停时仍核对源绑定、静态布局和实际安装，原生修改不匹配时撤回点云，不覆盖用户编辑；恢复有效来源后清除过时诊断。着色变化复用当前观测。几何遮挡仅包含 T1 展示叶片、塔筒和机舱外壳，忽略其他结构、环境及合成缺陷的额外拓扑。界面显示材料点差分径向速度，没有 RCS、SNR 或真实回波模型；未知属性为灰色。它不提供 X100 叶尖净空或安全报警。

“开始记录”只记录实际采样到的帧，回退造成记录时间倒退时记录失败；不保证 UI 记录包含完整 30 Hz 网格。完整区间导出使用[数据接口说明](../../wfrl/radar_x100/README.md#几何观测)的独立脚本。新记录目录必须不存在，关闭或结束记录后才可完整回放。失败状态、错误与 `INCOMPLETE` 标记保留。

工作区源码的记录至少包含一帧才可完成；零帧结束保留失败原因和 `INCOMPLETE`，有效零点帧可正常记录和回放。撤销／重做前结束当前记录并释放场景引用，按恢复后的场景重新绑定雷达；记录不会自动跨越历史边界继续。恢复复用归属明确的保存安装并保留各 View Layer 的隐藏选择；原生安装编辑与配置不一致时显示未就绪，保留编辑供用户检查。关闭安装时解除当前场景对独立共享对象的链接，保留其他场景的对象与网格。这些源码行为不作为公开附件或日常安装的复验结论。

## 文件回放

选择“文件回放”，填写单帧 PLY 或显式索引记录目录，再应用配置。目录使用独立文件时间轴，可播放／暂停、上一帧、下一帧和跳转；同一呈现时间的多帧可以按索引逐项访问。按时间寻址选取该时刻最后一项；起点前没有观测，片尾保留最后原始帧。几何仿真文件仍显示 `GEOMETRY_SIMULATION`，合成输入不变成实测。

单帧 PLY 没有连续时间、速度或航迹身份。实测序列先按[显式索引合同](../../wfrl/radar_x100/README.md#ply-与显式索引)导入；仅提供帧率时显示 `FPS_DERIVED`，不代表硬件同步。真实样例、坐标轴、原点和运动补偿尚未核验时，按原始点云展示并标为未同步，不将其安装到不相关的 MAPPO 动画上测量。

## 实时输入

实时模式只连接本机 `127.0.0.1` 的独立采集进程，设置端口、显示流和过期阈值，再应用配置。各流独立显示年龄、缺口、重复和显示替换计数。有效空帧清空点云，过期或断开隐藏旧点；新会话显式重新应用连接。Blender 最新帧不能代替完整采集记录，实时记录由外部采集端执行。

已具备有界组帧、记录分流、本地版本／长度／身份校验和非阻塞消费基础设施；尚未实现厂家 UDP／SDK 解码或 Track 航迹。软件注入和文件转发不属于真实设备验证。真实接入最少还需要：一段逐帧真实 PLY 及明确时间索引／厂家显示对照，以及与设备固件匹配的 UDP 或 SDK、实际工作模式、网络配置、坐标／速度／时间与空帧说明。

## 相机与验证

X100 GPU 点云与批绘视场线不参与原始离屏 RGB；视场等对象使用 `wfrl_x100_role=annotation`，从原始预览和采集中排除，实体外壳保留。视场线不依赖视口辅助叠加开关；普通刷新不改写各 View Layer 的用户隐藏选择，视场开关和临时隐藏恢复相应状态，不改变相机 FOV 或画幅。相机采集期间拒绝应用／移除 X100 安装；所属场景的几何仿真保留采集前的观测，避免相机事务临时访问的时刻进入雷达记录，实时接收仍继续。实体外壳进入原始相机状态摘要，辅助物更新不改变该摘要。雷达与实机相机投影、时间同步和目标关联仍待独立实现与标定。

验证入口为 `tests/radar_x100/`、`blender_frontend/tests/blender/radar_x100_regression.py`、`radar_x100_edges.py`、`radar_x100_history_regression.py` 与 `radar_x100_window.py`。后台检查覆盖同刻只读采样、安装变换、记录回放、暂停失效、重复时间索引、采集互斥、保存重开、原生撤销／重做与资源释放；窗口脚本检查更新雷达辅助物前后的真实 RGB 字节、状态摘要、可见性、时钟、相机参数和实际采集作业。原生脚本支持 `WFRL_ADDON_MODULE` 和 `WFRL_EXPECTED_ADDON_ROOT` 核对隔离安装来源，输出由 `WFRL_TEST_OUTPUT` 指向新目录。

当前软件检查不证明连续 30 Hz 绘制、长期满载性能、真实 PLY／UDP 兼容、厂家精度或现场保护效果。日常安装身份与配置保护见[安装记录](../../publication/daily-installation.json)，归档和精简检查结果见[安装核对](../../publication/daily-installation-x100/records/verification.json)。验证临时环境、合成录制和截图不作为交付资源保留。
