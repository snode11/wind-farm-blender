## 便携示例与时间合同

规范源为 assets/examples/mappo_reconstruction_split.blend（本地归档：`blender_frontend/wfrl_blender/assets/examples/mappo_reconstruction_split.blend`，未公开），随 ZIP 提供。用户安装路径为 **Blender 5.2+ → Preferences → Get Extensions → Install from Disk → 安装启用 ZIP → 三维视图 N → MAPPO → MAPPO＋重建示例**。当前文件未保存时先由 Blender 原生保存确认处理。

示例包含场景、MAPPO 数据、四张 packed 天空／地表纹理，无 linked libraries，无需作者本机文件或在线后端。四图分别为天空 HDR、地表颜色、法线和粗糙度图。原研究场景仍为 本地归档：`outputs/blade-recon-mappo-two-camera-20261004-a02/split-playback/MAPPO_demo_reconstruction_split.blend`；便携示例是其独立交付副本，不替代研究输入。

`wfrl_farm_flex_path` 保存为 `__WFRL_BUNDLED_MAPPO__`，由既有 manifest hash 匹配恢复到当前安装的 `assets/mappo`。匹配 hash 为 `d3002397dadf1e5351b9c9647add83f44b921a126dc800a97e1fc92897f71bde`；不能清空该路径或改为读取器不支持的 `//` 相对路径。

右侧三片叶片各 601 个绝对 shape keys，CONSTANT 样本保持，无 drivers。MAPPO 保存数据为 40 Hz，重建保存采样为 10 Hz，显示时间轴为 60 Hz。frame 52 的播放时刻为 117.850 s，保存重建样本为 117.800 s，保持时长为 50 ms。上一样本／下一样本先暂停并钳制端点。绿为两端截面受约束，橙为模型推断。

## 未验收范围

- 10 Hz 保存样本、40 Hz MAPPO 数据和 60 Hz 时间轴不是实际绘制帧率；本版未测稳定 60 FPS。
- 几何转换一致、软件播放及取景通过不构成重建精度、现场测量精度、硬件采样、保护延迟、完整片段性能或长期稳定性验收。
- 本轮没有运行 solver、Bridge、FAST.Farm 或渲染。Windows/Linux 未实测。
- 默认旧法与显式 TLS 雷达结果仍为 `REVIEW_ONLY / PENDING_ACCEPTANCE`；未改变历史研究数据或精度报告的结论。
