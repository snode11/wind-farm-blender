## 功能与使用

- Blade Recon v0.2 保存结果及三片 RGBA 图集导入，packed 纹理与嵌入数据的原生保存和新进程恢复。
- 原始纹理、增强灰度和青／洋红增强显示，人工选定的亮斑、横细线、纵细线近景。
- MAPPO → 进入重建对照使用内置独立合成纹理样例；样本步进、完整取景、布局恢复与退出沿用原分屏入口。侧栏绘制期间不写入材质。
- 保留原 601 样本便携 MAPPO＋重建示例、NREL 缺陷编辑器、三相机和原雷达回放。

新纹理样例为 SYNTHETIC，120 个保存样本、10 Hz、0–11.9 s，右侧样本游标与左侧 MAPPO 使用独立来源和时钟。右侧步进暂停左侧播放并保留其帧位置，不能解释为同源同步重建。

## 使用和限制

下载 ZIP，经 Install from Disk 安装后重启 Blender，加载 MAPPO 回放，在 **N → MAPPO → 进入重建对照** 使用新纹理样例；原 **MAPPO＋重建示例** 保留。操作说明见 [Blade Recon 使用说明](../BladeRecon可视化使用说明.md)。

增强仅改变显示。青／洋红表示纹理相对亮暗，绿／橙表示观测约束／模型推断；人工近景不代表自动缺陷检测、几何精度或现场效果验收。外部 `blade_recon0.2` 的纹理辅助几何和健康模板求解研究代码未打包，不能宣称本扩展交付了这些算法。Windows/Linux、稳定 FPS、长期稳定性和现场精度未验收，原雷达状态保持 REVIEW_ONLY / PENDING_ACCEPTANCE。0.3.16 已记录的叶尖精度失败及原生控制台切换崩溃原因未定，该包未据新纹理功能宣称修复；历史证据见 0.3.16 [发布核对](0.3.16发布核对.md)。
