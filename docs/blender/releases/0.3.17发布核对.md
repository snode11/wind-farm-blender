## 使用和限制

下载 ZIP，经 Install from Disk 安装后重启 Blender，加载 MAPPO 回放，在 **N → MAPPO → 进入重建对照** 使用新纹理样例；原 **MAPPO＋重建示例** 保留。操作说明见 [Blade Recon 使用说明](../BladeRecon可视化使用说明.md)。

增强仅改变显示。青／洋红表示纹理相对亮暗，绿／橙表示观测约束／模型推断；人工近景不代表自动缺陷检测、几何精度或现场效果验收。外部 `blade_recon0.2` 的纹理辅助几何和健康模板求解研究代码未打包，不能宣称本扩展交付了这些算法。Windows/Linux、稳定 FPS、长期稳定性和现场精度未验收，原雷达状态保持 REVIEW_ONLY / PENDING_ACCEPTANCE。0.3.16 已记录的叶尖精度失败及原生控制台切换崩溃原因未定，本次未据新纹理功能宣称修复；历史证据见 [0.3.16 发布核对](0.3.16发布核对.md)。
