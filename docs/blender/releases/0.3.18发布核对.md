## 修复及保留功能

- 场景恢复实例按场景绑定；复制场景缺少必要对象时明确未就绪，原场景继续回放；共享网格拒绝第二个时钟。
- 通过原生播放 PRE/POST 回调识别 owner scene，避免当前场景的单步、复位、停止或末帧处理误停另一场景；冲突明确拒绝。同进程仍是单一全局原生 player。
- C1/C2/C3 按实际固定槽位路由，缺少 C2 不把 C3 当成第二路，也不执行不完整三路分析。
- 采集核对原生／评估相机姿态、父级逆矩阵、约束、镜头和裁剪；拒绝非有限值，中断恢复事务并保留用户原生修改。
- GPU target 按采集事务／输出尺寸复用；Tools 新增版本、模块、构建、数据来源和默认关闭的短时视口绘制诊断；修正 `data.json` float64 姿态读取。
- 保留三机九片柔性回放、六类缺陷编辑、三相机、旧法及显式 TLS、原 601 样本几何示例、MAPPO 同源 601 样本纹理与独立合成 120 样本入口。
