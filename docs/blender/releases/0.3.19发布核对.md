## 展示工作流

- 从 **打开几何重建示例…** 进入左右完整风机分屏。左侧为 MAPPO 仿真，右侧三片叶片为保存的估计重建结果；右侧塔筒、机舱和轮毂为模拟展示结构。
- 当前分屏内用一个按钮在几何重建／同源纹理之间往返，保留播放时刻、播放／暂停状态和有效手动视图。纹理使用同一 MAPPO 两相机实验的 601 样本与固定灰度图集。
- 保留中段／叶尖两个人工观察点，仅定位一次。手动缩放、平移及自由绕转后，继续播放保留视图。点击原始／增强显示时先恢复两侧整机取景，再手动放大寻找纹理细节。
- 共享播放／暂停、单帧步进、复位与退出保留；10 Hz 保存重建样本每六个 60 Hz 显示帧保持。时间、样本及颜色说明在右侧视口左下角显示。
- 精简重复入口、上一／下一样本、进度滑块、自定义观察字段、自动跟随、完整取景、恢复布局和独立合成入口；独立 `synth_tex` 资产／底层工具保留自己的来源与 120 样本游标，其他功能页保留。
- 保存 `.blend` 后重开恢复当前模式、纹理选择、时间及视角，不触发显式原始／增强按钮的重新整机取景。

## 保留的研究与使用限制

几何与纹理仍为 **NOT_ACCEPTED**；原 0.2 mm 叶尖精度门槛仍为 **FAILED_GATE**；TLS／旧法仍为 **REVIEW_ONLY / PENDING_ACCEPTANCE**，既有 Blade Recon 失败状态不变。本轮为展示和回放交付，没有重跑 FAST.Farm、改写物理结果或放宽阈值。

同源图集由已有 Workbench 材质色仿真 RGB、掩码和逐时刻动态标定融合为每片叶片的固定灰度图集。原始／增强只改显示，滚轮放大不新增纹理分辨率；人工观察点不是自动检测的缺陷。图集的模糊、展向条带、接缝、叶尖错贴和拖影如实保留，未证明真实缺陷恢复。

40 Hz MAPPO 源、10 Hz 保存重建样本和 60 Hz 显示时间轴分别报告；软件流程通过不等于稳定 60 FPS、长期运行、Windows/Linux、实体三相机、拼接、现场精度或安全保护验收。
