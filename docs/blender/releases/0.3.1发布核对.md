## 数值与使用限制

有限数值敏感性对照中，最细 OpenFAST 步长相对该包的塔顶最大差 **0.442 mm**、叶片分量最大差 **11.410 mm**；塔筒积分节点细化的塔顶最大差 **6.445 mm**。这些数字只支持对应参数的展示用途筛查，不是完整风场、尾流、气动展向或边界影响的收敛认证。

T1 B2 有效样本为 **18/122**，低有效率保留，固定标定估计不补偿塔架弯曲。塔筒没有专用虚影、位移箭头或数值卡片。后台通过不能替代该发布包的完整鼠标操作、Windows 实机、持续 60 FPS、长期运行、完整录制/渲染、现场精度或控制收益验收。

原始 VTP 不随安装包交付，缺失原始数据时相应源表面抽查明确跳过；normal/close 校验也需要匹配外部包。原说明未提供可用的独立原始日志入口，不能据本页摘要复查所有测试明细。复验需使用匹配的 0.3.1 源码和载荷；当前构建器默认产物不能冒充该包。
