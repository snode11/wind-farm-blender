## 三相机行为

- **View → 三相机 → 1 · 安装整个盒体 → 恢复默认三相机** 读取随包内置的 `assets/cameras/t1-three-camera-default.json`，恢复默认盒体位置、朝向与 C1–C3 参数。默认资源及规范示例未改变。
- 保留当前帧、子帧和观察视角，提供相机撤销；已处于有效默认状态时不重复重建。编辑草稿、整盒放置、采集或后端暂停请求未完成时阻止复位；失败保留原布局与历史。
- 更新原生观察及布局的相机引用和退出快照。单路观察中复位后，退出继续使用替换后的相机，保留原自由视图。
- `network`／`files` 权限说明符合 Blender 格式要求；重建对照复用源结构细节，T2/T3 切换保持右侧结构与完整取景。

## 保留的验收边界

该包展示保存的仿真与重建结果，不包含重新求解或物理数据修改。几何与同源纹理仍为 **NOT_ACCEPTED**，原 0.2 mm 叶尖精度门仍为 **FAILED_GATE**，雷达仍为 **REVIEW_ONLY / PENDING_ACCEPTANCE**；既有 Blade Recon 失败门槛保留。

同源纹理使用 601 保存样本和固定灰度图集；独立合成 `synth_tex` 保持不同来源及 120 样本。原始／增强只改变显示，人工观察点不代表自动缺陷检测；条带、接缝、叶尖错贴及未观测区域保持。固定三相机默认布局不保证全转动周期无盲区，也不构成拼接、实物标定、现场精度或安全保护验收。

外部材料点候选 Patch 2/8、Crack 7/8、跨相机 RGB 0/264，仍为 FAILED_GATE / NOT_ACCEPTED，same_material_error_m 与 primary_gains 为 null；该[研究结果](../../../blade_recon0.2/docs/材料点对应实验报告_2026-10-11.md)不替换扩展正式 601 样本和图集。
