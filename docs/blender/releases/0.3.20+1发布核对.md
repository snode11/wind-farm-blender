## 三相机修补行为

- **View → 三相机 → 1 · 安装整个盒体 → 恢复默认三相机** 读取随包内置的 `assets/cameras/t1-three-camera-default.json`，恢复默认盒体位置、朝向与 C1–C3 参数。默认资源及规范示例未改变。
- 保留当前帧、子帧和观察视角，提供相机撤销；已处于有效默认状态时不重复重建。编辑草稿、整盒放置、采集或后端暂停请求未完成时阻止复位；失败保留原布局与历史。
- 更新原生观察及布局的相机引用和退出快照。单路观察中复位后，退出继续使用替换后的相机，保留原自由视图。
- 最终清单缩短 `network`／`files` 权限说明以符合 Blender 格式要求；沿用 0.3.20 的重建模型细节和 T2/T3 显示修复。

## 保留的验收边界

本轮是相机操作修补及 ZIP 交付，没有重跑 FAST.Farm、训练、重建求解或修改物理数据。几何与同源纹理仍为 **NOT_ACCEPTED**，原 0.2 mm 叶尖精度门仍为 **FAILED_GATE**，雷达仍为 **REVIEW_ONLY / PENDING_ACCEPTANCE**；既有 Blade Recon 失败门槛保留。

同源纹理使用 601 保存样本和固定灰度图集；独立合成 `synth_tex` 保持不同来源及 120 样本。原始／增强只改变显示，人工观察点不代表自动缺陷检测；条带、接缝、叶尖错贴及未观测区域保持。固定三相机默认布局不保证全转动周期无盲区，也不构成拼接、实物标定、现场精度或安全保护验收。
