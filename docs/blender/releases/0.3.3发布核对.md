# 0.3.3 安装包身份与验证范围

本文仅标识 **0.3.3** 载荷及 **2026-09-17** 的验证结果。安装包为 `wfrl_blender-0.3.3.zip`，SHA-256 为 `eef7356b30afab4a0c7fac10d4d4567051005599316e49775ead3c31d15ece82`。包使用 0.3.1 的物理数据，保持 **`REVIEW_ONLY`**；当前版本入口见[发布状态](../发布状态与验证范围.md)。

## 功能与验证事实

密封圈随塔顶截面运动，**28 / 56 m** 焊缝随各自截面运动；装饰密封圈外半径为 **1.898 m**，不改变物理塔架或雷达标定。151.733 s 的未随动对照相对正确支承变换偏移约 **0.2164 m**，该数值是附件变换对照，不是物理塔架精度。

## 限制

该载荷的短服务电缆末端悬空，末端中心距离机舱表面约 **6.7 cm**。Windows 实机、新窗口鼠标交互、稳定 FPS、全时段全部零件碰撞扫描未验收。部分 Blender 退出日志有少量未释放内存诊断，退出码为 0 不证明长期内存稳定。
