# 0.3.4 安装包身份与验证范围

本文仅标识 **0.3.4** 载荷及 **2026-09-18** 的验证结果。默认数据为 BeamDyn 预弯 v3 三机 **60 秒**离线回放，包含独立未受载参考、根系 xyz 挠度、**1.5 秒**轨迹渐隐和 Down 视角，状态为 **`REVIEW_ONLY`**。当前版本入口见[发布状态](../发布状态与验证范围.md)。

## 包身份与验证

安装包为 `wfrl_blender-0.3.4.zip`，SHA-256 为 `3f2c718e3ae438a49786df4de2f92a1153fd405ea026521d8c19f3e22434a9b0`。ZIP CRC、内置清单摘要及该版本已安装的 **107 个文件**逐字节匹配，见[包核验](../../../evidence/release-0.3.4/package-check.json)。

- [宿主结果](../../../evidence/release-0.3.4/host-tests.log)：**19 项**通过，覆盖可重复打包、独立导入、全部 **7,203 个** T1 保存叶尖、原始表面独立变换、雷达状态/过期/阈值与 v3 参考合同。
- [原生结果](../../../evidence/release-0.3.4/native/checks.json)：独立 ZIP 在 macOS / Blender **5.2.1 LTS** 后台通过三机回放、同刻视角/FPS 切换、保存重开及独立参考恢复。抽样保存帧最大分量偏差 **1.378 mm**，插值帧 **1.913 mm**。
- 后台帧更新 p95 为 **73.19 ms**，不等于可见窗口绘制 FPS。进程退出码为 0，仍有少量未释放内存诊断。

## 限制与复验条件

该载荷固定三束覆盖状态为 **`FAILED_AVAILABILITY`**，不以真值补齐无效读数。二维扫描候选不在包内。Windows 实机、现场精度、完整数值收敛、长期稳定性与稳定 60 FPS 未验收；后台结果不能替代完整窗口交互。

对应原生脚本为 `blender_frontend/tests/blender/prebend_regression.py`。复验需使用匹配的 0.3.4 源码及隔离解包载荷，设置 `WFRL_TEST_RUNTIME`、`WFRL_FARM_FLEX_PACKAGE` 和新的 `WFRL_TEST_OUTPUT`。当前构建器默认生成当前版本，不能直接称为 0.3.4 重建。原始 VTP 不随安装包交付；缺失时相应独立几何核验跳过，不能计为通过。
