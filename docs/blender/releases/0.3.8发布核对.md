# 0.3.8 安装包身份与验证范围

本文仅标识 **0.3.8** 载荷。安装包 SHA-256 为 `fa109829c598619aa647863a71d0fe0dddbc76a5394b7a1fd3be1a37d1acfe44`。当前公开包、源码与日常安装身份见[发布状态](../发布状态与验证范围.md)。

## 功能与验证事实

该载荷使用三相机堆叠盒体。加载 MAPPO 自动创建 C1/C2/C3 和共用盒体，整盒移动时三台光心共同移动、保持上下堆叠；可在机舱选点，输入整体 XYZ/水平朝向，并分别调整相机俯仰、方向与视场。

提供三路原生预览、同刻/序列 PNG、内外参、布局导入导出及撤销；盒体和相机参数共同保存/恢复。四路 JSON 输入明确拒绝，拒绝时保持当前布局。旧 `.blend` 不自动重建为堆叠盒体。

[结构化验证](../../../evidence/release-0.3.8/verification.json)记录 **170 项宿主测试**（含安装包复现检查）通过；macOS / Blender **5.2.1 LTS** 的已安装包、三视口、同步原图、序列采集、撤销及失败回滚检查通过。该检查没有完成鼠标选点的人工点击验收。

## 限制

该载荷盒体初始尺寸为 **29×18×10 cm**、相机约 **2.8 cm**，属于仿真假设；真实镜头和玻璃未标定。固定视野按参考姿态配置，不保证整个转动周期无盲区，不含拼接算法。

内置仿真数据为 **`REVIEW_ONLY`**。Windows/Linux、真实安装硬件、完整片段性能、长期稳定性和现场精度未验收。Blender 退出少量未释放内存块诊断仍保留，不因软件检查通过计为已解决。
