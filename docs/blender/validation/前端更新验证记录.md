## 0.3.10 r1 操作与性能范围

r1 隔离安装覆盖独立单路、独立三路、关闭后新开三路、播放中切换及暂停后切换。其完整片段结果只属于 r1 的实际路径，不作为后续版本性能保证。

两种切换路径均完成目标区间，但 C1 最大绘制间隔约 **0.57 s**；暂停切换还包含约 **0.587 s** 主动暂停。场景时钟继续推进不能证明可见画面毫无停顿。三路 PROFILE 开关各一轮为 **23.79 / 23.47 FPS**，不足以分辨计时器的独立开销，也不能声称零开销或开启提升性能。

约 2 s 暂停观察中，runtime timer 保持运行，无变化重绘跳过，主窗口/单相机窗口各 8 次回调、三相机合计 24 次。此项描述暂停绘制工作，不是播放 FPS 收益。

## 复验入口

从匹配源码和依赖环境的仓库根目录运行，使用新的输出目录。同一时间只运行一个 Blender 验证进程，避免其他渲染改变 GPU 条件。

```sh
PYTHONPATH=blender_frontend:. python3 -m pytest   blender_frontend/tests --ignore=blender_frontend/tests/blender -q

python3 scripts/blender/validate_frontend_package.py   --output outputs/frontend-package-check

python3 scripts/blender/run_playback_benchmark.py   --addon-module bl_ext.user_default.wfrl_blender --no-factory-startup   --path triple --layout GRID --profile   --output outputs/frontend-playback-check
```

包验证器的 `--build-only` 状态为 `BUILT`，不是安装 PASS。日常安装检查须读取实际模块路径和载荷身份；不能由工作区源码测试替代。

## 限制

Mac17,8 / Apple M5 Pro / 24 GiB / macOS 27.0 arm64、820×473 逻辑窗口、UI scale 2、预览倍率 2、8 次采样、`FRAME_DROP` 与渲染 FPS 60 是对应性能结果的条件。逻辑窗口、绘制区域物理像素和显示器扫描输出不混用。

这些结果不保证稳定 60 FPS、其他机器、任意窗口尺寸、物理键鼠操作或硬件同步。默认相机的固定取景材料为 `REVIEW_ONLY`，不证明全周期覆盖、真实镜头标定、实际拼接或硬件安装认证。物理精度、雷达保护延迟和用户接受须用各自证据判定。
