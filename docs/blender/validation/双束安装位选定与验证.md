# 双束安装位置约束与输入校验

双束发射器只允许位于**叶轮与塔筒之间的机舱内侧**，采用机舱底面中心线安装。有效仿真布局为 `[-2.5,0,87.54756] m` 和相对竖直向下朝叶轮侧 **10°/12°/14°**；详细数据与证据见[双束内侧安装位与验证](双束内侧安装位与验证.md)。

`configs/lidar/dual-beam-selected.json` 的状态为 `REJECTED_OUTSIDE_INNER_MOUNT`，`selected_for_use=false`。后处理与读取器必须拒绝不满足内侧约束的标定和结果包，不能将该文件当作运行入口。有效标定见[内侧配置](../../../configs/lidar/dual-beam-inner.json)及[手册合同配置](../../../configs/lidar/dual-beam-inner-manual-contract.json)。

三束共原点、外壳及支架尺寸是仿真假设。源保存姿态下的包络间隙检查不能代替连续时间避碰、载荷、光机设计或现场安装批准。高精度柔性叶尖反演仍为 **`REVIEW_ONLY / PENDING_ACCEPTANCE`**。

当前安装使用 **MAPPO → 净空 → 双束净空 / S1**，TLS 通过候选按钮显式选择。公开安装包、源码与日常本地修订的身份分别见[发布状态](../发布状态与验证范围.md)。
