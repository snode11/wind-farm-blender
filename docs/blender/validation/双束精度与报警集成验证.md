## 2. 《雷达3.0》实际规定了什么

依据仓库父目录《雷达3.0.pdf》，Molas CL V3.0-202310，SHA-256：`1a126ba6420f47136b17986064908215d6b0d7e0d574ff56247c1255b07a0363`。以下为 PDF 页码，含封面；印刷页码约少一页。

| 手册位置 | 内容 | 本项目处理 |
| --- | --- | --- |
| 第 7–8 页 | 测距精度 ±0.2 m、重复性 ±0.2 m、分辨率 ≤0.1 m | 不将这些指标写成柔性叶尖净空精度 |
| 第 8–10 页 | 相对束角与安装标定 | 标称角度仅作设备参考；当前布局保持 10° / 12° / 14°；实体安装以单机标定为依据 |
| 第 32–35 页 | 各通道原始采样 20 kHz，DP 输出 50 Hz / 20 ms | 当前保存几何是 40 Hz 理想首交，不等于真实脉冲数据或 DP |
| 第 32–35 页 | 距离以 cm 编码；65535 无效；距离 4 的 10000 为检测区外/地面哨兵 | 无效净空保留空值，不显示为安全的 100 m |
| 第 32–35 页 | DP 可能采用 20 ms 内叶片测距平均值 | 同一数据包的 S2/S3 不自动获得同时刻、同叶片身份 |
| 第 34 页，3.5.3 | 单束距离、角度、安装偏置与塔半径的简化公式，并说明叶片弯曲误差 | 作为手册公式单独保留，不冒充高精度双束柔性反演 |
| 第 35–36 页 | 系统状态、回光、故障和报警位 | 保留异常与未知状态；低净空警告位不屏蔽独立 S1 |

手册没有公开完整的柔性反演算法、最终净空精度保证或传感器至保护执行器的端到端延迟。因此不能仅靠这份手册给现有净空结果盖上“±0.2 m 达标”结论，也不能把 DP 周期 20 ms 当成保护延迟。

新增 [molas_cl.py](../../../wfrl/lidar/molas_cl.py) 是**已解析 DP 字段的语义解码器**，不是二进制总线驱动，也没有建立硬件连接。它处理单位、有效位、系统状态、低回光、计数器重复/回绕及未知时序；不制造叶片编号或光学命中时间。故障级位的拒绝策略明确标为本地保守策略，不宣称复现厂商固件。带 DP 时间区间标识的数据会被瞬时双束估计器拒绝。

## 3. P03：误差诊断完成，高精度反演未完成

本轮重新计算当前确认布局的 117–177 s、40 Hz 数据。三机仍有 94/94 次完整朝下经过包含有效双束配对，合计 400 个有效样本。

| 机组 | 配对样本 | 净空 MAE / m | 最大高估 / m | 两点方向与真实轮毂—叶尖方向最大夹角 |
| --- | ---: | ---: | ---: | ---: |
| T1 | 131 | 3.754 | 7.201 | 7.061° |
| T2 | 136 | 4.595 | 8.033 | 7.638° |
| T3 | 133 | 4.442 | 7.595 | 7.250° |
| 合计 | 400 | **4.269** | **8.033** | — |

合计绝对误差 P95 为 7.201 m，使用 nearest-rank 口径；净空误差定义为估计减独立仿真参考，正值表示高估。参考是同高度变形塔截面与结构叶尖的水平距离，不是整个叶片表面连续时间最小净空。

当前公式仍为 `T_est = H + R_eff * normalize(P3 - P2)`。主要诊断是：**两个叶片表面交点的方向不能直接等同于轮毂至柔性叶尖的方向。** 本批数据两点直线到轮毂的距离平均约 1.65–1.99 m，最大约 2.68 m；`R_eff / 两点间距` 在 2.29–7.86 之间，会放大方向扰动。理想无测距噪声条件下已经有上述米级误差，不能仅靠增加采样率消除模型偏差。

对每个有效配对进行 16 组 ±0.2 m 量程、±0.2° 相对方向端点扰动，最大净空变化约 1.52–1.57 m。此实验固定原命中对象，仅用于敏感性诊断；没有重新追踪扰动射线，不是实际单机标定误差、置信区间或系统误差上界。

仅给两个交点，柔性叶尖仍不可唯一确定。例如在两命中展向位置 `s2, s3` 之间外加形变 `a*s²*(s-s2)*(s-s3)`，可保持根部位置/斜率和两交点不变，却改变叶尖。需要额外、经过验证的叶片曲率/截面模型或其他观测约束，不能任意假设直线、球面或简化悬臂曲线就宣称准确。

本轮试算的简化模型以及误套手册角度的候选均已排除，记录在 excluded-experiments.json（历史路径 `../../outputs/dual-beam-improvement-20260929/excluded-experiments.json`，本地缺失），未装入最终 ZIP。没有把本段真值拟合成偏置补偿，没有将当前真实叶尖、终端截面变换输入估计器。

后续精度工作需要的具体输入是：单台设备三束出射原点/方向标定、同步原始回波及叶片关联信息、能够约束挠曲/扭转的独立物理模型或测量，以及独立工况和实测对照。现有仿真已知机舱姿态、塔架表面和叶片编号也必须在实机链路中找到可验证来源。取得这些约束前，P03 保持未完成；不自行填入精度容限或换用未经验证的“高级算法”制造达标数字。

完整诊断及最差样本见 audit.json（历史路径 `../../outputs/dual-beam-improvement-20260929/confirmed-audit/audit.json`，本地缺失）。

## 4. P04：软件报警与采样证据

| 机组 | 保存样本中的 S1 命中数 | 合并事件数 | 完整朝下窗口中无 S1 命中的次数 |
| --- | ---: | ---: | ---: |
| T1 | 53 | 28 | 5 / 33 |
| T2 | 77 | 33 | 0 / 33 |
| T3 | 73 | 28 | 0 / 28 |

203 个保存命中与 89 个事件中的命中记录完全一致；每个事件输出时间等于首个保存命中时间，软件仿真时间逻辑延迟为 0。**这不是物理零延迟。** 40 Hz 之间的实际首个命中时刻未知，设备处理、通信、显示和保护执行延迟也未知；1 仿真秒仅是显示保持。

这批实际保存数据中，所有 S1 命中恰好也有 S2/S3 配对，因此它不能单独证明“S2/S3 缺失时 S1 仍报警”。该独立性通过专门构造的单元测试验证，并在 DP 解码器中检查仅 S1 有效、S2/S3 无效时的报警输出。

T1 的五个无 S1 命中窗口不直接等于安全漏报：朝下经过不自动构成必须报警的真实危险事件。现场漏报率需要独立定义危险事件的真值、时间窗和分母后才能计算，目前保留未知。

对 40 Hz 保存序列按所有采样相位降采样：

- 20 Hz：T1 丢失 3–4 / 28 个原有事件，T2/T3 本段未额外丢失；保留事件最多再晚 25 ms。
- 10 Hz：T1 丢失 13–16 / 28，T2 丢失 12–15 / 33，T3 丢失 6–13 / 28；保留事件最多再晚 50 ms。

这些仅是相对 40 Hz 的损失。它们证明降采样会丢事件，不能证明 40 Hz 已充分，也不能代替手册的 20 kHz 回波与 50 Hz DP 链路。下一步需要高频输出或真实原始测量建立连续事件参考；将当前数据插值到高频不产生新证据。
