## 已实现的计算与回放

- `wfrl/lidar/dual_beam.py`：从 S2/S3 原始斜距和安装方向恢复两点，只接受同刻、同叶片的有效首交；检验量程、点间距和根到尖方向；从轮毂以固定长度外推叶尖，再计算同高度变形塔筒的有符号水平净空。估计器不接收真实叶尖、参考净空或当前帧真实长度。
- 有效长度固定为独立无载预弯参考 `[-1,0,63] m` 的模，约 63.00794 m，包含轮毂中心到叶根的长度口径。独立评估将同一结构参考点经保存的末截面变换恢复；末截面轮廓表面净空另列，不能混充结构叶尖真值。
- S1 每次有效叶片首交立即记入原始命中时间。连续同叶片命中归为事件，首次命中即输出，不等待事件结束或双束成功。地面、塔筒不触发；量程外或无效观测输出未知。
- 第一版报警显示和净空整组读数分别保持 **1 仿真秒**，写入配置。保持时长只是显示规则，不能解释为保护延迟。未知观测不清除历史报警；显示到期后未知仍显示未知。
- `wfrl/lidar/dual_beam_replay.py`：独立 `wfrl.dual-beam-review.v1` 结果目录引用原几何包，并校验源文件与结果摘要；不修改 v3 源包或旧 B2 字段。读取器按仿真时刻查询预计算累计状态，后退不泄露未来事件，重播不重复累计。
- Blender 原有柔性三机、相机和播放流程中加入新模式。S1 卡片独立显示；S2/S3 缺测显示等待或明确标注的历史整组读数；未知输入显示数据无效。新模式不会显示旧 7 m 阈值或沿用旧单束验收结果。三束方向和各自原点来自同一标定。

模型输入条件是已知仿真机舱、变形塔筒和叶片编号。射线候选包含完整三叶片表面、变形塔筒及地面；装饰外壳、支架等显示物体不进入计算。这不代表真实设备已能测出上述姿态或编号。

## 运行和加载

在仓库根目录，使用已具备 NumPy/SciPy 的 Python：

```sh
/opt/anaconda3/bin/python scripts/lidar/postprocess_dual_beam.py \
  --calibration configs/lidar/dual-beam-diagnostic.json \
  --output outputs/dual-beam-diagnostic-new
```

输出目录必须不存在，避免覆盖已有结果。结果目录通过 manifest 中的相对 `source_package` 引用原几何；移动目录后应保留相对关系，或者显式调整路径并重新核验摘要。当前侧车不是无需源几何即可携带的独立数据包。

源码版 Blender 可以通过现有 `wfrl.load_demo` 操作的 `package_path` 加载该结果目录，或调用：

```python
wfrl_blender.load_demo_scene('/Users/eason/Desktop/wfcrl/wind farm RL/outputs/dual-beam-diagnostic-20260928')
```

本次可视检查脚本位于 `evidence/dual-beam-20260928/open_review.py`，从仓库运行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --factory-startup \
  --python evidence/dual-beam-20260928/open_review.py
```

它在独立窗口加载源码和诊断结果，保留现有三相机模块，展示 T1 侧前方；右侧选择 MAPPO → 净空。已安装版本尚未更新，不能仅双击生成的 blend 就假定它会自动载入最新源码。
