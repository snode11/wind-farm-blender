# 双束重建与 S1 报警接口

当前双束链路使用机舱内侧 `[-2.5,0,87.54756] m`、**10°/12°/14°** 标定，默认 `hub-axis.v1`，TLS 为显式候选。安装操作与包身份见[发布状态](../发布状态与验证范围.md)，标定和源保存网格结果见[内侧安装验证](双束内侧安装位与验证.md)，方法对照见[TLS 研究说明](../../lidar/双束TLS候选实施与验证总报告.md)。

## 计算合同

- `wfrl/lidar/dual_beam.py` 从 S2/S3 的原点、方向和原始斜距恢复两点，只接受同刻、同叶片有效首交，检查量程、点间距和朝向。默认方法沿两点方向从轮毂以固定长度外推叶尖；TLS 使用过已知轮毂的等权正交拟合方向。
- 有效长度固定为独立零载预弯结构参考 `[-1,0,63] m` 的模，约 63.007936 m，包含轮毂中心到叶根的长度。真实叶尖、真净空和终端柔性变换不进入估计器。
- 净空为预测点到同一全局高度处变形塔截面的有符号水平距离。结构叶尖参考、末截面轮廓表面、全叶片和连续时间最小净空分别评价。
- S1 有效叶片首交独立记入命中与事件，不等待 S2/S3 成功。地面和塔筒不触发；无效或超量程保留未知。测量和报警保持均为 1 仿真秒，只是显示规则。
- `dual_beam_replay.py` 读取 `wfrl.dual-beam-review.v1`，核对结果、完整源文件摘要、机组和时间范围；按目标仿真时刻重算前缀状态。后退不泄露未来事件，重播不重复累计。

仿真机舱姿态、变形塔筒和叶片编号是已知输入条件，尚未证明真实设备能够提供等价观测。计算射线包括完整三叶片、变形塔筒与地面，装饰外壳和支架不进入求交模型。

## 后处理与加载

从完整工作区根目录，使用具备 NumPy/SciPy 的环境，显式选择有效标定并写入新的输出目录：

```sh
python3 scripts/lidar/postprocess_dual_beam.py --calibration configs/lidar/dual-beam-inner-manual-contract.json --output outputs/dual-beam-review-new
```

结果目录通过 manifest 的 `source_package` 引用原几何，侧车本身不能脱离源包携带。使用 `package_dual_beam.py` 生成包含完整 `source/` 的可携带包；安装版内置双束/TLS 层则共用 `assets/mappo/` 源数据。格式见[回放合同](../../../wfrl/lidar/REPLAY_FORMAT.md#dual-beam-review-v1)，工具见[脚本说明](../../../scripts/lidar/README.md)。

安装版通过 **MAPPO → 净空 → 双束净空 / S1** 或 **TLS 候选 / S1** 加载。读取器失败须清空旧读数；没有读数或报警不等于安全。

## 验证与限制

默认方法的内置三机 117–177 s、40 Hz 片段有 **94/94** 次完整朝下 ±15° 经过含有效配对，合计 **400** 个样本；并非每帧持续命中。公共有效集合的旧法 / TLS MAE 分别为 **4.268685 / 0.776096 m**，两者仍为 **`REVIEW_ONLY / PENDING_ACCEPTANCE`**。

宿主测试覆盖刚性解析、点序、坐标变换、扰动、间距、负净空、错误时间/叶片、遮挡、无效输入、独立 S1、保持、后退、空统计及损坏合同拒绝。软件接口通过不等于柔性反演精度、现场漏报率、端到端保护延迟或连续避碰通过。完整评分范围、独立工况与时间细化限制见 TLS 研究说明。
