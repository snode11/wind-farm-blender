# 发布状态与验证范围

发布版本为 **0.3.42.1**，源码标签 `v0.3.42.1`，Blender manifest 使用 SemVer **0.3.42+1**。公开状态与附件身份见[交付记录](../../publication/blender-0.3.42.1.json)，本机安装见[安装记录](../../publication/daily-installation.json)。

## 源码软件合同与验证

X100 允许尚未超时的在途前帧继续组装，记录队列保留接受的观测，显示槽不以迟到前帧替换较新帧。零帧记录失败并保留不完整标记，有效零点帧可正常回放。关闭安装解除当前场景对共享对象的独立链接，保留其他场景引用；撤销与重做前释放运行引用，恢复时重新绑定当前 FarmFlex，保留用户隐藏选择和原生安装编辑。

相机采集核对 `frame_set()` 请求与实际时刻；外部回调修改帧或子帧时事务保持未完成，不覆盖用户时钟。保存重开保留缺省时间基准的键存在性，缺键时继续使用保存的渲染 FPS/base。MP4 文件复制使用目标文件系统的暂存文件与排他提交，失败不删除外部程序创建的目标。

## 软件验证的适用对象

各项结果只适用于记录标识的源码、ZIP 或安装载荷。版本号不能代替文件摘要与新进程模块来源核对。正式软件验证入口为[发布验证汇总](../../publication/blender-0.3.42.1/public/verification.json)。

工作区修复验证有 1565 项宿主用例通过、4 项跳过，Bridge 113 项通过、3 项跳过；7 个源码原生后台脚本、缺省时间映射变体和 4 个隔离安装脚本通过。该记录的具体源码摘要与适用范围由发布验证汇总索引，不转记为新版本载荷的独立复验。

可见窗口、真实键鼠、GPU RGB、完整视频、全片段 FPS、长期内存、其他平台、真实 X100、MPI／求解／训练和科学精度须分别验证。后台合同通过不代表上述对象通过。
