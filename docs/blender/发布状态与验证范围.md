## 物理与使用边界

- 双束布局为 S1／S2／S3 = 10°／12°／14°；S2/S3 需同时刻、同叶片配对，S1 有效命中独立报警。保留旧 B2 回放兼容。
- 双束为研究估计。同一开发片段 400 对比较中，旧法 / TLS MAE 为 4.268685 / 0.776096 m；独立单机固定 9 rpm 工况、40/80 Hz 网格的 TLS MAE 约为 0.943/0.970 m。来源与窗口分别评价，不能合并为现场精度。高精度柔性叶尖反演未完成，数据仍为 REVIEW_ONLY / PENDING_ACCEPTANCE；40 Hz 保存网格不能证明硬件采样、现场漏测率或保护延迟。
- 固定相机有遮挡和空画面，不保证全周期完整覆盖；没有实体相机标定或拼接算法验收。
- Windows/Linux、长期稳定性和现场性能不在上述 macOS 验证结论内。
