## 源码软件合同与验证

0.5.0 的 X100 结束记录先停止接受记录帧，确认写盘线程退出后才释放会话；关闭失败保留记录器及归属供重试。记录终态与活动写盘器分别保存，失败记录结束后仍显示 FAILED 和原因；所属场景被删除时跳过状态写入，仍关闭记录线程。安装对象或父级存在约束／动画等不支持的驱动时撤回观测并保留原生编辑。缺陷提交与旧资源回收分别维护，回收失败保留已提交配置与撤销／重做历史。合成纹理、独立表面导入失败后恢复显示和属性，按自有资源清理并保留未确认资源的重试入口；共享 World、跨场景对象与原生删除的 RNA 按各自归属处理。

受控相机 PNG 绕过 VSE／合成器，并在完成或异常后恢复源设置。通用 PNG 保留 8 位来源，较高位深使用 16 位；后台动画仍拒绝未静音的 File Output。相机投影保留完整内参及实际输出比例，重建评分分别校验帧与显式时间；未观测或失败帧不推进已接受图像历史。自动生成的 RGB 注释保留未人工审核状态。

当前工作区的多视图 PNG 完整性、View Layer 标注隔离、已有 MP4 暂存及 RTSP 停止、相机采集检查点、Bridge 拒绝序号、进程树归属与独立会话凭据、X100 持续显示序号水位及失败处理，按[维护说明](../../blender_frontend/README.md)及对应测试定位。同帧塔面查询共享成功结果，安装搜索在多个种子间共享同一候选位的只读几何副本。这些实现由 0.5.0 扩展及配套源码提供。手动 Down 导出、现场视频分屏和安装报告导入分别见[风机手动控制](风机手动控制.md)与[X100 说明](X100雷达.md)。

训练 sampler 在失败和换回合时确认 driver 清理，无法确认时保留资源并阻止继续；单元素优势标准化、FLORIS 风向、Scene 整数秒步长与实验身份按[训练合同](../training/MAPPO_SETUP.md)执行。功率缺失不补零，合成机舱 lidar 不认作三维 BTS 插值或实测。

## X100 观测研究工作区验证

验证对象为工作区的面积材料采样、有限安装搜索与有拒绝条件的叶片模型估计源码，以本节保存的源码身份和输入为准。软件检查包含173项宿主检查及5个原生后台脚本，原生报告见[源码检查](../../outputs/x100-observation-research/source-checks/result.json)；[安装导入检查](../../outputs/x100-observation-research/import-check/result.json)覆盖来源不符、区间内任意未知帧的拒绝及原帧保留。窗口绘制与真实输入操作按各自证据单独判定，当前运行入口见[X100观测研究](X100观测研究.md)。

验证目录留存报告、原始日志、源码摘要与最终画布图像。临时测试场景、合成输入和隔离配置不随验证证据留存，复验由对应脚本重新生成；报告内的临时路径只标识测量时来源。

[预算对照](../../outputs/x100-observation-research/search-area.json)使用相同面积算法、25种安装、512／1024预算和三个种子，源网格1801个时刻、错误为0。512预算的部分叶片／种子缺少远端支持，最差配置为零，报告没有可应用推荐；不能把较高预算的支持比例用于界面初始512预算。

[窗口像素检查](../../outputs/x100-observation-research/window-geometry/result.json)在独立 Blender 进程直接读回真实画布：叶尖／拟合段局部区域分别有176／54个橙色像素，关闭估计后均为0，恢复后回到176／54。原始点云字节、帧对象及场景时刻保持；[画布图像](../../outputs/x100-observation-research/window-geometry/radar_x100_estimation_window/artifacts/enabled.png)保留当前显示。该检查使用脚本控制，未验证外部鼠标点击或键盘输入。

[安装搜索报告](../../outputs/x100-observation-research/search-supported.json)覆盖117–177 s的1801个源时刻、25种安装、1024／2048候选预算和三个种子。每帧至少3个远端点为支持条件；原安装位置90°俯仰的推荐，与82.5°原预设在最差叶片覆盖、最差经过覆盖、最长缺口及平均覆盖四项上相同，不能宣称覆盖率提升。所有采样配置中的最差单叶片支持比例约95.05%；两者只在末级遮挡统计有微小差异。水平侧面原预设在所定义下方窗口内支持比例为零。

[叶片估计报告](../../outputs/x100-observation-research/blade-evaluation-supported.json)使用推荐安装和2048候选预算，在895个完整经过期望样本中给出731个有支持估计，约81.68%，UNKNOWN=0。三叶叶尖误差均值为1.058／0.882／0.991 m，p95为1.273／1.006／1.152 m，最大值为1.918／1.069／1.273 m。关联精度只在已分配点和同源几何标签上评价，三叶各为1.0；未分配点及拒绝帧没有因此视为正确检测。

估计误差是上述几何模型、先验、采样配置和片段的独立评价结果，不能解释成实机精度。拟合离散度未覆盖全部模型偏差；三维叶尖误差仍为米级，模型估计塔距不用于安全判断。报告中的代码摘要分别界定所测算法载荷。
