## 源码软件合同与验证

X100 结束记录先停止接受记录帧，确认写盘线程退出后才释放会话；关闭失败保留记录器及归属供重试。缺陷提交与旧资源回收分别维护，回收失败保留已提交配置与撤销／重做历史。合成纹理、独立表面导入失败后恢复显示和属性，按自有资源清理并保留未确认资源的重试入口；共享 World、跨场景对象与原生删除的 RNA 按各自归属处理。

受控相机 PNG 绕过 VSE／合成器，并在完成或异常后恢复源设置。通用 PNG 保留 8 位来源，较高位深使用 16 位；后台动画仍拒绝未静音的 File Output。相机投影保留完整内参及实际输出比例，重建评分分别校验帧与显式时间；未观测或失败帧不推进已接受图像历史。自动生成的 RGB 注释保留未人工审核状态。

训练 sampler 在失败和换回合时确认 driver 清理，无法确认时保留资源并阻止继续；单元素优势标准化、FLORIS 风向、Scene 整数秒步长与实验身份按[训练合同](../training/MAPPO_SETUP.md)执行。Studio 停止通过事件循环等待线程退出；功率缺失不补零，合成机舱 lidar 不认作三维 BTS 插值或实测。

## 软件验证的适用对象

各项结果只适用于记录标识的源码、ZIP 或安装载荷。版本号不能代替文件摘要与新进程模块来源核对。当前软件验证见[发布验证汇总](../../publication/blender-0.3.42.3/public/verification.json)。

宿主合同 **1,699 项通过、7 项跳过**，数值合同 **425 项通过**，分进程重建检查 **7 项通过**。宿主的两项嵌套环境依赖失败及 Studio 字体初始化引起的一项时限失败，经独立复核通过；原始失败与复核报告均保留。源码后台专项 **12 项通过**，包括资源生命周期、合成纹理回滚、NREL／GW184 缺陷提交、相机 PNG 后处理隔离、雷达记录线程退出、手动 Down 副本、环境隔离、短 PNG 动画及 X100 数据／历史。公开 ZIP 的逐文件核对、隔离安装、持久启用、新进程模块来源、默认三相机与投影后台检查通过；两次独立构建的扩展摘要一致。原始报告分别见验证汇总链接。

验证环境为 macOS、Blender 5.2.1 LTS，使用独立进程、场景和配置。当前载荷未重复可见窗口、独立点云窗口 GPU／RGB、真实键鼠、完整视频、全片段 FPS、长期内存、其他平台、真实 X100、MPI／求解／训练或科学精度验收。本机日常安装保留 0.3.42.2，其 216 文件、109 个新进程模块及配置保护记录只适用于安装记录中的载荷。
