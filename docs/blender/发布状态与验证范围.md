## 当前功能与使用

- **统一重建对照**：**N → MAPPO → 打开几何重建示例…** 打开完整风机分屏，可切几何／同源纹理。右侧复用源风机塔筒、机舱、轮毂和机械展示结构，三片叶片仍为保存的重建估计。
- **视图与时间**：共享播放／暂停、单帧步进、复位和退出；中段／叶尖观察点仅定位一次，手动缩放、平移和绕转在播放后保留。原始／增强显式切换先显示两侧整机；保存重开恢复模式、显示设置、时间和视角。
- **三相机**：默认复位恢复整盒安装姿态和 C1/C2/C3 参数，支持完整布局撤销并保留帧、子帧及自由视图。已有默认且原生有效时保持对象和撤销历史；采集、草稿、安装或后端忙碌时拒绝，提交失败回滚。WATCH / LAYOUT 当前相机及退出快照保持有效引用。
- **普通离线工作台**：三台 NREL 风机 60 秒柔性回放、六类合成缺陷、同刻原图、默认双束／S1、TLS 候选及旧 B2。ZIP 内置数据、规范场景和 packed 纹理，无需作者路径或在线后端。
- **本地可靠性修订**：代理对象或镜头数据损坏时独立释放观察资源、恢复预览与主视口并显示错误；关闭及延迟恢复遵守场景播放归属。同源纹理稳定刷新复用已验证绑定，身份、清单、来源或撤销状态变化后重新校验，保留用户自由视图。此载荷未公开发布。

操作见[NREL 前端说明](../../前端readme.md)、[安装说明](INSTALL.md)、[三相机](T1三相机使用说明.md)、[Blade Recon](BladeRecon可视化使用说明.md)与[GW184 指南](GW184三相机与缺陷编辑器.md)。

## 研究与物理边界

| 对象 | 当前结论 | 解释 |
| --- | --- | --- |
| 同源几何与纹理 | **SAME_SOURCE_SIMULATION / NOT_ACCEPTED** | 601 个 10 Hz 保存样本、0–60 s 对应 MAPPO 117–177 s；60 Hz 时间轴每 6 帧保持。固定灰度图集有模糊、条带、接缝、叶尖错贴／拖影和未观测区域 |
| 独立合成纹理 | **SYNTHETIC / NOT_ACCEPTED** | `synth_tex` 为另一来源的 120 样本、0–11.9 s，使用独立游标；统一侧栏隐藏入口，资产和工具保留 |
| 外部材料点候选 | **FAILED_GATE / NOT_ACCEPTED** | Patch 2/8、Crack 7/8（87.5% < 90%）、跨相机 RGB 接受 0/264；`same_material_error_m = null`、`primary_gains = null`；[研究结果](../../blade_recon0.2/docs/材料点对应实验报告_2026-10-11.md)不替换扩展正式 601 样本或图集 |
| 叶尖显示精度 | **FAILED_GATE** | 原 0.2 mm 保存帧门槛与 5 mm 插值门槛保持；安装版抽样真实网格约 1.0613 mm，独立源运输约 1.0665 mm，两者差约 0.0290 mm；原始源文件缺失，未重新导出或放宽阈值 |
| 双束与 TLS | **REVIEW_ONLY / PENDING_ACCEPTANCE** | 保存记录 94/94 次完整过叶均有配对、400 有效样本，不代表每帧命中或现场精度；S1 报警独立于 S2/S3 配对 |
| 独立动态研究查看器 | **REVIEW_ONLY / DY1 NOT PASSED** | 只有四个保存估计时刻，其余帧不可用且不插值；不与 601 样本分屏合并验收 |

增强只改变显示，不增加观测分辨率或自动检测缺陷。右侧塔筒、机舱和轮毂是模拟展示结构；合成缺陷不改变材料刚度、气动或测量。三相机的参考姿态覆盖、实际遮挡、实体标定和拼接效果是独立对象。

Windows/Linux、稳定 30／60 FPS、完整片段性能、长期运行、现场精度、实拍缺陷恢复、安全保护和控制收益仍需独立验证。POST_PIXEL 是视口绘制完成，不是显示器扫描输出；60 Hz 是时间映射。
