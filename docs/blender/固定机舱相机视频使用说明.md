# 固定机舱相机视频

已有 MP4 的导出与推流直接使用 [Blender 视频输出页](Blender视频输出.md)。只有需要改变画面时才重新渲染。

源码入口为 `scripts/camera_video.py`，先安装项目 camera-video 依赖，并准备 Blender 5.2+、FFmpeg 与 ffprobe。查看 `python scripts/camera_video.py build --help` 核对全部参数。

```sh
python scripts/camera_video.py build --output /path/to/new-video --turbine T1 --fps 20 --resolution 4k --engine cycles --device cpu
python scripts/camera_video.py verify /path/to/new-video
```

输出使用现有 FarmFlex 数据驱动固定机舱相机，不运行新仿真。`--scene` 与 `--camera` 可选择已保存场景中的固定相机；默认由指定机组生成。每次新配置使用新目录；已完成帧按哈希检查后续作，不能混用不一致的渲染配置。

`scripts/blender/render_camera_video.py` 是原生渲染入口；主入口还生成逐帧数据、编码视频和校验清单。`loop` 子命令可重复已验证视频并保留循环标签，接点可能存在画面跳变；它不会生成新的物理过程。

示例输出目录请替换为实际新路径。4K、曝光和采样配置可能耗时较长；平台支持与依赖以目标电脑为准，macOS 验证不代表 Windows/Linux 验收。
