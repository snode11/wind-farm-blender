# WFRL 用户使用手册

适用对象：使用 Blender 前端演示风电场、观察相机视角和连接训练后端的用户。

阅读顺序：第一次只看第 2–4 节即可完成离线演示；需要连接训练后端时，再阅读第 5–7 节。第 8–10 节用于按菜单查找和排错。  
更新日期：2026-09-11。要求 Blender 5.2 或更新版本。

本手册覆盖 WFRL 自己的面板与相关 Blender 操作，不逐项介绍 Blender 的建模、雕刻等通用菜单。Windows 命令根据现有启动脚本整理，尚未在 Windows 机器上实测。

## 1. 先选择你要做什么

| 目的 | 应使用的功能 | 是否需要后端 |
| --- | --- | --- |
| 播放三台风机的演示动画 | Demo → Load Demo Scene → Start Demo | 不需要 |
| 看全场、机舱或操控云台视角 | Views & Layers；Camera 标签的云台面板 | 已加载场景即可 |
| 看真实仿真训练时的风机与数据 | Interactive + FAST.Farm | 需要 Python、Bridge、MPI 和 FAST.Farm |
| 连接 FLORIS 看真实仿真数据 | Demo → Connect Backend Demo | 需要 FLORIS 后端，但此入口不训练 |
| 提交正式训练并看训练进度 | Formal Training | 需要相应训练后端；没有逐步实时三维遥测 |
| 用已有模型回放 | Replay + 兼容的 Checkpoint | 需要相应后端；不更新模型 |

“真实后端”指实际运行仿真器和训练程序，不代表接入现场风机或实体摄像头。云台显示的是三维场景中的虚拟相机。

### 1.1 Interactive 和 Formal Training 到底有什么区别？

两者都会训练模型，区别在于运行入口、实时画面和结果保存方式，不是“假训练”和“真训练”，也不是只按训练时长区分。

| 你关心的事情 | Interactive | Formal Training |
| --- | --- | --- |
| 边训练边看风机动作 | 回传逐步快照，驱动三维姿态与遥测 | 不提供逐步三维遥测；画面中的风场不能代表当前训练动作 |
| 观察训练指标 | 支持 Training Dashboard | 支持 Training Dashboard 和终端进度 |
| 暂停、继续、单步 | 支持在后端控制边界操作 | 不支持暂停、继续或单步 |
| 保存模型 | 当前 Blender 界面未提供输出 checkpoint 路径，默认交互训练不保存模型 | 使用独立训练脚本的 checkpoint 保存流程 |
| 从已有模型继续训练 | 当前界面不提供 | 可填写兼容的 Checkpoint；从头训练留空 |
| 本次给老板演示 | **选这个：边训练、边看风场和数据** | 用于需要保存训练结果的实验任务 |

**按钮名称取决于面板：**CONNECTION 中统一叫 **Start**，执行当前选中的模式；RUN CONFIGURATION 中分别叫 Start Backend Demo、Start Training、Submit Formal Training、Start Replay。它们操作同一个任务，只点一个即可。选择 Interactive 后，直接点 CONNECTION 中的 Start 就能开始训练。

### 1.2 为什么 Demo 中三台风机会一起向一侧转？

Demo 有两个容易混淆的入口：

- **LOCAL DEMO → PRESENTATION → Start Demo**：离线固定 66 秒动画，无需连接。
- **CONNECTED + Demo → CONNECTION → Start**：通过 Bridge 运行 Demo。当前 FAST.Farm 场景走预设动画分支，不启动 FAST.Farm、不更新模型；三台风机会错峰向同一方向偏航约 60°，随后顺桨停机。这是演示动作，不是训练学到的策略，也不是上述 66 秒时间线。FLORIS Demo 则会调用 FLORIS，见第 6.7 节。

因此，CONNECTED 或 step 增长本身不能证明正在训练。要展示真实训练，先确认选中 **Interactive**，再看采样、更新阶段及实际遥测。

## 2. 第一次使用：进入目录、安装扩展

### 2.1 打开终端并进入项目目录

本手册中的“项目目录”，是下载或解压项目后，包含 `scripts`、`scenes`、`blender_frontend` 和 `pyproject.toml` 的文件夹。文件夹可以放在任意位置，也可以使用不同名称；请根据这些内容确认目录，不要依赖某个固定文件夹名。

`cd` 用于把终端切换到项目目录。完成这一步后，本手册的项目命令都从该目录执行。新开终端时，需要重新进入目录。

**Mac：**

1. 在 Finder 中找到项目文件夹。
2. 打开“终端”，输入 `cd`，再输入一个空格，先不要回车。
3. 将项目文件夹从 Finder 拖进终端，终端会自动填入路径，然后按回车。
4. 输入以下命令确认位置和内容：

   ```bash
   pwd
   ls
   ```

也可以手动输入下面的通用模板。先把 `<项目文件夹的完整路径>` 替换为实际路径，保留两侧引号，再执行；不要原样输入尖括号占位符。

```bash
cd "<项目文件夹的完整路径>"
```

**Windows：**

1. 在文件资源管理器中打开项目文件夹。
2. 点击地址栏，输入 `powershell`，按回车，即可在该文件夹打开 PowerShell。
3. 输入以下命令确认位置和内容：

   ```powershell
   Get-Location
   dir
   ```

如果已经打开 PowerShell，也可以使用同一个通用模板，替换路径后执行：

```powershell
cd "<项目文件夹的完整路径>"
```

PowerShell 的 `cd` 可以直接跨盘。若使用传统 CMD，则使用 `cd /d "<项目文件夹的完整路径>"`。

**检查结果：**目录列表中应能看到 `scripts`、`scenes`、`blender_frontend` 和 `pyproject.toml`。如果只看到一个外层包装文件夹，请继续进入其中实际包含这些内容的目录。路径中有空格时，手动输入的路径必须放在引号内。

### 2.2 安装 WFRL 扩展

如果已安装包含最新菜单的扩展，直接跳到第 3 节。源码更新不会自动更新已经安装的扩展。

1. 若需要自行构建安装包，先安装可在终端使用的 Python 3.11 或更新版本。在项目目录生成安装包：

   Mac：
   ```bash
   python3 scripts/blender/build_extension.py
   ```

   Windows PowerShell：
   ```powershell
   python scripts/blender/build_extension.py
   ```

2. 打开 Blender，进入 **Edit → Preferences → Extensions**。
3. 在扩展菜单中选择 **Install from Disk**。
4. 选择项目下的 `dist/wfrl_blender-0.2.0.zip`，安装并启用 **WFRL Blender**。直接选择 ZIP，不要先解压。
5. 返回三维视图，把鼠标移到三维区域内，按 **N** 打开右侧栏。
6. **Item** 标签放置演示、连接、训练、遥测等面板；**Camera** 标签放置云台相机。

只运行离线 Demo 时，安装扩展后直接从 Finder 或 Windows 开始菜单打开 Blender 即可，之后不必每次 `cd`，也不必启动 Bridge。首次构建安装包才需要上述终端命令；如果已拿到安装包，可以直接从第 2 步开始。

### 2.3 当前这台 Mac：更新安装扩展

工作区源码与 Blender 安装目录是两份文件。只修改源码或生成 ZIP，不会自动更新 Blender 已加载的扩展。

本次使用的源码位于 `/Users/eason/Desktop/wfcrl/wind farm RL/blender_frontend/wfrl_blender`；安装位置为 `/Users/eason/Library/Application Support/Blender/5.2/extensions/user_default/wfrl_blender`。

需要更新时，先正常停止任务、保存工作并退出 Blender，再构建：

```bash
cd "/Users/eason/Desktop/wfcrl/wind farm RL"
/opt/anaconda3/envs/wfrl-mac/bin/python scripts/blender/build_extension.py
```

可使用 Install from Disk 更新，也可将旧安装目录移入废纸篓，再把 ZIP 内容解压到原安装目录。ZIP 根目录直接包含 `blender_manifest.toml`、`__init__.py` 等文件，不要多套一层 `wfrl_blender`。保留旧版本直到验证新版本正常。重新启动 Blender 后才会载入新代码。

## 3. 核心功能一：跑 Demo

### 3.1 从空场景开始

建议使用新的 Blender 文件；有自己的未保存工作时先保存。Load Demo Scene 会构建或重建 WFRL 演示场景。

1. 在三维区域按 **N**，进入 **Item**。
2. 展开 **WFRL / CONNECTION**，点击 **Demo**。
3. 确认显示 **LOCAL DEMO**。
4. 展开 **WFRL / PRESENTATION → Scene**。
5. 点击 **Load Demo Scene**，等待出现三台风机。
6. 展开 **WFRL / PRESENTATION → Run**，点击 **Start Demo**。

成功时：画面中风机开始运动，面板时间推进，显示 `SYNTH / No physical backend`。这是固定的 66 秒、25 fps 脚本序列，不是实时训练。运行速度会受机器性能影响。

不要为了运行离线演示点击 **Connect Backend Demo**；该按钮用于连接仿真后端。

### 3.2 播放按钮怎么用

| 按钮 | 使用方法与结果 |
| --- | --- |
| Start Demo | 从开头播放演示 |
| Pause | 暂停在当前画面，便于观察 |
| Resume | 从暂停位置继续；取消手动姿态覆盖 |
| Step | 暂停时前进一个显示帧，即脚本时间 0.04 秒 |
| Stop | 跳到停止、顺桨的结束状态，不是停在当前姿态 |
| Reset to Ready | 回到开始位置，等待再次播放 |

动画阶段：0 秒开始启动；约 4 秒达到演示转速；56 秒开始顺桨减速；66 秒停止。想重复演示，可先 Reset to Ready，再 Start Demo。

### 3.3 暂停后手动看风机姿态

1. 点击 **Pause**。
2. 展开 **Manual Pose / Paused Demo**。
3. 勾选 **Override selected turbine pose**。
4. 在 **Turbine** 选择机组，调整 **Yaw (deg)** 和 **Pitch (deg)**。
5. 点击 **Resume** 恢复脚本。

Yaw 是风机偏航，Pitch 是叶片桨距；这与第 4 节的相机转向是两回事。手动姿态只改变展示几何，此时 RPM 为零、功率不可用，不会向后端发送执行器指令。

## 4. 核心功能二：总体视角与云台视角

### 4.1 查看全场及固定视角

离线 Demo 加载完成后，打开 **Item → WFRL / PRESENTATION → Views & Layers**。

| 菜单 | 看到什么 |
| --- | --- |
| World | 全场总体视角，适合介绍风机布局 |
| Top | 俯视布局 |
| Side | 侧面视角 |
| T1 Rotor Close-up | 第一台风机的转子近景 |
| T1 Nacelle Sensor | 第一台风机的固定机舱传感器视角 |
| World + Nacelle View | 分成总体和机舱两个视窗 |

这些固定视角按钮位于离线 Demo 面板；连接后该面板会隐藏。当前 **Views & Capture** 中没有旧文档所述的 Apply Camera 或 Single / Dual / Quad 按钮。

### 4.2 进入云台相机

1. 把鼠标放在要切换的三维视窗内，按 **N**。
2. 选择 **Camera** 标签，展开 **WFRL / Gimbal Camera 云台相机**。
3. 选择 **T1 / T2 / T3**。不存在的机组按钮会置灰。
4. 点击 **Camera Mode / 相机模式**。
5. 用以下方法调整画面：

| 操作 | 效果 |
| --- | --- |
| 在三维画面内按住鼠标左键拖动 | 调整相机观察方向 |
| 向上滚动滚轮 | 缩小 FOV，放大画面 |
| 向下滚动滚轮 | 扩大 FOV，看到更大范围 |
| 拖动屏幕摇杆并保持 | 持续转动；松开停止 |
| Joystick speed °/s | 调整摇杆转动速度 |
| Down ↓ | 镜头向下 |
| Front / Back | 切换预设前向、后向观察方向 |
| Reset / 复位 | 当前仍恢复旧预设：Yaw 180°、Pitch -90°、FOV 75°；不会恢复下述新建相机角度，也不会移动相机 |
| Esc 或 Exit Camera Mode / 退出 | 结束鼠标与摇杆控制 |

退出相机模式后，视窗可能仍显示云台镜头；**Esc 不等于切回总体视角**。云台模式接管中键和触控板导航，建议使用有滚轮的鼠标操作。

新建云台相机已改为相对机组 YawRoot 的位置 `(-35, -28, 22)` 米，初始 Yaw 180°、Pitch -35°、FOV 62°。这是虚拟外置观察位，不是实体机舱摄像头安装位置。已有 `.blend` 中的云台相机不会因更新扩展自动迁移；重新构建场景后新建相机才能使用新位置。该参数已完成语法检查，构图仍需在实际画面中确认，不能保证整片叶轮始终入镜。

近处叶片占满画面不一定说明叶片建模过粗，也可能是镜头位置、视场角和转子姿态共同造成；仅改变 FOV 不会改变相机与叶片的距离。Down 会重新垂直向下看，与初始斜视角不同。

当前显示使用 NREL 5MW 几何参数：塔筒高度 87.6 米、叶轮半径 63 米、直径 126 米，叶片长度约 61.5 米。不要按“叶片只有 10–30 米”的假设缩短该机型，也不要为改变构图直接把塔筒改成 120 米。塔筒高度与轮毂中心高度不是同一个数值；真实参考视频的机型尚未确定，不能直接当作本模型的尺寸标准。

### 4.3 从云台返回总体视角

离线 Demo 中：先按 **Esc**，在当前视窗的侧栏 **View → View** 中取消 **Local Camera**（本地相机），再到 **Item → Views & Layers** 点击 **World**。云台会为当前视窗启用本地相机；没有取消时，World 按钮可能没有改变该视窗。

连接后，或不想使用固定镜头时：先按 **Esc**，通过三维视图顶部 **View → Cameras → Active Camera** 切出相机视图（有数字小键盘时可用 `Numpad 0`），然后用中键旋转、Shift + 中键平移、滚轮缩放，退远观察整个风场。没有数字小键盘的 Mac 直接使用菜单即可。

### 4.4 同时看总体与云台

离线 Demo 中先点 **World + Nacelle View**，保留左侧总体视窗；把鼠标放进右侧视窗，按 **N → Camera**，选择机组并进入相机模式。云台只切换当前视窗的镜头。

如果希望训练时也保留两窗，可在连接前先做好这个布局，再切换 Interactive 并加载真实场景。真实场景加载后检查机组是否存在，必要时重新选择右侧云台。

## 5. Load Scene：如何加载场景

界面上有两个不同的“加载”入口：

| 入口 | 用途 |
| --- | --- |
| Load Demo Scene | 构建固定离线三风机演示，不打开 YAML 选择框 |
| Load & Validate Scene | 将 Default scene 指向的 YAML 发给后端校验；收到场景确认后构建三维风场 |

### 5.1 选择已有 YAML

1. 在 **CONNECTION** 中设置 **Project directory** 为项目根目录。
2. 设置 **Default scene** 为场景 YAML 的绝对路径；也可以在扩展 Preferences 中设置同名字段。
3. 启动 Bridge、选择目标模式并连接，确认 **CONNECTED**。
4. 展开 **SCENE CONFIGURATION**。第一次使用先不勾 **Override scene configuration**。
5. 点击 **Load & Validate Scene**。
6. 等待下方显示后端确认的场景名称、backend、机组坐标和控制步长，并确认左侧出现风场。只填了文件路径、或仅显示 CONNECTED，都不等于加载完成。

选择文件时，从你的项目目录进入 `scenes` 文件夹，再选择 `turb3_row.yaml` 即可。文件选择器若勾选了 **Relative Path**，请取消，避免得到以 `//` 开头、依赖当前 Blender 文件位置的路径。使用字段旁的文件选择按钮，让 Blender 填入实际路径，不需要手动照抄示例。

本手册中的 `scenes/turb3_row.yaml` 表示“项目目录下 scenes 文件夹中的 turb3_row.yaml”，不是要求把项目放在某个固定位置。界面的 Default scene 使用所选文件的完整路径；终端已进入项目目录后，则可以使用相对路径。

| 文件 | 推荐用途 |
| --- | --- |
| scenes/turb3_row.yaml | FAST.Farm 三机一列、yaw 控制；首次交互训练优先使用 |
| scenes/turb3_floris.yaml | FLORIS 三机后端演示；不要用它启动 Interactive |
| scenes/turb3_demo.yaml | 声明为 FAST.Farm 的 yaw/pitch 演示场景；文件名含 demo 不代表它不需要后端 |
| scenes/turb3_ctrl3.yaml | 三控制量场景；熟悉后端控制含义后再使用 |

### 5.2 覆盖场景参数

勾选 **Override scene configuration** 后，可以改 Backend、Requested wind、Requested direction、Turbulence box、Decorative terrain、Control channels，再加载校验。

- Requested 表示请求值，实际来流以 LIVE TELEMETRY 为准。
- FAST.Farm 不按此处请求改写风向；湍流箱也可能覆盖请求风速。
- 地形只影响画面，不会改变物理仿真。
- 初次运行保留 yaw 控制；torque 控制会替代原有发电机转矩控制，不是画面选项。
- 更换文件或覆盖参数后重新加载。活动任务或状态未确认时，配置可能锁定；先正常停止并等待确认。
- 若切换 FLORIS / FAST.Farm，还需要为对应后端重新准备启动环境，不能只改下拉框。

## 6. 核心功能三：连接后端，观察真实训练

### 6.1 运行前需要什么

本节假设后端 Python 环境及对应仿真依赖已经安装。只装 Blender 扩展不够；`pip install -e .` 也不会自动装齐仿真依赖。环境部署另见 [本地部署说明](../setup_local.md) 和 [扩展安装说明](INSTALL.md)。下面启动模板中，`<…>` 表示需要替换的内容，不是可以原样执行的路径。项目内的场景使用相对路径；外部程序使用用户实际安装的可执行文件路径。

在已激活的后端环境中运行以下命令，可查看应该填入的 Python 路径：

```text
python -c "import sys; print(sys.executable)"
```

| 字段 | 应填写什么 |
| --- | --- |
| Project directory | 包含 scripts、scenes 的项目目录 |
| Backend Python | 已安装 WFRL 和训练依赖的 Python 可执行文件，不是 Blender 内置 Python |
| MPI executable | 与 FAST.Farm 配套的 mpiexec 可执行文件 |
| FAST.Farm executable | 当前操作系统可运行的 FAST.Farm 文件 |
| Default scene | 本次场景 YAML 的绝对路径 |
| Bridge port | 默认 8765，前后端保持一致 |

Mac 不能直接运行仓库里的 Windows `.exe`，需要原生 FAST.Farm 及配套 MPI/控制器。Windows 也需要与其 FAST.Farm 构建匹配的 MPI 环境。以下使用平台启动器，减少手动配置遗漏。

### 6.2 Mac 启动模板

扩展须已安装。先按第 2.1 节进入项目目录，再激活已安装后端依赖的 Python 环境。使用 Conda 时，执行 `conda activate <后端环境名称>`，先将占位符替换为你自己的环境名称。

以下是启动模板：Blender 使用默认安装位置；如果安装在其他位置，请修改 `--blender`。其他程序路径也需要替换为实际安装位置。

```bash
bash scripts/blender/run_wfrl_macos.sh \
  --blender "/Applications/Blender.app/Contents/MacOS/Blender" \
  --python "<后端 Python 可执行文件的完整路径>" \
  --scene "scenes/turb3_row.yaml" \
  --mpi "<mpiexec 可执行文件的完整路径>" \
  --fastfarm "<FAST.Farm 可执行文件的完整路径>"
```

当前这台 Mac 可以直接使用以下完整命令；路径仅适用于本机。无需为了首次交互训练额外添加 checkpoint 参数：

```bash
cd "/Users/eason/Desktop/wfcrl/wind farm RL"
bash scripts/blender/run_wfrl_macos.sh \
  --blender /Applications/Blender.app/Contents/MacOS/Blender \
  --python /opt/anaconda3/envs/wfrl-mac/bin/python \
  --scene scenes/turb3_row.yaml \
  --mpi /opt/homebrew/bin/mpiexec \
  --fastfarm /opt/anaconda3/envs/wfrl-mac/bin/FAST.Farm
```

使用明确的 Python 路径可避免系统没有 `python` 命令别名的问题。Check Environment 仅检查运行环境，不加载场景、不启动训练。

### 6.3 Windows PowerShell 启动模板

先按第 2.1 节在项目目录打开 PowerShell，再激活后端环境。替换以下模板中的程序路径后执行；命令写成一行，避免复制换行符出错：

```powershell
.\scripts\blender\run_wfrl_windows.ps1 --blender "<blender.exe 的完整路径>" --python "<后端 python.exe 的完整路径>" --scene "scenes/turb3_row.yaml" --mpi "<mpiexec.exe 的完整路径>" --fastfarm "<FAST.Farm.exe 的完整路径>"
```

若 PowerShell 的策略不允许执行 `.ps1`，可以使用相同启动器的 Python 入口，无需更改系统执行策略：

```powershell
python scripts/blender/wfrl_launcher.py launch --blender "<blender.exe 的完整路径>" --python "<后端 python.exe 的完整路径>" --scene "scenes/turb3_row.yaml" --mpi "<mpiexec.exe 的完整路径>" --fastfarm "<FAST.Farm.exe 的完整路径>"
```

启动器会检查环境、启动本机 Bridge、打开 Blender、配置扩展连接。保留终端窗口查看错误。已有服务占用端口时会拒绝启动；不要反复开启多个启动器。连接成功不会自动开始训练。

**切换模式后必须重新连接：**点击 Demo、Interactive、Formal Training 或 Replay 会关闭当前前端连接并清空对应显示状态。即使启动器刚刚自动连接成功，切换模式后也要再次点击 Connect / Reconnect（Demo 下为 Connect Backend Demo）。

### 6.4 在界面里开始训练

1. 在 **Item → CONNECTION** 选择 **Interactive**。
2. 若未连接，点击 **Connect / Reconnect**；确认 **CONNECTED**。
3. 确认 Default scene 是 `turb3_row.yaml`，执行第 5 节的 **Load & Validate Scene**。
4. 展开 **RUN CONFIGURATION**，设置参数。首次了解流程可以先保留界面默认值：

   | 参数 | 默认值 | 含义 |
   | --- | --- | --- |
   | Iterations | 8 | 训练迭代次数 |
   | Rollout steps | 64 | 每轮采样步数 |
   | Warmup steps | 4 | 预热步数 |
   | Seed | 0 | 随机种子 |

   这些是界面默认值，不是正式实验推荐配置，也不保证尾流已充分稳定或模型已学好。

5. 点击 **CONNECTION → Start**（或 **RUN CONFIGURATION → Start Training**，二选一）。等待 `STARTING → RUNNING`。
6. 展开 **LIVE TELEMETRY** 和 **TRAINING DASHBOARD**，观察实际回传。
7. 需要近距离观察时使用 **Camera** 标签的云台；切换视角不改变训练参数。
8. 结束时点击 **Stop**，等待 `DRAINING → STOPPED`，再断开或退出。

### 6.5 连接后应该看到什么？

| 区域 | 如何判断 |
| --- | --- |
| CONNECTION | CONNECTED 表示握手成功；RUNNING 表示后端确认正在运行 |
| 三维画面 | 场景确认后显示风场；训练快照到达后更新可用姿态。显示帧不等于物理步骤 |
| LIVE TELEMETRY | Step 和时间推进；逐台数据带单位、来源及有效性。某些字段没有支持时显示不可用 |
| TRAINING DASHBOARD | 显示采样/更新等阶段、step、iteration，以及已产生的训练指标；初始可能等待第一条记录 |
| SAFETY HISTORY | 收到约束事件后显示 requested 与 applied，帮助判断指令有没有被限制 |

看板包括全场平均功率、训练奖励、原始奖励、Value loss、Explained variance、Episode return、Learning rate；字段是否有数值由后端提供情况决定。指标通常按训练迭代产生，不会和叶片转动同步刷新。

**CONNECTED 只证明连通；RUNNING、不断更新的实际数据和来源标签，才说明正在观察后端运行。** 不要把仍停留的 Demo 画面或 SYNTH 曲线当作训练证据。

### 6.6 暂停、单步与停止

| 操作 | 后端模式下的含义 |
| --- | --- |
| Pause | 在支持的控制边界暂停；不能把正在执行的物理步拆开 |
| Resume | 继续执行 |
| Step | 暂停时推进一个完整控制步，不是 Demo 的一帧 |
| Stop | 请求安全结束；DRAINING 期间继续等待 |
| Reset | 在后端允许的状态下复位运行，不等于重新载入 YAML |
| Disconnect | 断开前端通信；不等于后端已停止 |

按钮是否可用取决于后端能力和当前状态。断线后出现 unconfirmed 时，先查看终端并尝试重连确认，不要把断线当作停止成功。

### 6.7 只有 FLORIS 时怎么用？

在项目目录执行时，将上述启动命令的 `--scene` 改为 `"scenes/turb3_floris.yaml"`，删除 `--mpi` 和 `--fastfarm` 参数。进入 Blender 后选择 **Demo**，连接后端、加载校验，再点 **Start Backend Demo**。

它会运行 FLORIS 并回传实际稳态模型输出，但不做策略训练。当前 Bridge 的 FLORIS 适配器只接受 Backend Demo；选择 Interactive 或 Replay 会被拒绝。不要用 `--fake` 代替真实连接，`--fake` 是合成测试数据。

## 7. 其他模式：正式训练与模型回放

### Formal Training

1. 先结束现有任务并等待 STOPPED，再选择 **Formal Training**，点击 **Connect / Reconnect**，确认 CONNECTED。
2. 选择并校验场景，配置 Iterations、Rollout steps、Warmup steps、Seed。
3. 从头训练时 Checkpoint 留空；恢复训练时选择兼容模型。
4. 点击 **CONNECTION → Start**（或 RUN CONFIGURATION → Submit Formal Training），查看 TRAINING DASHBOARD 和终端。
5. 按状态使用 Stop，并等待 STOPPED。

这个模式启动正式训练流程，以结构化记录展示进度与指标。**正式训练 CLI 不提供逐步实时遥测，所以三维画面不是该模式的实时仿真监视器。** 暂停、继续和单步均不支持；可以请求 Stop 并等待结束。需要边训练边观察三维姿态时使用 Interactive。

### Replay

1. 先结束现有任务并等待 STOPPED，选择 **Replay**，点击 **Connect / Reconnect**，确认 CONNECTED 后加载兼容的 FAST.Farm 场景。
2. 在 **Checkpoint** 选择已有模型文件。
3. 设置 **Replay steps**、Warmup steps 和 Seed。
4. 点击 **CONNECTION → Start**（或 RUN CONFIGURATION → Start Replay），观察策略推理下的后端运行。

Replay 不更新模型。文件存在并不保证兼容；模型与场景或控制维度不匹配时查看错误详情，不要随意改后缀。

## 8. 全部 WFRL 菜单速查

面板有折叠三角；某些面板只在相应模式出现。以下英文名称与当前源码对应。

### Item → CONNECTION

包含 Demo、Interactive、Formal Training、Replay 模式选择；Connect Backend Demo / Connect / Reconnect、Disconnect；后端 Start、Pause、Resume、Step、Stop、Reset；六项路径/端口配置和 **Check Environment**。

Check Environment 逐项显示 Blender、Python、MPI、FAST.Farm 状态。检查结果不能代替完整任务运行；缺 MPI 不影响本地 Demo。错误区域的 **Full Details** 展开详细信息，**Copy Error / Copy Report** 复制诊断，方便求助。

### Item → PRESENTATION（仅 Local Demo）

| 子菜单 | 用法 |
| --- | --- |
| Scene | Load Demo Scene，构建三风机场景 |
| Views & Layers | 选择固定镜头或双视窗；开关 Wake proxy、T1 Lidar rays、DisXY、Atmosphere；选择 Environment、Visual quality；截图与录制快捷入口 |
| Run | 播放、暂停、继续、单帧、停止及复位，见第 3 节 |
| Telemetry / SYNTH | Focus 选择机组，读取脚本 yaw、pitch、RPM、功率 |
| Channels / Offline Fixtures | Sample & display telemetry 开关；关闭后脚本遥测采样冻结，不是退订后端传感器 |
| Manual Pose / Paused Demo | 暂停后预览机组姿态，见第 3.3 节 |
| Demo Events / SYNTH | 查看脚本阶段到达情况，不是真实安全事件 |
| Review Fixtures / SYNTH | Preview 切换等待、关闭通道、过期、不兼容、失败等静态展示状态；不改变真实运行 |

Environment、Atmosphere 和 Visual quality 改变显示外观。DisXY 开关只有收到对应 FAST.Farm 导出数据时才有内容；打开开关不会生成真实流场。

### Item → SCENE CONFIGURATION / RUN CONFIGURATION

前者控制 YAML 校验和可选参数覆盖，见第 5 节；后者配置训练/回放参数和运行按钮，见第 6、7 节。CONNECTION 中的通用运行按钮与这里操作同一个后端任务，无需点击两遍。

### Item → LIVE TELEMETRY

显示逐机组和全场数据。图表开关控制曲线可见性；通道选择切换要看的数据；**Turbine / curve filter** 选择机组。每台机组每个通道最多保留 600 个样本，不是完整训练档案。

点击 **Export Bounded History**，选择 `.json` 保存位置，等待 **COMPLETE**；失败会显示 FAILED。导出包含当前保留的历史与来源信息，不暂停训练，也不补回已经超过保留上限的数据。

### Item → TRAINING DASHBOARD

仅 Interactive / Formal Training 显示。读取阶段、步数、迭代和指标；WAITING 表示等待记录，UNSUPPORTED 表示尚未协商相应能力。训练阶段与指标分别计算时效，新阶段到达不代表上一轮指标变新。

### Item → SENSOR SUBSCRIPTIONS

先看列表里实际存在的 topic，在 **Sensor topic** 填入对应名称，再点 **Subscribe / Unsubscribe**。更改在控制步边界生效。空列表表示当前没有可订阅的 SceneRuntime topic；不能凭空输入一个名称就生成传感器。传感器采样与风机姿态遥测是独立的。

### Item → SAFETY HISTORY

显示保留的安全事件数（最多 256）、各规则次数和最近事件详情。requested 是请求动作，applied 是实际施加动作。没有事件只能说明尚未收到记录，不能据此证明没有任何风险。

### Item → Views & Capture

- **Wake visible**：显示或隐藏尾流。
- **Wake display**：Cinematic 当前仅调整流线颜色、亮度和线宽；Scientific 为绿色示意线。两者均不是 FAST.Farm 实际流场，当前没有烟雾状体积尾流效果。此次暂不改动 Cinematic，不能将其宣传为已实现参考视频效果。
- **Toggle Presentation / Development**：切换展示布局、隐藏部分开发界面；不改变数据来源。
- **Output folder**：截图与录制输出位置，建议用文件选择器指定绝对路径。
- **Save Screenshot**：保存当前可见 Blender 窗口为 PNG，包含当前可见界面，分辨率为窗口分辨率。需要记录数据来源时，请保留显示来源标签的侧栏；隐藏侧栏后，截图不会自动补上标签。
- **Capture FPS / Duration (seconds)**：设置录制频率与持续时间。
- **Record PNG Sequence**：开始保存 PNG 图片序列，Esc 取消；不是直接生成 MP4。

录制允许 1–30 fps、0.1–3600 秒。目录中有编号 PNG 和包含实际时间的 manifest.json；机器较慢时可能丢采样，录制不会推进后端步骤。如果展示模式隐藏侧栏，把鼠标放在三维区域按 N 重新打开。

### Camera → Gimbal Camera 云台相机

T1/T2/T3、Camera Mode、Joystick speed、Down、Front、Back、Reset 和当前角度/FOV，操作见第 4 节。相机朝向不改变风机 yaw/pitch，也不改变后端策略。

## 9. 数据标签怎么看

| 标签 | 用户应如何理解 |
| --- | --- |
| SYNTH | 演示脚本、代理或装饰，不作为物理训练结果 |
| DIRECT | 后端直接回传；仍需看是哪个仿真器、什么通道 |
| EXPORTED | 后端导出数据或按协议归类的数据；查看来源说明 |
| waiting / WAITING | 尚未收到所需数据 |
| unsupported / UNSUPPORTED | 当前路径不提供该功能或数据 |
| stale / STALE | 数据过期，不能当作当前值 |
| invalid / unavailable / — | 数据无效或不可用，不等于零 |

缺失值不会自动补为零；曲线遇到缺失、来源或单位变化可能断开。地形、天气、虚拟相机和示意流线即使与真实后端同时显示，也不因此变成物理测量。

## 10. 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 找不到 WFRL 菜单 | 确认扩展已启用；鼠标放在三维区域按 N；分别检查 Item 和 Camera 标签 |
| 没有云台 Camera 标签 | 可能安装了旧 ZIP；根据当前源码重新构建安装，必要时重启 Blender |
| 找不到 Load Scene | 离线用 PRESENTATION → Scene → Load Demo Scene；后端用 Default scene + Load & Validate Scene |
| Load & Validate Scene 灰色 | 检查是否 CONNECTED、任务是否停止并确认、配置是否可编辑 |
| 启动脚本找不到 | 确认进入包含 scripts 的项目根目录，保留路径引号；PowerShell 相对入口使用 `.\` |
| Python 找不到或无法导入 WFRL | 激活正确环境，确认 Backend Python 指向安装后端依赖的解释器 |
| 端口占用或连接失败 | 查看终端是否有 Bridge、端口是否一致；不要重复启动；必要时在启动器与界面同时使用另一个端口 |
| Dashboard 步数增长，左侧仍是默认立方体 | 检查扩展是否更新并重启；Load & Validate Scene 后应显示风场。本次用户已确认加载显示恢复正常；仍异常时查看错误详情，不能仅凭步数判断显示正常 |
| 只看到 Start，没有 Start Training | CONNECTION 中统一叫 Start；选 Interactive 后点它即可，RUN CONFIGURATION 中才使用 Start Training 名称 |
| 找不到 66 秒 Demo | 先 Stop 并等待 STOPPED，点击 Demo 进入 LOCAL DEMO，不再连接；到 PRESENTATION → Scene → Load Demo Scene，再到 Run → Start Demo |
| Demo 中风机向同一侧偏航 | 当前 FAST.Farm 场景的连接 Demo 是预设偏航动画，不能当作训练结果；真实训练选 Interactive |
| 连接成功但风机不动 | 确认加载了场景并点击 Start；确认 RUNNING、遥测是否刷新；Formal Training 本来就不提供实时逐步画面 |
| FLORIS 不能 Start Training | 当前 Blender Bridge 只提供 FLORIS Backend Demo；交互训练改用已配置的 FAST.Farm |
| 云台按钮灰色 | 先加载场景，选存在的 T1/T2/T3，并在三维视窗内操作 |
| Esc 后仍是云台画面 | Esc 只退出控制；按第 4.3 节取消 Local Camera 或切出相机视图 |
| Stop 后仍显示 DRAINING | 后端正在安全结束，等待 STOPPED；断开连接不能替代等待 |
| 看不到训练指标 | 等待首次迭代记录，检查 WAITING / UNSUPPORTED / STALE 与终端错误 |
| 录制后找不到视频 | 输出是 PNG 序列；需要视频时另外编码 |

## 11. 给第一次演示的用户：按这个顺序操作

1. 打开 Blender → N → Item → Demo。
2. Load Demo Scene → Start Demo，确认三台风机运动。
3. Views & Layers → World，讲解总体布局。
4. Camera → T1 → Camera Mode，用拖动、滚轮、摇杆展示云台；Esc 退出。
5. Pause → Manual Pose 观察偏航与桨距，Resume 恢复，Stop 结束演示。
6. 使用平台启动器启动 FAST.Farm Bridge → Interactive → Connect / Reconnect → 确认 CONNECTED → 选择 turb3_row.yaml → Load & Validate Scene。
7. 设置训练参数 → CONNECTION 中 Start（或 RUN CONFIGURATION 中 Start Training）→ 查看 LIVE TELEMETRY 和 TRAINING DASHBOARD。
8. 需要留档时截图或导出历史；最后 Stop → 等待 STOPPED → 退出。

验证范围：本次用户已确认更新扩展后风场显示正常，并找到了离线 Demo；新云台参数仅完成语法检查与安装同步，未确认最终构图。本文其余内容按当前代码、菜单和启动脚本整理，不代表所有操作已逐项完成实机测试；Windows 安装与运行流程仍待实机验证。
