# WFRL Blender 用户使用手册 · 0.3.1

当前交付版本为 **0.3.5**：[下载](https://github.com/snode11/wind-farm-blender/releases/tag/v0.3.5)。默认内置预弯 v3 数据，新增机舱云台视角（默认 120°）及相邻两圈轨迹定格淡出，保留原 Down 视角。固定三束覆盖率失败，仍为 REVIEW_ONLY；详见发布核对。

更新日期：2026-09-16。适用于 Blender **5.2+**。本版内置三机柔性塔架与九片叶片数据，操作统一为“挠度 / 净空 / 工具”三页。

[下载正式版](https://github.com/snode11/wind-farm-blender/releases/tag/v0.3.5) · [快速演示](MAPPO演示.md) · [本版验证范围](0.3.5发布核对.md)

## 1. 先选择使用方式

| 目的 | 入口 | 数据与运行方式 |
| --- | --- | --- |
| 展示三台风机、九片叶片形变和雷达读数 | **MAPPO → 三机 MAPPO 回放** | 随扩展提供的 60 秒离线仿真记录；无需启动求解器 |
| 使用已有 MAPPO 权重观察实时仿真 | **Item → CONNECTION → Replay** | 连接 Bridge，在 FAST.Farm 中重新运行策略推理；需要兼容 checkpoint |
| 一边训练一边看回传 | **Item → CONNECTION → Interactive** | 实时训练与遥测；会执行训练更新 |
| 提交正式训练 | **Item → CONNECTION → Formal Training** | 正式训练流程与指标；不提供逐步实时三维遥测 |
| 比较独立雷达正常／较小净空工况 | **打开净空雷达演示.command** | 两个独立的 18 秒结果包，见第 12 节 |

日常演示默认使用 **MAPPO · 60 秒**。这段记录来自同一次随机阵风仿真：MAPPO 控制偏航，降额基线控制器负责转矩和变桨。点击播放只读取已保存结果，不训练模型。

**Replay 是实时后端推理模式，与离线 MAPPO 播放器不同。** 本机启动命令指定的 `turb3_row.yaml` 为 8 m/s 工况，不会自动复现随包随机阵风片段。旧 66 秒 SYNTH 演示、手动姿态与脚本事件入口已从当前 Demo 移除。

## 2. 安装与启动

### 2.1 Windows / macOS 安装并离线播放

1. 安装 Blender 5.2 或更新版本。从上方正式版下载 **wfrl_blender-0.3.5.zip**，不要解压，也不要下载 Source code 作为安装包。
2. 在 Blender 的 **Edit → Preferences → Get Extensions → Install from Disk** 中选择项目的 [wfrl_blender-0.3.5.zip](../../dist/wfrl_blender-0.3.5.zip)，安装并启用 WFRL Blender。不同界面语言下菜单名称可能翻译。
3. 更新已有扩展后，关闭旧 Blender 进程并重新打开，避免仍运行旧代码。
4. 建议从新的 General 场景开始，避免沿用旧 `.blend` 中的数据路径。鼠标移入三维视图，按 **N** 打开侧栏，选择 **MAPPO → 三机 MAPPO 回放**，点击 **加载 MAPPO · 60 秒**。

ZIP 内置完整三机回放数据和读取器。只播放这段数据无需后端 Python、MPI、FAST.Farm 或网络。Windows 直接使用上述 ZIP 安装方式，不运行 `.command`，也不需要复制本机的 `/Users/eason/` 路径。首次安装可能需要等待数据解压。若已使用本地中间版 0.3.2–0.3.5，先在扩展管理中移除旧 WFRL Blender，再从磁盘安装正式 0.3.1 并重启；旧数据或场景请先另存。

可在 PowerShell 执行 `Get-FileHash .\wfrl_blender-0.3.5.zip -Algorithm SHA256`，与发布页或同名 `.sha256` 文件比较。Windows 实机尚未验收；本次实际运行验证使用 macOS Blender 5.2.1。

### 2.2 用原命令启动：默认 MAPPO，后端待用

当前这台 Mac 可直接执行：

```bash
cd "/Users/eason/Desktop/wfcrl/wind farm RL"
scripts/blender/run_wfrl_macos.sh \
  --blender "/Applications/Blender.app/Contents/MacOS/Blender" \
  --python /opt/anaconda3/envs/wfrl-mac/bin/python \
  --scene scenes/turb3_row.yaml \
  --mpi /opt/homebrew/bin/mpiexec \
  --fastfarm /opt/anaconda3/envs/wfrl-mac/bin/FAST.Farm
```

启动器检查环境，启动本机 Bridge，并打开已安装的扩展。默认显示 **T1 侧前方首帧**，60 秒片段处于暂停状态；点击 MAPPO 面板的播放按钮开始观看。Bridge 在 `127.0.0.1:8765` 待用，默认不连接、不开始求解或训练。

这条命令为“随时可连后端”的入口，因此仍要求后端依赖完整；只想离线观看时可按第 2.1 节直接打开扩展或便携入口。其他电脑需替换项目与可执行文件路径，不能照搬本机绝对路径。Mac 使用原生 FAST.Farm，不能使用 Windows `.exe`。

保留终端以便查看启动错误。关闭该命令打开的 Blender 后，启动器清理自己启动的 Bridge。再次运行同一命令前，先退出上一窗口，避免端口被占用。

### 2.3 源码、安装版与更新

`blender_frontend/wfrl_blender/` 是工作区源码；安装版由 Blender 从用户扩展目录加载；便携入口使用随包运行时。修改源码不会自动更新另两者。

修改扩展代码或随包数据后，从项目根目录执行 `python3 scripts/blender/build_extension.py`，安装生成的 ZIP 并重启 Blender。只更新本手册、项目启动器或后端代码，无需重新构建扩展 ZIP；启动器与后端改动需要重启对应进程。向其他电脑交付原命令的后端流程时，还需提供当前项目及配套环境；只发送扩展 ZIP 不包含项目启动器和 Bridge 修复。版本与校验信息见 [交付说明](../../dist/README-lidar.md)。

## 3. 播放 60 秒 MAPPO 记录

### 3.1 加载与播放

在 **N 侧栏 → MAPPO → 三机 MAPPO 回放** 操作。原命令已自动加载；普通安装窗口先点击 **加载 MAPPO · 60 秒**。连接区显示 **OFFLINE RESULTS**，表示当前查看已保存结果，属于正常状态。

| 操作 | 结果 |
| --- | --- |
| 播放／暂停 | 从当前位置播放，或停在当前记录 |
| 工具 → 数据来源与重新加载 → 从头重播 | 回到起点并播放 |
| 单步 | 暂停并前进一帧，对应 1/60 仿真秒 |
| 复位 | 回到起点并暂停 |
| 进度滑块 | 按 0–100% 定位片段；滑块显示已播放／总时长 |
| 到达片尾 | 停在最后一条记录，可重新播放 |

原始片段为仿真时间 **117–177 秒**，源数据 40 Hz、2401 个时刻；显示时间轴为 60 Hz、3601 帧（包括首尾）。60 Hz 是时间映射，不代表机器能稳定播放 60 FPS。改变 Blender 输出 FPS 只改变目标播放速度，同一帧对应的仿真时刻保持不变。

停止和片尾不会自动变成零转速或顺桨状态。当前 Demo 不提供手动覆盖物理记录姿态的入口。

### 3.2 三机形变与叶尖轨迹

三台塔筒及九片叶片分别显示已记录的柔性形变，机舱、叶轮和雷达安装随塔顶运动，幅度没有放大。叶尖轨迹颜色为 **叶片 1 橙、叶片 2 蓝、叶片 3 红**，最多保留最近 540 点；它来自变形网格的叶尖位置，不是相机或实体雷达测出的轨迹。

同一机组切镜头保留轨迹与进度；换机组、寻址、重播会清空并重新记录。暂停后没有新采样，轨迹不会继续增长。

### 3.3 遥测、曲线与导出

进入 **工具 → 三机遥测、曲线与导出**，可查看每台机组偏航、三叶片平均变桨、转速、发电功率、转矩、B1 叶根弯矩，以及风场总功率。新增通道来自同次保存的 OpenFAST 输出，数据包保留源文件摘要；奖励未记录，不以虚构值填补。

勾选 **采样遥测与曲线** 后随播放采样；关闭后读数和曲线冻结。选择曲线通道和机组后，可点击 **导出已采样历史** 保存 JSON，包含单位与来源。每台机组每通道最多保留 600 点，导出的是当前保留历史，不是整段原始数据。仅修改曲线显示开关不会重新运行物理仿真。

### 3.4 T1 叶尖挠度：一步步对照

1. 切到 **挠度** 页，选择 **叶片 1 / 2 / 3**。此页只对照 T1；想看其他机组净空请切到“净空”页。
2. 点击 **叶尖** 跟随局部特写，或点 **叶轮 / Down** 查看完整叶轮及下视画面。
3. 开启 **虚影 / 分量**：灰色为同刻未变形参考，橙色为实际结构叶尖，黄色为总位移，青色/粉色/绿色对应面外/面内/轴向分量。完整图例在 **图例与计算口径**。
4. 暂停或单步后读表：**仿真 / m** 是源输出；**坐标差 / m** 是实际点减参考点的投影；**偏差 / mm = 坐标差投影 − 仿真输出**。总位移单位为 m。
5. 留意“保存帧 / 插值帧”：源数据为 40 Hz，显示帧为 60 Hz，两者不完全重合；插值帧不能当成求解器直接保存的采样。

参考点随塔顶平移、倾斜及叶轮姿态一起运动，因此表中叶片挠度扣除了塔顶整体运动。轴向仅显示坐标差，源仿真没有对应输出，不生成轴向对照或零误差。结构叶尖与彩色运动轨迹采用的收尖网格点定义不同，二者不要求完全重合。

切换“挠度 / 净空 / 工具”只换页面，保留当前时间、镜头和播放状态。选到 T2/T3 后切回挠度页如提示 T1 隐藏，点 **叶尖** 返回。缺少同源数据会提示“无法核对”，不要把空表当成零挠度。本版未增加塔筒专用虚影、位移箭头或数值卡片。

## 4. 观察视角与环境

### 4.1 常用镜头

**净空** 页提供 T1/T2/T3 Down；**工具 → 机组、视角与云台** 另提供 T1 侧前方和风场全景。切镜头保留仿真时刻和暂停状态；全景显示三台风机，其雷达卡片仍对应当前选中机组，按卡片标题确认 T1/T2/T3。

全景下侧栏可能遮住 T3，可将鼠标移入三维区域按 **N** 临时收起，再按 N 恢复。**工具 → 机组、视角与云台** 中提供测量区侧视和雷达特写；特写只放大观察，不改变传感器尺寸或标定。

### 4.2 云台控制

展开 **工具 → 机组、视角与云台 → 云台控制**，点击 **Camera Mode / 相机模式**，在视图内拖动改变朝向、滚轮变焦，拖动摇杆可持续转动。Down、Front、Back、Reset 提供预设方向；Joystick speed 控制交互速度。

Pan / Tilt / Roll 是观察相机的姿态，不是风机偏航或桨距。垂直视轴时某些角度无定义，会明确标注。相机操作不改变策略动作、回放数据或雷达标定。

**Esc** 退出交互控制，可能仍保留当前相机画面。MAPPO 下点击 **T1 侧前方** 或 **风场全景** 即可切回对应镜头。后端及独立雷达模式的云台位于 **Item → WFRL / Camera 相机与演示 → 云台控制**。

### 4.3 视角与环境

进入 **工具 → 机组、视角与云台** 切换 Top / Side；在 **工具 → 画面与环境** 设置环境预设和画面质量。地形、天气、示意尾流和雷达橙色光束用于展示；调整它们不改变仿真输入。尾流样式不是 FAST.Farm 实际流场，橙线末端不是测距命中点。

## 5. 雷达卡片与数据来源

MAPPO **净空** 页的 **雷达与净空** 卡片显示当前机组的 B2 同次有效测量：雷达到叶片距离、叶尖—塔筒净空真值、B2 估计和估计误差。距离与净空是不同量；误差定义为 **估计 − 真值**，正值表示高估。

| 状态 | 含义 |
| --- | --- |
| 新测量 | 当前时间步内有有效 B2 测量 |
| 上次有效测量 | 暂时保留最近一次有效值，需同时看测量时刻和读数年龄 |
| 等待下一次有效测量 | 无有效值或保留值已过期，显示缺失 |
| 回放数据未就绪 | 数据包未成功加载，需要查看路径或错误信息 |

本版净空真值使用叶尖参考点到同高度变形塔筒截面的距离。B2 固定标定的估计公式尚未补偿塔架弯曲，数值偏差照实保留。

暂停时仿真时间不前进，读数年龄不会随现实等待增长。缺失值不等于零，也不自动代表危险；不能用其他光束填补 B2。

展开 **测量详情与统计** 查看截至当前位置的平均／最大绝对误差、有效样本比例与经过次数。有效率的分母为评估网格内预期样本，不是设备精度或安全通过率；整次漏测在片尾汇总。当前三机记录仍标为 **REVIEW_ONLY**，没有证明现场精度、控制收益或数值收敛，不能用于实体风机保护。

## 6. 需要时连接真实后端

### 6.1 从默认 MAPPO 切换到后端

1. 按第 2.2 节运行原命令，使 Bridge 待用。
2. 在 **Item → WFRL / CONNECTION → 后端连接（高级）** 选择 **Replay** 或 **Interactive**。若没有 Item 标签，先在画面中点选一片叶片。
3. 点击 **Connect / Reconnect**。握手确认后，启动器自动加载命令中的 `scenes/turb3_row.yaml`。
4. 等待 **CONNECTED / READY**，核对 **SCENE CONFIGURATION** 中的三机布局与场景，再配置运行。

切换模式会关闭当前前端连接，切换后需重新 Connect。选择模式、连接和加载场景都不会自动开始运行。**OFFLINE RESULTS** 下先选择后端模式，再连接。

自动加载是项目启动器提供的功能。直接打开普通 Blender 并连接已有 Bridge 时，需在 **CONNECTION → 环境与路径（高级）** 设置 Default scene，再到 **SCENE CONFIGURATION → Load & Validate Scene**。更换 YAML 或覆盖参数后也需重新加载校验；运行中先停止并等待后端确认。

### 6.2 已有权重推理：Replay

在 **Item → WFRL / 后端运行** 中设置 Checkpoint、Replay steps、Warmup steps 和 Seed。本机三机权重示例：

```text
results/checkpoints/mappo_fastfarm_Dec_Turb3_Row1_Fastfarm_mappo_s0_level_E128_none.pt
```

文件必须与场景及控制维度兼容；建议通过文件选择器选定完整路径。点击 **Start Replay**，等待 `STARTING → RUNNING`。该模式运行真实 FAST.Farm 和策略推理，不进行 PPO 更新。

### 6.3 交互训练：Interactive

选择 Interactive、重新连接并确认场景后，在 **WFRL / 后端运行** 设置 Iterations、Rollout steps、Warmup steps 和 Seed，点击 **Start Training**。界面初始值为 8、64、4、0，用于了解流程，不代表正式实验或收敛配置。

展开 **LIVE TELEMETRY** 与 **TRAINING DASHBOARD** 查看真实回传。训练指标通常按迭代产生，不与每一帧叶片画面同步。当前没有前端手动覆盖后端策略动作的接口。

### 6.4 如何确认后端确实运行

**CONNECTED** 只证明握手成功；**READY** 表示配置待运行。启动后应同时看到 RUNNING、不断推进的 step／仿真时间和带来源的实际遥测。Formal Training 的遥测限制见第 7 节。

本机真实短测中，yaw、pitch、power、torque 为 DIRECT；实时 rotor_speed 当前由功率／转矩、效率和齿轮比推算，标记 **SYNTH** 并保留 `FastFarmDriver._rotor_speed` 公式来源。离线 60 秒片段使用保存的转速记录，二者不能混用。

当前实时场景的三维更新主要表达后端姿态；不能据此宣称实时求解已输出与离线九片柔性回放相同的全表面动画。`Start Backend Demo` 属于旧后端合成演示路径，不能作为 FAST.Farm 实际运行证据。

### 6.5 暂停、单步、停止和返回 MAPPO

| 操作 | 后端含义 |
| --- | --- |
| Pause | 请求在控制边界暂停；等待 PAUSED 确认，预热或正在执行的物理步骤不会瞬间中断 |
| Step | 已暂停时推进一个控制步；重复进度快照不算新步 |
| Resume | 从暂停状态继续 |
| Stop | 请求安全结束，等待 DRAINING → STOPPED |
| Reset | 在允许状态下复位运行状态；按后端返回确认 |

这些按钮统一位于 **WFRL / 后端运行**，不在 CONNECTION 中。按钮是否可用由后端状态和协商能力决定。停止后如需继续演示，点击 CONNECTION 的 **MAPPO · 60 秒**，回到离线面板。断开连接不等于停止任务；退出前先 Stop 并等待 STOPPED。

### 6.6 路径检查与 Windows 模板

**CONNECTION → 环境与路径（高级）→ Check Environment** 检查 Blender、Python、MPI 和 FAST.Farm；不会开始训练，也不能代替完整任务测试。出错时用 Full Details 或 Copy Error / Copy Report 查看诊断。

Windows 在包含 `scripts` 的项目根目录打开 PowerShell，替换以下路径后执行：

```powershell
.\scripts\blender\run_wfrl_windows.ps1 --blender "<blender.exe 完整路径>" --python "<后端 python.exe 完整路径>" --scene "scenes/turb3_row.yaml" --mpi "<mpiexec.exe 完整路径>" --fastfarm "<FAST.Farm.exe 完整路径>"
```

也可调用同一启动器的 Python 入口：

```powershell
python scripts/blender/wfrl_launcher.py launch --blender "<blender.exe 完整路径>" --python "<后端 python.exe 完整路径>" --scene "scenes/turb3_row.yaml" --mpi "<mpiexec.exe 完整路径>" --fastfarm "<FAST.Farm.exe 完整路径>"
```

Windows 需要匹配的 FAST.Farm 与 MPI 构建；本轮未实机验证 Windows。FLORIS 适配器仅支持旧 Backend Demo，当前 MAPPO 默认入口也不等于 FLORIS 连接流程；本手册的实时 Replay／Interactive 流程使用 FAST.Farm。

## 7. 正式训练与其他后端面板

### 7.1 Formal Training

先 Stop 并等待 STOPPED，再选择 Formal Training、重新连接、确认场景。在 **WFRL / 后端运行** 设置训练参数；从头训练时 Checkpoint 留空，恢复时选择兼容模型，然后点击 **Submit Formal Training**。

该模式启动正式训练流程并展示进度与指标。正式训练 CLI 不提供逐步实时遥测，三维画面不能作为实时仿真监视器；不支持 Pause、Resume 或 Step。结束时请求 Stop 并等待确认。本轮后端短测覆盖 Replay，不代表已验收完整长时训练。

## 8. 截图、录制与保存

MAPPO 下展开 **工具 → 截图、录制与渲染**；其他模式使用相应 Views & Capture 面板。先设置输出目录，再执行需要的操作。

- **保存截图** 保存当前可见窗口 PNG，包含可见界面；需要保留数据来源时不要隐藏相关标签。
- **录制窗口 PNG 序列** 按设置的录制频率和持续时间采样窗口，输出图片序列和记录实际时间的 manifest，不直接生成 MP4；Esc 取消。机器较慢时可能丢采样，录制不会主动推进后端物理步骤。
- **渲染静帧／渲染动画** 使用 Blender 渲染输出，是独立于窗口录制的功能。本轮未逐项验证完整录制与渲染流程。

保存 `.blend` 可以保留回放状态，但不会自动把外部数据包全部嵌入文件。转移到其他电脑时同时保留扩展或便携数据；缺包时读数应清空并显示未就绪，不能使用旧画面作为有效结果。安装 ZIP 与便携包的保存重开和缺包恢复已通过回归。

## 9. 数据标签怎么看

| 标签 | 含义 |
| --- | --- |
| OFFLINE RESULTS | 已保存结果回放，不要求后端连接 |
| REVIEW_ONLY | 开发审查数据；数值细化等验证尚未完成 |
| DIRECT | 后端直接回传；仍需核对仿真器、通道、单位，不代表现场实测 |
| EXPORTED | 已导出或按协议归类的数据，需看具体来源 |
| SYNTH | 合成、派生或展示数据；如实时推算转速，要查看公式来源 |
| WAITING / UNSUPPORTED | 等待数据／当前路径不支持 |
| STALE / invalid / unavailable / — | 过期、无效或缺失，不等于零 |

来源或单位变化时曲线可能断开。仿真真值来自计算几何，B2 估计来自理想测距与简化公式，均不能称为实体设备实测。

### 12.1 专用入口

入口使用项目源码与 [交付清单](../../dist/lidar-delivery.json) 指定的结果包，不安装或替换用户扩展。历史 `clearance-demo.blend` 存在时加载该文件；缺失时重建场景，因此不必恢复已清理的历史演示文件。两个外部结果包仍需完整保留，不要只复制 `.command`。

在 N 侧栏按 **WFRL / Camera 相机与演示** 标题查找面板，再查看 **净空与误差对比**。专用入口把面板放到当前选中的侧栏标签，标签名可能是 Tool 或历史场景保存的名称；普通安装版的对应面板在 Item。点击“正常测量”或“较小净空”开始播放。

### 12.2 播放、暂停、切换和重新看一遍

| 想做什么 | 具体操作 | 应看到什么 |
| --- | --- | --- |
| 看正常测量 | 点击 **正常测量** | 自动转到测量区侧视，从片段起点播放，时间与姿态同步变化 |
| 看较小净空工况 | 点击 **较小净空** | 从另一片段起点播放，自动转到测量区侧视；常驻说明提示后端含形变、画面为刚性示意 |
| 停下来读数 | 点击卡片内 **暂停** | 按钮变为“播放”，状态显示“已暂停”，可查看测量时刻和误差 |
| 接着播放 | 点击 **播放** | 按钮变为“暂停”，从当前位置继续 |
| 查看指定位置 | 先暂停，再拖动或输入 **回放进度** 百分比，也可拖动 Blender 时间轴 | 进度限定在片段范围；回放时间、姿态和截至该位置的统计同步更新 |
| 从头重播 | 点击 **从头重播**；也可再次点击当前片段名称 | 回到片段起点并播放；两个交付片段的仿真起点均为 18 秒 |

“回放进度”是 **0–100% 的片段进度**，下方显示播放状态及已播放时长 / 总时长。两段结果均长 18 秒，实际仿真时间为 18–36 秒；例如进度 50% 对应已播放 9 秒、仿真时间 27 秒。帧号放在“测量详情与统计”中。超出范围的进度输入和原生时间轴定位会限制在片段起止处；片尾可点击“重新播放”。

需要变速时，可在 Blender 的 **Output Properties（输出属性）→ Format → Frame Rate** 调整 FPS；例如 25 改成 50 是提高目标播放速度，实际速度受机器性能影响。固定帧对应的仿真时刻保持不变。第一次操作保留默认值即可。

### 12.3 三个数和统计怎么读

主卡片显示净空真值、B2 估计、误差及测量状态、叶片编号、测量时刻和“多少仿真秒前”，无需展开详情。需要查看有效率和误差统计时，再展开 **测量详情与统计**。

| 界面项目 | 含义 |
| --- | --- |
| 仿真真值 | 后端根据柔性叶片几何计算的参考值，单位 m；不是现场实测 |
| 估计 B2 | 使用 B2 理想测距和手册公开简化公式得到的估计值，单位 m |
| 偏差 | 估计值减去同次测量的真值；正数表示高估净空，负数表示低估 |
| 测量时刻 / 仿真秒前 | 主卡片中显示这组数来自何时、距当前仿真时刻多久；不是距电脑当前时间多久 |
| 平均绝对误差 / 最大绝对误差 | 当前片段截至当前回放位置的统计；回退或重播不会把重复播放次数累加进去 |
| B2 有效样本 / 预期样本中有效 | 有效样本数 / 评估网格内预期样本数及对应比例；不是叶片经过成功率、设备精度或安全通过率 |
| 经过测量区 / 整次漏测 | 截至当前位置已进入测量区的经过次数；整次漏测只在片尾汇总，避免把正在经过但尚未取得有效样本的叶片判作整次漏测 |

片尾正常工况为 B2 有效样本 **25/71（35.2%）**，较小净空工况为 **33/71（46.5%）**；两段均经过 **8 次，整次漏测 0 次**。片尾主卡片下方显示本段摘要，展开详情可看完整统计。

三项读数属于同一叶片的同一次 B2 有效测量。主卡片按以下状态显示：

| 主卡片状态 | 怎么理解 |
| --- | --- |
| 新测量 · 叶片编号 | 在当前时间轴步长内取得的有效测量；下方显示测量时刻和读数年龄 |
| 上次有效测量 · 叶片编号 | 当前仍显示最近一次有效测量，可能与正在播放的时刻不同；看“仿真秒前”判断年龄 |
| 等待下一次有效测量 | 尚无读数或保留值已经过期；三项数值均显示 `--`，继续播放等待下一次有效测量 |

暂停时仿真时间不前进，读数年龄也不会随现实等待时间增长。切换三种状态时卡片保留固定高度，播放按钮不应上下跳动。`--` 表示没有可显示的有效值，不是零米，也不是净空危险。

主卡片显示仿真真值、估计 B2 和偏差，不显示阈值高低判断，也不能用于实体风机保护。“正常测量”和“较小净空”是同一套雷达及 B2 算法在 **8 m/s、12 m/s** 两种风速下的结果片段，均固定 9 rpm、零变桨，用于比较不同工况的估计误差。画面仍是刚性运动示意，**不会把后端弹性弯曲直接画出来**，请通过数值比较两种工况。

### 12.4 画面里的雷达、橙线和相机

调整云台或查看相机姿态前，先展开 Camera 面板中的 **云台控制**。折叠后仍可查看雷达读数、切换片段和播放，无需加宽面板。

机舱下方的传感器模型包括壳体、支架、镜窗、盖板、螺钉、安装垫与线缆，三条橙线表示光束方向。这些局部细节用于展示安装关系，不是厂家工程 CAD。真实红外不可见，橙线的显示长度不是量程读数，线端不是实际命中点；净空以右侧数据卡片为准。

点击 Camera 区域的 **雷达特写**，切换到大幅放大的传感器安装视角，观察外壳、支架、出光口和附近光束。特写跟随雷达所在机舱，保持当前工况、回放进度与暂停状态；不改变雷达安装位置或模型大小。需要看完整测量区域时点击 **测量区侧视**，需要看整个风场时点击 **风场总览**。

上方 **Camera Mode / 相机模式**、Down、Front、Back 等按钮用于改变观察视角，基本操作见第 4 节。Pan / Tilt / Roll 表示当前 Camera 的仿真姿态，其中 Roll 显示值没有独立控制按钮。相机朝向不会修改离线雷达测量或雷达安装标定。点击 **测量区侧视** 观察叶片、雷达与塔筒的相对位置；点击 **风场总览** 回到全场观察。两者只切镜头，不切换数据模式、不重置回放时间；切回侧视仍继续读当前工况。切换工况则自动转回侧视。

| 定位项目 | 当前模型中的位置 |
| --- | --- |
| 塔筒中心轴 / 机舱偏航轴 | `X = 0，Y = 0`；偏航父节点位于 `Z = 87.6 m` |
| 机舱外壳中心 | 相对塔筒轴向轮毂方向偏移约 0.753 m；坐标约 `(-0.753, 0, 89.713) m` |
| 塔筒轴在机舱长度方向的位置 | 距机舱前端约 4.768 m，距后端约 3.262 m，即从前端算全长的约 59.4% 处 |
| 轮毂旋转中心 | 相对塔筒轴向前约 5.00 m；离地高度约 90.00 m |
| 主轴倾角参数 | `ShftTilt = -5°`；建模时按代码的坐标约定应用旋转 |

因此，从侧面看，塔筒位于机舱底部、纵向中心略靠后的位置；从横向看，塔筒轴与机舱中心线对齐。87.6 m 是塔筒高度，90.00 m 是当前建模公式计算出的轮毂旋转中心高度，两者含义不同。本附录描述当前源码重新构建的模型；历史 `.blend` 中的旧装配不会仅因更新材质自动变成新装配。

定位计算使用 `OverHang = -5.0191 m`、`nacelle_x_bias = 0.15`：机舱中心的 X 偏移为两者之积；机舱中心的高度还包含 `Twr2Shft = 1.96256 m` 和外壳局部偏移 0.15 m。轮毂中心由 `hub_position()` 结合塔高、`Twr2Shft`、悬伸量和主轴倾角计算。偏航时，机舱与转子围绕塔筒轴一起转动，上述局部装配关系保持不变。

### A.3 数据来源与适用范围

- [几何数据 nrel5mw_geometry.json](../../blender_frontend/wfrl_blender/assets/nrel5mw_geometry.json)：记录单位、塔筒站点、叶片站点、翼型轮廓、主要标量与机舱外壳参数，并保留来源校验信息。
- [几何生成 turbine_geometry.py](../../blender_frontend/wfrl_blender/turbine_geometry.py)：生成塔筒、叶片网格，并计算轮毂旋转中心。
- [场景装配 scene_builder.py](../../blender_frontend/wfrl_blender/scene_builder.py)：定义机舱、轮毂、整流罩和各部件的局部位置及父子关系。

塔筒和叶片主要依据本地 FAST.Farm 的 NREL 5 MW 模板；机舱外壳尺寸来自项目的 `wfrl/turbines/nrel5mw.yaml` 配置。轮毂外观、整流罩及部分机械细节包含展示用造型。上述信息用于解释和复现当前前端模型，不能直接作为真实设备的制造、安装或施工图尺寸。
