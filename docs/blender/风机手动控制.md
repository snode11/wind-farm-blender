# 风机手动控制

公开扩展 **0.3.29** 提供独立风机手动控制、常用姿态、角度微调、三机参数概览和 JSON 姿态文件，下载 [wfrl_blender-0.3.29.zip](https://github.com/snode11/wind-farm-blender/releases/download/v0.3.29/wfrl_blender-0.3.29.zip) 后通过 Install from Disk 安装。公开附件与源码身份见[交付身份](../../publication/blender-0.3.29.json)；开发机日常安装的已有证据见[安装核对](../../publication/daily-installation.json)和[新进程检查](../../outputs/frontend-stability-fixes/daily-probe.json)，仅适用于其记录的载荷与范围。源码同步不会自动更新安装版，安装 ZIP 后须完全重启 Blender。

手动场景以材质预览显示风机表面，使用随包蓝天白云环境图与轻量地形；环境、World、材质和图片均独立管理。进入或点击“观察选中风机”会启用场景灯光与天空，返回原场景时恢复原有预览设置。

## 进入与调整

在三维视图中按 **N → 风机控制 → 创建 / 进入手动场景**，创建或进入三台 NREL 风机的独立刚性场景，无需先加载 MAPPO demo。须处于对象模式；后端仍已连接、运行或有待处理命令时，先停止并断开后端。

选择 **T1、T2、T3** 调整单台风机，或选择 **全部**。每台风机保留自己的参数；选择“全部”本身不改参数，直接编辑输入框时只同步当前字段，集体桨距和分别变桨的叶片联动按下表执行。参数不一致的字段以 **\*** 标记，输入框显示 T1 数值；编辑该字段不把其他差异字段一并同步。**三机实际参数**分别显示各机朝向、叶轮角度、RPM、运行状态，以及当前生效的统一或三片独立桨距。桨距模式混合时，选择单机编辑独立桨距，或统一设置分别变桨模式。

| 控件 | 效果与输入范围 |
| --- | --- |
| 机舱朝向 | 机舱与叶轮绕塔顶转动，−180° 至 180° |
| 三片统一桨距 | 集体桨距，−30° 至 90°；统一设置三片叶片，即使已启用分别变桨也会覆盖各片独立桨距。任一所选风机启用分别变桨时，控件下方显示覆盖提示 |
| 分别调整三片叶片 | 仅从统一桨距切到分别变桨时，以该机当前集体桨距初始化三片叶片；批量启用时，已启用机组保留独立桨距。关闭后再次开启会重新初始化；修改集体桨距仍会统一三片叶片 |
| 转速 RPM | 0 至 30 RPM；运行中改变转速保留当前叶轮角度，设为 0 自动暂停 |
| 叶轮角度 | 所选风机均未实际转动时，可在 0° 至 360° 间精确摆放；360° 与 0° 表示同一位置 |
| 观察选中风机 | 一次定位单台或全部风机；之后可自由缩放、平移和绕转 |

参数支持拖动滑块和数字输入，画面立即响应。上述范围是界面预览范围，不表示真实风机的运行限值或安全限值。

## 变桨速度

本节与”Down 相机与视频导出”描述工作区源码，尚未进入公开 0.3.29 附件或日常安装。本地构建的 `dist/build-livefix/wfrl_blender-0.3.34.zip`（未发布）包含这些功能，通过 Install from Disk 安装并完全重启 Blender 后生效。

静止风机处于顺桨状态：进入新建的手动场景时三台风机桨距均为 90°。点击 **运行** 后，开始转动的风机关闭分别变桨，三片叶片按变桨速度转到 0°；**暂停** 和 **停转** 使所选风机的三片叶片按变桨速度回到 90° 顺桨；**复位** 立即置为 90°。运行中仍可手动修改统一桨距或三片独立桨距，下一次运行、暂停或停转按上述规则重新设定。

**变桨速度 °/s** 为 0–30 °/s，默认 5 °/s，作用于手动场景全部风机。为 0 时桨距设置立即到位。大于 0 时，运行、暂停、停转，以及修改统一桨距、分别变桨开关、三片独立桨距或其 −／＋ 微调后，各叶片从当前实际桨距按该速度转向设定值，到位后保持不变。按默认 5 °/s，从 90° 到 0° 约需 18 s。变桨过程中面板显示该机三片叶片的实际桨距。

例如选择 T1 并运行，待桨距到 0° 后开启“分别调整三片叶片”，再把叶片 1 桨距设为 10°：叶片 1 约 2 s 后到达 10° 并保持，叶片 2、3 保持 0°。

常用姿态、复位和载入姿态文件使桨距立即到位。变桨速度和实际桨距随 `.blend` 保存，不写入姿态文件。视口中的变桨按实际经过时间推进，界面卡顿时可能一次跨过多步；用于算法输入的画面以导出视频为准。

## Down 相机与视频导出

展开 **Down 相机** 分组：

- **叶片外形**：在 NREL 与 rootkink（商用形制叶根拐点改型）之间切换手动场景三台风机的叶片网格，默认 NREL。rootkink 含 5° 迎风倾斜，与 MAPPO 回放的同名外形一致。
- **T1 Down／T2 Down／T3 Down**：当前视口切换到该机的 Down 相机，并恢复其安装位置与预设方向。挂点、光心、8 mm 镜头和 16:9 画面高度 60° 视场与 [T1/T2/T3 Down 机舱下视](T1Down机舱下视.md) 相同，相机随机舱朝向转动，不随叶轮转动。
- **T1 左侧／T1 右侧**（T2、T3 相同）：切换到该机三相机组的侧视相机。侧视相机与 Down 相同镜头，姿态为 Down 相机绕主轴转 ±47°（按每台 59° 视场、相邻重叠 12° 计，合计 153°），因此侧视画面中叶片轮廓与 Down 画面一致、同样在画面下半部水平划过，背景为倾斜地面与远处地平线，不含塔筒。叶片依次经过右侧、Down、左侧画面。再点击 Down 按钮即回到主相机。
- **叶片编号**（默认开启）：各机 Down 画面右上角的深色框只显示当前叶片的编号 B1／B2／B3（黄／青／粉）。当前叶片指半展长处最靠近相机视线的叶片：叶片从画面右侧进入、左侧离开，编号在相邻两片叶片之间切换，画面中暂时没有叶片时显示即将或刚刚经过的叶片。调整某片叶片桨距后，可在该编号出现时观察对应叶片。编号框是固定在相机前的标注物体，不投射阴影，不属于叶片几何。三台相机各自独立判断当前叶片；叶片位于两台相机的重叠区时，两台相机可同时显示同一编号。
- **导出 Down 视频 MP4…**：在对话框中选择风机、长度、帧率、分辨率、渲染方式、是否叠加叶片编号和保存位置。长度可按 **时长**（默认 10 s）或 **帧数**（默认 250）设置，帧率默认 25，对话框显示实际总帧数与时长。分辨率可选 1920×1080（默认）、1280×720、960×540。**叶片编号叠加** 默认跟随面板开关，开启时视频右上角包含当前叶片编号。
- **导出三路 Down 视频 MP4…**：以相同参数同时导出中心、左、右三路相机的 H.264 MP4，三路视频帧对帧同步。在对话框中选择中心路的保存路径；左路、右路文件名自动加 `_left`、`_right` 后缀保存在同一目录。该功能仅支持视口材质和视口实体两种渲染方式，且需要 FFmpeg；三路共用同一个离屏缓冲区，每帧依次渲染三个相机，总耗时约等于单路视频的 3 倍。中心路 MP4 旁写出同名 `.json`，内容与单路相同，另含三路文件名与三台相机在机舱坐标中的姿态。

视频为 H.264、MPEG-4 容器，无音频。第 n 帧对应时刻 t = n／帧率：每台风机的叶轮角度为导出开始时的角度加 RPM × 6 × t；叶片桨距从起点按变桨速度转向设定值，到位后保持。导出前所有风机暂停，三台风机都按各自 RPM 转动（零 RPM 风机静止），无论导出前是否在运行。勾选 **从变桨起点录制**（默认）时，桨距起点为本次变桨开始前的值，视频完整记录变桨过程；不勾选时从当前实际桨距开始。导出完成后场景的叶轮角度、实际桨距、相机和输出设置恢复为导出前的状态。

导出的视频带有模拟机舱振动的相机抖动，使叶片在画面中的轨迹逐圈不同：所选风机的全部导出相机共用同一组俯仰／水平小角度转动，由多个不同频率的正弦叠加而成，连续平滑，每次导出随机取相位。幅度随所选风机 RPM 线性增大，15 RPM 及以上时每个方向最大约 1.5°，0 RPM 无抖动。俯仰按帧限制，使画面附近的叶尖始终位于画面中线以下（至少 0.1°）。视口实时预览不抖动。每帧实际抖动角度与随机种子写入 `.json`。抖动只转动相机，不是塔筒或叶片的结构振动模型。

渲染方式：

| 方式 | 画面 | 说明 |
| --- | --- | --- |
| 实时 · 视口材质（默认） | 场景材质、天空、光照与阴影，单采样 | 需在 Blender 窗口中导出；导出期间界面暂停响应，不可取消 |
| 最快 · 视口实体 | 纯色实体着色 | 同上，用于检查构图与运动 |
| 高质量 · EEVEE 渲染 | 最终渲染，多采样抗锯齿（默认 16 采样，约 0.8 s／帧） | 打开渲染窗口，可取消；取消不写出文件 |
| 后台 · Workbench | 最终渲染路径的纯色模式（约 0.2 s／帧） | 可在后台运行 |

两种视口方式在能找到 FFmpeg 时（扩展偏好设置“相机视频输出”中的 FFmpeg 路径；未设置时查找系统 PATH），逐帧在显卡上离屏绘制并直接交给 FFmpeg（libx264）编码；找不到 FFmpeg 时改用 Blender 内置编码，速度明显较慢，对话框会给出提示。对话框同时显示 Blender 当前使用的显卡；若为集成显卡（如 Intel UHD），在 Windows“设置 → 系统 → 显示 → 图形”中将 `blender.exe` 设为“高性能”，然后重启 Blender。导出期间同一场景不能再次导出。

导出耗时取决于显卡、分辨率与散热状态。下表为工作区源码在同一台笔记本（RTX 3070 Laptop／Intel UHD，Blender 5.2.1 窗口）上，以 25 fps、视口材质、叶片编号导出 5 分钟（7500 帧）的实测；FFmpeg 路径两次运行中显卡均处于约 86–89 °C 的温度降频状态：

| 显卡 | 编码路径 | 分辨率 | 5 分钟视频用时 |
| --- | --- | --- | --- |
| RTX 3070 Laptop | FFmpeg 离屏绘制 | 1280×720 | 255 s（0.034 s／帧） |
| RTX 3070 Laptop | FFmpeg 离屏绘制 | 1920×1080 | 443 s（0.059 s／帧） |
| RTX 3070 Laptop | Blender 内置编码 | 1920×1080 | 484 s（0.065 s／帧） |
| Intel UHD | Blender 内置编码 | 1920×1080 | 544 s（0.073 s／帧） |

同一机器显卡未降频时，FFmpeg 路径 1080p 短时测量约 0.02–0.036 s／帧。需要在视频时长内完成导出时选择 1280×720；1080p 在该笔记本上持续导出约为视频时长的 1.5 倍。


MP4 旁写出同名 `.json`，记录相机光学参数、分辨率、帧率、渲染方式、编码路径、显卡、是否叠加叶片编号、叶片外形、每台风机的起始角度、RPM、起点与目标桨距、变桨速度，以及逐帧时刻、叶轮角度、三片桨距和相机抖动角度。

示例：T1 选择 rootkink，叶轮角度 180°（叶片 1 朝下），RPM 6，变桨速度 5 °/s，叶片 1 设为 10°、叶片 2/3 为 0°。导出视频中叶片 1 在前 2 s 内由 0° 变到 10°，之后保持 10°，叶片 2/3 始终为 0°。

手动场景为刚性模型，不含预弯、柔性挠度、塔顶运动、气动响应、运动模糊或镜头畸变；叶片在 Down 画面中的位置与 MAPPO 柔性回放不同。工作区源码的后台检查中，T1 叶片 1 朝下时 rootkink 叶尖约在画面高度 0.60、塔基约 0.35（回放中叶尖约 0.51–0.54）。叶片 1 为 10° 与 0° 时近根段和后缘轮廓在画面中有可见差异；该差异来自展示网格绕变桨轴的刚性转动，不代表实测图像。

## 现场视频分屏

本节描述工作区源码，尚未进入公开附件或日常安装。

展开 **现场视频** 分组，在输入框粘贴现场相机的流地址，例如 `rtmp://主机:1935/rtp/设备ID_通道ID`，点击 **分屏播放 · 左 T1 Down 仿真**。当前三维视图左右分屏：左侧切换到所选风机（选择“全部”时为 T1）的 Down 仿真相机，右侧播放现场画面。点击右侧现场画面标题栏右端的 **关闭现场视频**，或面板中播放按钮旁的 **×**，停止拉流并关闭右侧画面，左侧仿真视图恢复为整幅。

- 支持 `rtmp`、`rtmps`、`rtsp`、`rtsps`、`http(s)`（如 HTTP-FLV、HLS）和 `srt` 地址；RTMP 地址须包含应用名和流名称，只填到 `/rtp/` 会提示缺少流名称。RTSP 固定使用 TCP。
- 需要 FFmpeg，路径与视频导出相同（扩展偏好设置“相机视频输出”，未设置时查找系统 PATH）。
- **解码尺寸** 默认 1280×720，另可选 1920×1080、960×540；画面保持原始宽高比，不足部分加黑边。只显示最新一帧，网络或界面卡顿时跳帧，不累积延迟。
- 右侧左上角显示状态、实际接收帧率和不含账号与查询参数的地址；面板同步显示状态。断流或无法连接时显示 FFmpeg 的错误原因，每 3 s 自动重连，直到点击停止。
- 流地址只在当前 Blender 会话中保留，不写入 `.blend`。打开其他文件、关闭右侧画面或停用扩展时自动停止拉流。
- 现场画面只用于并排观察，不与仿真时钟同步，不录制，也不参与净空或重建计算。

## 常用姿态与角度微调

常用姿态只作用于当前所选风机，执行后保持暂停并保留 RPM：

| 按钮 | 姿态与保留项 |
| --- | --- |
| 叶片1朝下 | 叶轮角度设为 180°，保留朝向、桨距及分别变桨模式 |
| 叶片1侧向 | 叶轮角度设为 90°，保留朝向、桨距及分别变桨模式 |
| 顺桨90° | 三片桨距均设为 90°并关闭分别变桨，保留朝向与叶轮角度 |

朝下与侧向以叶轮盘方向定义；轴倾角和预锥角仍保留，不表示叶片在世界坐标中绝对竖直或水平。顺桨按钮用于姿态展示，不执行真实控制器或安全停机。

**微调步长**为 0.1°–15°，默认 1°。角度右侧的 **−／＋** 按各台当前值分别调整；选择“全部”时保留已有角度差异。朝向和桨距到输入边界后钳制，叶轮角度在 0°–360°之间循环。统一桨距微调同样覆盖三片独立桨距。朝向和桨距微调保留运行状态；叶轮角度必须先暂停再调整。

## 姿态文件

**保存三机…** 将 T1/T2/T3 的朝向、RPM、叶轮角度、统一桨距、分别变桨模式及三片桨距写入 JSON。保存不暂停运行；运动中的叶轮角度按同一时刻采样。

**载入所选…** 按机组编号恢复当前所选风机并保持暂停，未选风机不变。选择“全部”要求文件包含 T1/T2/T3；只选 T2 时只恢复 T2。文件先整体校验，缺少所选机组、未知字段、非有限值和超出预览范围的参数均拒绝，不部分载入或自动夹紧。文件不保存运行状态、相机、环境或物理结果。载入、预设和微调均支持撤销／重做。

文件合同为 `wfrl.manual-pose.v1`，顶层包含 `schema` 和 `turbines`；每台机组完整包含 `yaw_deg`、`pitch_deg`、`rpm`、`azimuth_deg`、`individual_pitch` 和 `pitch_b1_deg`／`pitch_b2_deg`／`pitch_b3_deg`。分别变桨未启用时，三片独立桨距仍按保存值保留。

## 运行、暂停与保存

**运行**使所选风机中 RPM 大于 0 的风机按各自转速转动，零 RPM 风机保持暂停。所选风机全部为零 RPM 时，运行按钮禁用并提示“请先设置转速”；正 RPM 与零 RPM 混合选择时，提示“零 RPM 风机保持暂停”。运行的风机变桨到 0°。**暂停**保留 RPM 和当前叶轮位置；**停转**把 RPM 设为 0 并暂停；两者都使叶片变桨回到 90° 顺桨。停转后要重新旋转，先设置正 RPM，再点击运行。**复位**将所选风机的朝向和叶轮角度归零，关闭分别变桨并立即顺桨到 90°，恢复 **9 RPM** 并保持暂停。

运动使用实际经过的时间，不依赖 Blender 时间轴的播放速度，也不受 demo 的 60 秒片段限制。没有窗口显示手动场景时自动暂停。保存 `.blend` 会保留参数和姿态，重开、撤销及重做后均保持暂停，需要再次点击运行。

点击 **返回原场景**会暂停手动风机，返回进入前的场景与有效视图。原 demo 的数据、模型和播放位置保留，不会重新加载或复位；同一会话中，进入前正在播放的 demo 会在返回且原生播放器未被其他场景占用时继续播放。重新打开文件后不自动恢复播放。

## 模型与数据范围

手动场景使用独立对象、网格和材质，与 demo 的柔性回放分开。与三相机、缺陷编辑器的串联暂缓，不属于当前交付范围。它只展示参考形状上的刚性转动，不启动 FAST.Farm、Bridge、训练或其他物理求解，也不生成与手动姿态对应的功率、载荷、尾流、形变或雷达读数。

对象缺失、装配层级损坏或控制对象与其他场景共享时，控制停止并显示原因；可通过面板重新创建手动场景。原场景已被删除时，使用 Blender 场景选择器切换。

首次创建与损坏重建具有独立撤销记录，撤销首次参数编辑保留手动场景。损坏重建保留原返回视图，保存重开后仍可返回原场景与有效视图。
