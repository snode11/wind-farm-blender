# 风机手动控制

本文描述工作区源码的 **N → 风机控制** 栏目；**N → WFRL → 手动** 复用同一个面板。公开安装包与日常安装的身份和适用能力分别见[发布状态](发布状态与验证范围.md)及[安装核对](../../publication/daily-installation.json)，修改源码不会自动替换安装扩展。

## 进入与选择

在三维视图中点击 **创建 / 进入手动场景**，创建或进入 T1/T2/T3 的独立刚性场景，无需加载 MAPPO。进入时须处于对象模式，并停止、断开活动后端。场景使用 rootkink 合成展示外形、独立天空和地形；不改动原回放数据。

选择 **T1、T2、T3** 调整单机，或选择 **全部**。选择对象不改变参数；编辑“全部”的输入框时只同步正在编辑的字段。多值字段以 **\*** 标记，输入框显示 T1 数值。**三机实际参数**显示各机运行状态、RPM、机舱朝向、叶轮角度与设定桨距；变桨过渡期间，设定桨距不等于已显示的实际桨距。

## 参数与姿态

| 控件 | 行为 |
| --- | --- |
| 机舱朝向 | −180° 至 180°，绕塔顶转动 |
| 三片统一桨距 | −30° 至 90°，覆盖三片独立桨距 |
| 转速 RPM | 0 至 30 RPM，运行时改变速度保留叶轮方位 |
| 分别调整三片叶片 | 开启时以本机统一桨距初始化 B1/B2/B3；批量开启不重置已经开启的机组 |
| 叶轮角度 | 所选机组均未转动时，可在 0° 至 360°之间摆放 |
| 观察选中风机 | 一次定位单台或全部风机；随后可自由观察 |
| 微调步长 | 默认 1°，范围 0.1°–15°；角度右侧 −／＋ 按各机当前值调整 |

桨距按默认 **5°/s** 从实际姿态走向设定值，达到目标后保持。`Scene.wfrl_manual_pitch_rate_deg_s` 是普通变桨速度，范围 0–30；0 表示立即到位。当前栏目不提供该属性的编辑控件。

**叶片1朝下**将叶轮方位设为 180°；**叶片1侧向**设为 90°，二者保留桨距与分别变桨模式。**顺桨90°**将三片桨距立即设为 90°并关闭分别变桨，保留机舱朝向与叶轮方位。姿态预设执行后暂停叶轮；桨距微调遵循普通变桨速度。

这些参数用于刚性姿态预览，不是实体风机的运行限值或控制器。

## 运行与顺桨

| 按钮 | 叶轮与桨距 |
| --- | --- |
| 运行 | 所选正 RPM 风机开始旋转，三片转向 0°集体桨距；零 RPM 风机保留参数和暂停状态 |
| 暂停 | 冻结叶轮方位并保留 RPM，三片按普通变桨速度转向 90° |
| 停转 | RPM 设为 0，冻结叶轮方位，三片按普通变桨速度转向 90° |
| 复位 | 机舱朝向和叶轮方位归零、恢复 9 RPM，关闭分别变桨，三片立即到 90°，叶轮保持暂停 |

运行、暂停和停转的桨距命令均使用集体模式。所选机组全部为零 RPM 时，运行按钮禁用。手动调整桨距仍可在旋转中进行；再次点击运行会重新命令 0°。

时钟按实际经过的墙钟时间推进。场景未在窗口显示、对象失效、原生控制冲突或文件恢复时，运动保持暂停，不补写未显示的后续姿态。**返回原场景**暂停手动场景，并恢复进入前的场景与有效视角；原回放的时刻和数据保留。

## 姿态文件

**保存三机…**按同一时刻保存三台机组的朝向、RPM、叶轮方位与实际桨距，不暂停运行。**载入所选…**按机组编号应用，并保持暂停；未选机组不变。文件先整体校验，缺失机组、未知字段、非有限值和越界参数均拒绝，不部分载入。

合同为 `wfrl.manual-pose.v1`；每台机组包含 `yaw_deg`、`pitch_deg`、`rpm`、`azimuth_deg`、`individual_pitch` 和 `pitch_b1_deg`／`pitch_b2_deg`／`pitch_b3_deg`。姿态文件不保存运行状态或变桨速度。`.blend` 保存场景、姿态与普通变桨速度；加载、撤销和重做后保持暂停。

## 功能范围

栏目包含机组选择、观察、姿态预设、角度微调、统一／分别变桨、RPM、叶轮方位、运行／暂停／停转／复位和姿态文件。Down、冻结试验、视频和显示精度的源码研究接口见[手动场景研究接口](手动场景研究接口.md)，这些接口不在此栏目中绘制。

`live_stream_view.py` 是现场视频显示层源码；工作区缺少其依赖的 `live_stream.py` 解码层，扩展入口未注册现场视频操作器。现场视频分屏尚不可用。

手动运动不生成对应的功率、载荷、尾流、柔性形变或雷达数据，不触发 FAST.Farm、Bridge 或训练。与缺陷编辑器及回放三相机的串联不属于此栏目。
