# 风机手动控制

公开扩展 **0.3.30** 提供独立风机手动控制、常用姿态、角度微调、三机参数概览和 JSON 姿态文件，下载 [wfrl_blender-0.3.30.zip](https://github.com/snode11/wind-farm-blender/releases/download/v0.3.30/wfrl_blender-0.3.30.zip) 后通过 Install from Disk 安装。公开附件与源码身份见[交付身份](../../publication/blender-0.3.30.json)；开发机日常安装的已有证据见[安装核对](../../publication/daily-installation.json)和[新进程检查](../../outputs/frontend-stability-fixes/daily-probe.json)，仅适用于其记录的载荷与范围。源码同步不会自动更新安装版，安装 ZIP 后须完全重启 Blender。

手动场景以材质预览显示风机表面，使用随包蓝天白云环境图与轻量地形；环境、World、材质和图片均独立管理。进入或点击“观察选中风机”会启用场景灯光与天空，返回原场景时恢复原有预览设置。

0.3.30 提供 **rootkink 叶片、T1 恒速变桨试验、独立 T1 Down 和视频作业控制**。视频渲染、编码和监管依赖配套完整项目源码；日常安装仍为 0.3.28。

macOS 可双击 [打开手动恒速变桨.command](../../scripts/blender/打开手动恒速变桨.command)，在独立工厂启动进程和临时配置中加载工作区源码，自动进入手动场景并打开“风机控制”侧栏。入口不替换日常扩展或载入已有场景文件；默认使用 `/Applications/Blender.app`，可通过 `WFRL_BLENDER_BIN` 指定可执行文件。关闭窗口前可自行保存需要保留的 `.blend`。

## 进入与调整

在三维视图中按 **N → 风机控制 → 创建 / 进入手动场景**，创建或进入三台风机的独立刚性场景，无需先加载 MAPPO demo。手动场景固定采用 **商用形制叶根拐点改型（rootkink）**；叶轮装配、塔筒、机舱和机械结构保留 NREL 展示基准。须处于对象模式；后端仍已连接、运行或有待处理命令时，先停止并断开后端。

选择 **T1、T2、T3** 调整单台风机，或选择 **全部**。每台风机保留自己的参数；选择“全部”本身不改参数，直接编辑输入框时只同步当前字段，集体桨距和分别变桨的叶片联动按下表执行。参数不一致的字段以 **\*** 标记，输入框显示 T1 数值；编辑该字段不把其他差异字段一并同步。**三机实际参数**分别显示各机朝向、叶轮角度、RPM、运行状态，以及当前生效的统一或三片独立桨距。桨距模式混合时，选择单机编辑独立桨距，或统一设置分别变桨模式。

| 控件 | 效果与输入范围 |
| --- | --- |
| 机舱朝向 | 机舱与叶轮绕塔顶转动，−180° 至 180° |
| 三片统一桨距 | 集体桨距，−30° 至 90°；统一设置三片叶片，即使已启用分别变桨也会覆盖各片独立桨距。任一所选风机启用分别变桨时，控件下方显示覆盖提示 |
| 分别调整三片叶片 | 仅从统一桨距切到分别变桨时，以该机当前集体桨距初始化三片叶片；批量启用时，已启用机组保留独立桨距。关闭后再次开启会重新初始化；修改集体桨距仍会统一三片叶片 |
| 转速 RPM | 0 至 30 RPM；运行中改变转速保留当前叶轮角度，设为 0 自动暂停 |
| 叶轮角度 | 所选风机均未实际转动时，可在 0° 至 360° 间精确摆放；360° 与 0° 表示同一位置 |
| 观察选中风机 | 一次定位单台或全部风机；之后可自由缩放、平移和绕转 |

参数支持拖动滑块和数字输入，画面立即响应。上述范围是界面预览范围，不表示真实风机的运行限值或安全限值。

## T1 恒速变桨与 Down 观察

选择 **T1**，在 **T1 恒速变桨试验** 中设置正 RPM，勾选 B1/B2/B3 中的一片、两片或三片，分别输入目标桨距和一个共同的正变桨时长，默认 **8 s**。目标仅暂存，填写和勾选不改变模型；下方“当前”显示三片实际生效的桨距。目标范围为 −30° 至 90°，转速范围为大于 0 且不超过 30 RPM；时长输入最小为 0.01 s。这些仅为预览约束。

点击 **确认并开始**时，整体校验参数，并从同一时刻的实际叶轮方位与三片桨距开始。若用 Blender 原生旋转工具改动了受控角度，使模型与面板参数不一致，确认会报错；先撤销原生变换或通过手动面板重新设置姿态。已在旋转的 T1 保留方位连续；暂停的 T1 直接开始。**变桨方式**默认平滑，所选叶片用 `3u²−2u³` 过渡，起止变桨速度为零；选择 **匀速** 时用线性插值，各片角速度为各自桨距差除以共同变桨时长。两种方式均在到达目标后保持；未选叶片保持起始时生效的桨距，三片叶片始终存在。试验只作用于 T1，不修改 T2/T3 的参数。

旋转与变桨使用同一个试验时钟，RPM 全程固定，叶轮累计转角由 `theta0 + 6 × RPM × t` 确定，显示方位对 360° 取模。**暂停／继续**同时冻结／推进两种运动；**复位试验**暂停并恢复该试验的完整起始姿态与时间零点，继续可重复同一次试验。**结束试验，保留当前姿态**解除试验控制，保持暂停，允许设置下一组目标；最近确认的起点、目标和时长仍保留，下一次确认才替换。运行中复位或结束后撤销，恢复操作前的试验时间与姿态，并保持暂停。每次仅保留一组目标，没有多事件编辑器。

试验期间锁定 T1 起始姿态、统一／独立桨距、RPM 和目标输入；先结束试验再修改。统一桨距仍会覆盖三片独立值，因此它与待确认目标分开。非试验时的普通参数和姿态工具沿用上文行为；试验中的通用运行、暂停与复位入口也使用同一试验时钟。姿态 JSON 保存当前同刻姿态，不包含整份试验配置；`.blend` 保存冻结的试验起点、目标、时长、模型身份和试验时间。保存重开或撤销重做后保持暂停。

点击 **T1 Down**从当前手动 T1 机舱固定下视同一套动画几何，**返回整机**回到自由观察。两者都保留试验时间与运行状态。相机通过手动条目的 `yaw_object` 挂载，独立拥有对象与镜头数据，无需加载 MAPPO。光心由实际机舱前部底壳挂点沿机舱局部 −Z 外伸 0.40 m，光轴沿该坐标系正下，水平视场 110°，镜头偏移 `(0.100, −0.070)`；完整安装定义见 [Down 说明](T1Down机舱下视.md)。相机随机舱，不随叶轮旋转或追踪叶片。

保留机舱、塔筒、轮毂、叶根封口及叶片自身遮挡，Down 只观察局部入镜区域，不保证整片叶片始终可见。9 RPM 一圈约 6.67 s；默认 8 s 的变桨过程覆盖超过一圈的经过机会，仍需根据实际画面判断各片变化是否清楚。

## 导出变桨视频

在源码入口的 **T1 Down 视频 · 1080p / 25 fps** 中导出：

1. 设置 T1 的正 RPM、所选叶片及目标桨距，将变桨时长保留为 **8 s**、变桨方式保留为 **平滑**，点击 **确认并开始**。可以先预览、暂停或结束试验；导出始终使用最近确认试验的完整起点、目标和变桨方式。
2. 将 **目标桨距保持 s** 保留为 **7 s**。全片按指定 RPM 转动：前 8 s 平滑变桨，后 7 s 保持目标桨距，共 **15 s、375 帧**。
3. 点击 **导出 MP4…**，在已有文件夹中选择一个新文件名。独立后台进程生成视频，面板显示帧数进度，支持 **取消视频生成**；完成后可点 **打开视频**。

输出为 **1920×1080、25 fps、H.264 MP4**，画面来自固定 T1 Down 相机，不含 Blender 窗口、侧栏或文字标注。导出保留当前预览，之后更改预览也不改变已启动作业。T2/T3 在视频中保持导出快照中的姿态。目标保持时长可调整；变桨与保持时长之和须为 0.04 s 的整数倍，否则导出会报错。

单叶片 20°、三分钟工况使用 rootkink 模型：起始三片均为 0°，T1 保持 9 RPM，仅选 B1，目标 20°，变桨方式为匀速，变桨时长 4 s、目标保持 176 s。前 4 s 的 B1 桨距为 `5t` 度，之后保持 20°，B2/B3 全程保持 0°；总长 180 s、4500 帧，叶轮持续旋转。

可从仓库根目录用以下命令生成该工况；`--output` 必须显式指定，已有 MP4、悬空符号链接及正在被其他作业占用的输出均不覆盖。命令等待最终结果，只有完成验证和发布才成功退出；失败或取消返回非零状态：

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup \
  --python-exit-code 1 --python scripts/blender/generate_manual_pitch_video.py \
  -- --output /absolute/path/T1-Down_B1-20deg_180s.mp4
```

需要脱离运行时，在生成命令末尾显式加 `--detach`；它仅确认启动，打印的 `job_path` 指向持久化的 `job.json`，不能据启动成功判断成片成功。关闭源 Blender 不会终止独立监管进程。启动后保存源 `.blend` 可保存面板关联，重开后恢复查询与取消；没有保存关联时，可直接用作业路径管理，无需打开 Blender：

```bash
python3 -B scripts/blender/manage_manual_video.py status --job /absolute/path/job.json
python3 -B scripts/blender/manage_manual_video.py wait --job /absolute/path/job.json
python3 -B scripts/blender/manage_manual_video.py cancel --job /absolute/path/job.json
python3 -B scripts/blender/manage_manual_video.py retry --job /absolute/path/job.json
```

`wait` 等待收尾；`retry` 默认等待，也支持 `--detach`。上述管理命令的最终结果退出码为完成 `0`、失败 `1`、取消 `130`、失去联系 `3`；`status` 对运行中的作业返回当前状态。取消会先请求终止，必要时强制停止该作业进程组中的 Blender、FFmpeg／FFprobe 及其子进程，完成收尾后才确认取消；若交付已经完整提交并核验，则保持完成。监管通过作业凭据验证本机端点，不会凭磁盘中可复用的 PID 杀进程。无法联系时显示 `LOST`，不推断为失败或取消；仍被进程持有的输出锁继续阻止重复作业。

视频旁边的 `<文件名>_data_<标识>/` 保存 `job.json`、PNG 母版、逐帧时间与姿态表、相机参数、试验配置、场景副本、状态及运行日志。只有所有帧生成后才产生完整母版凭据 `master.json`。编码、解码验证或发布失败后，`retry` 校验作业、配置、快照、源码与外部资源、相机、姿态表、连续帧数、每帧内容及编码参数，再仅执行编码、验证和发布；完整且属于该作业的已编码文件可复用。缺帧、损坏、来源不符、混合作业或没有完整母版凭据时拒绝，不补帧、不做逐帧渲染续传。此时需要使用新的输出名重新生成。已成功作业拒绝重试并保留成功状态；未知视频或他人文件不被覆盖。

输出在帧数、尺寸、时长、时间戳和严格解码通过后，先在目标文件系统暂存完整文件，再用拒绝替换的原子提交发布。渲染前检查该文件系统的提交和冲突保护能力；不支持硬链接的目标可使用原生的拒绝替换提交，无法安全发布时提前报错。并发新建的文件或符号链接仍会阻止最终发布，失败清理自有暂存文件。输出目录中的 `.wfrl-output-*.lock` 是持久化锁名，作业结束释放锁但保留文件，避免删除锁名造成并发竞争；不要在作业运行时手动删除锁文件或作业目录。

导出需要完整工作区源码、本机 **FFmpeg／FFprobe** 和独立 **Python 3.11+**；安装扩展使用偏好的 **Project directory** 指定完整项目目录，源码入口使用所在仓库。渲染进程加载该目录的源码，须与扩展交付版本配套。监管解释器可用 `WFRL_VIDEO_PYTHON` 指定。监管依赖 `flock` 和 `waitid(WNOWAIT)`，仅支持具备这些接口的 macOS／Linux；其他系统在启动前拒绝。纯 Python 隔离回归覆盖监管、母版重试和发布边界；0.3.30 安装版已在两个独立 Blender 进程中完成非媒体作业的恢复与取消检查；真实编码、Linux 及不同实际文件系统的集成仍需各自验证，不能据此宣布三分钟成片或渲染性能已验收。

生成速度由电脑和渲染设置决定，25 fps 是成片播放帧率。每帧采样 `t=k/25` 的确定姿态，关闭运动模糊，属于瞬时合成成像；不模拟实体相机曝光或真实风机控制器。当前不接入 RTSP 或识别算法。

## 常用姿态与角度微调

常用姿态只作用于当前所选风机，执行后保持暂停并保留 RPM：

| 按钮 | 姿态与保留项 |
| --- | --- |
| 叶片1朝下 | 叶轮角度设为 180°，保留朝向、桨距及分别变桨模式 |
| 叶片1侧向 | 叶轮角度设为 90°，保留朝向、桨距及分别变桨模式 |
| 顺桨90° | 三片桨距均设为 90°并关闭分别变桨，保留朝向与叶轮角度 |

朝下与侧向以叶轮盘方向定义；轴倾角和预锥角仍保留，不表示叶片在世界坐标中绝对竖直或水平。顺桨按钮用于姿态展示，不执行真实控制器或安全停机。

**微调步长**为 0.1°–15°，默认 1°。角度右侧的 **−／＋** 按各台当前值分别调整；选择“全部”时保留已有角度差异。朝向和桨距到输入边界后钳制，叶轮角度在 0°–360°之间循环。统一桨距微调同样覆盖三片独立桨距。朝向和桨距微调保留运行状态；叶轮角度必须先暂停再调整。

## 姿态文件

**保存三机…** 将 T1/T2/T3 的朝向、RPM、叶轮角度、统一桨距、分别变桨模式及三片桨距写入 JSON。保存不暂停运行；运动中的叶轮角度按同一时刻采样。

**载入所选…** 按机组编号恢复当前所选风机并保持暂停，未选风机不变。选择“全部”要求文件包含 T1/T2/T3；只选 T2 时只恢复 T2。文件先整体校验，缺少所选机组、未知字段、非有限值和超出预览范围的参数均拒绝，不部分载入或自动夹紧。文件不保存运行状态、相机、环境或物理结果。载入、预设和微调均支持撤销／重做。

文件合同为 `wfrl.manual-pose.v1`，顶层包含 `schema` 和 `turbines`；每台机组完整包含 `yaw_deg`、`pitch_deg`、`rpm`、`azimuth_deg`、`individual_pitch` 和 `pitch_b1_deg`／`pitch_b2_deg`／`pitch_b3_deg`。分别变桨未启用时，三片独立桨距仍按保存值保留。

## 运行、暂停与保存

**运行**使所选风机中 RPM 大于 0 的风机按各自转速转动，零 RPM 风机保持暂停。所选风机全部为零 RPM 时，运行按钮禁用并提示“请先设置转速”；正 RPM 与零 RPM 混合选择时，提示“零 RPM 风机保持暂停”。**暂停**保留 RPM 和当前叶轮位置；**停转**把 RPM 设为 0 并暂停。停转后要重新旋转，先设置正 RPM，再点击运行。**复位**将所选风机的朝向、桨距和叶轮角度归零，关闭分别变桨，恢复 **9 RPM** 并保持暂停。

运动使用实际经过的时间，不依赖 Blender 时间轴的播放速度，也不受 demo 的 60 秒片段限制。没有窗口显示手动场景时自动暂停。保存 `.blend` 会保留参数和姿态，重开、撤销及重做后均保持暂停，需要再次点击运行。

点击 **返回原场景**会暂停手动风机，返回进入前的场景与有效视图，包括相机画框的缩放和平移。原 demo 的数据、模型和播放位置保留，不会重新加载或复位；同一会话中，进入前正在播放的 demo 会在返回且原生播放器未被其他场景占用时继续播放。重新打开文件后不自动恢复播放。

## 模型与数据范围

手动场景使用独立对象、网格和材质，与 demo 的柔性回放分开。rootkink 是合成展示外形，不是厂家 CAD，也不证明实体性能。与三相机、缺陷编辑器的串联暂缓，不属于当前交付范围。它只展示规定的刚性转动和桨距过渡，不模拟气动力或执行器动力学，不启动 FAST.Farm、Bridge、训练或其他物理求解，也不生成与手动姿态对应的功率、载荷、尾流、形变或雷达读数。

对象缺失、装配层级损坏或控制对象与其他场景共享时，控制停止并显示原因；可通过面板重新创建手动场景。原场景已被删除时，使用 Blender 场景选择器切换。

首次创建与损坏重建具有独立撤销记录，撤销首次参数编辑保留手动场景。损坏重建保留原返回视图，保存重开后仍可返回原场景与有效视图。
