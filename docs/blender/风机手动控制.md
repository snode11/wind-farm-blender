# 风机手动控制

NREL / WFRL **0.3.22** 公开扩展提供独立风机手动控制，安装使用 [wfrl_blender-0.3.22.zip](https://github.com/snode11/wind-farm-blender/releases/download/v0.3.22/wfrl_blender-0.3.22.zip) 并完全重启 Blender。包身份、源码和适用验证见[0.3.22 交付身份](../../publication/blender-0.3.22.json)。开发机日常 **0.3.21** 安装不包含此入口，源码同步与公开发布不会自动更新安装版。

手动场景以材质预览显示风机表面，使用随包蓝天白云环境图与轻量地形；环境、World、材质和图片均独立管理。进入或点击“观察选中风机”会启用场景灯光与天空，返回原场景时恢复原有预览设置。

## 进入与调整

在三维视图中按 **N → 风机控制 → 创建 / 进入手动场景**，创建或进入三台 NREL 风机的独立刚性场景，无需先加载 MAPPO demo。须处于对象模式；后端仍已连接、运行或有待处理命令时，先停止并断开后端。

选择 **T1、T2、T3** 调整单台风机，或选择 **全部**。每台风机保留自己的参数；选择“全部”本身不改参数，编辑时只同步当前字段，集体桨距和分别变桨的叶片联动按下表执行。所选风机的参数不一致时，对应的可见字段旁显示 **多值**，输入框显示 T1 数值；编辑该字段不把其他差异字段一并同步。

| 控件 | 效果与输入范围 |
| --- | --- |
| 机舱朝向 | 机舱与叶轮绕塔顶转动，−180° 至 180° |
| 三片统一桨距 | 集体桨距，−30° 至 90°；统一设置三片叶片，即使已启用分别变桨也会覆盖各片独立桨距。任一所选风机启用分别变桨时，控件下方显示覆盖提示 |
| 分别调整三片叶片 | 勾选时以当前集体桨距初始化三片叶片，随后可分别调节；再次修改集体桨距会统一三片叶片 |
| 转速 RPM | 0 至 30 RPM；运行中改变转速保留当前叶轮角度，设为 0 自动暂停 |
| 叶轮角度 | 所选风机均未实际转动时，可在 0° 至 360° 间精确摆放；360° 与 0° 表示同一位置 |
| 观察选中风机 | 一次定位单台或全部风机；之后可自由缩放、平移和绕转 |

参数支持拖动滑块和数字输入，画面立即响应。上述范围是界面预览范围，不表示真实风机的运行限值或安全限值。

## 运行、暂停与保存

**运行**使所选风机中 RPM 大于 0 的风机按各自转速转动，零 RPM 风机保持暂停。所选风机全部为零 RPM 时，运行按钮禁用并提示“请先设置转速”；正 RPM 与零 RPM 混合选择时，提示“零 RPM 风机保持暂停”。**暂停**保留 RPM 和当前叶轮位置；**停转**把 RPM 设为 0 并暂停。停转后要重新旋转，先设置正 RPM，再点击运行。**复位**将所选风机的朝向、桨距和叶轮角度归零，关闭分别变桨，恢复 **9 RPM** 并保持暂停。

运动使用实际经过的时间，不依赖 Blender 时间轴的播放速度，也不受 demo 的 60 秒片段限制。没有窗口显示手动场景时自动暂停。保存 `.blend` 会保留参数和姿态，重开、撤销及重做后均保持暂停，需要再次点击运行。

点击 **返回原场景**会暂停手动风机，返回进入前的场景与有效视图。原 demo 的数据、模型和播放位置保留，不会重新加载或复位；同一会话中，进入前正在播放的 demo 会在返回且原生播放器未被其他场景占用时继续播放。重新打开文件后不自动恢复播放。

## 模型与数据范围

手动场景使用独立对象、网格和材质，与 demo 的柔性回放分开。它只展示参考形状上的刚性转动，不启动 FAST.Farm、Bridge、训练或其他物理求解，也不生成与手动姿态对应的功率、载荷、尾流、形变或雷达读数。

对象缺失、装配层级损坏或控制对象与其他场景共享时，控制停止并显示原因；可通过面板重新创建手动场景。原场景已被删除时，使用 Blender 场景选择器切换。

首次创建与损坏重建具有独立撤销记录，撤销首次参数编辑保留手动场景。损坏重建保留原返回视图，保存重开后仍可返回原场景与有效视图。
