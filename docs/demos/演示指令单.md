## 当前 Blender 演示：几何／同源纹理与三相机

1. 使用 Blender 5.2+，下载 [0.3.37 发布页](https://github.com/snode11/wind-farm-blender/releases/tag/v0.3.37) 的安装附件 `wfrl_blender-0.3.37.zip`。
2. **Preferences → Get Extensions → Install from Disk** 安装启用并重启 Blender。
3. 三维视图按 **N → MAPPO → 打开几何重建示例…**，在当前分屏双向切换几何重建／同源纹理；左右均显示完整风机，右侧塔筒、机舱与轮毂为模拟展示结构。
4. 播放后暂停，使用中段／叶尖观察点一次定位，再自由缩放和绕转，继续播放保留手动视角。原始／对比增强先恢复整机取景；共享播放、单帧步进、复位、退出及保存重开保留。
5. 普通 MAPPO 的 **View → 三相机 → 1 · 安装整个盒体 → 恢复默认三相机** 恢复默认盒体与 C1–C3 参数，保留帧和视角并支持相机撤销。独立 `synth_tex` 资产和底层工具使用 120 样本独立来源，不称同源同步。

同源为601样本、117–177 s，MAPPO源40 Hz、共享时间轴60 Hz。frame 52显示117.850 s播放／117.800 s样本／保持50 ms。绿为输入约束支持、橙为模型推断，两者均算法估计。条带、接缝与叶尖拖影保留；纹理、几何、缺陷及稳定FPS未验收。发布不会自动更新日常安装或后端服务器；自动 Source code 不是专用扩展 ZIP，不能代替安装包。

公开 ZIP 按钮与包检查见[0.3.37 核对](../blender/发布状态与验证范围.md#软件验证的适用对象)。普通三机、三相机和合成缺陷见[前端使用说明](../../前端readme.md)及NREL [缺陷编辑器](../blender/NREL缺陷编辑器.md)，数据与恢复边界见[Blade Recon 说明](../blender/BladeRecon可视化使用说明.md)。软件操作通过不改变 `FAILED_GATE / NOT_ACCEPTED`、双束/TLS 的 `REVIEW_ONLY / PENDING_ACCEPTANCE` 或现场与平台验证限制。

## 源码环境的 PowerShell / RViz

以下命令适用于具备匹配 Python、MPI、FAST.Farm、控制器与算例的完整源码环境，不是 Blender 扩展操作。路径使用 Windows 模板，必须替换成本机实际安装。macOS 和后端分流见[本地配置](../setup/setup_local.md)。Studio checkpoint Replay 会重新推进物理，不读取 Blender 内置离线结果。

PowerShell 调用带空格路径使用 `&`；换行使用末尾反引号，其后不能有空格。`& $MPI -n 1 $PY ...` 中 `$PY` 是 mpiexec 的参数，不再加第二个 `&`。

```powershell
cd "D:\project\wind farm RL"
$PY = "C:\Users\s1155\.conda\envs\wfcrl\python.exe"
$MPI = "C:\Program Files\Microsoft MPI\Bin\mpiexec.exe"
chcp 65001 > $null
```

### 动态气弹与双视图

```powershell
& $MPI -n 1 $PY -X utf8 -m wfrl.viz.rviz_app `
  --backend fastfarm --max-steps 60 --wake-vtk `
  --turb 90m_08mps.bts --terrain mountains --dual-view --focus 1 `
  --controls "yaw,pitch"
```

`--wake-vtk` 使用 FAST.Farm 的 DisXY 切面；地形不参与流场求解。`--turb` 需要对应 TurbSim 输入，存在命令不代表该文件已安装。`--controls` 指定控制通道，实际控制器覆盖和响应仍须从输出检查。RViz 的载荷代理或显示放大不代替 Blender 保存柔性几何。

`--model` 选择匹配策略；默认 `auto` 的选择逻辑和回退须以实际日志核对，不能仅凭画面认定已加载特定 checkpoint。`--headless N` 选择无窗口遥测路径，不显示 Qt 窗口。

### 稳态参考与无窗口遥测

```powershell
& $PY -X utf8 -m wfrl.viz.rviz_app --backend floris --terrain mountains --dual-view --focus 1
& $MPI -n 1 $PY -X utf8 -m wfrl.viz.rviz_app --backend fastfarm --headless 8 --max-steps 10 --wake-vtk --turb 90m_08mps.bts
```

FLORIS 是稳态参考，不提供动态尾流传播。动态遥测分别解释偏航、桨距指令/反馈、转矩、转速、功率、来流、叶尖与净空的来源和单位。界面约束检查不构成机组安全认证。

### Studio 策略评估

```powershell
& $MPI -n 1 $PY -m wfrl.studio.app --scene scenes/turb3_stagger.yaml --replay --ckpt <匹配的checkpoint路径> --replay-steps 400 --warmup 8
```

运行前核对 checkpoint、场景布局、控制量、机组顺序、观测维度/归一化和动作尺度。`scripts/demo/replay_studio.ps1` 硬编码 Windows 路径及 `stagE400ref` 权重，当前该权重和配套轨迹缺失，不能直接作为可运行交付。脚本打印的耗时、偏航角、3.28 MW 与 +5.3% 是旧固定来流实验的预期文字，不是当前运行保证；具体证据局限见[固定来流实验](../training/WAKE_STEERING_BREAKTHROUGH.md)。接口与使用见[Studio 回放说明](../../scripts/demo/REPLAY_GUIDE.md)。
