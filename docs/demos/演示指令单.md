# Blender 演示与后端入口

Blender 内置离线入口使用 NREL / WFRL 专用扩展 ZIP，下载与安装见[安装说明](../blender/INSTALL.md)。公开扩展与开发机日常安装按[发布状态](../blender/发布状态与验证范围.md)和[安装核对](../../publication/daily-installation.json)分别识别。

## 当前 Blender 演示：几何／同源纹理与三相机

1. 使用 Blender 5.2+，从[安装说明](../blender/INSTALL.md)取得当前公开版的专用扩展 ZIP。
2. **Preferences → Get Extensions → Install from Disk** 安装启用并重启 Blender。
3. 三维视图按 **N → MAPPO → 打开几何重建示例…**，在当前分屏双向切换几何重建／同源纹理；左右均显示完整风机，右侧塔筒、机舱与轮毂为模拟展示结构。
4. 播放后暂停，使用中段／叶尖观察点一次定位，再自由缩放和绕转，继续播放保留手动视角。原始／对比增强先恢复整机取景；共享播放、单帧步进、复位、退出及保存重开保留。
5. 普通 MAPPO 的 **View → 三相机 → 1 · 安装整个盒体 → 恢复默认三相机** 恢复默认盒体与 C1–C3 参数，保留帧和视角并支持相机撤销。独立 `synth_tex` 资产和底层工具使用 120 样本独立来源，不称同源同步。

同源为601样本、117–177 s，MAPPO源40 Hz、共享时间轴60 Hz。frame 52显示117.850 s播放／117.800 s样本／保持50 ms。绿为输入约束支持、橙为模型推断，两者均算法估计。条带、接缝与叶尖拖影保留；纹理、几何、缺陷及稳定FPS未验收。发布不会自动更新日常安装或后端服务器；自动 Source code 不是专用扩展 ZIP，不能代替安装包。

公开 ZIP 的适用检查见[软件验证范围](../blender/发布状态与验证范围.md#软件验证的适用对象)。普通三机、三相机和合成缺陷见[前端使用说明](../../前端readme.md)及 NREL [缺陷编辑器](../blender/NREL缺陷编辑器.md)，数据与恢复边界见[Blade Recon 说明](../blender/BladeRecon可视化使用说明.md)。软件操作通过不改变 `FAILED_GATE / NOT_ACCEPTED`、双束/TLS 的 `REVIEW_ONLY / PENDING_ACCEPTANCE` 或现场与平台验证限制。

## 独立风机控制

**N → 风机控制 → 创建 / 进入手动场景** 提供偏航、统一／分别变桨、RPM 与叶轮角度。刚性运动不产生功率、载荷或物理尾流结果；操作及保存规则见[风机手动控制](../blender/风机手动控制.md)。

## 后端策略与训练

按[本地配置](../setup/setup_local.md)准备 Python、MPI、FAST.Farm、控制器和场景资源。macOS 启动器 `scripts/blender/run_wfrl_macos.sh` 委托 `wfrl_launcher.py launch`；其他平台使用[用户手册](../blender/用户使用手册.md)对应的配置与验证范围。

在 Blender 的后端连接中选择 Replay、Interactive 或 Formal Training。Replay 从兼容 checkpoint 重新执行物理回合，具体配置与模型限制见[Blender 策略评估](Blender策略评估.md)；训练入口、采样和统计规则见[训练合同](../training/MAPPO_SETUP.md)。

## 无窗口合同检查

从仓库根目录运行：

```bash
PYTHONPATH=blender_frontend:. python -m pytest blender_frontend/tests --ignore=blender_frontend/tests/blender
PYTHONPATH=blender_frontend:. python -m pytest tests
```

这些宿主测试检查数值、协议与生命周期合同，不证明可见窗口、GPU 或真实后端性能。原生专项检查按[维护与验证入口](../../.agents/skills/windfarm-blender-dev/references/verification.md)选择；在线求解与训练探针只在明确的验证任务中运行。
