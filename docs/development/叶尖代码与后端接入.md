状态：2026-09-15 源码修复，未发布扩展。没有重新求解、训练或改写既有仿真结果。

## 文件位置

| 文件 | 职责 |
|---|---|
| `wfrl/viz/tip_geometry.py` | 几何、相机投影、带假设的像素反解；支持世界原点、偏航、相机位姿和标定 |
| `wfrl/viz/tip_tracking.py` | 三维/像素输入、时钟、丢检预测、有限缓存与轨迹开关，不依赖 OpenCV |

## 安装和运行

从仓库根目录运行。建议独立虚拟环境，避免影响训练环境：

```sh
python -m venv .venv-tip
.venv-tip/bin/python -m pip install -e '.[tip-preview]' pyyaml
```

不含镜头畸变的几何计算与状态处理只需 NumPy。使用畸变投影/反投影、视频或窗口预览时才需要 OpenCV。不平衡度算法可以通过 `imbalance_tracker=` 显式注入；缺失时不导入、不伪造指标，也不阻断基本功能。

### 直接读取已有物理结果

```sh
.venv-tip/bin/python -m wfrl.viz.tip_visualizer \
  --fastfarm-package results/lidar/packages/normal-v1.1 --frames 1441
```

当前 reader 支持已校验的 NREL5MW 单机结果包、19/37 个截面、原始 run_config 与 surface_hashes。需要保留原始 VTP：数据路径目前从包的来源清单解析；移动到其他机器前需要整理可移植的数据包，此处不是最终客户交付包。

### 完整经过现有 Bridge

终端一（独立端口，避免占用正在工作的 Blender Bridge）：

```sh
.venv-tip/bin/python -m wfrl.blender_bridge --port 8876 --scene scenes/turb3_row.yaml
```

终端二：

```sh
.venv-tip/bin/python -m wfrl.viz.tip_visualizer \
  --bridge 127.0.0.1:8876 \
  --fastfarm-package results/lidar/packages/normal-v1.1 --frames 1441
```

完整链路是 `BackendSession → RecordedTipTrainer → 已有 FAST.Farm 结果 → BridgeServer → TipBridgeClient → TipTracker/预览`。

Bridge `run.start` 使用：

```json
{"mode":"replay","options":{"tip_package":"/absolute/path/to/normal-v1.1"}}
```

这是新增的已保存几何结果回放分支。现有 `ckpt_path` 策略运行分支不变；两种参数不能混用。预览客户端一次请求一帧，暂停/调视角不继续求值。关闭客户端会停止它自己启动的回放。已有活动会话会被拒绝，不抢占现有训练。

快照中每个机组的 `channels.blade_geometry` 使用已有 v1 通道包装（来源、有效性、单位、时间）。内部含 `source=FAST.Farm`、`time_s`、世界坐标系说明和三片叶片的 `sections_m/tip_m`，ID 为 1/2/3；消费者统一转换成 0/1/2。截面和叶尖需要同一时刻，叶尖必须等于最后一个截面的参考点。

## 交互与数据规则

- 默认不显示轨迹。`t` 开启时从空白开始，随播放逐点增长；关闭时隐藏三色轨迹及标记。再次开启时开始一段新轨迹。
- `SPACE` 暂停/继续；暂停中 `a/d/w/s` 调整观察相机，仅重绘，不改变仿真时间。
- 同一时间戳不重复累计；输入时间倒退或切换来源清空状态。
- 三维轨迹保存世界坐标。相机改变后重新投影，不把旧屏幕像素与新屏幕像素连线。
- 只有叶尖像素时显示点和轨迹，不声称恢复了完整叶片。FAST.Farm 截面输入会画出对应弯曲中心路径；这是截面周界均值路径，不是结构中性轴或光滑实体网格。
- 像素丢检后最多保留 0.25 s 的明确预测，形变/净空读数为 `--`；超过时限隐藏预测点。预测不追加到有效轨迹。
- NaN/Inf、异常形状、重复 CSV 行、错误截面、时间不匹配、来源哈希不匹配都不会悄悄转成有效观测。
- 净空采用叶尖参考点到同高度塔筒圆截面的水平距离，塔筒半径随高度插值。超出塔筒高度返回缺失；不表示整叶片最小碰撞距离。
- `out_of_plane_m` 是相对标称面的偏移，含静态预弯/预锥；只有给出同一姿态的独立刚性参考点时，才提供 `elastic_out_of_plane_m`。
- 球面反解明确标记 `pixel_sphere_estimate` 与固定半径假设。它不是唯一三维重建；球外两交点会标记歧义。FAST.Farm 数据直接走 `update_world`。
- 无来源参数时的预览明确显示 `SYNTHETIC UI fixture`，仅用于交互检查；不能作为非稳态风、强化学习或现场响应证据。
