# 叶片响应、弹性扭转与研究用 DEL

本文描述保存的预弯 BeamDyn 结果及本地分析入口。分析不启动求解器；响应差异、弹性扭转、应力、疲劳寿命和物理不平衡分别判断。显式 `physics.blade_torsion` 使用官方直叶片模型及六站位旋转输出，见 [BeamDyn 叶片弹性扭转](BeamDyn叶片弹性扭转.md)；该定义不自动适用于本文的预弯结果。

## 九项响应指标

[export_blade_response.py](../../scripts/analysis/export_blade_response.py) 从三叶有效BeamDyn通道生成独立分析包；当前工作区 [内置结果](../../blender_frontend/wfrl_blender/assets/blade_response/results.json) 为T1／T2／T3保存全部九项指标，覆盖117～177 s。

| 指标键 | 每片叶片的通道后缀 | 单位与含义 |
| --- | --- | --- |
| `tip_x`、`tip_y`、`tip_z` | `TipTDxr`、`TipTDyr`、`TipTDzr` | m；叶尖三向位移 |
| `root_Mx`、`root_My`、`root_Mz` | `RootMxr`、`RootMyr`、`RootMzr` | N m；根部三向力矩，Mz为根部扭矩 |
| `root_Fx`、`root_Fy`、`root_Fz` | `RootFxr`、`RootFyr`、`RootFzr` | N；根部三向力 |

实际通道以前缀B1／B2／B3区分叶片。r系随叶根刚体运动和变桨转动，z沿根到尖；界面将力矩和力换算为kN·m和kN。导出器拒绝缺失、错误单位或非有限的必需BeamDyn通道，单位为INVALID的列只保留单位诊断，不读取数值，不用ElastoDyn替代或补零。

`common-turn-phase-mean.v1` 取三叶都完整覆盖的共同转次，在5°中点网格插值，按转等权平均，提供全片段曲线、三叶均值／偏差及最近完整转统计。[imbalance.py](../../blender_frontend/wfrl_blender/imbalance.py) 兼容完整六项位移／力矩包及完整九项包；部分根部力组无效，缺根部力的六项包显示不可用。当前九项资产不意味着其他来源或既有安装载荷也含九项。数据绑定和读取规则见[离线不平衡分析](../../blender_frontend/README.md#离线不平衡分析)。

## 保存的预弯结果：弹性扭转未提供

当前 [BeamDyn输入](../../__simul__/fastfarm/FastFarm__208s__3T_1789663025.003069/5MW_Baseline/NRELOffshrBsline5MW_BeamDyn.dat) 的参考轴从根部到叶尖具有1 m迎风预弯，曲线为 `x=-(z/61.5)^2`，并保存 `initial_twist`。它不是直梁；局部展向切线随位置变化，受载弯曲还会改变截面方向。[prebend.py](../../blender_frontend/wfrl_blender/prebend.py) 校验该参考和独立零载静止求解身份。

`TipRDxr/yr/zr` 是无量纲Wiener–Milenković旋转参数，三个分量共同表示有限转动，单个分量不能乘180/π当角度。即使恢复叶尖总姿态，现有端点位移／旋转和根部力／力矩也不唯一确定沿预弯、受载中心线的截面转动场，不能唯一分离刚体运动、变桨、参考预扭、弯曲转动与弹性扭转。根部扭矩也不能在缺少沿程载荷及完整结构响应时直接换算为叶尖扭角。

当前 `NNodeOuts=0`；输入虽列出 `OutNd`，仍不产生沿程节点输出，`OutList` 只请求根部力／力矩、叶尖位移／旋转。因此面板保持“弹性扭转：未提供数值”。显示网格截面或插值几何不能补成独立结构通道。

得到可解释的弹性扭转需要在独立算例落实以下配置与分析，**均待实现，且需要重新求解**：

1. 按当前BeamDyn输入允许的0～9范围，将 `NNodeOuts` 设为非零有效节点数，在 `OutNd` 选择根部、沿程及末端所需节点，并从求解器摘要确认节点编号与展向位置；仅改 `OutNd` 无效。
2. 在 `OutList` 请求所选节点的三分量位移和三分量旋转；同时保留根部边界姿态、变桨／方位和未变形几何／预扭。节点通道名需按实际求解器支持列表确认，不能把输出槽号当几何节点号。若同时研究展向内力，另请求相同节点的三向内力和力矩，只有载荷输出不足以完成扭转分离。
3. 保存共同时间轴、单位和坐标定义，用完整旋转及中心线切线构造截面材料坐标，明确从零载参考到受载截面的运输与扭转定义；通过独立纯弯曲、纯扭转和刚体运动算例验证分离。当前通道不能通过补标签或单分量相减完成这一分析。

## 研究用根部弯矩 DEL

[blade_del.py](../../scripts/analysis/blade_del.py) 读取已有40 Hz BeamDyn输出，分析T1／T2／T3各三片叶片的 `RootMxr`、`RootMyr`，不包含RootMzr、应力或寿命计算。输入必须具有连续递增的0.025 s时间轴、准确的秒／N-m单位与有限值；无效ElastoDyn列不会成为替代输入。默认输入由脚本 `DEFAULT_INPUT` 指向本地保存的三份 `Case.T1.out`、`Case.T2.out`、`Case.T3.out`。

方法为四点雨流计数：先保留反转点和端点，平台取最后一点；连续反转点A、B、C、D满足 `|B-C| ≤ |A-B|` 且 `|B-C| ≤ |C-D|` 时计B–C一个完整循环并继续检查，残余相邻反转点各计半循环。不作周期闭合、滞回阈值、DEL范围分箱或均值修正。循环范围S是峰谷差，不是半幅。

`DEL = (Σ nᵢ Sᵢ^m / N_eq)^(1/m)`，其中 `N_eq = 1 Hz × (结束时刻−开始时刻)`。默认 **m=10** 是复合材料叶片研究假设，同时输出m=8和12敏感性；不是已标定材料S–N曲线。`--m` 修改主指数，默认40 Hz参考、统计窗和下采样规则保持不变。

统计窗为回放117～177 s和全记录0～183 s，都要求原数据包含两端点；全记录包含启动瞬态。先截窗，再从首点按步长1／10／40／120抽取40 Hz／4 Hz／1 Hz／每3 s一个点，分别重新计数。没有抗混叠滤波或插值，暴露时长保持相同。低采样率同时带来漏掉极值／循环和混叠；循环数变化是重新计数后的净变化，不是逐个追踪消失的循环。

### 当前保存样本的采样率影响

以下是上述三机九叶、两个根部弯矩分量、m=10的局部数据结论，变化率以相同窗口的40 Hz结果为基准：

| 窗口 | 4 Hz相对40 Hz | 每3 s一个点相对40 Hz |
| --- | --- | --- |
| 117～177 s回放 | 约−2.48%～−0.52%，差异在约2.5%以内 | 约−33.76%～−9.91%，即偏低约10%～34% |
| 0～183 s全记录 | 约−2.46%～−0.12%，差异在约2.5%以内 | 约−21.30%～−2.76% |

“偏低10%～34%”仅适用于回放窗口，不能推广到全记录、其他工况或其他采样相位；4 Hz接近本段40 Hz也不证明4 Hz普遍足够。40 Hz是可用保存数据参考，不是连续时间真值。

从仓库根运行已有分析入口，输出必须为新文件；不传 `--output` 时在系统临时目录保存JSON：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 scripts/analysis/blade_del.py --m 10
```

结果标为 `research_estimate`，保存方法、输入摘要、窗口、各采样率及指数。它只用于研究，**不能作为认证级疲劳或寿命评估**：没有材料应力、标定S–N曲线、均值载荷修正、工况概率／寿命外推或设计载荷集合。该脚本未自动接入三叶响应面板；完整疲劳评价仍待实现。[本地测试](../../tests/test_blade_del.py)覆盖雨流基准、半循环、幅值／时长归一化、混叠、单位和时间轴拒绝，不代表认证或实际载荷收敛验收。
