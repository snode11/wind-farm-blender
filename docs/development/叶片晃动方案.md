# 三机柔性叶片回放要求与实现

当前 NREL / WFRL 公开安装 ZIP 为 **0.3.39**（标签 **v0.3.39**），源码入口为 [`wind-farm-rl-all-work`](https://github.com/snode11/wind-farm-blender/tree/wind-farm-rl-all-work)；开发机日常安装为 **公开 0.3.37 的 193 文件独立载荷**，按[安装记录](../../publication/daily-installation.json)核对。[身份与验证范围](../blender/发布状态与验证范围.md)、[操作说明](../../前端readme.md)及[实现说明](../../blender_frontend/README.md)分别描述对应对象。

## 回放数据与显示要求

回放采用提前求解、保存结果、离线读取的方式。内置 `assets/mappo/` 包包含 T1、T2、T3 共九片独立柔性叶片，117–177 s 的共同片段、40 Hz 源数据和固定 60 Hz 时间轴。Blender 使用轻量数据驱动实体网格、姿态、叶尖与读数，播放不需要 Bridge、FAST.Farm 求解器或强化学习训练。

实体叶片应连续变形，叶根与轮毂保持连接。三机各用自身数据，不能复制一台的形变充当其他机组的结果。显示保留物理幅度，不缩小偏航、放大形变或用人工周期曲线代替保存运动。全景、Down 和固定三相机观察同一时刻的状态。

单个叶尖或截面周界均值不能确定完整叶片实体。当前轻量回放与单机 VTP / Bridge [叶尖预览](叶尖代码与后端接入.md)使用不同合同；后者只有 `sections_m/tip_m`，不能直接代替包含表面/截面姿态和参考几何的三机包。

## 模块与数据责任

| 模块或资产 | 责任 |
| --- | --- |
| `farm_flex.py`、`assets/mappo/` | 包合同、摘要、源时钟、机组映射、姿态与九片网格驱动 |
| `deflection.py`、`deflection-t1.json` | 独立刚性参考、结构通道与实际网格叶尖对照 |
| `tip_tracking.py` | 有界世界坐标轨迹、编号颜色、显隐与跳转清空 |
| `tower_motion.py` | 保存塔架运动与整机姿态的组合 |
| 三相机及净空模块 | 使用匹配机组、同刻姿态和标定，保留缺失与无效语义 |
| `source-run.json`、`source-surfaces.json`、manifest | 策略、输入、几何、单位、参考点、有效范围和来源摘要 |

保存策略为 `mappo_fastfarm_Dec_Turb3_Row1_Fastfarm_mappo_s0_level_E128_none.pt`，控制量为偏航；`source-run.json` 记录机组顺序、观测统计、确定性推理、3 s 控制周期及约束。画面使用保存的实际响应，策略指令和测量反馈分别解释。这段运动没有匹配基线，不能单凭展示片段宣称增发电或减载收益。

物理表面、平滑展示表面、结构叶尖、展示叶尖和净空参考点分别定义。含弹性弯曲的结果不能自动证明完整弹性扭转模型已验证；结构自由度与几何映射须按实际模型和来源检查。

## 共同时钟与交互

60 Hz 时间轴是显示采样约定，不是实际窗口达到 60 FPS 的证据。方位角跨 360° 保持正确方向；姿态、形变、叶尖、相机和读数按同一目标仿真时刻更新。缺失、损坏或不兼容输入明确拒绝或显示未就绪，不以真值填补测量。

连续原生播放按片段循环，手动样本步进在首尾钳制。暂停时只允许视角变化；继续播放保留用户缩放和绕转后的观察位置。寻址、从头重播、切换来源或机组时，轨迹按实现清空，避免跨时刻或首尾错误连线。

轨迹与叶尖辅助标记默认关闭。开启后从当前时刻逐点累积，关闭后隐藏辅助物但保持实体运动。轨迹保存世界坐标，相机变化时重新投影；同一时间戳不重复累计。叶片 1/2/3 对应橙/蓝/红，颜色随编号保持一致。缓存有界，具体采样与保留参数以 `tip_tracking.py` 和场景属性为准。

## 数据生产与验证条件

改变物理工况、结构、控制器或几何时，需要与该来源匹配的姿态、表面、叶尖、净空、遥测和来源摘要。只调整文案、取景或界面时复用正式保存结果。生成新的物理结果必须使用新的运行和输出目录，保留原始求解输入、日志与失败状态。

验收分别检查数据合同、来源、数值、安装版窗口、可见性、交互和完整片段性能。目标包括九片独立网格、叶根连接、同刻读数、Down 可见弹性摆动、轨迹开关、暂停/寻址/重播、相机切换与脱离原始目录后的启动。自动测试、截图、离线视频 FPS 和真实窗口持续播放分别报告。

## 当前限制

内置数据保持 **`REVIEW_ONLY`**。稳定 60 FPS、求解器收敛、现场净空与保护性能没有验收结论。工作区源码用保存的结构叶根边界运输独立无载参考，按 **0.2 mm** 保存帧与 **5 mm** 插值帧门槛通过保存数据对照，见[源码验收](../../outputs/regression-repair/integration/result.json)。匹配的原始结构输出和无载参考可核验，受载 VTP 缺失使原始表面拟合无法重跑。0.3.18 安装载荷的 [FAILED_GATE 证据](../blender/validation/NREL本地0.3.18修复与验证.md)仍限于对应载荷，源码通过不替代安装复验。

Blender 源码窗口发生过原生 SIGSEGV，原因未定；局部功能检查不能替代整体窗口稳定性。重建分屏、同源纹理、双束/TLS 和 GW184 刚性场景使用各自的来源与验收边界，不能借柔性运动展示升级为科学接受。
