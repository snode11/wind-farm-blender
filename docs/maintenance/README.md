## 恢复约束

按清单核对 `source` 与 `destination`，确认保存位置仍存在、源位置没有同名新内容，并在可用时核对摘要。恢复仅针对需要的资源，不覆盖当前源码、正式资产、用户偏好或未保存场景。路径中的日期用于识别证据对象。

清单中的废纸篓路径属于对应本机；GitHub 上的清单不会提供这些文件或安装环境。重新执行验证需要恢复匹配输入，或使用对应最终 ZIP 建立新的隔离安装。版本、环境和失败结论仍以原始证据为准。
