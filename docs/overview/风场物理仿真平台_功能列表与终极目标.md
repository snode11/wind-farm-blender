# 风电场物理仿真平台：当前能力与长期目标

NREL / WFRL 当前公开安装 ZIP 为 **0.3.20+1**（标签 **v0.3.20.1**），公开扩展源码为 **v0.3.18**；日常安装为同版本号的本地未发布修订，与公开附件载荷分别核对。GW184 为独立 **0.4.0** 运行包。版本、[模块来源与验证范围见发布状态](../blender/发布状态与验证范围.md)。

## 1. 平台定位

WFRL 将风场控制环境、保存物理结果、Blender 展示和传感器研究工具放在同一项目中，用于预演、算法研究及可追溯的演示。长期希望将物理模型、数据预测和工程规则结合，服务感知、诊断、决策与控制。

这是目标方向。当前没有机舱净空相机硬件产品交付、通用工业 AGI、现场精度、疲劳寿命改善或全工况安全认证的完成证据。仿真输出是对应模型/算例的参考，不能直接称为真实风场测量真值；渲染几何与求解几何也须按具体来源核对。

## 2. 当前能力与入口

| 类别 | 当前源码或使用入口 | 状态与边界 |
|---|---|---|
| FLORIS 稳态控制环境 | `wfcrl-env/`、`scripts/train/train_ppo.py` | 已有环境及 PPO 管线；忽略动态尾流传播，不能验证动态载荷或变桨实效 |
| 参数共享 IPPO | `scripts/train/train_mappo.py`、`wfrl/mappo_sb3.py` | SB3 路线的 critic 只读单机局部观测；文件名 mappo 不代表 CTDE |
| 集中式 MAPPO | `wfrl/mappo_central.py`、`scripts/train/train_fastfarm.py` | 共享局部 actor、全场 critic，可选 GRU critic；算法存在不代表相对收益已证实 |
| FAST.Farm 动态后端 | `wfrl/fastfarm_driver.py`、`wfrl/scene/runtime.py` | 已有动态计算、控制和测量链路；运行需要匹配 MPI、求解器/控制器及算例，不随扩展 ZIP 安装 |
| 当前主展示界面 | Blender 5.2+ / `wfrl_blender-0.3.20+1.zip` | MAPPO 离线回放、双束/TLS 层、三相机及默认复位、NREL 缺陷编辑器；统一几何示例入口双向切换几何／同源601样本纹理，独立合成120样本资产与底层工具使用独立来源；源码、ZIP、安装版分别核对 |
| 三机九片柔性运动 | `blender_frontend/wfrl_blender/farm_flex.py`、`assets/mappo/` | 117–177 s 保存片段，40 Hz 源数据、60 Hz 时间轴；数据保持 `REVIEW_ONLY`，稳定 60 FPS 未验收 |
| 双束净空 / S1 | `wfrl/lidar/`、Blender MAPPO 面板 | 默认 `hub-axis.v1` 与显式 `hub-tls.v1`；软件接入已有验证，算法/现场精度仍待验收 |
| 固定三相机 | `stacked_camera_rig.py`、`native_camera_views.py`、采集模块 | 安装盒体、GRID/STRIP/WATCH、PNG 采集；视野、无遮挡、可拼接和计量精度分别验证 |
| NREL 叶片缺陷编辑 | `nrel_defects/`、`scripts/blender/nrel_defects.py` | 六类形态与默认修补痕迹，使用保存运动展示；不改变 FAST.Farm/BeamDyn 结构或雷达结果 |
| Blade Recon 保存结果展示 | `blade_recon_data.py`、`split_reconstruction.py` | 内置便携分屏包含 601 个 10 Hz 样本；显示同步不等于几何精度验收，轮廓重建不等于局部表面缺陷恢复 |
| Studio / RViz | `wfrl/studio/`、`wfrl/viz/`、`scripts/macos/run_desktop.sh` | 保留的 Qt/VTK 路线，不能将旧 GUI、传感器或性能结论并入当前 Blender 验收 |
| 场景与约束 | `scenes/`、`wfrl/safety.py` | 控制、传感器和事件配置已有实现；代码限幅及测试不是机组安全认证 |

## 3. 数据来源与指标应怎样表述

旧 Studio 通道按 DIRECT / DERIVED / SYNTH 分类：功率、叶根载荷及部分执行机构来自后端；转速可由功率与转矩推导，振动可由载荷代理计算，相机安装位姿及声学健康代理属于合成。当前 Bridge 又有带来源、单位、有效性和时间的通道合同，离线包则记录自身 manifest、schema 与来源摘要；不要将不同路径的标签统一等同于传感器实测。

- 三机柔性回放使用保存形变，不用旧 RViz 的“载荷代理＋显示放大”说明代替；物理表面、平滑展示表面、结构/展示叶尖和测量参考点分别定义。
- 净空读数须明确算法、命中与参考定义；旧独立 normal/close 的叶尖参考点距离不是整叶片最小碰撞距离。双束/TLS 又有各自评估口径，不能混用。
- 实际偏航、桨距反馈与指令分别记录；桨距下界/基线控制器覆盖须以所用控制器及运行响应核对。动画变桨不证明物理控制已生效。
- 地形、代理尾流、视口插值和辅助颜色是展示来源；不把它们当成求解器几何、测量或控制收益。
- 有效、无效、缺失、过期及 `REVIEW_ONLY` 保留原状态；缺测不填零，不以真值补作估计。

## 4. 当前可宣称与尚不可宣称的结果

公开安装包提供三相机默认复位、六类 NREL 合成缺陷、便携几何与同源纹理分屏。样本步进首尾钳制，连续原生播放共同循环；保存场景支持 embedded / packed 恢复。当前公开 ZIP 的检查见[0.3.20+1 核对](../blender/releases/0.3.20+1发布核对.md)，场景恢复、播放归属、槽位与采集一致性的软件证据见0.3.18 [验证](../blender/validation/NREL本地0.3.18修复与验证.md)，分别保持其载荷身份。

软件保存重开与同步播放通过不等于重建精度、双束/TLS 精度、现场采样、保护延迟或 Windows/Linux 已验收。0.3.18 的叶尖保存帧 **0.2 mm** 门槛仍为 **`FAILED_GATE`**，对应 y 方向网格对结构通道误差约 **1.0613 mm**；原始运行 VTP 与 `Case.T1.out` 缺失，源验证为 `SKIPPED_SOURCE_ABSENT`。原生 SIGSEGV 原因未定，整体窗口稳定性不能由局部软件通过推定。

2026-08-20 三机错列固定来流实验曾报告约 +5.3% 功率增益；当前对应原始轨迹/历史/权重缺失，且原“+178 kW”与列出的功率差不一致。该历史结果不能表述成“平台已经验证通用增发电收益”，详见[尾流控制历史记录](../training/WAKE_STEERING_BREAKTHROUGH.md)。

表面重建研究与证据入口见[研究入口](../proposal/叶片表面重建_2026-10-06/README.md)。它与已发布便携轮廓重建示例、NREL 动态研究查看器和未来原型分别判定，不以功能显示替代观测或几何证据。

## 5. 长期目标与实施关口

| 目标 | 当前定位 | 下一步证据 |
|---|---|---|
| 物理、数据、经验三驱动世界模型 | 愿景；已有降阶 Prototype 计划 | 统一时序数据、Persistence 对照、候选动作覆盖、预测误差与物理复核 |
| 偏航＋集体变桨联合控制 | 计划范围，待实现 | 命令/实测响应、控制器覆盖与单位、匹配基线、冻结评价 |
| 相机净空硬件 / 现场系统 | 产品方向，当前为仿真安装与成像研究 | 可观测性、标定、硬件选型、同步与现场实测 |
| 表面缺陷诊断 / 健康监测 | 独立研究方向 | 材料身份、成像可辨识性、表面模型与独立真值；跟踪成功不代表诊断完成 |
| 大规模风场、QBlade、HDF5 标准数据接口 | 规划项，未在当前主链路确认完成 | 专项实现、接口合同及对应运行验证 |
| 真实 SCADA / HIL / 实机控制 | 后续研究，当前未交付 | 独立部署、响应、约束与硬件验证 |

具体四周范围、工期假设与失败关口见[工业 AGI Prototype 计划](../proposal/platform/工业AGI_4D世界模型_可实现性审计与Prototype计划.md)。规划不是启动许可或完成报告；数据模型有效、控制有效与工程链路完成分别验收。
