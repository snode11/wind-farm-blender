## 1. 目标、实施顺序与边界

用户需要在指定叶片上人工布置缺陷，先近距离检查其形态与尺寸，再确认缺陷在指定相机安装条件下的成像。系统遵循“尺寸和位置是输入，能否看见及辨认是输出”的原则。

两套验收分别记录：

1. **缺陷本身**：能编辑、位置与尺寸可复现、形态有依据、随叶片运动且表面贴合正确。
2. **相机观测**：在固定点位、朝向、画幅和时间下，正确呈现投影、遮挡、像素尺度与对应模式的图像。

### 1.1 必须遵守的阶段范围

| 阶段 | 工作场景与内容 | 通过后得到什么 |
| --- | --- | --- |
| 第一阶段：刚性场景闭环 | 以独立 GW184 项目为主验收场景，完成缺陷编辑、近景检查、固定三相机成像、基础可见性统计与保存恢复；平面、块体和简化刚性叶片仅作算法测试工具 | 可操作、可复查的 GW184 刚性场景功能；几何模式和外观模式分别验收 |
| 第二阶段：柔性前端接入 | 第一阶段通过后，复用缺陷描述与生成接口，增加主前端参考表面、形变、缓存、回放与多视图适配 | 用户实际使用的柔性前端中可用，并完成性能与回放回归 |
| 第三阶段：传感器与应用扩展 | 按实际需求和参数来源增加曝光、模糊、噪声、压缩、畸变及必要的读出模型；再扩展算法标签和批量数据功能 | 在声明条件下的成像实验与应用接口；实机一致性需另有标定证据 |

第一阶段不接入或修改主前端柔性叶片、形变缓存、回放更新、雷达结果和多视图机制，也不进行柔性适配试验。仅在接口设计中预留柔性适配能力。第一阶段使用的独立编辑面板不等于主前端功能已交付。

第一阶段必须包含基础投影、遮挡、像素尺寸和实际时间线的可见时段摘要，不能把老板的第二项要求整体推迟到后续阶段。高级传感器效果与算法自动辨识不是第一阶段的通过条件。

简化场景用于定位、切割、投影和遮挡的已知几何检查，其通过结果不能替代 GW184 叶片及既有固定三相机条件下的主验收。首批仍只要求一个材质型细裂纹和一个几何型开口裂缝预设。

### 1.2 与其他工作的关系

- 本功能处理人工定义缺陷及其观测；自动检出、三维重建和缺陷深度估计见另一份[固定三摄叶片三维重建与表面缺陷首轮诊断方案](../reconstruction/固定三摄叶片三维重建与表面缺陷首轮诊断方案.md)，不并入本功能第一阶段。
- 这里的图片和统计是本功能的验收资料，不改变已有三份独立原始 MP4 的交付约定，也不要求先制作 320 秒长片。
- 首版损伤只影响可见外观与显示几何。断裂发生、扩展、碎片轨迹，以及损伤对质量、刚度、气动载荷和净空的影响，均需另行定义物理任务。

## 3. 用户流程与两个观察视图

### 3.1 编辑流程

选择机组与叶片 → 新建缺陷 → 点击参考表面定位或输入参数 → 预览 → 确认 → 近景检查 → 指定相机检查 → 保存配置与所选验收资料。

- 进入编辑时保存当前时刻与播放状态并暂停。确认或取消后恢复原时刻和先前播放状态；检查图必须先冻结时刻再生成。
- 编辑面板提供缺陷列表、启用/禁用缺陷、显示/隐藏辅助标记、类型、位置、尺寸、方向、形态、外观、确认、取消、撤销、复制和删除。两个开关使用明确文字，不共用含义不明的“眼睛”操作。
- 点击只负责选择位置；持久化必须使用第 4 节的参考表面坐标。
- 编辑已有缺陷时，从健康参考表面求定位，不把凹槽内壁上的点击误保存成新的参考表面。无法唯一映射时要求重新选点。
- 预览使用临时状态。涉及叶片重建时，以整片叶片的有效缺陷配置、派生网格、材质遮罩及分析缓存作为一次提交单元；全部成功后统一替换，失败或取消则整体保留上一次有效状态，并给出明确原因。
- 复制产生新实例 ID；修改保留实例 ID 并增加修订号。固定随机种子控制形态，播放和相机切换不重新随机生成。

| 操作 | 生效范围 |
| --- | --- |
| 禁用缺陷：`enabled=false` | 保留该实例配置以便恢复，但不参与几何/材质生成、可见性计算和相机原图；同一叶片的其他启用缺陷保留。清单标记该实例已禁用，不伪装成“被遮挡”或计算零可见率 |
| 隐藏辅助标记 | 仅关闭定位框、高亮和控制点；不改变 `enabled`、叶片几何/材质、分析结果或干净的相机原图 |

提交单元使用同一个叶片状态版本，显示、分析和导出不得混用新旧版本。新网格所需的几何分析缓存须随提交准备好，旧可见性统计标记失效；重算完成前显示“尚未评估”。提交前仍在运行的旧版本任务不得把结果写成新版本结果。撤销同样恢复整片叶片的有效状态，而不只恢复一个界面字段。健康对照图在独立快照中禁用目标叶片的全部缺陷，不等同于只禁用其中一个缺陷，也不覆盖当前编辑配置。

### 3.2 观察视图

| 视图 | 操作 | 验收用途 |
| --- | --- | --- |
| 缺陷近景 | 自由旋转、靠近、查看斜侧面；显示尺寸；切换健康对照；按需使用检查光照 | 检查形态、尺寸、贴合、开口/内壁和轮廓；检查光照必须标记 |
| 指定相机 | 选择既有相机和时刻；显示完整原图及由原图生成的裁切图 | 检查当前固定安装条件下的投影和成像；不得自动跟踪、改焦距或扩大缺陷 |

近景导航不写入相机布局。原图不带框、文字、比例尺或定位高亮；辅助信息显示在旁边或独立诊断图中。轻量实体窗口仅用于操作与几何检查，材质外观通过按需外观图验收。

**固定相机固定的是相对于安装结构的安装变换。** 设 `T_mount_from_camera` 为相机到安装结构的固定变换，则每帧 `T_world_from_camera(t) = T_world_from_mount(t) × T_mount_from_camera`；观测使用该时刻的逆矩阵作为世界到相机的外参，并声明相机轴约定。第二阶段中，安装结构运动时相机世界位姿同步更新；近景检查相机不修改安装关系。相机布局摘要一致只证明安装配置未变，不能单独证明逐帧外参正确。此处仅冻结定义，柔性安装结构的适配与回归留到第二阶段。

## 4. 参考表面坐标与缺陷配置合同

### 4.1 位置表示

保存坐标为 `turbine_id + blade_id + reference_geometry_id/hash + surface_side + s_m + u + theta_deg`，禁止把世界坐标或“当前朝向相机的一面”作为唯一定位信息。

| 字段 | 规定 |
| --- | --- |
| `turbine_id`、`blade_id` | 场景内稳定 ID；叶片编号按模型登记，显示名称变化不改变 ID |
| `reference_geometry_id`、`reference_geometry_sha256` | 健康参考模型及其参数化版本；摘要由实际资源计算 |
| `s_m` | 从叶根参考截面起，沿未施加动态运动的参考变桨轴量出的展向米数；GW184 对应参考局部 Z，不是预弯曲线弧长，也不含轮毂到叶根的径向偏置 |
| `s_normalized` | 可由 `s_m / reference_span_m` 导出显示；不与 `s_m` 同时作为可独立修改的权威字段 |
| `surface_side` | `pressure` 或 `suction`；由模型适配器按参考翼型方向登记，不根据当前世界坐标或朝向相机的法线判断 |
| `u` | 对应截面翼型弦线的归一化坐标，前缘 0、后缘 1；同一 `s_m,u` 在两侧表面分别映射到不同点，不是表面弧长比例 |
| `theta_deg` | 以局部展向切向为 0°，绕该侧外法线按右手规则旋转；范围 `[0,360)`，正值在两侧表面不必指向相同弦向 |
| `region_hint` | 可选的 `surface / leading / trailing` 区域选择提示；不覆盖 `surface_side,s_m,u` 的权威定位 |

**前缘、后缘和压力面、吸力面的语义分开。** 前两者是区域/接缝，后两者是表面。面板可提供四类快捷选择，但保存时必须解析到明确的表面侧别与坐标。前后缘区域宽度由模型适配器登记，不能默认所有机型都使用同一条弦向阈值。

第一阶段基础闭环只接受适配器声明有效的表面域；圆柱根部、收尖奇点和未验证的跨前/后缘路径返回“不支持的表面区域”，不悄悄吸附到旁边。前后缘缺口预设扩展时，需增加接缝映射和跨侧路径；接缝点规定唯一归属，同一缺陷可有多个表面片段但共用实例 ID。

模型适配器必须输出参考点 `P(s,u,side)`、外法线 `n` 和局部坐标基。令 `e_s` 为参考表面上沿 `s` 增大方向的单位切向，`e_t = n × e_s`，方向为 `cos(theta) e_s + sin(theta) e_t`。切向退化或表面映射不唯一时拒绝提交。单位长度、宽度与深度均使用米。

### 4.2 曲线、尺寸与形变

- 整条裂纹以参考表面控制点或确定性生成规则定义。每个控制点能还原为表面坐标，不能只绑定中心点、其余顶点留在世界空间。
- 曲线长度采用参考表面中心线弧长；开口宽度为沿局部表面、横跨裂纹中心线的距离；深度沿健康参考表面内法线测量。凹坑与不规则损伤另记录两个方向的范围，不能仅用一个包围框冒充精确直径。
- 区分输入名义值、生成后测量值和容差。局部切割器的尺寸不直接等同于曲面开口尺寸。
- 世界坐标、面索引和重心坐标可作运行缓存；面索引只能在相同拓扑摘要下使用，不能作为跨版本持久化标识。
- 第一阶段在参考局部坐标中生成，再应用现有刚性转动/变桨。第二阶段才由形变适配器处理全部控制点、边界和新增顶点。
- 模型摘要或参数化版本改变时，结果标记 `STALE_GEOMETRY`。禁止把原有 `s,u` 静默套用到新机型；显式重绑定后形成新修订并重新验收。

相机和运动配置不嵌入单个缺陷，以便复用缺陷描述；每次验收运行通过清单绑定对应相机布局、运动、灯光、成像模式及其摘要。相机变化会使旧观测结果失效，但不改变缺陷参考位置。

## 5. 材质型与几何型缺陷

| 类别 | 适用形态 | 实现路径 | 边界 |
| --- | --- | --- | --- |
| 材质型 `appearance` | 细裂纹、烧蚀痕迹、轻微涂层变化、污渍/变色 | 表面材质遮罩、bump/normal；可选局部轻量位移 | 遮罩固定于参考表面；法线效果不能作为真实开口或深度的证据 |
| 几何型 `geometry` | 开口裂缝、凹坑、穿孔、缺口、局部断裂 | 一次性布尔切割、网格替换或局部补片，配套断口/内壁材质 | 真正影响轮廓、深度或遮挡的部分必须进入几何；更新后同步几何分析 |
| 组合型 `hybrid` | 带烧蚀、穿孔、开裂的雷击损伤等 | 多个上述子缺陷共享一个事件 ID | 分别记录可见形态和成因，不能仅凭一个洞宣称识别出雷击 |

轻量位移若实际改变几何，则按几何效果检查遮挡、边界和网格质量；“材质型”不表示可以绕过几何一致性。第一阶段可先使用 bump/normal，不依赖自适应高密度位移。

### 5.1 三类损伤的设计

| 用户类型 | 参数与形态 | 近景验收重点 |
| --- | --- | --- |
| 裂纹 | 分细裂纹与开口裂缝；中心线、宽度/深度变化、方向、分叉、种子 | 遮罩分辨率、边缘过渡；实体开口有侧面视差和内壁；不统一画成纯黑锯齿 |
| 雷击损伤 | 击中区域、烧蚀范围、可选坑洞/穿孔、开裂或局部剥离 | 按参考样式组合，不强制所有成分同时出现；只做可见外观，内部损伤不能伪装成 RGB 可见证据 |
| 断裂 | 边缘缺口、局部壳体缺失或静态断尖；断口形状与材料层次 | 轮廓确实改变、露出面合理；简化内部结构须标明建模假设，不暗示有实机 CAD 依据 |

基础闭环至少包含一个材质型细裂纹预设和一个几何型开口裂缝预设，以验证两条实现路径。现有 80 mm 最大开口只作为大开口样例；不据此宣称能观察毫米裂纹。雷击组合与局部断裂可在刚性闭环通过后逐项增加，并复用相同接口；未完成的类型不得显示为已支持。

保持一份健康参考模型和独立缺陷配置。编辑确认时从健康基线按稳定顺序重建相关叶片，不在已破坏的网格上无限追加切割或靠补洞实现删除。第一阶段基础版本拒绝重叠缺陷；扩展后才定义组合顺序和交叠区域归属。

## 6. 三种成像验证模式

| 模式 | 包含 | 输出结论 | 不能替代 |
| --- | --- | --- | --- |
| G：几何模式 | 投影、视野、遮挡、几何像素占比和尺寸；使用明确的诊断显示 | 给定几何与相机参数下的可见性 | 材质外观、肉眼辨识与实体相机验证 |
| A：外观模式 | G 的相机/时刻条件，加材质、灯光、基本纹理细节；默认瞬时理想采样 | 声明的渲染条件下的外观检查与人工辨识记录 | 曝光、读出、镜头/传感器及实机一致性 |
| S：传感器条件模式 | 在 A 基础上按配置加入曝光、运动/光学模糊、噪声、压缩、畸变；必要时建模逐行读出 | 给定传感器条件及假设下的合成成像 | 未提供标定数据时的实机复现结论 |

面板、文件清单和报告都显示模式及已启用/未启用效果。某次 S 模式只启用了曝光与压缩时，必须逐项列出，不能暗示其他效果也已实现。每个传感器参数标记来源：实测、设备文档、用户输入或建模假设。

G 模式中的高亮/掩码不是相机原图。A/S 模式原图保持固定相机的完整画幅。若畸变、曝光或读出改变了图像位置和形态，相应诊断与未来标签必须遵守同一成像过程。

30 fps 表示帧间采样，不等于曝光 1/30 秒。像素统计优先使用实际边界投影；简单 `f_px × size_m / depth_m` 只作限定条件下的估算，不用于斜视曲面的统一尺度换算。

## 7. 可见性、像素统计与时间线合同

### 7.1 当前时刻记录

每条记录关联 `run_id, defect_id, revision, support_id, support_kind, camera_id, frame_index, time_s, mode`。`frame_index` 是导出作业内索引，与 Blender 帧坐标的对应关系见第 7.3 节。

几何状态为 `OUT_OF_FRAME / OCCLUDED / PARTIAL / VISIBLE / INVALID / NOT_EVALUATED`，并附原因列表。分辨率和图像审核另设字段，避免“几何可见”自动变成“肉眼可辨”。未知或无法计算的量用 `null + reason`，不填零。

遮挡使用实际求值后的叶片、其他叶片、机舱、塔筒、相机盒体和支架；几何缺陷形成的孔洞与断口必须同步进入检查。材质型缺陷使用其真实表面遮罩范围，不能把整片叶片当成缺陷。

每个生成器必须输出带版本的 `support_definition`，明确分析区域，不能由统计模块临时猜测：

- 材质型默认以参考表面语义遮罩值 `>= 0.5` 的区域为主统计范围；阈值和遮罩版本写入定义。此阈值仅定义区域边界，不是图像亮度阈值或检测阈值；需要统计外围渐变时另设区域，不能偷偷变更分母。
- 开口裂缝、凹坑和穿孔的主区域采用健康参考表面上的开口/坑口足迹；其可见性结合实际边缘和实体遮挡计算，不把虚拟健康表面加入遮挡场景。新增内壁/受损面的集合以独立 `damaged_surface` 区域统计，不能与开口足迹相加作为一个面积。
- 局部断裂的现存断口、受损表面和相对健康模型缺失的区域分别定义，声明哪个是主观测区域。多个子区域不得默认相加，以免重叠投影重复计数。
- 每条尺寸、面积、包围框与状态都指明对应区域。整体缺陷状态使用已声明主区域，并保留子区域状态，不把“开口可见”扩大为“全部内壁可见”。

开口足迹采用“到开口之前是否被挡住”的判定：对参考开口位置 `P` 与相机中心 `C`，先检查入画条件及该参考侧面的朝向，再检查线段 `C→P` 是否被实际几何提前遮挡。若真实命中距离小于 `|P-C|` 减去登记的遮挡容差，则该点被遮挡；不能要求射线在 `P` 处命中实体，因为该处原健康表面已被移除。射线越过 `P` 后命中更深的槽底，或穿过孔洞后未命中，不构成开口前方的遮挡。内壁、槽底按各自实际表面独立做可见性检查。前后侧开口若均存在，应分别定义；背面观察不能因为射线穿透孔洞而自动被计为正面开口可见。

该规则先用带凹槽的块体作已知几何检查：正对开口且首个实体命中在槽底时，开口应可见；遮挡物挡住部分开口时，仅对应部分不可见；从背面观察时不得误报正面开口可见。几何创建验收还需独立确认开口确实存在，不能仅凭这条可见性规则判定切割成功。

| 字段/指标 | 定义 |
| --- | --- |
| `projected_bbox_px` | 按 `support_definition` 定义的完整候选区域的理想投影包围框，固定为未裁到画幅的浮点框 |
| `visible_bbox_px` | 考虑画幅和遮挡后的可见范围；完全不可见时为空 |
| `in_frame_fraction` | 画幅内候选投影面积 / 完整候选投影面积；候选面积忽略遮挡，分子分母使用相同区域定义与分析精度 |
| `visible_fraction_in_frame` | 可见投影面积 / 画幅内候选投影面积；候选面积忽略遮挡，可见面积考虑遮挡；两者采用相同投影区域定义，投影重叠不重复计面积 |
| `visible_area_px2`、`image_fraction` | 可见投影面积及其除以 `width × height` 的画幅占比；与上一行比例分别报告 |
| `length_px`、`width_px` | 沿投影中心线的长度和对应横截面开口宽度；宽度报告分布/范围及有效覆盖，不能用包围框短边替代裂缝宽度 |
| `view_angle_deg`、`camera_depth_m` | 基于对应表面点的观察角与相机坐标深度，曲面报告范围；不以相机到轮毂的轴向间距代替 |
| `method, sampling, tolerance` | 深度掩码或采样方法、分析分辨率/超采样、步长、遮挡容差与阈值；射线样本计数比例只能另记 `sample_visible_fraction`，不能冒称像素面积比例 |
| `appearance_review` | `NOT_REVIEWED / DISCERNIBLE / INSUFFICIENT / INDETERMINATE`，附图像、审核人/方法及任务目标；不是仅由像素数量自动判定 |

画幅内候选投影面积为零时，`visible_fraction_in_frame` 为空并说明原因；若完整候选投影有效，则 `in_frame_fraction` 可为零。无遮挡候选存在但完全遮挡时，可见面积与条件可见比例为零。完整区域投影退化、位于相机后方或跨越近裁面而当前方法无法可靠处理时，返回明确原因，不执行不成立的面积除法。亚像素形态保留浮点投影量；掩码没有命中像素不自动等于缺陷不在视野。

基础几何状态按已评估支持区域的入画及遮挡结果判断，并记录容差。仅当 `in_frame_fraction` 与 `visible_fraction_in_frame` 都在容差内达到完整时，才可标记 `VISIBLE`；有可见部分但任一不完整时为 `PARTIAL`。例如仅十分之一入画且无遮挡时，不能因为条件可见比例为 1 就称完整可见。`VISIBLE` 不代表成像后可辨认；采样方法不得宣称连续表面无遗漏。

缺失区域另定义为相对健康模型的反事实区域；现存断口/受损表面与缺失区域分别统计。后续标签不得把反事实区域直接叫作实际可见缺陷分割掩码。

### 7.2 可见时段

- 按实际运动时间线和每台固定相机检查，不用任意组合的转角/桨角代替实际经过姿态。
- 第一阶段对所选时间范围逐个目标输出帧做几何检查；如提供快速抽样，只能输出“抽样摘要”，不能宣称覆盖全部目标帧。
- 可见区间记录首末帧（含端点）、首末采样时刻、采样间隔、完整/部分可见帧数、候选最佳帧和选择指标。离散区间只表示这些帧的结果，不保证帧间连续可见。
- 连续过境时间细化属于可选检查，须另记细化容差；S 模式还应考虑曝光窗口及读出时间覆盖的运动。
- “无可见帧”与“尚未扫描”是不同状态。被取消的扫描保留完成范围并标记不完整。
- 推荐时刻不修改缺陷尺寸、相机朝向或焦距。“最佳帧”按几何指标选取时必须标记为几何候选，不能自动称最易辨识帧。

### 7.3 帧号、时间与端点

沿用当前 GW184 的采样函数（本地路径：`projects/gw184-single/gw184/model.py`）、导出管线（本地路径：`projects/gw184-single/gw184/pipeline.py`）和场景时间约定（本地路径：`projects/gw184-single/gw184/scene.py`）。清单明确登记导出起始时刻 `start_s`、时长 `duration_s`、采样率 `export_fps`、导出索引起点，以及 Blender 的起始帧、起始时刻和帧率，扫描、原图及视频共同使用这份映射。

设导出采样率为 `r`、导出作业内索引为 `i`：

```text
N = round(duration_s × r)，前提是 duration_s × r 在约定数值容差内为整数
i = 0, 1, …, N−1
t_i = start_s + i / r
普通输出采样区间：[start_s, start_s + duration_s)
视频内相对时刻：i / r；绝对动画时刻：t_i
```

Blender 完整时间线的起点为 `F0=1`、`t0=0 s`，帧率为 `r_B`，对应的连续帧坐标为 `F_i = 1 + r_B × t_i`，反算 `t = (F−1)/r_B`。当前 GW184 的 `r` 与 `r_B` 均为 30；两者仍分别登记，不能由播放速度或窗口刷新率推断。若 `F_i` 非整数，记录整数帧 `floor(F_i)` 与子帧 `F_i−floor(F_i)`，不得四舍五入改变采样时刻。

| 样例 | 导出索引 | 动画时刻 | Blender 帧坐标 | 普通视频样本 |
| --- | --- | --- | --- | --- |
| 完整输出首帧 | 0 | 0 s | 1 | 是 |
| 完整输出末帧 | 9599 | `9599/30 ≈ 319.9666667 s` | 9600 | 是 |
| 完整动画终点 | `null` | 320 s | 9601 | 否；仅额外端点检查或烘焙关键帧 |
| 从 100 s 开始的短片首帧 | 0 | 100 s | 3001 | 是，属于该短片作业 |

完整 320 秒、30 fps 的普通输出为每路 9600 帧，不能把终点追加成第 9601 张普通视频图。额外端点检查使用独立名称，记录 `sample_role=endpoint_check`、`included_in_video=false`；任意当前时刻若不对应本作业输出样本，也使用独立检查记录与空导出索引，不冒填最近帧号。

现有 PNG 序列按作业从 `000000.png` 编号，`frames.csv` 登记相同的 `frame_index` 与绝对 `time_s`。新验收图采用带相机名的文件名时仍使用同一作业内索引，并在清单保存实际文件路径。相同编号只有在同一作业映射下才表示相同时刻。

现有导出通过 `at_time(t)` 直接设定姿态，不依赖 `scene.frame_set()`；不能把界面残留的 `scene.frame_current` 当成图像时间证据。新增扫描和出图须用同一个 `t_i` 更新姿态、相机外参和分析状态，再保存对应记录。续跑保留原作业起始时刻和索引，不按本次已完成进度重新编号。自由组合转角/桨角的 `stills` 属于姿态检查，不登记为普通时间线帧。

## 9. 模块划分、持久化与性能

拟划分接口：配置校验 → 参考表面绑定 → 材质/几何生成 → 刚性或柔性运动适配 → 固定相机观测 → 导出与审核。

- 缺陷配置与最终网格分开；派生几何可重建，健康参考不可被原位破坏。
- 第一阶段的实现放在独立项目中，复用已有几何/投影工具；不为了复用而提前重构主前端。新增模块名与具体目录在实施前的变更清单中确定。
- 材质遮罩的纹理分辨率或程序化采样能力必须足以表达声明尺寸，防止缺陷在渲染前已被纹理采样抹掉；记录其限制。
- 布尔运算和网格重建发生于编辑确认或显式预览更新，不发生于逐帧播放。帧更新只应用运动，不重采样随机形态。
- 局部细节集中在缺陷附近，不默认统一细分全部叶片。先做几何筛选，再按需生成少量外观图。
- 几何扫描和按需出图可取消；停止后释放任务资源并恢复时刻/显示设置，不把不完整结果标为完成。
- 第二阶段先重建带缺陷的参考表面与对应形变缓存，再参与回放；材质坐标、新增顶点和诊断采样点使用一致变形。不能只把缺陷设为叶片子物体。
- 第二阶段保留原有物理与雷达数据来源，明确它们未因视觉缺陷而重新求解；缺陷关闭时应回到原有健康显示与回放行为。

| R02 | 编辑闭环 | 新建、点击/数值定位、修改、取消、撤销、复制、删除可用；禁用缺陷与隐藏辅助标记分别验证；同叶片多缺陷时，禁用一个保留其余，重建失败则配置、网格、遮罩及分析缓存整体保留上一有效状态 |
| R03 | 坐标与尺寸 | 已知参考点的点击—保存—重建位置一致；两侧、方向角和单位明确；记录实际尺寸与误差 |
| R04 | 可复现 | 同一配置、资源、生成器和环境下保存重开后实例 ID、锚点与形态一致；跨版本按声明容差比较，不强求跨平台图像逐字节一致 |
| R05 | 刚性运动 | 转动与变桨后定位正确；暂停、单步、后退、重播无漂移；近景与各相机对应同一时刻 |
| R06 | 两类实现 | 至少一个材质型细裂纹与一个几何型开口裂缝完成近景检查，几何开口确实存在；无悬浮、错误穿透或重复表面 |
| R07 | 固定相机 | 缺陷编辑和近景导航前后相机布局摘要一致；使用相同约定的独立投影与实际诊断图位置对照 |
| R08 | 遮挡与难例 | 先通过凹槽块体的正视、部分遮挡及背视检查，确保不要求射线命中已移除的健康表面；再在 GW184 上覆盖清楚可见、部分遮挡、背面/完全遮挡、画幅外、亚像素投影，不强迫所有样例可辨识 |
| R09 | 时间扫描 | 枚举选定目标帧，检查首帧、末帧、非零起点短片及子帧映射；三路图片和统计使用同一绝对时刻；完整普通输出为 9600 帧且排除 320 s 端点；续跑不重编号，重播不重复累计，抽样不冒称全量 |
| R10 | 模式与产物 | G/A 分别标记，清单中的配置、近景、健康图、原图、裁切和统计互相对应；未生成与失败有状态 |
| R11 | 运行性能 | 同机同场景记录无缺陷基线、带缺陷帧耗时、编辑确认耗时和资源占用；逐帧布尔调用为零；未测不能写“性能无影响” |
| F01 | 第二阶段柔性绑定 | 弯曲/变桨/转动下整条裂纹和几何边界均贴合，缓存重建、结果包切换、保存重开不丢失 |
| F02 | 第二阶段前端回归 | 安装变换不变时，逐帧外参与同刻安装结构运动相符，不能仅验布局摘要；原有相机同步、时间寻址、多视图及来源提示保持；按相同环境比较性能，原有功能证据不被新场景替代 |
| S01 | 第三阶段传感器效果 | 每项效果有参数和来源；对照理想图、有限曝光图和编码图；实机标定缺失时只报告给定假设下结果 |

工程容差在实施开始时随运行基线冻结，至少包含表面绑定误差（m）、名义/生成尺寸偏差（m）、独立投影误差（px）、遮挡容差（m）、扫描时间分辨率（s）及交互性能目标。先用解析/已知几何样例检查方法精度，再选择目标；不得事后调宽容差使失败样例通过。

“几像素即可检测”的阈值不在本规格中凭空指定。人工检查、发现异常、分类和尺寸测量分别记录任务目标，后续由真实图像或接收方实验确定所需条件。

每类形态建立参考卡，写明参考图来源、已知尺寸、采用的特征、未知信息和建模假设。没有真实参照时只能通过“定义的合成形态与尺寸一致性”验收，不能将其改称实物形态真实性通过。

操作可用、G 模式几何一致性通过、A 模式外观审核通过分别报告。代码完成或简化测试通过不能替代 GW184 的对应图像检查，也不能据此宣称第一阶段整体通过。

## 11. 实施前需冻结的最小输入

这些是后续实施任务的检查项，本次文档工作不要求现在启动任何验证。

1. 主验收场景已选定独立 GW184；冻结其健康参考几何及表面参数化，验证压力/吸力侧别、有效表面域与前后缘定义。平面、块体和简化叶片只作为已知几何测试工具。
2. 冻结相机、时间线、输出分辨率和拟扫描范围；可复用当前配置，但记录其建模假设。
3. 确定首批材质裂纹、开口裂缝的尺寸组与参考卡。宽度可以包含可见和难辨样例，不能依据希望得到的图片自动改尺寸。
4. 确定工程容差与目标机器上的交互性能基线；成像辨识阈值单独留给实证，不与工程误差容差混用。
5. 形成只涉及刚性项目的变更清单和可观察验收步骤，确认后续实施任务的范围；既有渲染暂停约束继续有效。

最终交付结论按阶段、模式和证据分别书写，例如：“刚性场景缺陷编辑及 G/A 模式验收通过；柔性接入与 S 模式未实施。”不能用“已真实复现所有缺陷”概括不同层级结果。
