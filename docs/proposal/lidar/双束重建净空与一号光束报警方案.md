## 1. 目标与本次范围

采用用户确定的测量方式：**2、3 号激光同时测到同一叶片，用两个测距点估计叶片方向，结合轮毂坐标与叶片长度重建叶尖，再计算净空；1 号激光最靠近塔筒，一旦有效命中叶片，立即产生独立报警。**

本方案包含安装标定、两点重建、报警逻辑、已有数据复用、结果回放和验证方法。优先复用已有 FAST.Farm 风机运动，先重做雷达后处理，再依据采样验证决定是否重跑物理仿真。

本文初稿阶段仅交付方案；其后用户已授权实施与选位，进展见上方状态及记录。实施目标是接入现有 Blender 前端，保留三机柔性画面、相机、轨迹和播放操作，不另做一套演示程序。不包含实体设备接入、自动停机或收桨控制。

与旧《激光净空雷达演示方案》的关系：本文是本轮测量与报警逻辑的后续方案。未来按本文实施时，旧方案中“主卡取 B2 单束简化估计”和“7 m 阈值驱动报警”的规则不再适用于新模式。旧方案、旧数据及其验证记录保留作历史对照，不能改名冒充新结果。

## 2. 已确定的测量布局

本文用 S1、S2、S3 表示 1、2、3 号激光。旧数据中的 `beams.B1/B2/B3` 分别映射到 S1/S2/S3；叶片编号另用 `blade_id`，避免把光束编号与叶片编号混淆。

以下为初稿的名义布局；现行实施经用户授权统一增加 8°，采用 S1=10°、S2=12°、S3=14°，相邻夹角仍为 2°。S1 的名义塔壁间距随之变为 10.471 m，原 4.5 m 仅保留为未达到的参考目标，不用作软件报警阈值。

| 光束 | 初稿名义方向 | 职责 | 有效输出 |
| --- | --- | --- | --- |
| S1 | 与竖直方向约 2°，最靠近塔筒 | 独立报警通道；目标安装关系约对应 4.5 m 净空 | 有效叶片命中事件及时间 |
| S2 | 约 4° | 与 S3 配对测量 | 测距值与测点坐标 |
| S3 | 约 6°，最靠近叶轮 | 与 S2 配对测量 | 测距值与测点坐标 |

三束处于标定的测量平面，相邻夹角约 2°。S2、S3 稳定触发是布局需要达到的目标，不能在计算前当作已经满足的事实。

### 2.1 角度和安装位置

- **内侧安装是硬约束：发射器须位于叶轮与塔筒之间、机舱可承载的内侧安装区域。轮毂前侧、叶轮外侧的候选均不可用，不得用外侧命中覆盖替代内侧方案。**

- 名义角度在基准安装姿态下相对重力竖直向下定义，向叶轮侧倾斜为正。雷达固定在机舱上；机舱运动后，每束实际世界方向由安装变换计算，不人为保持与世界竖直的夹角恒定。
- 手册给出的相对夹角为 2.05°、4.09°。本方案先按用户提出的约 2°、4°、6°描述布局；实施配置必须记录采用的精确角度及依据，不静默替换为另一组角度。
- 标定保存每束发射原点、单位方向和坐标系。若仿真近似三束共用同一原点，应明示该近似；实际光源间距不可自动当作零。
- 标定内容还包括雷达与机舱的固定变换、轮毂参考点、机型尺寸、有效测距范围、塔筒模型。不得直接继承旧配置而不核对。

### 2.2 “2°、约 4.5 m”需要核对的几何关系

暂将“约 4.5 m”理解为：S1 在名义叶尖高度处到塔筒壁的水平间距目标。它不是仅由 2° 决定的固定值，也不是直接写入软件的净空数值报警阈值。

在竖直塔筒、测量平面经过塔心的简化侧视几何中：

```text
C1 = (z_lidar - z_tip) × tan(theta1) + s_lidar - r(z_tip)
```

其中 `s_lidar` 是雷达相对塔心向叶轮侧的水平偏距。沿用旧 demo 的名义参数时：

```text
z_lidar = 87.6 m，z_tip = 27.2 m，s_lidar = 2 m，r(z_tip) = 2.67 m
C1 ≈ 60.4 × tan(2°) + 2 - 2.67 ≈ 1.44 m
```

这说明旧安装几何与新描述尚未一致。实施的第一步应输出带尺寸的侧视安装图，核对 4.5 m 的参考高度、距离定义和实际安装位置。不得为了得到 4.5 m 擅自改变用户确定的角度，也不得把计算结果强行截断或平移成 4.5 m。最终标定通过后，再生成用于评估的新测距数据。

## 3. 双束净空重建算法

### 3.1 输入与计算边界

估计器允许取得：S2/S3 的斜距、测量时间和有效性，安装标定，轮毂坐标，与轮毂参考点一致的固定有效长度，以及明确约定的塔筒模型。

仿真负责产生测距输入；仿真真实叶尖、真实叶片轴线与参考净空只交给评估分支。估计器不得读取它们修正方向、逐帧调整有效长度、筛选误差较小的结果或补齐无效测量。

轮毂及塔筒运动信息的来源需登记。第一版可以采用仿真提供的同刻机舱姿态恢复轮毂，并在“已知仿真塔筒几何”的条件下评估两点重建；这一输入条件必须明示，不能据此声称真实雷达已能自行测出轮毂或塔筒运动。若另评估只用静态标定塔筒的版本，应单独命名和统计。

### 3.2 生成测距并判断有效性

对每个保存时刻恢复变形叶片、塔筒和机舱几何，将三束激光变换到统一世界坐标，计算射线与全部候选表面的最近正向交点。

同一时刻只有满足以下条件，S2/S3 才构成有效测量对：

1. 两束的首交点都属于叶片，且属于同一片叶片；塔筒、地面或其他叶片遮挡不能忽略。
2. 两束距离均在标定的有效量程内，数值有限，标定与姿态数据有效。
3. 两点处于同一仿真时间。第一版不跨帧凑点，不拿上一片叶片的历史测距补配。
4. 两点间距足以稳定计算方向，根到尖方向可以判定。间距门限在解析与扰动试验后固定并记录，不根据实际误差倒选。

仿真可以用交点所属叶片编号保证同叶片配对，报告需注明采用了仿真标签。真实设备若无叶片编号，需要另行设计事件关联。手册的 DP 数据可能是 20 ms 窗口内的均值，同一个报文也不能未经处理就视作两个严格同时的瞬时点。

### 3.3 从斜距恢复两点坐标

对 `i = 2, 3`：

```text
Pi(t) = Oi(t) + Di(t) × di(t)
```

`Oi` 为该束发射原点，`Di` 为斜距，`di` 为世界坐标中的单位方向。保存两个恢复点与原始测距，便于复核。计算使用未舍入数值。

### 3.4 计算等效轴线方向与叶尖

用三维单位方向表达两点直线的斜率，避免竖直方向的除零问题：

```text
v = P3 - P2
u = v / ||v||
M = (P2 + P3) / 2
若 dot(u, M - H) < 0，则 u = -u
T_est = H + R_eff × u
```

`H` 为约定的轮毂参考坐标，`R_eff` 为从该参考点到估计叶尖的固定有效长度；点积接近零、两点近重合等无法可靠确定方向的情况输出无效。

该模型将两表面测点的连线方向视为叶片当前等效轴线方向，并将这一方向放到轮毂参考点上外推。它不要求测点连线严格穿过轮毂。

长度口径须与起点一致：若 `H` 取轮毂中心，不能直接使用仅从叶根起算的叶片长度；轮毂半径、叶根偏置、预锥和预弯的处理需要写入机型配置。`R_eff` 由机型与预先固定的近似确定，不从当前帧真实叶尖距离倒算，也不按验证段误差拟合。

激光打在叶片表面，叶片可能弯曲或扭转，因此测点连线只是轴线方向的近似。这些影响应保留为待评估误差，不在前端人为修正。

### 3.5 从估计叶尖计算净空

净空取估计叶尖与同一全局高度的塔壁之间的水平距离。

对于竖直、圆截面塔筒：

```text
C_est = sqrt((T_est.x - xc)^2 + (T_est.y - yc)^2) - r(T_est.z)
```

对于变形塔筒，应按已声明的塔筒模型求同高度截面及最近壁面点，不能继续无条件使用初始塔心。估计点不在塔筒高度范围、截面不可求或输入无效时，输出明确原因，不强行投影到塔底或塔顶。若穿入塔筒，保留有符号距离语义，不将负值变成零。

### 3.6 参考值与误差口径

主指标使用同一定义的轴线／结构叶尖比较：

```text
位置误差 = T_est - T_ref
净空误差 = C_est - C_ref
```

`T_ref` 从仿真结构参考点及其变形独立恢复，不能由估计方向或估计净空生成。正净空误差表示高估间隙。使用相同塔筒输入条件时，可以集中评价叶尖重建引入的误差；更换塔筒输入条件后另列总误差。

已有包的 `truth_m` 是“末截面轮廓表面到同高度变形塔壁的最小净空”。它与轴线／结构叶尖净空分列展示，不能直接换个名字作为新算法的同定义真值。若同时报告 `C_est - C_surface`，应标为“相对末截面表面净空的偏差”，保留取点差异的解释。两者均不代表整叶片三维最小碰撞间隙。

## 4. 一号光束独立报警

### 4.1 触发规则与优先级

**S1 的首交点为有效叶片回波时，在该测量时刻立即生成报警事件。** 不等待 S2/S3 配对、叶尖重建、净空计算、下一次叶片经过或连续多帧确认，也不要求估计净空小于 4.5 m 或旧 7 m 阈值。

S1 在完整回放时间轴的所有保存时刻独立判断。不得沿用旧代码的“叶片朝下 ±3° 才计算”的限制，也不得写在“双束计算成功”的分支中。塔筒或地面命中不触发叶片报警；无数据、无效标定和故障状态与已确认无叶片触发分开记录。

| S1 观测 | S2/S3 配对 | 本次净空 | 报警处理 |
| --- | --- | --- | --- |
| 有效叶片命中 | 有效 | 输出新估计及误差 | 立即生成报警事件，优先显示 |
| 有效叶片命中 | 无效 | 显示本次无有效净空 | 仍立即生成报警事件 |
| 已完成有效观测，未命中叶片 | 有效 | 输出新估计及误差 | 本样本不新增 S1 报警；历史报警是否保持按复位规则处理 |
| 已完成有效观测，未命中叶片 | 无效 | 等待双束测量 | 本样本不新增 S1 报警；不据此宣称净空安全 |
| 数据或观测条件无效 | 任意 | 按双束自身有效性处理 | 标记报警通道状态未知，不用无效数据清除已记录报警 |

### 4.2 事件、显示与复位

“立即报警”已确定；报警是否锁存、显示保持多久、怎样复位尚未由用户指定。方案将它们与触发计算分开，实施前固定到配置及验收样例中：

- 必须保存每次原始有效命中时间，第一次命中就是本次事件的起点。
- 连续命中可以归并成一个事件，但不得等事件结束后才输出报警。
- 报警保持与复位只能影响事件后的显示状态，不得延后事件起点，也不得让 S2/S3 缺测自动复位报警。
- 显示用光束闪亮、短时动画或卡片保持是可读性效果，不作为传感器脉冲时长或报警延迟。
- 暂停、寻址、后退和重播都按仿真时间读取事件与预计算状态，不使用电脑墙钟累积，不把未来报警显示到过去。

报警事件时间与界面显示时间分别记录。40 Hz 后处理中的“立即”只表示在首次保存到的有效命中样本上触发；无法据此保证实际物理触发后 25 ms 内必然报警，窄事件仍可能落在保存帧之间。

### 5.2 新光束布置必须重算命中

旧布局为 6.45°、8.5°、10.54°。改为新名义布局后，**三束斜距、首交对象、命中点、有效性和报警事件均须重新计算**；旧 `data.json` 中的测距结果仅供历史对照。

此前旧窗口内的双束有效时刻 T1/T2/T3 为 7/27/27，旧单束误差与 `FAILED_AVAILABILITY` 也属于旧方案，不作为新方案的结果或达标依据。

第一轮遍历完整 60 s 的全部保存时刻。双束有效性由实际首交判定；逐次经过的评估窗口按几何位置／方位角预先定义，包含该次 S2/S3 预期测量区，不依据成功命中结果反向裁剪分母。报警通道始终扫描全时段。

### 5.3 分两阶段处理采样问题

**阶段 A：40 Hz 后处理基线。** 不重跑 FAST.Farm，先完成安装核对、几何恢复、新射线计算、双束算法、S1 事件和统计。可以评价已有保存时刻上的表现，不能给出连续时间最小值或真实设备漏测率。

**阶段 B：必要时加密输出并重跑。** 若双束共同命中只有孤立样本、事件边界跨帧不清、S1 报警触发无法解析，或需要量化时间精度，则保留相同物理工况，对几何输出采样进行细化比较。按相同时间区间比较双束覆盖、事件起止、净空极值和误差变化，再判断采样是否足够，不预先指定某个频率必然达标。

现有内部求解步长为 0.0015625 s，不表示这些内部状态已全部保存。若新输出频率超出当前求解或输出链路支持范围，还需协调求解步长与输出方式。若没有可用恢复点，必须保留必要启动过程重跑，不能从 117 s 凭空初始化。

插值可以用于画面平滑和敏感性诊断，必须标注为 `interpolated`，与实际保存的 `source` 时刻分开统计。手册每通道 20 kHz 原始测距和 50 Hz DP 输出是硬件数据链路信息，不要求直接把风机结构仿真改成 20 kHz，也不能用插值冒充这种测量证据。

改变风况、叶片结构、柔性配置或控制工况时需要新物理仿真；只改被动测量布局或估算公式，优先对已有兼容几何做后处理。

使用独立版本和目录保存新结果，引用原几何包的摘要；不覆盖旧结果，不将旧读取器无法理解的新语义塞进旧 B2 字段。

| 三束观测 | 时间、光束号、斜距、首交对象、叶片编号、命中点、有效性及原因 |
| 双束重建 | 配对叶片、P2/P3、点间距、方向、轮毂坐标、有效长度、估计叶尖、估计净空及无效原因 |
| 独立评估 | 同定义参考叶尖与净空、位置误差、净空误差；另列末截面表面净空 |
| S1 报警 | 原始命中时间、事件起止、报警状态、保持／复位配置及通道未知状态 |
| 统计与回放 | 各机组、各叶片、各次经过的统计；支持按仿真时间直接读取的累计状态 |

双束无效时 `clearance_estimate` 为 null，禁止填零、复制真值或把旧值登记为新测量。若界面保留最近一次结果，必须整组保留估计、参考值、误差及同一个测量时间，并显示年龄；保持时限单独配置。S1 报警不依赖这组结果是否仍在保持期内。

### 6.2 前端表现

接入现有净空卡片和雷达实体，保留相机及柔性风机展示。卡片至少清楚区分：

```text
净空测量：双束有效 / 等待双束 / 数据无效
双束估计净空：… m
同定义仿真参考：… m
净空偏差：… m
测量时间：… s · 叶片 …

1号光束报警：触发 / 本次观测未触发 / 通道状态未知
最近报警时间：… s
```

S1 报警优先显示，S2/S3 即使无结果也必须可见报警。无新测量时明确显示等待或历史值，不能显示“安全”。旧 7 m 阈值和 0.1 m 回差不再控制新模式的 S1 报警。

光束视觉方向必须来自同一标定配置；若展示精确命中点或重建叶尖，须与同刻几何、坐标及数据一致。外推得到的叶尖标注“估计”，与仿真结构参考点明确区分。

## 8. 验证与验收

### 8.1 必须满足的功能规则

1. 刚性直叶片解析样例中，两点方向、轮毂参考、有效长度和净空公式能够相互核对；包含竖直叶片、点顺序交换及整体平移旋转。
2. S2/S3 同时、同叶片配对，单束缺失、不同叶片、近重合点、错误标定或过期数据均输出明确无效原因。
3. S1 首次有效叶片命中在同一数据时刻产生报警，不被双束失败、估计净空大小或旧角度窗口阻止。
4. S1 塔筒／地面回波不产生叶片报警；通道未知不被解释为未触发，也不自动清除历史报警。
5. 无效值不进误差均值，但保留在预期样本、缺测和经过统计中。零分母及空误差集为“不适用”，不能填 0 或 100%。
6. 估计分支无法取得真实叶尖或真值作为修正输入；同定义参考与表面净空分列。
7. 重播、后退、换机组、换片段及改变播放速度不改变样本结果和事件时间，不重复累计，也不跨片段保留旧测量。

### 8.2 必须报告的性能量

| 方面 | 统计内容 |
| --- | --- |
| 净空精度 | 有符号偏差、MAE、最大绝对误差、最大高估、绝对误差 P95；P95 固定采用 nearest-rank，记录样本数 |
| 叶尖重建 | 三维位置误差、各方向分量及同定义参考点说明 |
| 双束覆盖 | 预期测量区样本有效率、有测量的经过比例、整次漏测、最长缺测间隔 |
| 稳定触发 | 每次经过的连续共同命中样本数、共同有效时间段及边界不确定性；40 Hz 相邻命中不等同于已证明中间持续命中 |
| S1 报警 | 命中事件数、首次观测命中与事件输出的时间差、几何首交类别、数据时钟与界面显示时钟的差异 |
| 时间细化 | 不同真实输出采样下的覆盖、事件起止、最低净空和误差变化 |

“稳定触发”应由测量覆盖和连续性共同证明，不能仅凭三束线穿过画面认定。误差只在有效双束上计算，同时报告缺测；不得仅挑误差较小或命中较多的片段。

本轮尚未约定新算法的精度容差、稳定触发最低覆盖比例和报警端到端延迟预算。实施评估前应固定这些数值、预期测量区以及报警保持／复位规则；不能根据最终结果倒设门槛，也不沿用旧单束目标宣称新算法达标。阈值未固定时可交付实算结果和功能检查，但结论应为“待性能验收”。

如果原 60 s 中没有 S1 有效命中，报告“本片段无报警事件”。可用独立解析样例验证事件逻辑；如需真实物理低净空演示，再补充有来源的新工况，不能移动显示叶片或伪造触发记录。

## 9. 手册依据与结论边界

依据用户提供的《MolasCL 激光净空监测雷达使用手册 V3.0-202310》，即工作区的 雷达3.0.pdf（本地路径：`../../../../雷达3.0.pdf`）：

- 第 2.1、2.2 节，印刷第 5 页（PDF 第 6 页）：净空定义为叶尖与其高度处塔筒壁的最近距离，测距后通过反演得到净空。
- 第 2.3 节，印刷第 6 页（PDF 第 7 页）：直接飞行时间测距，每通道原始测距频率 20 kHz。
- 第 2.4.2 节，印刷第 7–9 页（PDF 第 8–10 页）：三束相对夹角、安装几何和标定关系。
- 第 3.5.1、3.5.2 节，印刷第 31–32 页（PDF 第 32–33 页）：50 Hz DP 数据、三束直接测距与独立的最终净空字段。
- 第 3.5.3 节，印刷第 33 页（PDF 第 34 页）：公开的逐束简化公式及刚性直叶片假设。
- 第 3.5.4 节，印刷第 33–34 页（PDF 第 34–35 页）：有效叶片数据、地面数据及无效数据的区分。

手册没有公开“两点方向＋轮毂＋有效长度”最终反演的完整推导。本文采用用户确定的双束重建和 S1 独立报警规则，不将其称作已经复现厂家专有算法。

当前能确认的是输入数据和后处理复用路径；新角度下的命中、重建误差、稳定性与报警表现尚待实施计算。仿真结果用于评价本方案在指定模型和输入条件下的表现，不等同于真实设备精度或现场保护效果。
