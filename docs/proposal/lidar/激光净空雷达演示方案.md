# 激光净空雷达演示要求

现行前端使用三机柔性保存回放、双束净空估计与S1独立叶片命中报警。测量、[安装与无效值合同见双束方案](双束重建净空与一号光束报警方案.md)，[实际操作见Blender使用手册](../../blender/用户使用手册.md)，[发布及验证范围见发布状态](../../blender/发布状态与验证范围.md)。

## 演示数据与时间

演示复用FAST.Farm保存运动结果，离线计算模拟测距、估计净空与独立仿真参考，再以同一时间轴同步播放。画面明确区分仿真几何参考、算法估计和现场测量；实时播放不等于实时物理求解。每条估计、参考、误差和有效状态保留同一个测量时刻。

## 测量与显示

S2/S3在同一时刻首命中同一片叶片时构成测量对；默认 `hub-axis.v1`由两测点方向、声明轮毂参考及固定有效长度估计叶尖。`hub-tls.v1`仅为显式候选。S1有效叶片首命中立即生成独立报警，不等待双束成功，不以净空数值阈值代替触发。

无有效测量时净空为null并显示原因；最近结果若保留，必须同时保留原测量时间和年龄。真实叶尖、动态源网格和参考净空只供独立评价，不得用于补齐测距、修正方向或选择小误差结果。

前端显示风机、塔筒、叶片形变、三束方向、首命中点、估计叶尖、参考净空、估计误差和S1事件。自由视角与播放控制应持续有效；软件显示及保存不证明测量精度。

## 验收边界

验收分别覆盖输入来源、同刻配对、几何与时间有效性、无效状态、报警独立性、回放同步和独立精度。默认模型及TLS候选保持 `REVIEW_ONLY / PENDING_ACCEPTANCE`；[详细测量和限制见TLS总报告](../../lidar/双束TLS候选实施与验证总报告.md)。演示不包含实体设备接入、自动停机、收桨控制或现场安全认证。
