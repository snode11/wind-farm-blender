### 3.1 从这些论文实际借鉴什么

**CoTracker3 / AllTracker：**建立独立于当前叶片深度的 RGB 对应基线。当前源输入已有标定和模板，先用二维对应能减少把错误单目深度带回求解器的风险。这是本项目选型判断，不是证明二维方法必然比三维方法强。

**TrackEverything：**借鉴表面身份持续化、按需新增观测、来源记录；官方代码发布后先测试补漆/条纹上的稀疏保护查询，再决定是否做全场景密集跟踪。不能把 H/4 特征分辨率或体素大小解释为已验证的缺陷测量分辨率。

**VGGT-Ω / V-DPM / SpatialTrackerV2：**区别“每帧深度”、“共同坐标系中的几何”和“同一材料点随时间的运动”。只有深度序列并不自动给出材料身份。使用估计相机/尺度时记录来源和变换，不替换已验证标定而不做对照。

**D4RT：**将源观测时间、目标状态时间和表示坐标系分开。这正对应本项目必须分开的 frame_id、simulation time、model/world/camera frame。

**Shape of Motion：**低维运动表示与长期图像对应可以共同优化。已有 `blade_recon` 正有低维状态，优先沿此扩展；无需为了借鉴这种思想先换成 Gaussians。

没有在所读资料中发现这些方法针对本用户的 NREL 细长叶片、当前补漆和现有相机布置的已验证结果。作者、会议和通用榜单不能代替本项目对照实验。

### 3.2 VGGT-Ω 的复现说明不能忽略

官方 `reproduction.md` 表示发现潜在训练/评价数据重叠风险，但无法确定对原权重的影响，因此另行核查数据并再训练；要求后续基准采用 Reproduction checkpoint。不能把“潜在风险”改写为“已证实造假”，也不能跳过该说明。[G3]

工程规则：记录具体权重文件、SHA-256、分辨率、预处理模式、代码 revision；416 Reproduction 按官方要求使用对应预处理。512 in-the-wild 模型的展示效果不与416基准数字混为一谈。

## 5. 先定义输入合同与能力边界

### 5.1 模式必须显式，而不是靠文件个数猜测

- `single_image`：严格只读取一张 RGB，允许已声明的健康模板、相机/安装先验。输出模板条件下的三维解释与可见外观。不存在时间跟踪收益。
- `synchronized_multiview`：同一个物理时刻，多相机共同观察同一材料区域。先检查真实光心基线、重叠和标定；共光心不同朝向主要扩大覆盖，不自动提供三角测量基线。
- `video`：逐时刻状态变化、摄像机可能运动；不能当静态 SfM。需持续材料身份和时间戳。

目标另设 `rotor`、`mounted_single_blade`、`free_single_blade`。首轮优先原转子/有安装参考的单片；任意自由摆放单片涉及额外刚体姿态和尺度规范，不应和首轮窗口优化一起全部放开。

单片必须同步修改轮廓循环、初始化、活动参数与输出读取。`Rotor.blade()` 只是可复用几何函数，不是现成单片重建 API。已安装单片的方位角初始化要处理完整角度/离散身份候选；原转子未标号的三重对称规范仍可保留。自由单片需固定姿态与桨距等重复旋转自由度，避免冗余。

### 5.2 默认允许和禁止读取的信息

| 信息 | 首轮默认处理 |
|---|---|
| 选定输入 RGB、对应时间、文件尺寸 | 允许 |
| 由 RGB 生成的叶片 mask、补漆区域、人工二维提示 | 允许，记录人工程度及源文件 |
| 健康 NREL 设计模板和设计长度 | 允许作为声明的先验；不当成已测量的动态表面 |
| 相机内外参/安装坐标 | 根据数据合同允许；记录标定来源，当前a02用逐帧资料 |
| 桨距、方位角、RPM传感器 | 只有明确列为输入时允许；相同信息给所有对照组；不得自动读源状态 |
| 原始场景的补漆位置、大小、UV、三角形绑定 | 禁止进入求解；只用于评价 |
| 原动态网格、真实缺陷深度、真实pointmaps、对象ID图 | 禁止进入正式RGB求解；可另做清楚标注的理想输入诊断 |
| 留出相机RGB、留出帧RGB、留出人工标签 | 不得进入跟踪、深度估计、背景估计、纹理构建或调参 |

同一 RGB 经模型预测的深度是允许的图像派生先验，但不变成独立测量；其使用会改变方法组的输入处理链，应在比较中披露。

### 5.3 严格单图的正确验收

单图仍应实现，不把它称为“无法做”。可复用模板与已知标定得到合理姿态、受支持的形变和可见补漆外观；背面由模板提供几何并标记无图像外观。

但如果表面纹理与其位置均完全自由，那么沿当前网格反投影、再投回同一张图的零误差是构造上的自洽。不能以此证明额外深度观测。独立已知标记、学习先验或已知纹理模板可以提供不同的约束，但必须明示这些信息，不能从源缺陷参数偷取。

相机、尺度、刚体姿态、桨距和弯曲不应在缺乏约束时全部自由优化。不能只按最小二乘success决定是否唯一可辨识；应记录候选差异、数据约束弱方向和先验依赖。

## 6. 推荐处理链：从图像证据到共享材料点

### 6.1 输入、成像与原始分辨率

新增 `FrameBundle`，至少保留原始 RGB uint8、mask、frame_id、timestamp、相机信息及预处理变换。`cv2.imread` 实际为BGR；不得因变量名叫rgb就认为顺序正确。

为整体几何与局部外观提供双分辨率：整体 mask 可降采样；补漆边缘、细纹理与纹理烘焙保留原始高分辨率。低分辨率跟踪结果映回原图，不把网络输出尺寸当真实细节精度。

裁剪/缩放/补边必须记录仿射变换 A，使齐次像素 `p_net = A p_raw`。K同步变成 `K_net = A K_raw`，预测点用A的逆映回原图。当前相机缩放使用像素中心约定 `(cx+0.5)*s-0.5`，新代码必须保持一致。动态ROI每帧A不同，不能只保存一个固定offset。

如果模型需要整段ROI，先选覆盖轨迹的稳定区域；逐帧紧裁剪会改变运动与尺度，必须保留逆变换并单独验证。不得利用源动态网格预测ROI却把结果标成纯RGB独立前端。

当前 Workbench 采集显示材质视口颜色，不等于完整节点材质。先比较少量实际输出PNG，确认补漆在目标相机可辨识；需要节点噪声、bump、高光等时验证对应渲染器。诊断无光照图、正常照明图分组记录。不能只检查源模型编辑器里存在补漆就认为输入图里也存在有效信号。[S2:99,142]

### 6.2 三类表面观测分开

1. `blade_mask`：叶片在图像中的可见占据区域，不因补漆色差产生内部孔洞。真实开口、遮挡不能无差别填补。
2. `patch_region` / `internal_boundary`：补漆区域及内部边界，允许首轮人工提示，不能说已自动语义识别。
3. `point_tracks`：尽可能对应稳定材料点的局部图像特征，例如不重复的纹理、条纹端点、可信角点。

补漆分割结果的质心、包围盒中心，以及平滑边缘上随意采样的位置，不保证是跨视角不变的材料点。区域/边界应使用区域残差或法向边界距离，而不是强行作为相同3D点。

阴影、高光、污渍等作为负样本和混淆类。第一轮可以诚实地交付“人工提示辅助的外观区域恢复”，后续再做自动分类。跟踪器跟住一个色块，并不证明它识别了补漆或损伤成因。

### 6.3 后续跟踪器适配（P2b 之后的条件性候选）

attempt02 为 Codex 审核对应，CoTracker/torch 没有运行；P2b 继续优先受控、可审核 RGB 材料点，不同步安装或比较多个自动模型。以下协议保留为未来设计，不能写成已有接口或运行状态。

本项目自定义统一协议，不模仿尚未公布的 API：

```python
# 拟新增本地接口，不是第三方现有函数签名。
class SurfaceTracker:
    def track(self, frames, queries, metadata) -> "TrackBundle":
        ...
```

`queries` 明确每个查询的源帧和原图像素。每路相机独立跟踪，局部ID使用 `(camera_id, backend_run_id, local_track_id)`，不能以相同整数ID匹配不同相机。

**CoTracker3适配：**官方高层示例返回tracks和visibility；底层模型/论文还有confidence信息，不能假定高层接口总是暴露原始置信。核对固定revision的predictor；分别保存可得输出，不把布尔visibility伪装为校准概率。模型查询分布会影响输出，固定种子点和支持点策略供对照。[G7,P7]

**AllTracker适配：**2026-10-05 v2 核查时实际读取`demo.py`，`forward_sliding()`返回的是flow与vis/conf图，demo再加查询帧像素grid得到绝对坐标。查询帧之前由反向视频推理再反转、剔除重复查询帧。适配器不能忘记flow→坐标，也不能重复拼入查询帧。demo可视化按confidence筛点，不应原样当几何可见性判定。内部新显露表面不在原查询帧里，应择新关键帧重启查询并审慎关联。[G5]

**TrackEverything适配：**当前仅占位配置 `available=false`，不能放假的成功返回或静默切换后还标为TrackEverything。将来代码/权重和许可核实后，先测试论文支持的稀疏查询排除合并路径。记录输入pointmap来源、参考世界系、全序列尺度因子和体素单位；不能将论文规范化空间的voxel参数解释为米。[P1,G2]

**三维候选适配：**VGGT-Ω只提供几何先验不自动提供材料ID；V-DPM和SpatialTrackerV2输出的动态对应也须转换到统一参考坐标并验证。不得把两路同步图交错成“单路时间视频”。

### 6.4 从局部跟踪到全局表面身份

新增关联表，不要求一开始自动解决所有跨相机重识别：

- 同刻不同相机的对应，利用RGB描述、区域归属、有效基线的对极约束和多视图一致性。
- 几何初值可提供宽松候选区域，但错误初始网格不能成为过严筛选条件，把正确观测先删光。
- 叶片身份、正反面、轨迹历史不确定时，保留未关联或多候选状态，不强行合并。
- 相邻叶片进入同一像素或同一空间位置，不是同一个材料点。
- 遮挡时的模型轨迹是预测，不是可见表面观测。仅在经质量检查的可见时刻进入图像数据残差。
- 对周期运动与长遮挡设置重识别测试，不能用评价阶段的B1/B2/B3循环映射补全算法身份。

### 6.5 材料坐标的表示

推荐在求解中使用规范态表面chart；导出时转换为固定拓扑上的 `triangle_id + barycentric_weights`。

可采用`span_norm + perimeter_coordinate`，再附加压力/吸力侧标签。若采用“展向＋弦向＋侧面”，必须处理前缘、后缘接缝与根部近圆截面的歧义。侧面是离散语义，不能假设一个连续变量自然穿过薄叶片。

绑定表达：

\[
X_m(q_j,x_t)=\sum_{k=1}^{3} b_{jk}(q_j)V_{f_{jk}}(x_t).
\]

一条轨迹的q在所有输入时刻共享，顶点位置随状态x_t变化。不能每帧重新在源场景叶片上找最近点，也不能调用默认补漆的源绑定参数。

初次射线求交只用于初始化。固定拓扑、三角形朝向、最近可见面、表面接缝和q↔绑定变换均要单测。初值不足以保证深度正确，后续用其他观测联合验证。

## 7. 几何优化：这是“表面参与重建”的核心

### 7.1 坐标变换唯一约定

记M为叶片前向模型所在机组系，W为固定世界系，C为OpenCV相机系：

\[
X_w(t)=T_{W\leftarrow M}(t)X_m(q,x_t),\qquad
u_{ct}=\pi(K_{ct}T_{C\leftarrow W}(c,t)X_w(t)).
\]

当输入已提供 `T_C_from_M` 时，直接投影，不再乘 `T_W_from_M`。a02历史字段虽叫`T_cv_from_world`，实际就是该模型到相机变换。新loader显式解析为`extrinsic_from_frame="model"`，转换后记录语义。[S3: a02 capture.py:39–53]

固定标定原则：首轮不同时优化相机和叶片全部参数。如果确有标定误差需要调整，另设实验、校准先验及尺度/世界系规范。不能让相机漂移吸收模板误差。

### 7.2 目标函数与变量

通用目标函数设计（P2b 固定边界/光度项关闭，只比较轮廓与材料点增量）：

\[
\min_{\{x_t\},\{q_j\}}
E_{silhouette}
+\lambda_{track}E_{track}
+\lambda_{boundary}E_{boundary}
+E_{temporal}+E_{physical\ prior}.
\]

这里的E_silhouette首先沿用现有实现；boundary是可选第二步，photometric默认关闭，避免同时引入太多未验证项。

点跟踪项：

\[
E_{track}=\sum_g\frac{1}{Z_g}
\sum_{(c,t,j)\in g}
w_{ctj}\rho\left(\left\|\Sigma_{ctj}^{-1/2}
[\pi_{ct}(X_m(q_j,x_t))-u_{ctj}]\right\|^2\right).
\]

g按轨迹/区域/相机分组，Z_g用于控制重复采样权重；不要让一个补漆上的上万相邻像素压倒全部轮廓。w来自可见性与开发集质量规则，Σ来自明确的噪声假设或验证标定；模型confidence不直接当成真实协方差。

全局x与局部q同时自由会产生耦合。一个小补漆不一定足以约束整片叶片的全部状态，不能因点数很多就解冻所有参数。只放开由数据支持且规范固定的自由度，其余保持先验并标记。

### 7.3 复用现有窗口求解与受控数值诊断

attempt02 的 `window_surface_fit.py` 已实际运行共享 q 联合求解；原逐帧 `Fitter` 作为 fresh A0 和 legacy 基线保留。P2b 四组仍只活动每帧 psi/pitch0/flap0/edge0，另外 9 维保持同一 A0；共同 psi 会改变三片方位，不能称另外两片网格不动。

每组从同一 A0 独立启动；首帧输入像素在估计模板初始化一次 q，相关轨迹逐值复用初值。不得逐帧重绑定、从源标记参数初始化，或仅给 A3 使用 A1 热启动。预确认观测不因预测出画/背面而静默删掉，残差维度固定，坏深度/域使用显式罚项或失败状态。一次鲁棒化、二次先验、真实 dt 的加速度约定继续保留。

旧轮“±1e9° psi 占位边界”数值问题与统一 diff_step 修正已记录，不称 attempt02 当前根因。A1/A3 在 nfev=11/14 由 xtol 停止，并未耗尽 60 预算；只增加 max_nfev 不能替代终止/边界诊断。raw gradient 非零也不单独证明有界求解错误。

拟议 P2b-0 输出具体触界变量、值、active_mask、SciPy optimality、分项残差/梯度、可行方向与实际有限差分扰动。大展开角的相对 diff_step 风险尚待检验；拟比较统一加 360k° 的等价初始化，必要时另提相对参考角增量参数，不逐帧取模制造加速度断点。只做预声明、同尺度的有限 dense/exact 与 sparse/LSMR 开发对照；不能无限收紧容差或调旧结果直到获胜。详细停止条件见 §16.1。

### 7.4 数据可辨识性与不确定性

对标准化后的纯数据残差构造雅可比；排除先验的“补秩”。若材料q或相机是干扰变量，需检查消除干扰后的状态敏感性，而不是仅看完整J满秩。例如在适当加权/尺度下，可用投影后的`J_eff=(I-J_nuisance J_nuisance^+)J_state`作局部诊断。

P2b-0 应在同一个参考状态、固定噪声白化和参数特征尺度下分别形成轮廓 `J_s`、轨迹状态 `J_tx` 与轨迹材料 `J_tq`；消 q 后比较轮廓弱方向的信息增量，不只比较各自最优点的 rank。无约束伪逆消元仅适用于内部可行情形；触界需报告限制并采用可行切向/profile 诊断。A3 局部 rank 32/32 可以由轮廓提供，不证明材料观测有效。

该局部线性诊断不是全局唯一性证明，也不是校准后的误差区间。对称叶片需额外候选身份比较；低纹理、共光心、集中局部点、平滑单边缘及同一射线附近运动都要单列退化案例。

若数据不足，允许输出`PRIOR_DOMINATED`或`DEGENERATE_GEOMETRY`，保留可见纹理恢复结果，不把该状态写为准确三维计量。

### 7.5 不要做循环验证

使用当前模板估计网格渲染深度→三维跟踪→再拟合该网格，是一种模型辅助迭代，可能有用，但三维输出不是独立真值。不能用“轨迹与初始网格吻合”证明网格本身正确。

如果将三维轨迹重新投影为二维，其深度/姿态先验影响仍存在。必须记录该分支为geometry-assisted，和RGB-only二维跟踪组分开，最后仍靠留出图像或隔离真值评价。

## 8. 外观恢复与 Blender 显示

### 8.1 输出是图像来源的表观颜色，不默认是去光照材质

首轮将可信、实际可见的RGB像素映射到估计网格UV，输出补漆区域与纹理。单张图无法在未加其他信息时唯一分离底色、光照、粗糙度和法线；保存`appearance_kind="captured_rgb"`。

多视图融合先检查几何对齐，按可见性、观察角度、分辨率、清晰度选择来源或鲁棒融合。边界冲突时保留冲突/未知标记，不直接平均成一块模糊补漆。跨图像曝光补偿应简单、受限、只从允许输入估计，不能用灵活的逐像素颜色模型掩盖错误几何。

网络输入尺寸与纹理尺寸分开。纹理可分区、分tile，以原始图像有效采样率分配；扩大贴图分辨率不会创造原图没有的裂纹。首轮不使用生成式纹理补全；后续展示性补全必须有独立标签，不能参与测量或图像证据覆盖率。

### 8.2 几何证据和外观证据是两个轴

建议分别存储：

- `geometry_evidence`：image-constrained / prior-dominated / unresolved。
- `appearance_evidence`：input-image-supported / declared-prior / unknown / conflicted。

背面可以有健康模板几何，同时外观unknown。当前绿色截面只说明轮廓接近，不可升级为整圈表面图像支持。每个texel或区域保存源相机、源帧、支持观测数和质量摘要，必要时保留像素映射索引。

这些标签是证据来源，不是已校准准确率。图像支持的点也可能被错误跟踪，故准确性仍靠独立评价。

### 8.3 固定拓扑绑定与显示模式

导入时建立UV；每帧更新顶点坐标，UV不动。前缘、后缘与正反面chart在Blender中使用loop-domain UV处理接缝。独立裂纹曲线或点标记可以使用重心权重绑定到**重建网格**，不能绑定源场景叶片。

增加三种显示模式：

1. 外观模式：图像纹理；提供无额外光照的对照显示，避免把烘入图像的阴影重复照明。材质重新打光仅作展示，不能宣称完成逆渲染。
2. 证据模式：分别查看几何与外观来源，并可显示未知区域。
3. 几何模式：网格、表面点、轨迹、边界与必要误差。

先验证静态单帧/单窗口，再恢复原有播放、暂停、单步、寻址、分屏、保存重开。外观模式改变视图设置时必须能恢复旧设置，不强行让所有窗口进入最重渲染模式。

新增images/materials/node groups必须有所有权标识，清理时只删本次资源且不删外部共享纹理。保存`.blend`后可嵌入或受控相对路径恢复纹理；坏哈希、缺贴图、错拓扑要报错并保持原场景，不静默回退白色模型后称成功。

保留现有离线前端，不在frame handler里运行PyTorch或最小二乘；推理进程结束后输出结果包，由Blender读取。

### 10.2 开发、冻结、盲测与新主指标

P2b 拟为1开发窗口+3非重叠测试窗口，每窗8帧/10Hz/4K；保持WideInput唯一输入、WideEval完全留出。64张RGB、最多384个输入二维观测只是计划上限。帧列表、区域边界、D4具体ID等保持 `null` 待未来实施确认，不在此次凭空指定。依据固定时序和输入可见性选窗，排除旧attempt02/scout开发片段，不依据成绩重选；同一回放三窗不能称统计独立现场样本。

新增 q-independent 主指标：预声明目标叶片/侧面区域的面积加权双向点到三角面距离；分内/中/外带报告mean/P95。固定MODEL米制、时刻、区域、源/估计对应、采样种子/密度，不逐组ICP/旋转/平移/尺度对齐，不以近反面替代正确侧面。主指标与统一 `q_eval`、方法拟合q材料指标、WideEval RGB指标分列。

开发诊断后冻结输入/点子集/配置/代码/指标/门槛/三窗列表；所有测试几何结果冻结后才开评价，不追调。影响估计的修复将旧测试降为开发/回归并选择未使用测试数据。完整合同、拟议门槛和停止状态见§16.3–16.8。

### 10.3 理想单测与真实源模型实验分开

用同一个`Rotor.forward`生成输入并求解，适合数值单测、接口闭环和故障定位；不能作为跨模板/实际场景的最终成功证据。这类“同模型理想实验”需标明。

应用评价继续使用与近似模板不同的原始AeroDyn/柔性显示几何，独立真值仅评测读取。允许静态健康设计先验的范围预先确定，不能借此把真实时刻动态网格输入算法。

### 10.4 指标与统计单位

分别输出：

**跟踪指标：**原图像素误差的中位数/P95、可见/遮挡判断、错误身份关联、遮挡后恢复、有效覆盖率。记录总查询数和拒绝数，不能只报成功子集。

**表面定位指标：**留出视角补漆区域IoU、边界距离和稳定点重投影误差；有适当定义的真值时增加材料位置和尺寸误差。区别表面弧长、欧氏距离、投影面积和真实面积，不混用。

**几何指标：**在一致物理定义下比较几何位置/表面距离/姿态和形变，按区域及可见性分组。不得把源mesh特殊索引点和模型轴端当成同一个物理叶尖；旧3.4914m数字不是新项目验收基线。

**外观指标：**仅在共同可见且定义一致的区域比较，单独记录照明差异；全图PSNR容易被大片背景主导，不能独立作为补漆定位成功条件。

**证据与运行指标：**输入图像支持面积、unknown/conflict面积、失败率、总耗时、峰值GPU/CPU内存、预处理与推理分别耗时。

相邻密集像素与同一短轨迹高度相关，置信区间不能把它们当独立样本；按视频片段/独立场景进行配对统计或重采样。单个漂亮案例只能叫演示。

尚无厘米/毫米工程用途阈值。§16.4 的10%、5mm、0.25px及20次扰动是待冻结研究筛选草案，不是精度证书；δ_dev尚未计算。经验敏感性带不称置信区间。通过最多记CONTROLLED_GEOMETRIC_GAIN_ONLY并保持REVIEW_ONLY，不能称工程验收。

#### 16.1.1 核对当前模块和评价材料点的 q 来源

- 轮廓数据 J_s。
- 跟踪数据对状态 J_tx，对共享 q 的 J_tq。
- 先按观测噪声/固定区块权重白化，再按固定参数特征尺度缩放列。
- 对内部可行点，J_t,eff = (I − J_tq J_tq^+) J_tx。

#### 16.2.2 输入质量门槛（建议，正式运行前冻结）

- 在输入原分辨率有清晰二维定位线索；不能靠最近邻放大制造信息。开发候选中局部可辨识结构建议至少 8 px 宽、查询点有足够间距；这一条件是采集质量检查，不是相机精度承诺。
- 第一轮优先让预声明 12 点在各窗口 8 帧均可审核可见。达不到时先报告采集/观测失败，不在看完评价后换窗口。既定盲测失败仍保留在覆盖分母中。
- 不再把 Codex 审核称为用户人工标注。记录点的来源、首次选择、后续审核、亚像素/整数像素策略和不确定度。
- 重复输入侧定位或明确的图像角点检测可用于估计标注稳定性。开发侧可以在结果冻结后用源材料点评价身份漂移，不能将其坐标回灌正式标注。
- 如开发窗口的 P95 材料身份漂移仍大于 1 原图 px，先检查图案与定位；1 px 为本试验建议的受控观测门槛，不是普适界限。

#### 16.2.3 四个几何条件

| 条件 | 观测子集 | 用途 |
|---|---|---|
| A1_new | 相同 RGB 的窗口轮廓，无材料点损失 | 新数据基线 |
| A3_C4 | 中段 4 点 | 同数量集中观测 |
| A3_D4 | 预先固定的分散 4 点，例如内段 1、中段 2、外段 1，兼顾弦向分离 | 与 C4 隔离“空间分布”因素 |
| A3_D12 | 三个区域全部 12 点 | 检查更多分散对应的额外作用 |

四组固定目标模型叶片 blade0，每帧仍只更新 psi/pitch0/flap0/edge0，其他 9 维保持同一 fresh A0；不同时放开二阶模态。各 A3 从同一 A0 独立启动，不通过 A1 热启动而伪称相同初值。

C4 与 D4 都是 32 个二维观测、40 个优化标量；D12 是 96 个二维观测、56 个优化标量。共享 q 初值由相同 A0 网格和输入首帧像素规则得到，相关轨迹的初值应逐值复用。

同点数仍不足以隔离全部因素。应尽量匹配各区特征的原图可辨识尺度与对比度，记录逐点定位重复性，并按冻结的不确定度白化。若外段点的观测质量明显不同，分布效果的结论必须附上这一限制，不能把观测质量差异全归因于空间布局。

A2_new 仍仅为 A1_new 的字节不变几何加外观；它不是第五个几何方法。可以暂不为所有组制作精美 Blender 并排，先完成数据判断。

点损失按预先固定的轨迹/观测数归一化，使不能只因为点多就把整个块权重机械放大；C4/D4 是最干净的同点数对照。保持同一个整体 track weight 约定，并记录原像素 sigma。任何在开发阶段确认必要的统一数值修正，必须同步用于四组；测试开始后不再调权。

#### 16.2.4 主指标必须与 q 定位解耦

现有材料点误差保留为重要次指标，但不能作为唯一“网格几何改善”证据。

拟新增主指标：在预先定义的目标叶片参考表面区域上，计算源显示表面与估计三角网格的面积加权、双向点到三角面距离，并按内/中/外展向带报告 mean 和 P95。

要求：
- 目标源叶片身份由评价侧固定并记录；不回传求解。
- 同一 MODEL、米制、同一保存时刻；不使用并排 UI 平移。
- 不按组额外拟合 ICP、旋转、平移或尺度来隐藏误差。
- 区域按静态参考材料展向和预声明侧面定义，不能按各组“看起来好”的面裁剪。薄叶片的最近面搜索应限定正确叶片及声明侧面，避免以很近的反面替代目标面；源与模板的区域对应规则在评价开始前固定。
- 使用同一源样本，估计侧按各自面面积正确加权；采样种子和密度固定，并做一次采样密度稳定性检查。
- 区分点到三角面与最近顶点；不要让源/估计不同网格密度制造差异。
- 双向表面距离本身不证明语义材料身份；必须并列材料点和留出 RGB 评价。
- 结果范围只覆盖所声明区域，不推广至整机、内部损伤或工程计量。

次指标：
- WideEval 的材料点投影 median/P95，源材料点 3D distance，以及同区域 RGB 边界/占据质量。
- 在所有方法上对统一的 12 个评价材料点，几何冻结后用同一“只读首帧定位协议”得到 q_eval，再预测后续时刻/留出相机。此步骤读取相同的首帧输入像素，不更新几何，不从 WideEval 或源绑定取得 q；q_eval 与各方法拟合 q 分文件，不能混用。
- 分别报告四个正式拟合 q 的同点指标与统一 q_eval 指标，不能将方法各自不同的点集合直接平均排名。
- 源参考可延续首帧射线定义以保证历史可比，但要保持名称；另可用合成标记真实绑定作评价专用第二参考，严格分表，不回灌。不把两类参考混称现场地标。
- 对首帧、后 7 帧分别报告；源侧首帧构造性零误差不能计入主轨迹质量。
- 旧 occupancy proxy 有塔/机舱污染且未完整处理外部遮挡，仅保留辅指标。可在评价侧新增源物体 ID 分离的纯叶片指标，但不得用于求解 mask，也不得称它与旧 proxy 是同一指标。

### 16.4 建议研究继续门槛与停止规则

这些门槛是**拟议的研究筛选规则，不是设备或工程验收标准**。正式运行前写入机器可读文件一次性冻结。

#### 16.4.1 开发侧建立经验稳定性带

使用预先固定的 20 次观测微扰诊断和一次采样密度/数值方法对照。微扰应包括同一轨迹各帧共享的偏移与帧级分量，幅度来自输入定位重复性，而不是假设每个像素独立。所有方法使用配对扰动。扰动结果只用来估计现有流程的敏感性，不称置信区间或现场噪声模型。

定义配对改善量 Δ=E_A1−E_A3；δ_perturb 为开发侧20次 |Δ_扰动−Δ_未扰动| 的经验95%分位数。数值方法/采样密度对照同样比较配对改善量差，δ_dev取δ_perturb与这两类绝对差中的较大者；这是经验敏感性幅度，不是概率覆盖保证。建议 δ_min = max(0.005 m, 2 δ_dev)。5 mm 仅是本受控实验预设的绝对收益门槛，不代表可测量 5 mm；测试前可基于用途讨论修改，测试后不得追调。

#### 16.4.2 主要继续条件

A3_D12 对 A1_new：
- 三段按“每段等权”平均的主表面 mean 距离至少降低 10%，且绝对降低不小于 δ_min。
- 至少 2/3 段各自达到上述相对/绝对收益门槛。
- 任一段的退化不得超过 max(该段 A1 的 5%, δ_min)。
- 留出材料投影 median/P95 不得出现超过预先冻结像素稳定性带的恶化；建议保护带不小于 0.25 原图 px，并结合开发敏感性制定。
- 求解/纹理侧无禁止输入读取，源真值仅由隔离捕获/评价侧读取；无静默删失、无未解释的数值不稳定、无评测后重选。

通过只称“该受控标记/模板/视角范围出现值得继续验证的几何收益”，仍保持 REVIEW_ONLY。三个短片段不支撑广泛统计显著性。

“空间分布假设得到支持”还要求同点数 A3_D4 相对 A3_C4 在至少 2/3 段表现同方向、且平均差超过开发侧稳定性带。若仅 D12 优于 A1 而 D4 不优于 C4，只能说更多分散观测组合有用，不能单独归因于分布。

#### 16.4.3 停止/分流

- 观测仍无法稳定定位：OBSERVATION_GATE_FAILED。先改实际输入信号，不安装大模型凑流程。
- 数值解对尺度、边界或方法显著敏感：NUMERICAL_INCONCLUSIVE。先修数值链路并重做公平基线。
- 数据干净但消 q 后增量很小：NO_INCREMENTAL_CONSTRAINT。下一轮才考虑增加新的输入视角/更有变化的窗口；旧 WideEval 不能直接变成输入后仍叫留出。
- 材料对应稳定而模板区域误差持续：MODEL_MISMATCH_SUSPECTED。进入独立的模板/形状表达诊断，不当场给某组增加局部自由度。
- 所有门槛满足：CONTROLLED_GEOMETRIC_GAIN_ONLY。之后才能选 CoTracker 或其他自动方法，在相同数据上比较“已审核对应”与自动对应；不是现在同时改变观测和模型。
- 输入基线已在稳定性带内，无法检出有意义收益：INCONCLUSIVE_NEAR_BASELINE。不能故意破坏 A1 制造空间；有意退化只允许单列压力测试。
