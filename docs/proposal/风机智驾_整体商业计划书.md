# 风机智驾（WT-IP）：端到端物理 AI 智能体，实现风电机组的主动式自主控制

## 概述

风机智驾（Wind Turbine Intelligent Pilot, WT-IP）是一套面向风电机组的端到端物理 AI 智能体，其目标是将风电机组由被动响应式设备升级为具备感知—决策—控制能力的自主智能装备。项目以三驱动世界模型（物理/数据/经验三驱动，覆盖"感知·诊断 → 决策·控制 → 进化·经营"）为方法论内核，通过多模态感知提前识别来流扰动，主动生成偏航、变桨与转矩指令，将来流冲击转化为最小的结构损伤与最平稳的功率输出。

项目的终极价值在于提升风场容量因子与发电稳定性：稳定性提升带动容量因子上升，进而提升新能源在电网中的准入占比，助力风电由补充电源向电网主力电源转变，最终服务于国家能源结构的战略性调整。项目当前已建成物理保真、专家可验证的仿真底座，并沿"部件—整机—风场"三阶段推进产品落地，以影子模式实现安全部署。

## 一、项目概述与技术定位

### 1.1 产品定位

风机智驾将风电机组视为一类"工业机器人"，参照汽车自动驾驶由人工操作向端到端感知—决策—控制演进的路径，为风电机组构建同等的自主运行能力。其核心运行逻辑为**感知—判断—主动控制**：机组通过多模态传感器提前识别数百米外逼近的阵风与湍流，在其到达叶轮之前主动调整偏航角与桨距角，将来流冲击转化为最小的结构损伤与最平稳的功率输出。

当前风电机组普遍采用被动响应机制，即在载荷异常出现后再行调整，此时结构冲击已经发生。风机智驾将这一逻辑前置，实现感知前置、决策前置、动作前置。

### 1.2 智能体能力构成

风机智驾以端到端物理 AI 智能体为核心，能力覆盖机组全生命周期的健康与性能管理：

- **多模态感知**：融合视觉、激光雷达（前馈测风）、振动、载荷、SCADA 等多路信号，构建机组的高保真数字镜像。
- **全生命周期健康评估**：对叶片净空、叶片表面缺陷、疲劳损伤累积与部件寿命进行持续在线评估。
- **载荷估计与疲劳评估**：由可测信号反演不可直接测量的叶片应力与载荷分布，将部件剩余寿命转化为可量化、可预测的指标。
- **主动控制**：以损伤最小化与风场级稳定发电为目标，主动生成偏航、变桨与转矩指令。

### 1.3 技术架构：三驱动世界模型

风机智驾的方法论内核为三驱动世界模型，即融合数据、物理、经验三大范式，覆盖"感知—诊断—决策—控制—进化—经营"六个方向的工业 AI 一体化架构。该架构由基础设施底座支撑，各功能层分层解耦、逐级递进，构成完整闭环：

```
┌───────────────────────────────────────────────────────────────┐
│ 应用·经营层   电力交易预测 · 智能报价 · 辅助服务 · 碳资产      │ 经验+数据
│ 进化·知识层   数字孪生校准 · 知识图谱因果推理 · 持续学习       │ 经验+数据
│ 决策·控制层   MPC+DRL 多目标 · CBF 安全屏障 · 影子模式         │ 物理+数据
│ 感知·诊断层   多模态融合 · 物理信息反演 · VLM 诊断报告         │ 数据+物理
├───────────────────────────────────────────────────────────────┤
│ 基础设施底座  双仿真引擎（传统工业仿真 + 具身智能仿真）        │
│              ＋ 两库（算法资产库 · 工程知识库）＋ 决策中枢     │
└───────────────────────────────────────────────────────────────┘
        贯穿全栈的三驱动：物理为基 · 数据为翼 · 经验为魂
```

三驱动范式各司其职、相互支撑：

- **物理驱动为基**：以第一性原理提供真值监督、安全边界与仿真环境，适用于数据稀缺、安全要求高的工业场景，对应底座的高保真求解器与 CBF 安全屏障。
- **数据驱动为翼**：以深度学习与强化学习在物理难以显式建模处高效逼近，加速感知反演与决策探索。
- **经验驱动为魂**：以运维沉淀的工程经验、失败案例与因果知识图谱支撑跨风场迁移，避免重复性失效。

基础设施底座是架构落地的关键。**双仿真引擎**中，传统工业仿真承担高保真验证，具身智能仿真提供批量并行的 AI 训练环境；**两库**沉淀即插即用的算法资产与"适用条件、失败边界"等工程知识；决策中枢负责统一调度。本计划书第四章所述的物理 AI 仿真平台，即为该底座的首个落地实现。上层六个方向沿"感知诊断—决策控制—进化经营"逐级递进，各层通过标准化接口独立演进。

**智能体的认知模型由两类模型协同构成**：通用视觉语言基座与风电垂类专家 LLM。

- **通用视觉语言大模型（基座）**：提供图像理解、多模态对齐与自然语言交互能力，承担图像识别、指令理解与报告生成。
- **风电垂类专家 LLM**：注入风机物理知识、控制逻辑、故障案例与运维经验，承担专业判断与决策。

通用基座保障泛化与交互能力，垂类专家保障专业性与可信度，二者协同以兼顾通用智能与行业深度。

### 1.4 落地路径：影子模式渐进部署

针对工业场景不容试错的特性，风机智驾采用源自汽车自动驾驶的影子模式（Shadow Mode）分阶段上线，以控制部署风险：

| 阶段 | 智能体角色 | 控制权 |
|:--:|:--|:--:|
| **Shadow 影子** | 与现有控制器并行运行，仅观察不接管 | 现有控制器 |
| **Guard 守护** | 输出建议，经物理安全层校验后在低风险工况选择性执行 | 混合 |
| **Auto 自主** | 全面接管，现有控制器作为热备份 | 智能体 |

物理安全屏障（超速、过载、净空等硬约束）在任何阶段均具有最高优先级，确保智能体输出不越过物理边界。

## 二、市场机遇与战略价值

### 2.1 战略定位：以稳定性驱动能源结构升级

能源结构调整是国家级战略。在"双碳"目标下，新能源需由补充电源转变为主力电源，其核心制约并非装机规模，而是**发电稳定性**。风机智驾的核心目标即为提升机组与风场的稳定性，其价值传导链条如下：

> 稳定发电时间延长 → 风场容量因子提升 → 风电可被电网信赖度提升 → 新能源在电网中的准入占比提升 → 火电/水电调峰配额下降 → 国家能源结构向清洁能源倾斜。

该链条由单机控制直接贯通至国家能源结构：

```
风机智驾（主动控制、损伤最小）
   ▼
单机稳定性、寿命提升，故障率下降
   ▼
风场容量因子提升（稳定发电时间延长）
   ▼
风电可预测、可依赖，获得更高新能源准入配额
   ▼
挤出火电/水电调峰配额，能源结构向清洁能源倾斜
```

### 2.2 稳定性是风电行业的核心瓶颈

- **风电的主要短板在于出力波动，而非发电量不足**。波动性迫使电网配置大量火电/水电备用容量，既抬高系统成本，也构成新能源占比的上限。
- **稳定性提升是新能源准入空间扩展的关键**。容量因子每提升一个百分点，均对应度电成本的下降与电网信赖度的上升。
- **在大叶轮柔性机组时代，安全与稳定高度耦合**。随着叶片长度增加、柔性增强，叶尖净空（叶尖扫塔间隙）成为强制安全监测项，净空不足将导致整机报废级事故。主动感知与主动控制既是安全刚需，也是稳定发电的前提。

### 2.3 由稳定发电向市场化经营延伸

稳定性不仅是技术指标，更是市场化经营的前提。风电正深度参与电力现货与辅助服务市场，出力稳定且可预测是获得理想结算价格的基础。该环节对应三驱动世界模型最上层的自主经营（OaaS），构成风机智驾价值链的收口：

- **电力市场交易预测**：采用市场预测模型（LSTM/Transformer 类电价预测）预判现货电价与供需走势，结合博弈论智能报价，将发电时机与出力策略转化为可优化的经营决策。
- **智能报价与调度**：以物理资产模型（机组寿命、载荷、可用容量）约束交易策略，在发电收益、部件损耗与电网结算之间实现多目标最优。
- **辅助服务与碳资产**：稳定可控的出力使风场具备参与调频、调峰等辅助服务市场的能力，并可协同管理碳资产与绿证，将稳定性转化为多元化收入。

由此形成经营闭环：主动控制提升发电稳定性，稳定且可预测的出力提升市场化收益，收益进而反哺机组健康管理与控制优化。稳定性是该闭环的核心驱动，也是国家能源战略落地的技术支点。

### 2.4 技术范式的成熟度

汽车自动驾驶已在高安全性、长尾工况场景中验证了"端到端 + 世界模型 + 影子模式"技术路线的可行性。风电机组运动学复杂度显著低于汽车，而物理约束同样刚性，具备迁移该成熟方法论的充分条件。该路线为经过验证的技术范式，其目标市场为万亿级规模的清洁能源产业。

## 三、产品路线图

产品按"由部件到整机、由整机到风场"的路径分三阶段推进，各阶段均可独立形成商业价值。

### 3.1 阶段一：风机部件级（当前阶段，已有产品与技术积累）

聚焦单个部件的感知与健康评估，交付可独立采购、快速变现的软硬件产品：

- **叶片净空监测**：机舱底部净空相机结合物理保真视野仿真，直接量测叶尖扫塔间隙，对应刚性安全需求，为首款落地产品。
- **叶片表面缺陷检测**：基于视觉识别叶片分层、裂纹、结冰与腐蚀。
- **叶片载荷分析**：由可测信号反演叶根与叶片载荷分布，为疲劳评估提供输入。

部件级产品需求刚性、决策链条短、单点即可变现，是切入客户并积累真实运行数据的入口。

### 3.2 阶段二：风机整机级

将部件级感知升级为整机级自主控制：整合单机多模态感知、全生命周期健康评估与主动偏航/变桨控制，实现"感知阵风—主动规避—损伤最小"的单机闭环，并进入影子模式验证。

### 3.3 阶段三：风场级

由单机控制延伸至风场协同优化：通过尾流偏航（wake steering）等场级策略，引导上游机组主动调整以优化下游机组来流，实现全场发电量与稳定性的联合最优。该阶段是容量因子提升的最大杠杆所在。

```
阶段一 部件级 ──► 阶段二 整机级 ──► 阶段三 风场级
叶片净空/缺陷/载荷   单机主动控制       风场协同、容量因子最优
（已落地/进行中）    （影子模式验证）    （终极价值兑现）
```

## 四、技术基础：已实现的物理 AI 仿真平台

项目已建成风机智驾的物理仿真底座，即一个物理保真、几何与真机一致、支持反复安全试错的数字风场。当前已实现并验证的功能包括：

- **物理保真数字镜像**：真实机组几何重建、柔性叶片实时变形、叶尖净空真值计算与尾流可视化。
- **双物理后端**：FAST.Farm（场级动态气弹与多机尾流）与 FLORIS（场级稳态尾流），支持高低保真配合使用。
- **多模态感知体系**：八路传感器，并强制标注三级保真度（直读/导出/合成），确保数据来源可溯。
- **净空相机产品原型**：机舱相机安装位姿、挂机点位库与物理保真视野，对应阶段一首款硬件。
- **强化学习与安全约束层**：已跑通 PPO/MAPPO 训练，并验证尾流偏航可带来约 +5.5%（约 178 kW）的场级发电增益。
- **交互式仿真平台（Studio App）**：集成场景配置、手动摆位、实时训练与安全约束监控。

### 4.1 物理约束在后端求解器中的引入方式

平台的可信度源于物理约束直接嵌入后端求解链路，而非事后附加。其机制分为两层：

- **求解器本体即物理模型**：后端（如 FAST.Farm）依据气动、结构、传动的控制方程与守恒定律求解，输出的功率、载荷与变形天然满足第一性原理，而非数据拟合结果。
- **约束层与求解器紧耦合执行**：在求解器与执行机构之间设置约束校验层，将真实物理约束代码化，包括偏航电机散热占空比、桨距指令下界语义、外部转矩顶替包线与转子超速限值。任一智能体动作在下发前均须经过该层校验，越界即被修正并记录。该层构成决策—控制回路中安全屏障（CBF 类）的雏形。

此外，机组几何全部取自真实设计数据，渲染与物理计算共享同一套几何常量，确保可视化结果与求解对象严格一致。

### 4.2 平台的商业化演进路径

物理 AI 仿真平台自身构成一条可独立造血的产品线，分两步递进。

**第一步：开源的通用风机仿真器（当前阶段）**

先将平台构建为通用仿真器并开源：

- **参数化建场**：以参数化方式搭建真实风场的地形环境、风机 3D 模型与机组坐标位置，支持快速复现目标风场。
- **产品级预演**：借助物理 AI 后端求解器对机组进行产品级预演（点位选择、姿态设置、视野评估、净空计算、控制策略验证），在真机部署前完成数字风场验证。
- **开源策略**：以开源方式建立生态、聚合数据、确立标准，推动求解器与坐标体系成为行业事实标准，为后续商业化及智能体训练积累场景与用户。

**第二步：商业化订阅的高保真平台**

在通用底座之上构建更精细、更专业的付费版本，以订阅方式交付：

- **精细化建模与丰富物理输出**：持续将风机控制与健康监测相关的物理模型与方程融入后端求解器（如传动链动力学、执行机构模型、场级尾流协同；叶片疲劳损伤累积、应力与裂纹扩展、部件寿命退化），提升可导出物理参数的数量与精度。
- **多传感器机位物理仿真**：支持在机组外表面与内部任意布置多路传感器机位，并物理保真地输出各路传感器数据，使客户在硬件采购前即可验证传感方案的可测性。
- **风机内部结构仿真**：支持机舱布局等内部结构的仿真，将建模范围由外部几何延伸至内部空间，服务更专业的设计与运维需求。

底座的物理保真度与精细度越高，为智能体提供的真值越可信，影子模式落地时的 Sim2Real 差距越小。开源通用器负责聚合生态，商业订阅版负责兑现价值，二者相互供血，共同支撑三驱动世界模型的持续演进。

## 五、核心竞争力

- **物理约束为底、专家可验证**：全部设计均基于物理约束并经风电专家验证，坚持对近似模型的诚实标注，避免不可验证的虚假精度，构成工业场景应用 AI 的前提。
- **技术范式已获验证**：端到端、世界模型与影子模式已在汽车自动驾驶领域跑通，项目将其系统性迁移至风电，并以物理仿真底座补齐安全试错环节。
- **各阶段独立变现**：由部件级产品切入，以真实收入与真实数据反哺整机及风场级智能体训练，形成"产品—数据—模型"的正向循环。
- **跨行业可迁移**：三驱动世界模型方法论不限于风电，可迁移至数控机床、机器人、航空发动机等高价值工业装备，风电为首个落地场景。

## 六、总结

风机智驾的目标不止于单机发电量的提升，而在于将风电稳定性提升至可支撑电网主力电源的水平。稳定性提升带动容量因子提升，进而提升新能源准入占比，最终推动国家能源结构优化。

项目由刚性最强的部件级安全需求切入，以物理保真、专家可验证的世界模型底座为支撑，沿"部件—整机—风场"三阶段稳步推进，并以影子模式实现安全落地。该路径兼具科研深度、清晰的商业路径与国家能源战略契合度，具备长期发展价值。
