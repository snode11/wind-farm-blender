# T1 叶尖挠度对照 · 0.3.1 本地更新

## 实现与定义

基于最新 0.3.0 回放升级到 0.3.1，只增加 T1 的 B1/B2/B3 对照，默认 B1。原三机几何、遥测、净空结果与时间轴保留；没有重跑 FAST.Farm。

- 灰色虚影：同一时刻的未变形叶片，独立使用输入几何、偏航、方位角、预锥角、轴倾角和变桨角计算。
- 橙色实际点：结构叶尖局部坐标 `(0, 0, TipRad)`，作为独立参考顶点经过实体叶片相同的逐截面形变流程；从 Blender 网格世界坐标读取。原收尖顶点仍处于最后一个顶点，现有彩色轨迹继续跟踪它。
- 参考点不通过“实际点减挠度”生成。仿真挠度只进入最后的比较函数，不能影响任一坐标。
- 向量投影采用 ElastoDyn 未变桨的预锥坐标 `xc/yc/zc`，分别对应面外、面内和轴向。不能把变桨后的叶片局部轴误当成 `OoPDefl/IPDefl` 的输出轴。
- 总位移是三维两点距离，区别于面外分量。轴向本次没有保存输出，只显示坐标差得到的分量，不制造仿真数值或误差。
- 原数据为 40 Hz，画面为 60 Hz。插值帧同时对几何和数值插值，刚性参考用插值姿态独立重算，面板标明“插值帧”，不强行消除残差。
- 加入“叶尖对照特写”，跟随所选 T1 叶片，保留当前播放进度；原 T1 Down、侧前方与全景入口继续可用。

公式依据实际记录的 OpenFAST v3.5.3：[CalcOutput](https://github.com/OpenFAST/openfast/blob/v3.5.3/modules/elastodyn/src/ElastoDyn.f90#L744-L755) 及同文件第 6144–6156 行坐标定义。本地留存源码摘要可从 evidence 内文件计算。

适用范围由导出器检查：固定塔架及平台、三叶片、相同预锥、初始零变形/零姿态，原始输入与显示标量一致。同次记录只有实际 BlPitch1；导出前检查三个命令全程一致，使用该算例的集体变桨假设。此假设已写入 sidecar，不能直接用于独立变桨或柔性塔架算例。

## 已运行验证

环境：Blender 5.2.1 LTS，内置 Python 3.13 / NumPy 2.3.4。

- `blender_frontend/tests/test_tip_deflection.py`：5 项通过。覆盖完整 2401 保存帧 × T1 三片 = 7203 个叶尖，独立抽查原始 VTP 在 117/147/177 秒的 SHA-256 与重拟合坐标、刚性零变形、变桨轴、篡改仿真数值不影响坐标、损坏/缺失数据。
- 保存帧全片段基于独立几何计算的最大绝对残差：面外 **0.003368 mm**，面内 **0.049164 mm**。这说明该回放映射和输出一致，不是现场测量精度或求解器收敛精度。
- `blender_frontend/tests/blender/tip_deflection_regression.py`：实际网格、B1/B2/B3 切换、显示开关、T2 视角下 T1 继续同步、寻址、固定时钟、特写跟随、保存重开与清理通过。抽查保存帧网格最大残差面外 0.003768 mm、面内 0.039608 mm；抽查插值帧最大残差面外 0.259785 mm、面内 0.097483 mm。未把抽查称为逐帧 Blender 全片扫描。
- `blender_frontend/tests/blender/mappo_demo_regression.py`：原三机播放、遥测、保存重开、缺包恢复回归通过。
- `blender_frontend/tests/test_extension_package.py`：2 项通过，包括字节可重复打包、完整性与隔离导入。
- 本机安装目录与 ZIP 各文件一致；安装前备份路径见 `installation.json`，安装后独立 Blender 回归见 `installed-checks.json`。
- Blender 退出仍有原有少量未释放内存提示，未发现 Python 回调异常；稳定播放帧率未作专项验收。

## 使用

沿用原启动命令，或双击便携目录里的“打开三机叶片回放.command”。右侧 N 侧栏 → MAPPO → T1 · 叶尖挠度核对：选 B1/B2/B3，勾选虚影，点击“叶尖对照特写”。表格显示仿真、坐标差和两者有符号偏差（mm），暂停/单步/拖动进度同步。

当前数据仍为 REVIEW_ONLY；没有新增物理精度认证。

## 实际窗口验收

从本机实际安装扩展启动（见 `window-runtime.json`），通过原生窗口操作核对 B1/B2/B3、虚影开关、特写、播放、停止与复位。播放时仿真时刻、位置差和读数同步变化；最后停在 117 秒 T1 B1。为突出对照，当前窗口关闭原有彩色轨迹显示，用户可随时重新开启。

修复透明虚影给实体叶片造成的抖动阴影；特写观察方向包含径向分量，使面外/面内分量在画面中能够区分。关闭对照图层时特写仍跟随实体叶片，该边界已补充回归。
