# MAPPO 面板布局整理 · 0.3.2

本轮为纯 UI 调整，复用 0.3.1 数据与算法，没有运行仿真或重算挠度。

## 布局

顶部共享播放/暂停、单步、复位及进度，统一显示仿真时刻。下方三页：

- **挠度**：T1 B1/B2/B3、叶尖/叶轮/Down 视角、虚影和轨迹开关、面外/面内仿真与坐标差及偏差、总位移。图例、轴向读数、参考点定义和计算说明放在“图例与计算口径”。
- **净空**：当前机组的雷达 B2 测距、净空与误差；测量年龄和无效状态保持原逻辑，统计按需展开。
- **工具**：视角/云台、遥测/曲线、画面/环境、截图/录制、数据来源/重新加载。各组默认折叠。

常驻“加载 Demo”移入工具页，仅在没有回放时显示启动按钮。常用播放/暂停与复位承担主要操作，原“从头重播”仍在数据工具中。切换页面只改变面板，保持相机、时间和播放状态。

## 验证

Blender 5.2.1 LTS，内置 Python 3.13。

- 源码 `blender_frontend/tests/blender/mappo_demo_regression.py` 通过：三机数据、播放、遥测、缺包恢复，以及三个页面的全部控件解析；切页保持时间和相机，保存重开保留所选页。
- 同一回归从本机实际安装目录通过，见 `installed-regression.log`。
- `blender_frontend/tests/test_extension_package.py` 两项通过：字节可重复构建、清单完整性和隔离导入。
- 实际窗口已检查三页切换及紧凑挠度页，常用控件和完整数值表在面板上半部可见，计算口径折叠。
- 安装 ZIP、本机与便携运行时逐文件一致；物理数据文件和数据 manifest 与 0.3.1 一致。

本轮未重跑物理数值验证或性能基准。Blender 退出仍打印此前已有的少量未释放内存提示，没有 Python 回调错误。

安装备份、文件摘要与路径见 `installation.json`。窗口保留 T1 B1 / 117 秒，位于“挠度”页。
