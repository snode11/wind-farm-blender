# 预弯改型：模型与接口记录

这是基于 NREL 5MW 的预弯改型，数据为 REVIEW_ONLY 仿真演示。不是未经修改的官方基准，也不宣称等效于某台实机。本轮不交付弹性扭转专项功能。

## 物理输入及来源

- 迎风预弯：从叶根起的展向坐标 z∈[0,61.5] m，x=−(z/61.5)² m，y=0，叶尖偏移 −1 m。BeamDyn 的 49 个几何关键点与 AeroDyn 的 19 个截面分别设置，后者在原气动中心偏移上加预弯。
- 来源：[Jonkman 2016 年 NREL 5MW 预弯示例](https://forums.nlr.gov/t/pre-bended-sweep-blade-simulation-with-beamdyn-aerodyn-15/1268)。源附件、固定提交的 OpenFAST r-test 输入及 SHA-256 见 `reference/sources.json`。
- 保留原 −2.5° 迎风预锥，作为明确记录的改型组合。预弯、预锥、受载变形分别保存；静态预弯不记入挠度。
- BeamDyn 截面质量/刚度的 6×6 矩阵来自固定 r-test 提交的 `NRELOffshrBsline5MW_BeamDyn_Blade.dat`，49 个截面；阻尼类型 1，六分量系数 0.001、0.001、0.001、0.0014、0.0022、0.0022。未为了画面修改刚度、质量、阻尼或求解器自由度。
- 原生 OpenFAST/FAST.Farm 3.5.3；BeamDyn 接管叶片，ElastoDyn 保留塔架等结构。短例 0.00625 s 可运行；三机同一步长启动不收敛，完整三机改用 0.0015625 s，控制器仍为 0.00625 s。成功运行不代表时间步收敛认证。

## 贯通合同

| 环节 | 定义与检查 |
| --- | --- |
| 时间 | 求解保存 40 Hz，秒；回放 60 Hz 固定时间轴，FPS 仅改变墙钟目标速度。非保存时刻为插值，不冒充求解点 |
| 编号 | 完整包 T1/T2/T3，各叶片 1/2/3；短例包明确只有 T1，禁止复制成三台 |
| 坐标 | 每台机组的世界轴，z 向上，位置单位 m；场景整体布局平移最后加一次。机舱和塔架运动已包含在截面变换内，不再次叠加到叶片世界点 |
| 结构与气动节点 | 49 个 BeamDyn 参考关键点、单元阶次 5；19 个 AeroDyn 表面截面，每截面 399 个轮廓点。二者不按索引一一对应 |
| 几何导出 | 每气动截面用独立未受载参考 VTP 对当前 VTP 拟合刚体变换；截面几何残差必须 ≤2 mm。显示使用原有平滑网格，先加相同预弯，再按展向分段插值变换 |
| 未受载参考 | 单独的零重力、无入流、静止转子求解。BeamDyn 首个受载帧已有预平衡挠度，不能作参考。参考曲线、参考表面、输入源哈希独立保存 |
| 挠度 | 结构参考点局部坐标 (−1,0,63) m；实际点由末截面变换输运。参考点由独立预弯形状与同刻机舱/方位角/桨距计算。差值投影到含变桨的根系 xyz，对照 `B1/2/3TipTDx/y/zr`，全部机组分别验证，容差 5 mm |
| 旧挠度 | v1/v2 仍用 ElastoDyn 无变桨锥坐标与 OoP/IP 两分量，不能仅改名套用到 BeamDyn |
| 雷达 | 安装位置 (−2,0,87.6) m 与三束标定方向随机舱变换输运；射线对全部叶片、移动塔架和地面取首交。未命中目标叶片不填零、不补真值 |
| 净空真值 | 改为末截面轮廓表面与同一全局高度塔壁的最小水平距离；保存叶尖与塔壁见证点。求各轮廓线段与塔面三角形在相同高度约束下的最短距离，包含边内点，不只是最近顶点。不是整叶片三维碰撞检测 |
| 轨迹 | 显示网格的稳定收口尖端；是运动辅助线，与结构挠度点、净空表面点分别定义 |
| 估算/卡片 | 固定标定公式只接收同刻有效斜距；卡片保留最近有效 B2 的估算、真值、误差与年龄；7 m 明确为演示报警阈值，解除回差 0.1 m |
| 包格式 | 新 `wfrl.farm-flex-review.v3`，新增 `blade-reference.json`、独立参考表面与三分量挠度侧文件；哈希绑定模型/曲线/几何/塔架/时间。旧 v1/v2 仍可读；未知模型、曲线、坐标约定或损坏文件报错 |

## 对照、取点及窗口决定

A/B/C 单机短例使用相同 8 m/s 恒定风、规定 9 rpm、初始条件和 6 秒启动段。A→B 用于识别更换结构模块的差异；B→C 用于识别预弯差异；见 `ABC-short-comparison.json`。不能把这组启动段直接与旧风场 MAPPO 段解释为同输入控制收益。

原包独立登记于 `baseline-A.json`，不覆盖。原包关键经过帧中，中心/最近表面顶点最大差异约 0.186 m，8 帧改变 7 m 分类，超过冻结的 0.05 m 取点容差。因此新包采用末截面表面定义，旧中心真值保留为诊断字段。

旧包 ±15° 诊断没有增加任何有效 B2 命中；三个机组的有效数分别仍为 18/48/48。扩大窗口只增加预期样本分母。新包继续先用 ±3°，对 ±15° 独立统计。最低净空帧没有 B2 命中的，明确计为测量盲区，不以真值填充。

冻结指标见 `acceptance-budget.json`；是否需要估算补偿以完整新包的同一定义、同一样本误差为依据，不能以换模型前后差异冒充补偿收益。

## tip 脚本的边界

已检查 `wfrl/viz/tip_geometry.py`：像素反解用固定轮毂—叶尖半径约束，角速度预测也使用固定半径圆轨迹；其截面净空采用静态塔半径。这些假设不能直接代表预弯、受载叶片与移动塔架。新回放不进入这两条近似路径，直接以已导出的三维截面变换跟踪网格尖端；保留旧脚本作原用途，不宣称它已具备 BeamDyn 反解能力。
