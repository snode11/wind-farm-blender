# WFRL Blender 0.3.7 · 四相机观察与图像采集

本版汇总 0.3.5 发布后的相机研发、原生观察窗口、布局与视频输出改动。此前的 0.3.6 为本地迭代，本次统一以 0.3.7 发布。要求 Blender 5.2+。

## 更新内容

- **T1 四台独立相机**：C1–C4 支持表面选点或研发坐标安装，独立设置位置、Yaw/Pitch/Roll、水平/垂直视场和输出尺寸；支持草稿确认/取消、参与开关及最近 20 步相机专用撤销。
- **原生单路与四路观察**：独立 Blender 窗口共享场景与回放时间，保留材质、草地纹理和颜色管理。退出后释放临时观察相机。旧离屏四格自动刷新入口已移除，单路精确预览与按需原图导出保留。
- **同刻原图与时间序列采集**：按参与相机导出 PNG，记录双 FOV、内外参、仿真时刻、来源哈希和布局；完整组提交，取消/失败保留明确的不完整状态，并恢复回放状态。
- **布局导入导出**：导入前显示四槽替换摘要，确认后一次提交；失败回滚、无变化不记历史。随发布提供同一片 B1 叶片的四段固定相机试用布局 v2。
- **Blender 内的视频输出**：MAPPO 视频页支持现有 MP4 原样导出及 RTSP 循环推流；视频与工具路径可配置，停止、载入文件及卸载时回收本插件进程。推流使用已生成视频，不随当前视口或云台改变。
- **修复与兼容**：修复扩展启用时过早读取场景导致的注册失败；完善相机编辑、提交失败回滚、撤销、导入状态及窗口关闭清理；原 Down、机舱相机、三机回放、净空/挠度和叶尖轨迹继续保留。

## 安装与布局

从下方 Assets 下载 `wfrl_blender-0.3.7.zip`，在 Blender 的 Install from Disk 中安装并启用，再重启 Blender。不要选择自动生成的 Source code 压缩包。ZIP 内置三机 MAPPO 60 秒回放，离线播放无需仓库、后端 Python、MPI 或 FAST.Farm。

试用四段布局时，另下载 `T1-same-blade-four-cameras-v2.json`。加载 MAPPO 后，进入 N → View → 采集设置 → 导入布局 JSON，核对替换摘要并确认；暂停在第 1 帧 / 117.0 s，再打开“四路对照”。导入不自动跳转时间，也不会自动预装四台相机。

RTSP 需要自行配置 FFmpeg 与 MediaMTX；扩展不包含视频母版及这两个工具。MP4 原样导出不依赖外部视频工具。

## 已知限制

- 四路播放仍会掉帧。此前 Apple M5 Pro / macOS / Blender 5.2.1 LTS 的最终布局短测约每秒 7.09 次有效画面更新；这是视口回调统计，不是显示器呈现 FPS，也不是性能保证。默认画质未降低。
- 四段布局用于同一叶片经过特定方位时的分段观察，不持续追踪或锁定叶片身份。最内侧叶根未完整呈现，叶尖路与中外段有重叠；12 个同方位样本不代表连续全周期或整片表面无盲区。
- 内置物理结果沿用已发布的预弯 v3 数据，仍为 REVIEW_ONLY；固定三束雷达覆盖率验收未通过。未重跑 FAST.Farm，不代表现场测量或真实硬件安装认证。
- Windows/Linux 实机、长期稳定性和完整人工交互验收未完成。相机原图采集需要有效 GPU 窗口上下文。
