# 阶段 1、2：统一输入和重建诊断

本目录为新验证证据，未改写 `outputs/blade-recon-v02-audit-20261007-a01` 或旧输入/结果。

实现：`blade_recon0.2/input_adapter.py`、`recon.py`、`tests/test_input_recon.py`。`input_adapter.py` 使用独立模块命名空间复用同级 `blade_recon/input_bundle.py` 的声明文件、原图尺寸、刚性 MODEL→CV、RGB/掩码和禁止真值路径校验；因此执行 bundle 模式时必须保留同级旧 `blade_recon` 目录，不应以 v0.2 覆盖旧目录。

`InputSequence` 同时用于几何和纹理。bundle 使用真实帧号/时间和该帧相机，静态旧视频需要每路一致帧数/FPS/原图尺寸及均匀呈现时间，帧目录需要一致数字文件身份。显式掩码按真实帧号寻找，缺失、坏文件、错误尺寸不退回自动分割。自动分割只在没有声明掩码时使用，输出记录极性、最低对比度和面积阈值。`--max-frames` 的 bundle 模式使用临时限定声明目录，只读选定前 N 帧，不读取邻近真值；原目录不写入临时 manifest。完整 bundle 默认沿用旧 loader 的全部显式载入。

`reconstruction_status` 区分 `no_observations`、`prior_prediction`、`unidentifiable`、`prior_assisted`、`image_constrained`。`reconstruction_valid` 仅表明求解器终止成功且存在局部图像约束；每帧 `geometry_acceptance=NOT_EVALUATED`，不代表全局唯一性、真值精度或现场验收。`observation_std` 根据不含先验项的图像雅可比计算，零空间/未观测方向为 JSON null；`posterior_std` 单独包含时序和物理先验。`std` 仅在图像方向均有限时提供，保留严格旧读取器兼容性。有限状态允许无观测先验展示，但不可视为有效观测。保存完整求解器 success/status/message/optimality。
