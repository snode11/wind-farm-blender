# 健康模板合同实现与静态验证

2026-10-07，本组件是第4项候选实验的健康模型支持，不单独宣布实际几何或纹理验收通过。

## 实现

生产改动为 `blade_recon0.2/model.py`、`input_adapter.py`，新增 `tests/test_healthy_template.py`。默认解析 NACA 模型与默认配置输出字段保持原合同。只有输入显式声明健康设计时，才启用严格 `blade-healthy-loft.v1` 固定设计；没有增加求解状态自由度，仍为既有13维位姿/全局振型模型。

实际已有 MAPPO 输入仅声明了40×32解析近似及 `prebend_tip_m=1.0`，没有设计翼型坐标。新资产从仓库规范静态 `nrel5mw_geometry.json` 设计坐标建立，读取8组翼型及19个 AeroDyn 设计站，按固定环编号进行设计采样和形状保持插值。资产不读取 `geometry.npz`、回放姿态、变形网格、对象ID、缺陷坐标或源贴图。源码及资产版本记录在 `identity.json`。

输入 MODEL 坐标沿用实际采集明示的 native WORLD x/y 翻转。原 source 上表面注册为 suction，下表面注册为 pressure；固定环倒序后保持算法 TE→pressure→LE→suction 的环身份。AeroDyn 的 curve、sweep、reference 和结构扭角全部写入固定截面偏移，避免解析近似及扭角符号合同差。固定偏移不含额外 BeamDyn 1m reference prebend；该项由输入已声明的 `prebend_tip_m=1.0` 加一次。健康模型让此 reference 随 pitch 旋转，匹配 native rest design→pitch 变换；默认解析模型维持其既有行为。

固定资产采用40个径向环与32个周线点。保留18个原设计站及63m标称终点，其余环在设计站间固定细分。源末站为62.9999m，标称终点相差0.1mm；用1微米终环近似展示用途的尖端 apex，以满足现有封闭环 Atlas 合同。这一展示尖端近似没有接受为局部缺陷或深度测量模型。

## 显式输入与重放

将 `assets/healthy-loft-40x32.json` 复制到新输入目录内，在 `input_bundle.json` 顶层添加：

```json
"healthy_template": {
 "path": "healthy-loft-40x32.json",
 "sha256": "83116a84c242518c24a81f0195a1be62f4fec4c9e502f70aa9b845675d0d2008"
}
```

`InputSequence` 要求声明路径留在输入根目录内，拒绝 evaluation/truth/object_id/geometry.npz/source-surface 等答案路径及解析后指向这些路径的符号链接，核对文件字节SHA并记录 `explicit_fixed_healthy_design` 访问。原 legacy 输入验证器继续核对其原字段，未放松RGB、mask、时钟、相机或未知域校验。

`cfg.to_dict()` 将固定 payload 与规范JSON SHA内嵌在 `turbine.healthy_template`、`turbine.healthy_template_sha256`。`Rotor(TurbineConfig.from_dict(...))` 可以独立重建同一健康模板，无需读取外部源资产。payload SHA为 `26d68880988d58cffd60d73b3b574b9e976d2817a7fd328069f8b01f156d15f1`。这支持外部算法的独立 Blender 网格生成；已有安装扩展的内置解析 reader 未在本组件中更新，不能据此宣称安装 reader 支持健康模板。

## 已运行验证

`regression-results.json` 保存最终源码SHA及24项组件回归日志：6项新的显式健康模板合同、16项既有输入/图像可辨识性/数值合同、2项既有全局状态与旧API合同，全部通过。新测试覆盖JSON内嵌重放、默认合同、固定参数化、reference prebend随pitch、维度/内容hash/动态额外字段/非有限值拒绝、声明输入访问记录、truth符号链接拒绝。

`static-design-comparison.json` 使用独立设计站公式及独立 native矩阵链核对，不做 ICP、最近点、平移/旋转或形变拟合。三个原设计站同固定弦向样本/pressure-suction分支的健康模型最大误差≤1.39e-17m；三种设计姿态×三个站的native matrix最大误差≤2.85e-14m，固定设计坐标合同通过。Atlas metadata有效，3×40×32顶点有限。

| 径向站 | 旧解析固定设计坐标差 P95 | 新健康固定设计坐标差 P95 |
| --- | --- | --- |
| 40.45m / DU21 | 0.5364m | 0m |
| 44.55m / NACA64 | 0.4519m | 0m |
| 56.1667m / NACA64 | 0.3044m | 0m |

本表包含设计reference、curve/sweep、结构扭角符号、翼型与截面采样全部坐标差。它与旧复核仅按归一化弦向比较翼型外形的0.113/0.073/0.056m P95不是同一个指标；也不是实际动态拟合后的误差、最优下界或指定缺陷点误差。不能把静态模板差消失表述为actual几何通过。

## 可复现命令

从实际 Git 根目录 `REPOSITORY_ROOT` 运行：

```bash
blade_recon/.venv-trial/bin/python outputs/blade-recon-v02-stage4-20261007-a01/healthy-contract/build_healthy_template.py
blade_recon/.venv-trial/bin/python outputs/blade-recon-v02-stage4-20261007-a01/healthy-contract/verify_fixed_design.py
blade_recon/.venv-trial/bin/python -m unittest discover -s blade_recon0.2/tests -p 'test_healthy_template.py' -v
blade_recon/.venv-trial/bin/python -m unittest discover -s blade_recon0.2/tests -p 'test_input_recon.py' -v
blade_recon/.venv-trial/bin/python -m unittest discover -s blade_recon0.2/tests -p 'test_full_model_state.py' -v
```

构建脚本只使用本目录冻结静态JSON及当前规范 `turbine_geometry.py` 的纯设计采样/插值函数。复现时应核对 `identity.json` 记录的规范模块SHA；若发生后续变更，不能将新输出当本次冻结资产。未启动FAST.Farm、未操作任何Blender窗口。

## 尚未由本组件验收

固定设计的 r/ring 与 Atlas 材质参数在模型内部持续不变；它尚不证明实际动态source健康三角面与图像异常特征已经建立不可重置的跨帧身份。没有以nearest-source或源缺陷坐标建立观测，也没有填补实例未知域。13维全局振型仍不覆盖任意逐截面动态回放变换。实际Patch/Crack、留出相机、对应原像素误差、指定点几何可辨识性和纹理质量，需看root随后同输入轮廓/纹理候选消融及独立评分；本静态PASS不能替代这些门槛。
