# 旧布局状态：不符合当前观察目标

2026-09-23，用户明确要求最多四台相机分别观察同一片叶片沿长度方向的不同区域。

本目录的 `T1-four-cameras-v1.json` 将 C1–C4 分别指向叶轮上、右、下、左四个方位，这是此前对目标的错误理解。该文件及桌面同名副本保留用于复现历史测试，**不再作为推荐布局或满足需求的方案**。此处仅更正文件状态，没有篡改旧 JSON、旧采样记录或用户已安装的相机参数。

`validation.json` 中的 `import_validation: PASS` 仅说明当时导入检查通过，不证明观察区域正确、同一片叶片的各段可见，或全旋转周期覆盖达标。

新 [同一叶片分段试用布局 v2](../camera-layout-same-blade-v2/README.md) 已按实际机舱表面和 B1 叶片形状重新计算，提供真实四路截图、12 个同方位经过时刻的采样检查和安装版播放记录。请测试 v2 JSON；它采用固定机舱相机，参考第 1 帧／117 s，不提供全程自动跟踪。
