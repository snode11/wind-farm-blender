## 保留 A02 表面的结构点假设

历史 v2 模型是从 RGB 拟合的静态加载形状，参考时刻为 122.175 s，即帧 43。A03 没有重新拟合它的弦长、厚度、扭转或中心线，也没有把静态模型改写成独立卸载参考。原有 `DynamicBladeReference` 继续提供所有 q 候选的表面、气动参考轴和最小旋转场。

计算前，静态白名单适配阶段生成了 [`dy0/static_prior.json`](../inputs/structural-prior/static_prior.json)。它保存同一材料站位的 `station_m`、`aero_reference_B_m`、`structural_reference_B_m`、`aero_twist_deg` 与静态来源哈希。适配后的终端材料站位统一为 61.5 m：气动轴的 61.4999 m 末端横向坐标常值延伸至 61.5 m，两条轴均使用 z=61.5 m，没有把两个近重复端点同时当作独立材料站位。估计器只读取这份导出的静态先验，不打开其源静态容器或源动态状态。

设源静态气动轴与结构轴分别为 a₀(s)、b₀(s)，其差为 δ₀(s)=b₀(s)−a₀(s)。A03 在同一材料 s 上插值，使用：

```text
Fsrc(s) = Rz(源静态气动扭转)
h0(s)   = Fsrc(s)^T · δ0(s)
Fv(s)   = Rz(v2 模板固定扭转)
bref(s) = av2,ref(s) + Fv(s) · h0(s)
bq(s)   = av2,q(s) + Qq(s) · Fv(s) · h0(s)
```

其中 Qq(s) 来自既有**气动参考轴切向**的最小旋转。A03 没有将它声明为机械中心线切向的法截面，也没有从 RGB 估计扭转。源静态偏移以米为单位保留，不随拟合弦长缩放。这是清楚声明的几何／运动学结构点假设，不能代替 BeamDyn 材料对应或机械识别。

围绕这个结构轴重新表达截面时，表面满足：

```text
Vq = bq + Qq · (Vref − bref)
   = av2,q + Qq · (Vref − av2,ref)
```

因此选择结构点定义不改变 A02 可见表面。实现直接保留既有候选表面数组，并核对上述等价表达：本轮 441 个 q 状态全部检查，最大差为约 `7.11e-15 m`；q=0 的表面数组与冻结 v2 表面严格相同。核对结果保存在 `sequence.json.surface_cache_identity`。

包中的 `point_world_m` 是 bq(61.5 m) 经同一刚性根部位姿变换后的候选结构点，不是环形截面质心，也不被声明为已经验证的源结构叶尖。距离始终由这个点、同一时刻的理想刚性平面中心和法向共同计算：

```text
d = n · (point − center)
foot = point − d · n
```

`d_m` 为有符号点到平面距离，`abs_d_m` 为其绝对值；不能直接解释为已验收的物理净空。

## G1、G2、G3 与固定运动学先验

| 组 | 本轮估计行为 | 记录状态 |
| --- | --- | --- |
| G1 | 冻结 v2 参考和同一刚性位姿；四帧均 q=(0,0) | `PRIOR_DEFINED_BASELINE` |
| G2 | 使用与 G3 相同的状态网格、锚点、运动学先验和 DP 预算，关闭当前序列图像成本 | `PRIOR_ONLY_AMBIGUOUS` |
| G3 | 使用同一模型和 DP，开启 A02 缓存的三相机等权图像成本 | 帧 42/45 为 `PRIOR_ASSISTED_AMBIGUOUS`，43/44 为 `IMAGE_CONSTRAINED_AMBIGUOUS` |

G2 关闭的是本轮序列目标中的图像项。三组共用的历史 v2 静态参考本来就来自 RGB，不能把 G2 描述为“从未使用图像”的对照。全部四帧均为已查看的非盲开发样本。

每个 q 分量在 −0.5 至 +0.5 m 内，以 0.05 m 为间隔，得到每帧 21×21=441 个状态。帧 43 固定为 q=(0,0)，名义初始化为全零序列。DP 求解完整有限状态最小值；名义初始化没有额外约束帧 42。目标函数为：

```text
G2: Σt 0.01 · ||qt / 0.5 m||²
    + Σ相邻帧 0.05 · ||(qt − qt−1) / 0.1 m||²

G3: G2 的同一目标 + Σt 图像三相机等权平均距离 / 10 native px
```

各分量的速度上限为 4 m/s，相邻实际采样中心相隔 0.05 s，对应每步各分量最多改变 0.2 m。该上限及惩罚权重只是计算前冻结的运动学先验，没有经过载荷、刚度或 BeamDyn 动力学验证。空图像项保持缺失状态，在 G3 中禁止该候选赢得零成本；不能用后端空项返回的零值当作成功拟合。

G2、G3 各评价 3×441²=583,443 个相邻状态对；优化器迭代与重启均为 0，CPU 线程为 4，冻结墙钟上限为 300 s。DP 联合使用后续帧，是离线求解，不能宣称实时或因果估计。
