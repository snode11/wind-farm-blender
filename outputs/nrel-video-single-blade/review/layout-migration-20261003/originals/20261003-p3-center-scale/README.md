## 1. 受控拆分得到的结论

从冻结的正式 v2 / T1_B1 恢复网格；`center_x/y` 是参考轴偏移，不是截面顶点均值。原模型改变弦长时，几何环中心会沿旋转弦轴移动 Δchord/4。这里几何环中心只指环顶点的算术均值。

以 z=9.225 m 处半弦长变化 a 归一化，扰动第一个自由控制系数。A 为原弦长变化，B 为同样的弦长/厚度变化但逐环扣除伴随中心平移，C 只保留该平移；X/Y 是匹配幅度的参考轴偏移。控制支持域延伸至30.75 m，本实验并非仅修改根带。

640工作宽度、fit根带固定495个观测点的结果如下。RMS 是 `(d(+a)−d(−a))/2` 的逐点均方根，距离换算到原生像素；它不是拟合后误差。

| 半弦长幅度 / mm | A：原尺度变化 RMS / px | B：保持中心 RMS / px | C：仅平移 RMS / px | [X,Y,A] 最小奇异值 / px/m | [X,Y,B] 最小奇异值 / px/m |
|---:|---:|---:|---:|---:|---:|
| 5 | 0.5655 | 0.6474 | 0.3189 | 14.599 | 14.362 |
| 10 | 1.1085 | 1.2097 | 0.6173 | 13.878 | 12.740 |
| 20 | 2.1066 | 2.1531 | 1.1648 | 10.100 | 10.525 |
| 50 | 4.3291 | 3.6942 | 2.5203 | 6.871 | 6.705 |

在5 mm幅度，B矩阵的另外两个奇异值为170.908、90.493，最小项仍明显较弱；320工作宽度复核的A/B最小项分别为11.051/11.013。非盲44/45也独立保存在子报告，未据其选择新模型。

**这些是有限差分响应矩阵的弱方向；本轮没有沿 B 的弱向量另做组合前向验证。** 5→10 mm时，A/B响应向量仍变化11.3%/21.0%，尚不能称为收敛的局部Jacobian。最小幅度下A/B各有9/12个正负相机帧配置检出采样、投影边归属或deadband等分支变化。

SVD采用 `J/sqrt(N)`，按观测点池化，受坐标单位与分组权重影响；C也除以a，尽管其目标位置实际平移为a/2。不能把条件数变化解释为增加了观测信息。几何拆分满足A=B+C至1.19e−7 m浮点误差，但图像距离非线性、非可加；不能用C/A的RMS比值估计“中心移动解释了多少误差”。

原生产双向robust轮廓项另外核验，24次最大绝对差4.47e−8。fit全图等权基线0.285658084，根带池化O2C robust基线0.035628930，二者口径不同；均不含正则，不是完整优化目标。与P2重叠的312配置，其raw O2C、固定z和双向robust图像项逐项重现，最大差均为0。[完整几何对照](geometry/README.md)

## 2. 可以怎样公平地更换坐标

逐环固定几何中心的B是网格干预。将所需补偿投影回原中心B-spline空间，8个幅度的最大环残差为 **0.111–1.123 mm**，约4%的补偿L2分量不能由原空间表达。原边界在这些投影中均未激活。它可被近似实现，但不能被称为原模型内的精确坐标变换；毫米级差别是否适合用途也没有验收依据。

Greville位置的几何中心坐标则可以保持原模型：令 `Gg=A C+Dg(ell)`，通过 `C=A^-1[Gg-Dg(ell)]` 恢复原参考轴系数。矩阵秩7、条件数3.599；本次恢复原25环中心的最大代数误差2.22e−16 m，原正则差5.55e−17。这些是浮点代数校验，非测量精度。

采用此变换时必须保留从属根节点、耦合参数域，并通过逆映射计算原正则。独立插值绝对几何中心会使同一基线的环中心最大差48.186 mm；保留模板再插值相对中心仍有2.440 mm差别。直接给新中心套旧正则公式也会改变形状先验。[模型族及正则核验](family/README.md)

## 3. 原生 RGB 定位了两种不同的轮廓缺失

原生1920×1080帧重新解码，8/8像素SHA匹配原标注。下表为根带外轮廓的模型条件诊断；“保留”只表示满足原轮廓域和同模型自遮挡检查，不表示通过了真实外物遮挡或三维精度验收。

| 相机 / fit帧 | 根带轮廓入图线长 / px | 射线可见且被排除 / px | 射线可见且原域保留 / px |
|---|---:|---:|---:|
| C1 #42 | 894.243 | 450.877 | 362.657 |
| C1 #43 | 875.395 | 0 | 789.432 |
| C2 #42 | 651.240 | 11.994 | 419.707 |
| C2 #43 | 0 | 0 | 0 |

C2 #43 的7条根带silhouette边在精确图像裁剪后全部在画外。640/原生、默认/扩展采样预算均得到根带C2O/O2C零点，因此本例不能归咎于采样预算不足。上侧最接近画面的带端点仅高出边界3.275 px，这个结论限定于冻结模型、理想标定/姿态及当前根带，不能直接推广到有标定误差的场景。与此同时，z=9.225 m截面仍有部分表面入图：表面入图不等于外轮廓入图。

C1 #42 存在排除域屏蔽的根带轮廓，值得从原RGB与外物边界归属重新审核。但450.877 px是当前模型投影线长，不能直接当作可新增的正确RGB观测量。C1 #43上方肉眼可见却被排除的边界位于更内侧，不能混算进本次根带。

保存的RGB轮廓点全处于FBU不确定带U，同时满足独立的contour-valid掩膜。U本身不表示轮廓约束被删；必须检查独立的轮廓域。当前未改任何原mask或添加轮廓。[原生图、裁剪图及逐边审计](rgb/README.md)

## 4. 后续阶段的决定与证据边界

后续受控实验应将“坐标变换”和“观测修订”拆开比较。先建立可逆Greville实现的几何、原图像目标、原正则及链式梯度一致性测试，再以相同初始化、图像、参数域和计算预算比较优化轨迹。逐环B不能直接作为该实现。坐标变换可以改变有限步数优化表现，无法凭空增加现有图像信息；是否改善根部几何须另行冻结模型后评价。

观测方向优先逐段审核C1 #42被排除的原生边界，单独记录哪些确为目标叶片外轮廓、哪些属于遮挡或无法确认。通过RGB审核的候选再进入新版本观测分支及消融，不能因为更贴近当前模型就保留。C2 #43根带轮廓不在画面内，放宽mask不会补回它。现有非盲44/45也不能改称盲验证集。

P3没有建立新的几何验收阈值，没有证明完整表面恢复、唯一退化原因或工程精度；用途对应的误差和覆盖要求仍待定义。本阶段完成的是受控诊断，正式v2和原P0–P2证据继续保留。
