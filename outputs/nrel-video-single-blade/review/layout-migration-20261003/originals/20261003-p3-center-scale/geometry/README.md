## 预冻结协议与几何定义

[frozen_protocol.json](frozen_protocol.json) 和 [SHA256](frozen_protocol.sha256) 在 `_prepare` 读入真实图像标注和所有真实图像前向之前保存。协议锁定输入及 7 个相关源码文件签名、幅度、模式、区域、采样预算、比较指标和解释边界，签名为：

`8cfa43ed6a7b59b021232c9f949bf569117f6104f8ba65c601d48eba81107ca4`

从 `20261002-second/reconstruction/model_state.json` 恢复正式 `T1_B1`，与冻结 PLY 最大坐标差 **4.94934×10⁻⁹ m**，300 顶点/596 面拓扑一致。运行前后所有许可输入、依赖源码及协议签名保持一致。

这里的几何环中心是每个既有网格环全部顶点的**算术中心**，不是质量中心，也不是模型的参考轴偏移量。按连续场 z=9.225 m 的半弦长变化 `a` 归一化，扰动第一个自由控制系数 index=1；根诊断带固定为 `[6.15,12.30] m`。该控制的支持域跨越 0–30.75 m，不能把本实验理解为只修改这条根带。

在每个网格环 i 上，旋转弦轴为 `e_i=(-sin(twist_i), cos(twist_i), 0)`，原弦长扰动产生 `t_i=Δchord_i·e_i/4`。以冻结网格 `V0` 为基线：

| 模式 | 实际几何操作 | 几何解释 |
| --- | --- | --- |
| X | 原 `center_x` 控制扰动 | 参考轴 x 偏移；目标位置幅度为 a |
| Y | 原 `center_y` 控制扰动 | 参考轴 y 偏移；目标位置幅度为 a |
| A | 原 `chord_halfwidth` 控制扰动 | 截面尺度变化，同时伴随几何环中心移动 |
| B | `VA − t_i` | 去除伴随平移，围绕原几何环中心改变截面尺度 |
| C | `V0 + t_i` | 只保留 A 的伴随平移，环的尺寸/形状保持 |

幅度固定为 ±0.005、±0.010、±0.020、±0.050 m。A/B 的绝对厚度随弦长同比改变，厚弦比和截面扭转固定；C 没有尺度变化。A 在 z=9.225 m 的解析中心平移模长为 `|a|/2`。该位置是归一化连续场的位置，不是新增顶点；表中实际几何校验逐既有网格环执行。

**B/C 是网格级干预，不保证属于原七控制系数模型族。它们不是已证明等价的重参数化，也没有可直接比较的原模型正则化。** 本实验报告真实图像轮廓项，不计算或声称含正则化的完整优化目标相等。

### 几何校验

在查看真实图像响应前，按预冻结 float32 数值容差 2×10⁻⁶ m 检查全部 8 个有符号弦长幅度：

| 校验 | 所有幅度最大误差 m |
| --- | ---: |
| `(VA−V0) = (VB−V0)+(VC−V0)` | 1.19209×10⁻⁷ |
| B 几何环算术中心保持 | 8.47504×10⁻⁸ |
| C 去中心后的环顶点保持 | 9.80993×10⁻⁸ |
| C 环内两两距离保持 | 1.33276×10⁻⁷ |
| B 去中心后按同一比例缩放，保持厚弦比 | 6.06458×10⁻⁷ |
| 根端、尖端、控制支持域外、z 坐标保持 | 全部 0 |

上述浮点余量如实保留，不能把它写成精确算术相等；没有添加后验中心纠正来改变解析操作。所有模式沿用原面拓扑。

## 同一后端与固定观测集合

五种模式都使用原 `projected_contour_candidates` 后端：每幅最多 300 候选点/段、600 观测点、1 工作像素采样间隔和每条边最多 512 点。标注、不确定带、相机、刚体位姿和工作分辨率在每次对应比较中保持一致。

每个分辨率/相机/帧只在基线上分配一次观测点的 z 归属，此后固定点索引、坐标和 z。它来自最近投影边的模型条件归属，不是已知三维对应。候选点、段、遮挡、掩膜选择和候选分区仍按每个前向输出重新计算。

以逐点 unsigned O2C 原生像素距离 `d(a)` 计算有限差分 `J_a=(d(+a)−d(−a))/(2a)`。响应表中的对称 RMS 是 `RMS((d(+a)−d(−a))/2)`。SVD 对矩阵 `[J_X,J_Y,J_A]` 或 `[J_X,J_Y,J_B]` 除以 `sqrt(N)` 后计算。它们不是稳健目标的 Hessian、Fisher 信息或参数置信区间。 本轮没有沿 B 的新弱向量追加组合前向；B 的“弱方向”指预设单变量有限差分矩阵，不能转述为新的完整组合输出已经验证。

真实图像目标另行计算：先用工作像素不确定带做 `relu(distance−uncertainty)`，再用原 `distance_scale=10`、`robust_delta=2` 的 smooth-L1，C2O/O2C 两方向各自均值后各占一半。全图 fit/nonblind 组内保持每张图等权；根带 O2C 则在冻结根带观测点上汇总，两个口径明确分开。

24 个实际基线与原 `projected_contour_loss` 交叉核验，最大绝对差 **4.47×10⁻⁸**。本轮与 P2 重叠的 **312 个配置**，逐点 raw O2C、冻结 z 和真实双向 robust 图像项均逐项重现，最大差都是 **0**。

## 主比较：去掉中心联动后仍有弱方向

640 fit 根带固定 **495 点**：

| 半弦长幅度 a (m) | A 对称 RMS (原像素) | B 对称 RMS | C 对称 RMS | `[X,Y,A]` 奇异值 (原像素/m) | `[X,Y,B]` 奇异值 |
| --- | ---: | ---: | ---: | --- | --- |
| 0.005 | 0.5655 | 0.6474 | 0.3189 | 142.714 / 114.223 / 14.599 | 170.908 / 90.493 / 14.362 |
| 0.010 | 1.1085 | 1.2097 | 0.6173 | 133.634 / 113.267 / 13.878 | 157.945 / 90.090 / 12.740 |
| 0.020 | 2.1066 | 2.1531 | 1.1648 | 116.972 / 110.040 / 10.100 | 135.875 / 88.403 / 10.525 |
| 0.050 | 4.3291 | 3.6942 | 2.5203 | 94.654 / 79.177 / 6.871 | 83.366 / 79.013 / 6.705 |

保持几何环中心的 B 有明确尺度响应，但和 X/Y 联合后仍有明显弱方向。例如最小幅度下 B 的最小奇异值为 14.362，另外两项为 170.908/90.493。它和 A 的最小值 14.599 同量级；这不支持“消除四分之一弦长中心联动即可消除弱响应”。

去掉中心移动会改变列之间的相关结构，而不是带来新的图像。640 fit、a=0.005 m 时，X–A 余弦约 0.476，X–B 约 0.820；Y–A 约 0.039，Y–B 约 −0.421。不能把相关系数或条件数的变化解释为测量信息增加，尤其 B 的控制空间与原模型族不同。

320 fit 复核也保留弱方向：a=0.005 m 时 `[X,Y,A]` 最小奇异值 11.051、`[X,Y,B]` 11.013；a=0.020 m 时分别 9.595/9.488。跨尺度没有得到“B 消除了局部补偿”的证据。

640 非盲根带固定 **528 点**，a=0.005 m 的最小奇异值 A/B 为 6.253/5.984，a=0.020 m 为 6.986/6.029。a=0.020 m 的 Y–B 余弦仍约 **0.9923**（Y–A 约 0.9946）。这些是分开保存的非盲诊断结果，未用于挑选模式或新模型。

## 小幅度仍未得到稳定 Jacobian

640 fit 根带的相邻幅度变化定义为 `||J_new−J_old||/||J_old||`：

| 幅度变化 | X | Y | A | B | C |
| --- | ---: | ---: | ---: | ---: | ---: |
| 0.005→0.010 m | 23.8% | 17.6% | 11.3% | 21.0% | 13.8% |
| 0.010→0.020 m | 33.2% | 22.7% | 17.4% | 26.6% | 19.9% |
| 0.020→0.050 m | 43.9% | 37.5% | 33.0% | 43.2% | 31.8% |

更小的两档幅度给出较接近的响应，但 B 仍有约 21% 的向量变化，不能称为收敛 Jacobian。几何顶点的 A=B+C 不意味着图像距离的变化可加；图像响应 `||J_A−J_B−J_C||/||J_A||` 在四档幅度上分别为 **18.6%、24.9%、31.1%、48.3%**。因此不能把 C/A 的 RMS 比值写成“中心移动解释了多少百分比误差”。

本轮除了原计数，还保存了 silhouette edge 集合、每个观测点最近原始投影边的诊断归属及 deadband 活动状态。640 fit、a=0.005 m 的 A/B 各有 **9/12** 个正负相机帧配置检出至少一类分支变化，C 为 8/12；A/B 的根带 deadband 状态变化合计分别 61/78 次（同一点可在正负不同配置重复计数）。不能把这些变化全部归因于某一个分支，更不能以计数不变证明所有采样选择不变。

640 fit 全图等权双向 robust 基线为 **0.285658084**；根带固定 495 点的 O2C robust 基线为 **0.035628930**。它们是无量纲工作像素稳健损失，不是原像素误差，也不与 320 的数值直接比较。

例如 B/0.005 m 的负向全图图像项降低，而根带 O2C robust 略升，体现了区域/方向/均值口径的区别。本轮没有按这些结果选最优符号、幅度、模式或正式模型。无独立根部正确性证据时，局部 loss 下降也不能作为几何验收。
