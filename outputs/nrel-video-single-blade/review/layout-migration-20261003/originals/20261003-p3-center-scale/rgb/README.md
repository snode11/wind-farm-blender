## C2#43：表面入镜不等于外轮廓入镜

[完整原图](C2_000043_native_rgb.png) · [原生坐标叠图](C2_000043_native_overlay.png) · [画外投影证据](C2_000043_crop_projection.jpg)

先将正式 v2 的 front/back silhouette edges 在三维中裁到 z∈[6.15,12.30] m，再投影和裁到图像中心域 0≤u≤1919、0≤v≤1079。C2#43 共有 **7 条**根带候选边，**没有任何一条与图像相交**；入图线长严格为 0。该判定发生在读取 contour-valid、模型自遮挡、旧 backend 的 union-probe 筛选与全局采样上限之前。

- 上侧最靠近图像的带端点，z=12.30 m 时 `(u,v)=(318.450,−3.275)` px；同一条原边要到 z≈12.35542 m 才从 v=0 进入图像，已超过此诊断带上界。
- 下侧 z=12.30 m 端点为 `(396.397,1137.587)` px，仍低于画面底边；其余带内上/下边在上方、下方或左侧画外。
- z=9.225 m 截面仍有 **20/72 个周长采样点在图内，且都为模型可见 F**；周长积分估计约31.92%在图内。此时看到的是叶片表面内部，不能据此推出截面外轮廓也可见。
- unchanged historical backend 在 640/native、默认/扩展全局采样四种配置下，根带 C2O 和 O2C 数都为 0。原图没有 C1 那种人工结构排除框。故本帧的根带缺失不需要用标注排除、实体遮挡或 backend 错误解释。

以上是**固定正式 v2、声明的理想标定/刚体姿态、当前根带定义下**的确定性结果。上端仅比图像边界高3.275 px，不能把这个条件性判定推广为其它模型、帧、标定误差或不同根带也必然缺失，更不能由它单独解释全部重建误差。

## C1：下排除域中有需要重新审核的边界候选

实际看图结论：

- **C1#42 下边**：约 x=1200–1600 附近，实际 RGB 中连续的白色叶片与深色背景边界可辨，处在统一下排除框内。说明这个矩形会连同结构附近区域一起去掉一部分看起来可用的边界。模型线和实际边界并非处处重合，不能把451 px全部直接加入观测，也不能宣称恢复这段就会消除退化。
- **C1#43**：上/下排除框中仍能看到更靠内侧的清楚边界，但正式 v2 的本次6.15–12.30 m根带候选本身没有被排除。不得把更内侧的视觉候选误写成这一帧本根带缺失。
- **C1#44/45 非盲**：根带上边局部进入上排除域；可以作为解释裁域与时序变化的诊断图，不用来挑选新正式模型或宣称泛化改善。
- 这里的“可用候选”只表示人工看图值得继续精审；**没有新增可信轮廓点，没有改 valid mask，没有完成新的遮挡审核，也没有用模型投影代替 RGB 标注**。机舱、杆件、贴近结构的区域仍需逐段区别。

## F/B/U 的 U 与独立 contour-valid 必须分开

8帧保存的 **15,436 个观测轮廓点全部位于 F/B/U 的 U 像素，同时全部位于独立 contour-valid=True 的域**。这并不矛盾：F/B/U 在边缘加入一般不确定环；独立轮廓是在加入该环前保留下来的 RGB 边界，只排除明确的结构/crop审核域。旧轮廓目标已经使用独立 candidate-valid mask，所以 U 本身并不会删除这些轮廓约束。

例如 C1#42 有298个原生根带采样同时满足“精确射线可见、FBU=U、独立域有效”，C1#43为336个。若仅用 F/B/U 的 U 判定“根部都没约束”，会遗漏这些已有约束。F像素一致也只证明投影前景一致，不证明三维位置正确。

原生审计还在独立的≤1 px采样上检查了旧 backend 的0.35/0.75/1.5 px两侧 union probes。部分精确射线可见且域有效点会被这些有限半径探针拒绝（C1#42为17点、C1#43为11点、C2#42为46点）；这只是两种判据的局部差异，采样集合和浮点精度也不同，不能在本轮直接认定 fit backend 有错误或据此切换 backend。**C2#43 在探针前已无入图候选，因此其零根带样本不由这项差异造成。**
