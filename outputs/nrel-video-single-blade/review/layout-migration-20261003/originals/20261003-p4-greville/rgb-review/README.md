## 与历史域的关系

在既有 `C1_000042_contour_valid.png` 中，x=1200 的有效行是 **256–887**。保存的下方排除框从 y=896 开始，加上独立轮廓域的 8 px 膨胀后，888 行已无效。R1–R4 所有锚点及各自的 ±3 px 方形邻域均为无效；这是直接读取历史掩膜得到的检查，不是从模型推断。

J1 的 (1800,888) 位于旧域边缘，其容差邻域同时包含有效和无效像素；(1810,884) 已位于有效域。未来如果修改这一小段，必须决定域衔接和去重，不能把整段无条件添加。当前没有读取历史 `contour.npy` 的坐标来挑选新锚点，只对其文件字节做 SHA 核验。

## 进入未来分支的建议

R1–R4 可以进入**单独版本的 RGB 标注与局部有效域审核分支**。下一步应从原图独立完成正式标注，保存像素不确定带、fit 帧身份、定位/遮挡依据和与旧观测的去重规则，再冻结该观测版本。当前连接定位锚点的展示折线不可直接当作密集观测。

之后才可在独立观测消融中比较新增图像项响应；P4 坐标变换对照应继续冻结原图像目标。候选是否使用不能由“更贴近冻结网格”、拟合后 loss 或真值误差决定。原 RGB 不提供准确的三维 z 归属，因此不能将本次审阅的像素范围等同于 P3 的 6.15–12.30 m 根带，也不能把 P3 的 450.877 px 模型投影线长记为本次通过审核的观测线长。
