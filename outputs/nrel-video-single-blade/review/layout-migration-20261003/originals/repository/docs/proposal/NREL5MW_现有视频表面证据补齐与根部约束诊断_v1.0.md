## 范围与输入

只复用已有 5 秒三路 MP4、标定、共享时间表、理想 B1 叶根刚体观测、12 张审核图的 F/B/U 与可信轮廓、冻结模型与日志。目标为 T1/B1，参考时刻 122.175 s，拟合帧 42/43，44/45 保留非盲时序诊断身份。

本轮不采集、不开 Blender、不编码、不运行优化器，不改变历史模型、评分或验收阈值。所有模型前向扰动只计算诊断响应，不输出新候选作为正式模型。真值网格只由独立面积诊断读取，不生成拟合掩膜或对应，也不据真值筛选扰动方向。

## P0：交付与来源对账

1. 重新核验原视频、冻结模型、参数、配置与历史签名；当前快照与启动时源码、最终交付源码分别对照，差异如实保留。
2. 从 MP4 完整解码 300 帧，核对原生尺寸、PTS 和 12 张审核帧的 RGB 签名；不以 JPEG 缩略图代替原始 RGB 哈希。
3. 保存本轮前后的历史输入哈希，证明诊断没有修改模型及原报告。现存隔离探针作为历史运行证据，除非实际重新运行，不称本轮重验了原拟合进程隔离。
4. 分别报告流程完成、本片段全局改善、局部截面保护、证据交付完整性、用途几何验收。

“仅平滑 26 次”分支仍使用图像，只改变参数插值；真正无图像对照为图像损失权重归零。历史 `NOT_YET_ESTABLISHED` 保持原意和原门槛，新增解释不能回写成历史通过。

## P1：分开记录三层证据

| 层 | 输出 | 解释边界 |
| --- | --- | --- |
| 候选外轮廓与 RGB 关联 | 模型边/面 ID、相机帧、可信域、距离、排除原因 | 最近轮廓关联不是材料对应；轮廓一致不能扩展为内部表面恢复 |
| 模型条件下表面可见性 | 每面采样、面积权重、投影像素、近面/画外/自遮挡、F/B/U、三模型分歧 | 必须检查自遮挡；其它实体遮挡只有已有 RGB 排除域的支持，不能宣称完整场景可见真值 |
| 参数响应 | 局部形状扰动引起的各视图残差变化 | 可见、有梯度、模型有变化均不能单独证明独立测量或可辨识 |

使用初始模板、26 次可信轮廓分支、正式 v2 三个冻结模型比较相同拓扑 ID。模型间判断不同的样点先记不确定。面积采用明确的模型表面分母和采样权重，区分单帧、拟合帧并集、非盲时序并集；不能重复相加多视图面积。

展向同时报告原固定分区 [0,20.5]、[20.5,41]、[41,61.5] m，以及根部诊断带 [6.15,12.30] m。固定截面为 z=9.225、30.75、52.275 m。两侧只能使用声明的模板参数侧或坐标代理，未经材料语义确认不得命名为实物压力面/吸力面。前后缘代理曲线报长度，邻域带报面积，两者不能混用。

独立面积核验对原真值三角面做精确 z 裁剪，分开保存 z<0、三个历史区间及 z>61.5 的面积与面片归属，不生成裁剪封口面。统计总面积闭合与边界/非流形边。无拓扑边界不代表表面被观测或恢复正确。

在全部现有 100 帧/相机中制作 RGB 总览，结合允许的刚体位姿标出冻结模型截面入镜候选。其它叶片过境不能当成新的 B1 观测。新候选保留新诊断身份，未经单独审核不自动生成或复用 42–45 的掩膜。

## P2：根部最小前向扰动

从保存参数恢复模型并与正式 PLY 核对。改变根部 B-spline 系数，在 z=9.225 以物理尺度归一化 centre x、centre y 和 chord 响应，至少使用两个小幅度与正负方向。厚度继续随 chord 与固定 thickness_ratio 耦合。

每次只前向投影；分相机、帧和区域保留残差、有效轮廓数量、掩膜及采样损失。不同图像尺度改变了像素尺度和有限采样上限，不能将差异一概归因于分辨率。可用响应相关或局部 SVD 寻找中心—尺度补偿提示，但应明确有限维子空间、硬可见性切换和小扰动近似。

结论按证据回答：当前审核图里是否有根部响应；信息是否被可信域/采样削弱；是否出现参数补偿；哪些残差无法由所选自由度解释。如果无法区分观测不足与截面表达失配，保留未定，不强选唯一根因。

## P3：下次试验的决策规则

P2 后先选择一个能验证的主因素：现有图像处理/损失、参数表达或观测。试验前冻结相同初始、图像集、参数先验、预算和报告指标；只改变被检验因素，其余保持不变。更多预算与更高分辨率不能与目标函数一起改后仍称单因素试验。

若现有 5 秒中有不同可信边界，先审核少数候选并证明新增信息；仅重复视角或仍被挡则停止堆帧。只有证据表明当前数据确实不够时，才另提小窗口补采或观察方向调整。

针对根部的研究诊断默认报告全局双向 mean/P95、三固定截面的包围矩形长短边、局部退化及表面证据。工程用途、绝对误差目标、可接受局部退化和覆盖要求尚未由用途确定，保持 `PENDING_USE_CASE_TARGETS`；不得从当前误差反推一个刚好通过的阈值。本片段已经用于诊断，不重新命名为独立测试。
