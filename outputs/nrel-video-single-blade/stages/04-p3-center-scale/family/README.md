## 逐环几何中心补偿

记 C 为原 7×2 参考轴中心系数（C₀=0），ℓ 为7个弦长 log-scale 系数，B 为基函数，c(z)=c₀(z) exp(B(z)ℓ)，u(z)=(−sin twist, cos twist)。原截面顶点均值为：

`G(z) = B(z) C + D_z(ℓ),  D_z(ℓ) = c(z) u(z) / 4`。

当弦长变动时，固定 G 所需参考轴补偿严格为 `f(z)=−Δc(z)u(z)/4`。这里“保持几何中心”只是截面均值不动，弦长及绝对厚度仍按固定厚弦比一起改变；不等于整个表面不动。

本次仅改变 index=1 的 chord-log 系数，在 z=9.225 m 归一化为下表中的半弦长变化 h。弦长变化为2h，若不补偿，几何中心位移为 h/2。该控制支持域延伸到30.75 m，不能解释为只改变一个根部截面。

在全部25环上，求解 `min ||B_free ΔC_free − f||²`，严格消去 `ΔC₀=0`，并检查原 `−5<C+ΔC<5` 的每个分量。所有结果都在约束内，所以消元后的线性最小二乘解也是带原边界的约束最优解；没有截断或放松边界。它只是在函数空间投影已知解析位移，不涉及图像拟合。

## 可逆的 Greville 中心坐标

令 g 为7个 Greville 位置，A=B(g)，Dg(ℓ)=c₀(g) exp(Aℓ)u(g)/4，定义新坐标 `Gg=A C+Dg(ℓ)`。本次 A 满秩7，二范数条件数3.5990854，因此：

`C = A⁻¹ [Gg − Dg(ℓ)]`；
`G(z) = B(z) A⁻¹ [Gg − Dg(ℓ)] + D_z(ℓ)`。

原自由度仍为6×2个中心坐标和7个弦长参数。**Gg₀=Dg₀(ℓ₀) 是由弦长第0系数决定的从属值，不是新的自由度。** 原 C₀=0 只锚定参考轴；正式模型的几何根中心为 (−0.246402494, 1.041706176) m，相对于零 log-scale 模板也有 (−0.042573123, 0.179984724) m 偏移。把新的几何根中心强行设为0或模板值会改变原约束；本组只扰动 index=1，所以其根部几何中心恰好保持不变。

原边界必须继续作用于 `A⁻¹[Gg−Dg(ℓ)]` 的自由行，每分量严格落在 (−5,5) m，且 ℓ∈(−0.35,0.35)。它们在 Gg 空间是与弦长耦合的域，不能替换成彼此独立的 ±5 m 新盒子。

基线由 Gg 逆映射恢复 C 的最大误差2.22e−16 m，原25环几何中心最大恢复误差2.22e−16 m；这支持代数坐标变换。**保持 Gg 不变而只改变弦长，只能保持7个 Greville 位置的中心；不保证全部25环或连续展向的中心同时不变。**

直接独立插值几何中心会改变函数族：

- 正确把绝对 Gg 插值成几何中心 B-spline，即 `Q=A⁻¹Gg; Gnew(z)=B(z)Q`，基线25环中心误差最大 **48.186 mm**、RMS **19.812 mm**。
- 保留零弦长模板几何中心，再插值相对中心，即 `Qrel=A⁻¹[Gg−Dg(0)]; Gnew(z)=D_z(0)+B(z)Qrel`，基线最大 **2.440 mm**、RMS **1.063 mm**。保留模板也没有得到严格原模型族。
- 更粗糙地把 Gg 样本直接当原 B-spline 控制系数，即 `B(z)Gg`，基线最大误差 **372.162 mm**；Greville 位置只是控制多边形的报告位置，样本不等于系数。

这些数值是模型代数之间的差别，不是真值误差。独立的 B-spline 几何中心函数族不应被无证据称为原函数族的超集；它与原参考轴中心族的弦长相关约束不同。

## 正则必须通过逆映射保留

原惩罚是 `mean((C/5)²)+mean(ℓ²)` 和 `mean((Δ²C/5)²)+mean((Δ²ℓ)²)`，包含7行中的根部行。它是控制多边形的二阶差分，不是几何中心曲线曲率。

同一几何用 Gg 坐标表示时，精确保留惩罚的定义是 `Rnew(Gg,ℓ)=Rold(A⁻¹[Gg−Dg(ℓ)],ℓ)`。直接将新中心变量代入原公式一般改变 shape prior。基线对照：

| 计算方式 | relative_parameter_change | span_smoothness |
|---|---:|---:|
| 原 C 系数 | 0.021079093150 | 0.074833665147 |
| Greville G 经逆映射回 C | 0.021079093150 | 0.074833665147 |
| 直接对 Q=A⁻¹G 套原公式 | 0.017705921874 | 0.101194210974 |
| 直接对 Qrel=A⁻¹(G−Dg(0)) 套原公式 | 0.021064549068 | 0.080548587430 |
| 误把 G 样本直接当系数 | 0.012880866574 | 0.018718523198 |
| 误把 G−Dg(0) 样本直接当系数 | 0.015336792456 | 0.016625568447 |
| 仅把 AC 样本直接当系数 | 0.015524870423 | 0.016208851823 |

精确逆映射的最大惩罚差仅5.55e−17；其余行只是展示语义变化，不能直接替代正式损失。Qrel的relative-change虽很接近原值，smoothness仍从0.074833665147变成0.080548587430；不能用一个接近的总数证明两者正则相同。每个有补偿的投影模型也分别记录了原正则与 Greville 逆映射核验，未以正则或 loss 降幅选择幅度。

## 对下一次拟合的限制与建议

可以设计采用 Gg 的精确坐标变换实验，但完整实现必须保留逆映射、从属根节点、原参数域和 pullback 正则，并先验证相同参数的顶点、目标函数和梯度一致；这次仅做映射设计核验，未实现该新 fit。相同模型和目标换坐标不会消除固有的可辨识性问题，有限步优化轨迹可能随坐标/预条件变化，但不能据此声称新增了信息。

本次逐环固定几何中心的图像响应可作为独立的前向诊断。若据此把每环补偿或独立几何中心 B-spline 引入新拟合，则须明确它改了形状假设，并做分开的受控消融；不能把输出覆盖为原模型的无变化“修正”。目前8个方向只有近似的原族内投影，未通过“原 family 精确不变”的门槛。
