# WFRL Blender 0.3.17.1

新增 **MAPPO 同源纹理同步对照**，并修复反复切换、失败恢复和布局忙时的状态问题。公开 0.3.17 的独立合成样例继续保留。

- 使用原 MAPPO 两相机实验的全部 **601 个保存状态**及三片固定 RGBA 灰度图集。117–177 s 共用时间轴；右侧 10 Hz 样本在每 6 个显示帧之间保持，界面分别显示播放时间、采样时间与保持时长。
- 同源与独立合成各自保留 9 项显示设置；切回、CURRENT 恢复、退出返回和保存重开保留各自选择。损坏数据或失败切换保持原来源；布局忙时取消完整取景不再关闭近景追踪。
- 构建及运行时严格核对来源摘要、模型身份、完整时钟和全部 601 个样本，拒绝缺失或错误的同源合同。

安装：下载 `wfrl_blender-0.3.17.1.zip`，在 Blender 5.2+ 使用 **Install from Disk** 安装并重启。公开版本为 `0.3.17.1`、标签为 `v0.3.17.1`，包内兼容版本为 `0.3.17+1`；build metadata 不用于自动升级排序，请手动安装。

加载 MAPPO 后，在 **N → MAPPO → 同源纹理同步对照** 进入。**打开几何重建示例…**保留原 601 样本几何；**独立合成纹理样例**保留 120 样本及独立游标。上一／下一样本先暂停并在首尾钳制；连续播放沿用 Blender 原生循环，两侧共同回到起点。
