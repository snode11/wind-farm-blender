# 同源纹理导航修复（本地，未发布）

日常安装版和当前 Blender 5.2.1 LTS 窗口已更新。当前窗口保留原帧 88，右侧为背面自由视图、三片叶片可见，播放已暂停。

## 原因和行为

- 近景自动跟随每帧覆盖手动导航，因此暂停后拉远再播放会回到缺陷近景。现在检测手动缩放、平移、转动及透视切换，解除跟随；继续播放、样本步进、CURRENT 恢复和保存重开保留手动视角。
- 同源入口默认完整叶轮取景，整体旋转可见。右侧此前从左侧复制了约一万米以外的自由绕转中心，因此离开相机后叶片跳出画面。现在初始化重建叶轮中心、相机方向和距离，并通过原生相机切换缓存退出方向；完整取景与近景均可自由绕转。

## 验证

- [最终安装版原生报告](orbit-after02/navigation-window-validation.json)：PASS，9 项检查。默认退出相机后绕转中心误差 0 m；12 次原生 15° 绕转到背面，前后方向点积 -1，三片叶片始终在视野内；背面播放保持视角并验证两侧几何随共享时钟变化。手动导航、采样步进、CURRENT 和原生保存重开均通过。
- [旧安装版复现](orbit-before02/navigation-window-validation.json)：退出相机的绕转中心误差约 10001.43 m，失败。首次只修中心而未缓存原生退出方向的 [中间结果](orbit-after/navigation-window-validation.json) 仍失败；最终版本通过同样检查。
- 宿主针对性回归：50 passed，104 subtests passed。
- 当前用户窗口另外实际执行原生相机退出、12 次键盘绕转、滚动缩放、侧栏播放／暂停，确认背面三片叶片仍可见；[当前背面截图](live-final-back.png)、[当前视图状态](live-final-back.json)、[窗口更新记录](live-orbit-fixed-ready.json)。未直接注入真实触控板手势。
- [安装文件核对](install-final.json)：三个修改模块与规范源码逐字节一致；几何示例资源哈希保持原值。完整源码差异保留在本地 `changes-final.diff`，不随本次文档同步公开。
