Abstract.Single-agent reinforcement learning algorithms can be directly applied to multi-agent systems in4
an independent learning approach, but often lose their convergence properties as the environment5
becomes non-stationary. We prove that in transition-independent Decentralized Markov Decision6
Process (TI Dec-MDP) non-stationarity can be mitigated by a multi-scale approach when the inter-7
dependence of agents’ dynamics can be represented by a directed acyclic graph (DAG). Although8
TI Dec-MDPs are thought to be restrictive, we show that they can describe complex real world9
problems through a careful design of local states. We propose a multi-scale Q-learning algorithm10
(MQL) where agents update local Q-learning iterates at different timescales without communication11
and still converge. To this purpose, we first show that we can model the loss of information on12
the global state as a state-dependent Markovian noise. Then, we show that results from stochastic13
approximation theory can be used to prove the convergence of MQL under local state observability.14
We give practical solutions to exploit knowledge about agent interaction to assign learning rates15
that ensure convergence, and propose a NetworkMQL algorithm that can achieve convergence in16
Network-Distributed POMDP (ND-POMDP). We validate both MQL and NetworkMQL on a wind17
farm control problem. 18

1. Introduction.Recent advances in reinforcement learning (RL) have seen a growing21
interest in solving cooperative multi-agent problems, where several agents interact with the22
same environment to optimize a common objective [44, 29]. Multi-agent reinforcement learning23
(MARL) has encountered successes in fields as varied as games with multiple players [5],24
vehicle routing problem for traffic regulation [43], or distributed optimal control of wind farms25
[36, 9, 20]. In this article, we consider a family of fully cooperative, infinite horizon multi-26
agent reinforcement problems, where state information is distributed among all agents and27
they must collaborate to maximize a shared reward. Such problems are commonly formulated28
as decentralized partially observable Markov decision processes (Dec-POMDPs) in the MARL29
literature. It is known that solving Dec-POMDPs is very hard: finding a solution to a two-30
player Dec-POMPD has been proven to be NEXP-hard, and is undecidable for the infinite-31
horizon case [8]. Instead of general Dec-POMDP, we focus on the special case of thetransition-32
independentDec-MDP, which is of NP-hard complexity [3]. In a transition-independent Dec-33
MDP, each agent’s local observations only depend on local states and actions, so that agents34
only interact through the shared reward. In general, blind cooperation problems in which35
agents must learn to coordinate while being oblivious to each other’s existence will fit this36
description. In the rover exploration problem introduced by [7] for example, several rovers37
must coordinate to explore a planet. Rovers are assigned distinct sides of the planet to explore38

Transition-independent Dec-MDPs have been studied in the planning literature, and sev-41
eral planning algorithms have been proposed to find optimal local policies [28, 7, 17, 14].42
However, they exploit full knowledge of the transition matrix and the reward function, which43
are rarely available in real-life problems. MARL algorithms, on the other hand, focus on learn-44
ing solely from interactions with the environment. In a centralized training, a single learner45
updates all local policies based on global observation. Multi-agent systems are, however, of-46
ten under constraints that prevent instantaneous communication of all agents with a central47
controller. Moreover, centralized approaches are vulnerable to the curse of dimensionality, as48
the size of the search space increases exponentially with the number of agents.49
In an online decentralized training approach, each agent updates its own local policy50
only with the information it has collected. To compensate for the loss of information, online51
learning algorithms for Dec-POMDP typically allow agents to keep past observations in their52
memory, allow communication between agents during training, maintain beliefs about the53
global state of the environment, or estimate the behaviors of other agents [28, 29]. Instead,54
an interesting question is to see whether memory-less policies can still be learned without55
additional estimates or communication. In particular, MARL has focused on extending the56
success of single-agent reinforcement learning algorithms to the multi-agent case, such as the57
classic Q-learning algorithm [41]. One naive way to adapt the single-agent Q-learning to58
the multi-agent case is to simply let each agent run local Q-learning updates, with other59
agents considered as a part of its environment. This approach was first introduced by [39]60
asIndependent learning. Independent learning has been shown to produce good empirical61
results in a number of problems [24], and is used as a baseline to develop current state-of-the-62
art MARL algorithms [42]. As it avoids the exponential dependence of dimension of the search63
space in the number of agents, independent learning is more scalable. However, agents learning64
simultaneously make the state and reward processes appear non-stationary for each agent, an65
issue that is commonly referred to as thenon-stationarityproblem. This leads to the loss of66
convergence guarantee for single-agent RL algorithms. Moreover, the system may prevent full67
observability of the environment to the agents, with each agent only collecting a function of68
the global state. Solutions to mitigate the non-stationarity typically rely on a modification69
of algorithm’s local rule. Examples have been turn-based control [32] or turn-based updates70
[37], two stages algorithms requiring agent coordination during learning [34, 4], coordinated71
exploration between agents, and consensus-based approaches or explicit modeling of other72
agent’s behavior [44]. We propose a multi-scale approach that does not require coordination73
between agents during learning, and converges to a best-response equilibrium in transition-74
independent Dec-MDP.75
Although transition-independent Dec-MDPs are thought to be restrictive, our first con-76
tribution is to show that they can be imposedby designto describe complex real world prob-77
lems, showing a trade-off between observability and complexity. In this article, we show that78
transition-independent Dec-MDPs can be constructed from certain standard Dec-POMDPs,79
and that such a reformulation can be useful to solve real industrial problems. In [25] for80
example, a distributed wind farm optimization problem is considered, in which the local in-81
formation of the Dec-POMDP can be factorized into two components. The first is a private82

We show that for independent learners in transition-independent Dec-MDP, the loss of92
information due to partial observability can be seen as a Markovian noise. We then focus93
on the case where agent dynamics can be described by a directed acyclic graph (DAG), and94
show that in such a case the non stationarity issue can be addressed by a multi-timescale95
learning approach: by allowing agents to learn at different time scale, we ensure that for any96
”fast” agent, the ”slow” evolution of other policies will lead iterates to behave as though the97
environment was stationary, and ultimately converge. Note that this approach belongs to98
the independent learning family and thus is scalable to large number of agents. Moreover,99
we show that our multi-scale Q-learning approach can further exploit information on inter-100
actions between agents to accelerate convergence. For this purpose, we focus on the network101
distributed POMDPs (ND-POMDPs), a class of transition independent Dec-POMDP intro-102
duced in [26], where agent interactions can be represented by a sparse graph. [26] focuses on103
the finite-horizon problem where the dynamics of the MDP are fully known, and proposes a104
decentralized planning algorithm relying on communication between agents and costly best105
response computations at each step. In our reinforcement learning framework, the environ-106
ment dynamics are however unknown, the horizon is infinite and learning must be done online:107
we show how our independent learners still converge to a best response equilibrium when the108
graph is acyclic.109
Our convergence analysis is based on stochastic approximation techniques. Stochastic110
approximation and multi-timescale approaches have been used to analyze fully observable111
learning algorithms. In [11], the convergence of the single-agent Q-learning has been proven112
with a stochastic approximation approach. Two-timescale stochastic approximation was then113
introduced in [10], showing that two interdependent stochastic processes can both converge114
when they are updated at two different scales. These have been successfully used to build re-115
inforcement learning algorithms maintaining different iterates. The learning of future rewards116
and of the best response has for example been decoupled in various fictitious-play [6, 33, 23]117
and Q-learning [31] inspired schemes for fully observable zero-sum and team games. Two-118
timescale results have been extended to an arbitrary number of scales in [22], and used to119
analyze a multi-scale learning algorithm in some classes of repeated games. In [27], a similar120
multi-scale approach is further evaluated on several multi-agent reinforcement learning prob-121
lems, but a convergence analysis is not provided. Unfortunately, convergence results of these122
works have required the reward function to be stationary, meaning that for a given agent123
observation-action pair, the collected reward is always sampled from the same distribution.124
These results therefore cannot apply to the Dec-MDP case where global state information is125
distributed among agents, and each can only observe a local state. We make the following126

6. Conclusions.By allowing all agents to run a single-agent reinforcement algorithm692
in parallel, independent learning provides the simplest way to adapt these algorithms to693
cooperative multi agent environments. Although this approach has encountered experimental694
successes, it has no underlying theoretical guarantee. To provide a first step towards bridging695
this gap, we have here focused on transition-independent Dec-PODMP, and shown that in696
these problems the partial observability of the global state can be modeled as a Markovian697
perturbation in a stochastic approximation iterates. We have shown that when there is an698
acyclic dependence structure between agent dynamics in these cooperative systems, a careful699
assignment of learning rate sequences following a multi-scale approach can be sufficient to700
establish convergence. In particular, knowledge of the interaction graph between agents in701
ND-POMDP can be exploited to assign learning rates to preserve convergence. We have then702
applied these results to wind farm control, a real optimization problem from the industry.703
Further work can extend these results to systems with noisy local observations or non-704
independent transition functions. Furthermore, independent learning has often encountered705
experimental success without the multiscale approach in multiagent reinforcement learning706
settings ([42, 39]), and our acyclic dependence analysis could provide a basis to find a theo-707
retical explanation of these results.708
