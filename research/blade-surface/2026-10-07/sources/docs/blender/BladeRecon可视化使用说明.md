# Blade Recon 叶片三维重建可视化 · 0.3.16

更新日期：2026-10-06。当前 NREL 扩展为 **0.3.16**，延续 0.3.15 的 **MAPPO＋重建便携分屏示例**和独立算法结果导入入口，两者使用方式不同。本文只对齐已有实现与记录，未重新运行 Blender。

独立开发入口把 `blade_recon` 算法输出的重建模型接入 Blender，按保存的模型参数显示叶片随时间变化的三维表面。入口位于三维视口右侧 N 侧栏的独立 **叶片三维重建** 标签，与 Item、MAPPO、View 并列。

独立算法导入的重建回放使用单独场景。进入时保留原场景的对象与回放位置；点击 **返回原场景** 可继续查看原有风场。重建数据和 MAPPO、雷达结果使用各自的数据来源。

## 先打开随 ZIP 的 MAPPO＋重建示例

1. 使用 Blender 5.2+，在 Preferences → Get Extensions → Install from Disk 安装启用 [0.3.16 发布页](https://github.com/snode11/wind-farm-blender/releases/tag/v0.3.16) 的唯一手动附件 `wfrl_blender-0.3.16.zip`，升级后重启 Blender。
2. 三维视图按 **N → MAPPO → MAPPO＋重建示例**。当前文件未保存时由 Blender 原生对话框提示保存；打开的是安装目录内 `assets/examples/mappo_reconstruction_split.blend`。
3. 左侧观察 MAPPO，右侧观察三片保存重建。播放／暂停共用时间轴；**上一样本／下一样本**先暂停并跳到真实样本，端点钳制；**完整取景**和**恢复布局**用于取景与分屏恢复。窗口缩放可恢复可用区域，左侧相机切换保留右侧独立视图。
4. **退出对照**保留数据和当前时间，可重新进入。另存自己的 `.blend` 后，启用匹配扩展即可原生重开恢复。

ZIP 自带 MAPPO 数据、便携场景及四张 packed 天空／地表纹理，无 linked libraries，不需要作者本机文件路径或在线后端。0.3.16 仅发布 ZIP，新版源码未提交／推送；GitHub 自动 Source code 不包含完整新版实现，不能作为安装包。

此示例右侧三片叶片各有 **601 个 absolute shape keys**，以 **CONSTANT holds** 保存，**无 drivers**。MAPPO 保存数据为 **40 Hz**，重建保存样本为 **10 Hz**，共享时间轴为 **60 Hz**、frame 1–3601；每 6 帧一个重建样本。**frame 52** 显示播放 **117.850 s**、样本 **117.800 s**、保持 **50 ms**。时间轴帧之间不产生新观测。绿为两端截面受约束，橙为模型推断；重建精度未验收，60 Hz 时间轴不代表稳定 60 FPS。

规范源为 `blender_frontend/wfrl_blender/assets/examples/mappo_reconstruction_split.blend`，应保留。便携场景通过非空 `__WFRL_BUNDLED_MAPPO__` 路径 marker 与已保存 manifest hash 匹配当前安装的数据；开发时不得清空该路径或改为读取器不支持的 `//` 相对路径，完整恢复合同见 [实现与维护](../../blender_frontend/README.md)。隔离安装、便携恢复、实际分屏窗口、保存重开和注册生命周期的 macOS Blender 5.2.1 LTS 证据属于 [0.3.15 历史发布核对](releases/0.3.15发布核对.md)。0.3.16 延续示例，但未重测分屏窗口；本版后台安装与已知失败见 [0.3.16 发布核对](releases/0.3.16发布核对.md)。Windows/Linux 尚未实测。

## 独立算法导入入口：开始查看

1. 启用包含此功能的 WFRL Blender 扩展，在三维视口按 `N` 打开侧栏。
2. 选择 **叶片三维重建** 标签。
3. 点击 **加载合成样例**，先查看算法模型的三维回放及显示图例。合成样例标记为 **SYNTHETIC**，用于演示输入和显示流程。
4. 使用面板中的 **正面**、**侧面** 和 **总览** 按钮观察叶片；通过 Blender 原生时间轴播放、暂停、逐帧或跳转。
5. 查看完毕后点击 **返回原场景**。

独立算法导入场景的时间轴每一帧对应输入重建序列中的一个保存时刻。当前帧的模型参数、表面和标记使用同一时刻；改变 Blender 播放帧率只改变目标播放速度，不改写算法输出时刻。

## 导入自己的算法结果

在 **叶片三维重建** 标签点击 **导入结果**，在打开的文件选择器中选择 `blade_recon` 生成的 `recon.json`。使用原算法输出，保留其模型参数、时间序列和输入来源；Blender 可视化不重新拟合图像，也不在查看时启动求解器。

需要指定真值或相机输入时，先填写可选的真值和相机路径字段，再点击 **导入结果**。字段未填时会尝试读取 `recon.json` 同目录的 `truth.json` 和 `cameras.json`。真值用于显示对照层，相机用于显示标定位置与朝向；未提供且未找到对应输入时，这些显示层保持不可用。导入失败时查看 Blender 的操作错误报告，再核对文件类型、完整性和时间序列。

成功导入后，使用 **真值线框** 控制真值对照层，使用 **三摄位置** 控制相机示意层。真值对照和相机位置帮助理解重建结果，三维重建本身按 `recon.json` 中的模型生成。

## 颜色与观测范围

显示图例区分与已拟合轮廓相符的采样标记，以及依赖模型推断的部分。这里的观测标记表示该模型采样点与输入轮廓的符合关系；它不表示该点已获得独立的三维测量，也不表示完整叶片表面都在原图中可见。

轮廓以外的完整三维表面由算法模型推断。查看这些部分时结合原输入、相机布局和可选真值判断，不把合成样例的完整表面当作实拍重建精度结果。

原 `blade_recon` 使用二值轮廓／剪影约束，RGB 纹理、修补颜色及局部缺陷不是该几何求解器已经恢复的输出。0.3.16 的 [NREL 缺陷编辑器](NREL缺陷编辑器.md)提供合成展示与输入制作，两者不构成缺陷重建验证。表面特征扩展的最新执行状态从 [2026-10-06 方案与交接入口](../proposal/叶片表面重建_2026-10-06/README.md)读取。

独立 NREL 动态研究查看器使用 [合并目录的统一入口](../../outputs/nrel-video-dynamic/runs/20261004-integrated/README.md)，载入冻结源码与研究包，状态仍为 `REVIEW_ONLY / DY1 NOT PASSED`。它只有四个保存估计时刻，其余帧为 `UNAVAILABLE; no interpolation`；这与上述 601 样本便携分屏分别判断，软件播放同步不证明动态计量通过。

## 保存与重新打开

导入成功后保存 `.blend`，重建回放所需的输入内容会嵌入场景。重新打开时可恢复回放，无需保持原 `recon.json`、真值或相机输入路径可用。

恢复动态回放需要启用包含此功能的 WFRL Blender 扩展，或通过匹配的启动入口打开。仅保存对象几何不能替代回放代码；重新打开后应在 **叶片三维重建** 标签核对数据来源、当前帧与就绪状态。

## 开发与验证范围

独立算法导入仍为开发入口，MAPPO＋重建示例于 0.3.15 发布并随 0.3.16 延续。工作区源码、构建 ZIP 和已安装扩展是不同运行来源，修改源码不会自动更新已安装扩展；安装新包后重启 Blender，再核对实际载入模块路径。实际检查应分别记录输入读取、模型回放、场景切换、保存重开、安装版及可见窗口结果。

此可视化入口展示算法输出与合成流程；重建精度、实拍适用性和播放性能以各自数据与测量记录为准。前端维护入口见 [Blender 实现与维护](../../blender_frontend/README.md)。
