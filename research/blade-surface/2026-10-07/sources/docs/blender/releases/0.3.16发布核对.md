## 功能与使用

安装 ZIP、重启后加载 **MAPPO · 60 秒**，在 **MAPPO → NREL 5MW · 叶片缺陷** 点击 **启动缺陷编辑器**。T1/T2/T3 九片叶片均可选择，支持材质细裂纹、几何开口裂缝、凹坑、局部表面侵蚀、涂层剥落及雷击损伤。

编辑器提供新建与修改、预览确认／取消、撤销重做、健康对照、严格参考几何绑定的 JSON 读写、`.blend` 保存重开和三相机 G 分析／逐帧扫描。缺陷展示网格、辅助轮廓与支持区域使用同一份已有柔性变换；时间寻址不重新执行 Boolean，不改写 FAST.Farm / BeamDyn 或雷达保存结果。配置不能直接与 GW184 互用。

本版包含 T1/B1 默认修补痕迹，并延续 0.3.15 的便携 MAPPO＋重建分屏示例、默认三相机、双束净空 / S1、显式 TLS 候选和旧 B2 回放。便携资源与 40 Hz 源／10 Hz 重建／60 Hz 时间轴合同见 [0.3.15 历史核对](0.3.15发布核对.md)，完整编辑操作见 [NREL 缺陷编辑器](../NREL缺陷编辑器.md)。

## 开发证据与已知失败

本版载荷来自最终 package04；此前 12 项宿主检查、源码后台保存重开、主动抛错后的九片叶片几何恢复、三相机 72 条离散 G 扫描及源码窗口操作检查，分别见 [移植验证记录](../validation/NREL缺陷编辑器移植验证.md)。没有在本次发布中重跑这些开发检查，也未重测 0.3.15 分屏窗口或完整片段 FPS。

既有 `tip_deflection_regression.py` 的 **0.2 mm** 阈值检查仍失败，最大方向误差约 **0.895 mm**。移除本次新方法与钩子的内存基线得到完全相同的三方向误差；[基线诊断](../../../outputs/blender-validation/nrel-defects-20261005/tip-baseline-diagnostic.json)保留，本次未改旧阈值或保存结果，此项不计为通过。

源码 `window02` 完成功能检查后，在 CUA 切换 Python 控制台时发生 SIGSEGV；[崩溃栈](../../../outputs/blender-validation/nrel-defects-20261005/window02/result/blender-console.crash.txt)位于 Blender 原生控制台选择代码，没有 Python 回溯。两次无插件空场景对应操作未复现，原因仍未确定，不能宣称已修复；整体窗口稳定性不计为通过。
